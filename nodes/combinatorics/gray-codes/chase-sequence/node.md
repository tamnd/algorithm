Chase's sequence lists all $N = C(n, k)$ bit strings of length $n$ with $k$ ones so that each step moves a single 1 by one place, $01 \leftrightarrow 10$, or by two places over a 0, $001 \leftrightarrow 100$. Knuth calls such a list near-perfect: in the subset view one element changes by 1 or 2 and never jumps over another element. Phillip J. Chase found these lists in 1976, and they come from two mutually recursive lists $A_{st}$ and $B_{st}$, where $s = n - k$ is the number of zeros and $t = k$ the number of ones. The recursive generator below takes $\Theta(N)$ time after $\Theta(n)$ setup, so $O(1)$ amortized per string.

## In plain words

Think of $k$ fingers on a piano with $n$ keys, and you must play every chord of $k$ keys once. A [revolving door](/revolving-door-ordering/) plan may move a finger from one end of the keyboard to the other, over the other fingers. Chase's plan moves one finger at a time, by one key or by two keys, and only over a key that no finger holds.

The plan is built in two shapes. In shape A the block of fingers ends one key to the right of where it started, and in shape B it ends two keys to the right. Each shape is made from smaller copies of the other shape, glued so that every step is still a short move.

## The problem

Given $n \ge 0$ and $0 \le k \le n$, list every bit string $a_{n-1} \ldots a_1 a_0$ with exactly $k$ ones once, so that consecutive strings differ by $01 \leftrightarrow 10$ or $001 \leftrightarrow 100$ in some positions. This is [combination Gray code generation](/combination-gray-code-generation/) under the strongest rule that can be met for all $n$ and $k$. Bit $a_j = 1$ means that element $j$ is in the subset; the index form $c_k \ldots c_1$ lists the elements from the largest. Let $s = n - k$ and $t = k$.

Knuth's recursions, for $s, t \ge 0$ and not both 0, are

$$A_{st} = 1B_{s(t-1)},\ 0A^R_{(s-1)t}, \qquad B_{st} = 1A_{s(t-1)},\ 0A_{(s-1)t},$$

where a list with a negative index is empty, $A_{00} = B_{00}$ is the list of the empty string, $L^R$ is $L$ reversed, and $1L$ puts the bit 1 in front of each string of $L$. Both lists start at $1^t 0^s$. For $t \ge 1$, $A_{st}$ ends at $0^{\min(s, 1)} 1^t 0^{s - \min(s, 1)}$ and $B_{st}$ at $0^{\min(s, 2)} 1^t 0^{s - \min(s, 2)}$. **Chase's sequence** is $C_{st} = A_{st}$ if $s + t$ is odd and $C_{st} = B_{st}$ if $s + t$ is even.

## The algorithm

The walk keeps the string in an array $a_{n-1} \ldots a_0$. A call for $(s, t)$ works on the low $s + t$ bits, whose top position is $m = s + t - 1$. In the forward direction it walks the first part with bit $a_m = 1$, moves that 1 down to position $y$, and walks the second part with $a_m = 0$. The move goes two places in a list of kind A with $s \ge 2$, and one place otherwise.

```pseudo id=main
CHASE(s, t)                                 ▷ s zeros, t ones, n = s + t
L1  a_{n−1} … a_0 ← 1^t 0^s
L2  WALK(s, t, A if n is odd else B, forward)

WALK(s, t, X, d)                            ▷ visits X_st on a_{s+t−1} … a_0, reversed if d = reverse
L3  if s = 0 or t = 0 then visit a; return  ▷ a single string
L4  m ← s + t − 1; y ← m − 2 if X = A and s ≥ 2, else m − 1
L5  Y ← B if X = A, else A                   ▷ the kind of the first part
L6  if d = forward then
L7      WALK(s, t − 1, Y, forward)
L8      a_m ← 0; a_y ← 1                    ▷ the 1 at m moves down to y
L9      WALK(s − 1, t, A, reverse if X = A, else forward)
L10 else
L11     WALK(s − 1, t, A, forward if X = A, else reverse)
L12     a_y ← 0; a_m ← 1                    ▷ the 1 at y moves up to m
L13     WALK(s, t − 1, Y, reverse)
```

The calls never touch positions above $m$. The recursion depth is at most $n$, and an explicit stack replaces it in the implementation. The four branches of Knuth's Algorithm C are the same moves found without recursion.

## Example

For $s = 3$ and $t = 2$, $n = 5$ is odd, so the list is $C_{32} = A_{32}$. The move column gives the 1 that moves to reach the next string.

| step | $a_4 \ldots a_0$ | index form | move |
|---|---|---|---|
| 0 | 11000 | 43 | 3 to 2 |
| 1 | 10100 | 42 | 2 to 0, over 1 |
| 2 | 10001 | 40 | 0 to 1 |
| 3 | 10010 | 41 | 4 to 2, over 3 |
| 4 | 00110 | 21 | 1 to 0 |
| 5 | 00101 | 20 | 2 to 1 |
| 6 | 00011 | 10 | 1 to 3, over 2 |
| 7 | 01001 | 30 | 0 to 1 |
| 8 | 01010 | 31 | 1 to 2 |
| 9 | 01100 | 32 | |

Rows 0 to 3 are $1B_{31}$, and the move at row 3 is line L8 at the top level with $X = A$ and $s = 3$, so $y = m - 2 = 2$. Rows 4 to 9 are $0A^R_{22}$. Each two-place move passes a position that holds 0. The list ends at 01100, the start block 11000 moved one place right. For $s = t = 3$ the generator gives 543, 542, 540, 541, 521, 520, 510, 530, 531, 532, 432, 430, 431, 421, 420, 410, 210, 310, 320, 321 in index form, which is $C_{33} = B_{33}$ in Knuth's Table 2.

## Correctness

The proof in `proofs/correctness.md` shows three things.

- **The lists.** By induction on $s + t$, $A_{st}$ and $B_{st}$ contain each string with $s$ zeros and $t$ ones once, because the first part holds those that start with 1 and the second part those that start with 0, and $C(n-1, t-1) + C(n-1, t) = C(n, t)$.
- **The ends and the steps.** By the same induction, both lists start at $1^t 0^s$ and end where stated above. Steps inside a part are near-perfect by induction, since a reversed list and a list with a fixed first bit keep the property. At the junction of $A_{st}$ with $s \ge 2$, the string $1\,00\,1^{t-1} 0^{s-2}$ meets $0\,01^t 0^{s-2}$, so the leading 1 moves two places over a 0. With $s = 1$, and at every junction of $B_{st}$, a string $1\,0\,1^{t-1} 0^{s-1}$ meets $0\,1^t 0^{s-1}$, a move of one place.
- **The walk.** Each call starts at the first string of its list (or the last if $d$ is reverse), visits the list in order, ends at the other end, and never touches positions above $m$. Lines L8 and L12 do exactly the junction moves.

## Complexity

- **Time.** The calls form a binary tree whose leaves are the $N$ visits. A call with $s \ge 1$ and $t \ge 1$ makes two calls with nonempty lists, so the tree has $N - 1$ inner nodes and the walk takes $\Theta(N)$ time, plus $\Theta(n)$ for line L1. The amortized time per string is $O(1)$, so the generator is CAT.
- **Delay.** Between two visits the walk may return from and enter up to $n$ levels, so the worst-case delay is $\Theta(n)$. Knuth's Algorithm C finds the next move with a table of $n + 1$ flags and a short loop that runs less than once per step on average, and exercises in Knuth give loopless forms.
- **Space.** The array, the flags of Algorithm C, or the stack of the walk: $\Theta(n)$ extra space.
- **Output.** Two bits change per step, at distance 1 or 2. In index form exactly one $c_i$ changes, by 1 or 2.
- **Lower bound.** Any generator visits $N$ strings, so $\Omega(N)$ time is needed, and Chase's sequence meets it.

## Properties

- **Near-perfect and homogeneous.** Every step is $01 \leftrightarrow 10$ or $001 \leftrightarrow 100$. So no element jumps over another one, which is the homogeneous property of the [Eades-McKay order](/eades-mckay-algorithm/), with the extra limit of a jump of at most 2.
- **Genlex.** Strings with the same prefix $a_{n-1} \ldots a_j$ appear together. Jenkyns and McCarthy showed that for $st > 0$ there are exactly $2s$ near-perfect genlex lists of the strings with $s$ zeros and $t$ ones: for each $1 \le a \le s$ one list $N_{sta}$ that starts at $1^t 0^s$ and ends at $0^a 1^t 0^{s-a}$, and its reverse (Knuth, Theorem N). $A_{st} = N_{st1}$ and $B_{st} = N_{st2}$.
- **Not cyclic in general.** The last string is the first block of ones moved one or two places right. For $t = 1$ this is one near-perfect step, so the list is cyclic. For $t \ge 2$ the two strings differ in two bits at distance $t$ (a shift by one place) or in four bits (a shift by two places), so they are not one step apart. For $s = t = 3$ the list goes from 111000 to 001110.
- **Graylex.** Within each block of strings with a common prefix, the next bit takes its values in a monotone order. Chase called such lists graylex.

## Variants and improvements

- **Algorithm C.** Knuth gives Chase's sequence as Algorithm C, which keeps a table $w_n \ldots w_0$ of active bits and a pointer $r$, and branches four ways on the parity of $j$ and the value of $a_j$. It uses the equivalent forms $C_{st}$ and $\hat C_{st}$ of the recursions, chosen by the parity of $s + t$.
- **Loopless.** Knuth's answers to the exercises of Section 7.2.1.3 give a loopless algorithm for Chase's sequence that tracks the positions of the zeros, and Knuth notes that Chase gave a similar procedure for a related list (Congressus Numerantium 69, 233 to 237).
- **TWIDDLE (1970).** Chase's earlier procedure, Communications of the ACM Algorithm 382, is homogeneous: a 1 jumps only over zeros, but it may jump over several of them. The alias Chase's twiddle algorithm comes from this procedure.
- **Adjacent transpositions only.** Using only $01 \leftrightarrow 10$ is possible exactly when $k \le 1$, $n - k \le 1$, or both $k$ and $n - k$ are odd (Buck and Wiedemann; Eades, Hickey and Read). Chase's sequence is the best that works for all $n$ and $k$.
- **Multisets.** The same ideas give near-perfect lists of multiset permutations (Knuth, Section 7.2.1.3).

## When to use it

Use Chase's sequence when a change of a subset costs in proportion to the distance an element moves, for example when the elements are positions on a line, keys on a keyboard, or adjacent cells of a memory. Each step changes one element by one or two positions. When only the number of changed elements matters, the [revolving door order](/revolving-door-ordering/) has a simpler rank formula, and [cool-lex order](/cool-lex-order/) has a simpler loopless step.

## Pitfalls

- **The two-place move when $s = 1$.** Line L4 written as "$y \leftarrow m - 2$ if $X = A$" sends the 1 to a position that already holds a 1 when only one 0 is left. For $s = 1$, $t = 2$ the walk gives 110, 101, 001 and loses a 1. Line L4 must use $y = m - 1$ when $s = 1$.
- **The same kind in the first part.** Line L5 written as "$Y \leftarrow X$" builds $1A_{s(t-1)}$ inside $A_{st}$. The first part then ends one place short of where line L8 expects, and for $s = t = 2$ the string 0101 is visited twice. Line L5 must switch the kind.
- **The direction of the second part.** In line L9 the second part of $A_{st}$ runs in reverse and the second part of $B_{st}$ runs forward. With the two swapped, for $s = t = 2$ the walk visits 1001 twice. Line L11 must use the opposite directions of line L9.
- **The wrong start list.** Line L2 must choose A for odd $n$ and B for even $n$. Both choices give valid near-perfect lists, but only this one is Chase's sequence $C_{st}$, and the rank formulas in Knuth's exercises assume it.

## History

Phillip J. Chase published TWIDDLE, a homogeneous generator of combinations, as Algorithm 382 in Communications of the ACM in 1970. Knuth reports that Chase discovered the near-perfect sequences $A_{st}$ and $B_{st}$ in 1976. Chase published them in 1989 in Congressus Numerantium 69, with the remark that an implementation is simpler with $C_{st}$ and $\hat C_{st}$, and coined the term graylex. T. A. Jenkyns and D. McCarthy proved in 1995 that near-perfect genlex lists are exactly the $2s$ lists of Theorem N. Ruskey notes that the first homogeneous combination generator was found by Lathroum and implemented by Chase in 1970, and his book builds a related pair of lists for the weaker condition that the two changed positions are one or two apart (Algorithm 5.9).
