---
title: The D-algorithm finds a test exactly when the fault is detectable
proves: [correctness]
status: full
---

Let $C$ be a combinational circuit of AND, OR, NAND, NOR, NOT and BUF gates and fanout branches, with lines in topological order, and let $(\ell, s)$ be the fault "line $\ell$ stuck at $s$". A *state* gives each line $k$ two entries, $S_G(k)$ for the good circuit and $S_B(k)$ for the faulty circuit, each in $\{0, 1, X\}$. The entry $S_B(\ell)$ is *fixed*: it is always $s$, and no rule reads the inputs of $\ell$ to change it. A line has an *effect* in $S$ when both entries are known and differ.

For a two-valued input vector $\tau$, write $g_\tau(k)$ and $b_\tau(k)$ for the values of line $k$ in the good and the faulty circuit. The state $S$ *agrees with* $\tau$ when every known entry is the true value: $S_G(k) \ne X$ implies $S_G(k) = g_\tau(k)$, and $S_B(k) \ne X$ implies $S_B(k) = b_\tau(k)$. Let $\mathrm{cv}(G)$ be the controlling value of $G$ (0 for AND and NAND, 1 for OR and NOR).

The implications of line L1 are these rules, applied in both circuits until nothing changes. Forward: if the known inputs of a line fix its value, set it. A primary input other than $\ell$ has the same entry in both circuits. Backward at NOT, BUF and branches: the input follows from the output. Backward at an AND-type gate whose output needs all inputs non-controlling: set them all to $1 - \mathrm{cv}$. Backward at an AND-type gate whose output needs some controlling input, when no input is controlling yet: if exactly one input is X, set it to $\mathrm{cv}$, and if none is X, report a conflict. Setting a known entry to the other value is also a conflict. No rule touches the fixed entry.

**Lemma 1 (implications are sound).** If $S$ agrees with a detecting vector $\tau$, then line L1 reports no conflict, and the state after it still agrees with $\tau$.

*Proof.* Each rule writes a value that the gate equations force from known entries. Since the known entries are the true values under $\tau$, the written value is the true value too, and a conflict, two different true values for one entry, cannot occur. The rule for primary inputs holds because only line $\ell$ differs between the circuits at the inputs. $\square$

**Lemma 2 (soundness).** If line L9 returns true, then every completion of the good values of the primary inputs is a test.

*Proof.* At line L9 the implications are at a fixpoint, some output has an effect and the J-frontier is empty. So for every entry that is known and not fixed, the known inputs of its line fix it: for a gate this is the empty J-frontier together with the forward rule, and for a branch, NOT or BUF the backward rule has made the input known. Let $\tau$ be a completion. We show that $S$ agrees with $\tau$ by induction over the lines in topological order. A primary input other than $\ell$ has equal known entries in both circuits, and $\tau$ gives it that value. The fixed entry is the true faulty value $s$. Any other known entry is fixed by known inputs, which have their true values by induction, so it is the true value. So the output with an effect differs under $\tau$. $\square$

**Lemma 3 (propagation is complete).** Let $S$ be a state after line L1 that agrees with a detecting vector $\tau$, with no output with an effect. Then some gate $G$ of the D-frontier is such that the values of line L5 for $G$ agree with $\tau$ and make at least one new entry known.

*Proof.* Some output differs under $\tau$ and has no effect in $S$. Let $G$ be the first line in topological order that differs under $\tau$ and has no effect in $S$. Line $\ell$ has an effect in $S$, since both its entries are known from the start, so $G \ne \ell$. As in the PODEM proof, a line other than $\ell$ that differs has an input that differs. Every input of $G$ that differs comes earlier, so it has an effect in $S$. If $G$ were a branch, NOT or BUF, the forward rule would have copied that effect, so $G$ is an AND-type gate with an X and an input with an effect, a gate of the D-frontier. Take an input $j$ of $G$ with no effect in $S$. Then $j$ does not differ under $\tau$, so $g_\tau(j) = b_\tau(j)$. Since $G$ differs, one of the two circuits has $G$ at its value with no controlling input, and in that circuit every input of $G$ is at $1 - \mathrm{cv}(G)$. So $g_\tau(j) = b_\tau(j) = 1 - \mathrm{cv}(G)$, which is the value line L5 writes in both circuits. Last, $G$ has an X in some circuit, and the forward rule did not fix it, so some input of $G$ is X in that circuit. That input has no effect, so line L5 makes it known. $\square$

**Lemma 4 (justification is complete).** Let $S$ be a state after line L1 that agrees with a detecting vector $\tau$, with an output with an effect and a nonempty J-frontier. Let $(G, m)$ be the pair chosen at line L10. Then one pass of the loop of lines L11 to L14 calls D-ALG on a state that agrees with $\tau$ and has one more known entry.

*Proof.* The entry of $G$ in circuit $m$ is known but not fixed by the known inputs. If this value needed all inputs at $1 - \mathrm{cv}$, the backward rule would have set them, and the forward rule would fix the output. So it needs some input at $\mathrm{cv}$, no known input has $\mathrm{cv}$, and at least two inputs are X, or the backward rule would have acted. Let $j_1, \ldots, j_t$ be these X inputs in the order of line L11. Under $\tau$ some $j_i$ is at $\mathrm{cv}$ in circuit $m$; take the first such $i$. For $i' < i$, the input $j_{i'}$ is at $1 - \mathrm{cv}$ under $\tau$, and this is the value that line L14 writes after the pass for $j_{i'}$ fails. So the state of pass $i$ is $S$ with $j_1, \ldots, j_{i-1}$ at $1 - \mathrm{cv}$ and $j_i$ at $\mathrm{cv}$, which agrees with $\tau$. $\square$

**Theorem.** D-ALG stops, with recursion depth at most $2L$. The D-algorithm returns a vector exactly when the fault is detectable, and every completion of the returned vector is a test.

*Proof.* Each recursive call of line L6 or line L13 gets a state with at least one more known entry than the state after line L1 of its parent. Line L1 never makes an entry unknown. There are $2L$ entries, so the depth is at most $2L$, and each call has finitely many children, so the search stops.

If the result is a vector, then line L9 returned true somewhere, the true value passed up to the top, and Lemma 2 applies to the good values of the inputs at that moment, which are the returned values.

Now let $\tau$ detect the fault. Then $g_\tau(\ell) = \lnot s$, since otherwise the two circuits agree on every line. So the first state, with $S_G(\ell) = \lnot s$, $S_B(\ell) = s$ and X elsewhere, agrees with $\tau$. We show by induction on the number of unknown entries that a call on a state that agrees with $\tau$ returns true. By Lemma 1, line L1 finds no conflict and keeps agreement. If no output has an effect, Lemma 3 gives a gate of the D-frontier whose child state agrees with $\tau$, and this child returns true by induction. The loop of line L4 restores the state at line L7 after each gate, so it reaches that gate with the same state unless it returns true earlier. If an output has an effect and the J-frontier is empty, line L9 returns true. Otherwise Lemma 4 gives a pass whose child agrees with $\tau$ and returns true by induction, and the loop reaches it unless it returns true earlier. So the top call returns true. $\square$
