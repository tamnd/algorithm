---
title: The one-step lattice check of STE is sound for binary runs
proves: [correctness]
status: full
---

**Setting.** The lattice is $L = \{\mathrm{X}, 0, 1, \top\}$ with $\mathrm{X} \sqsubseteq 0 \sqsubseteq \top$ and $\mathrm{X} \sqsubseteq 1 \sqsubseteq \top$. The circuit has inputs, latches $s$ with next-state nodes $\mathrm{next}(s)$, and gates $u$ with operators $\mathrm{op}(u)$ in topological order. A binary run $\rho$ gives each node $u$ and time $t$ a value $\rho_t(u) \in \{0, 1\}$, with $\rho_t(u) = \mathrm{op}(u)(\rho_t \text{ of the fanins})$ for each gate and $\rho_{t+1}(s) = \rho_t(\mathrm{next}(s))$ for each latch. Inputs and initial latch values are free. An assignment $\phi$ gives 0 or 1 to each symbolic variable. A constraint $(t, u, e, g)$ holds in $\rho$ at $\phi$ when $g(\phi) = 0$ or $\rho_t(u) = e(\phi)$. A formula is a finite set of constraints, and $\rho$ satisfies it at $\phi$ when all its constraints hold.

**Encoding.** A value under all assignments is a pair of BDDs $(a_1, a_0)$. At $\phi$ it denotes X if $a_1(\phi) = a_0(\phi) = 0$, 1 if only $a_1(\phi) = 1$, 0 if only $a_0(\phi) = 1$, and $\top$ if both are 1. In this encoding, $a \sqsubseteq b$ at $\phi$ is $(a_1 \rightarrow b_1) \wedge (a_0 \rightarrow b_0)$ at $\phi$, and the join is $(a_1 \vee b_1, a_0 \vee b_0)$. Both are checked on the 16 pairs of $L$. The value of $\delta_F(t, u)$ is the join over the constraints $(t, u, e, g)$ of $F$ of $(g \wedge e, g \wedge \neg e)$. All statements below are about one fixed $\phi$, and we write $\tau_t(u)$ for the lattice value that the pair denotes at $\phi$.

**Claim.** Let $R = \neg(\mathrm{OK} \vee \mathrm{AF})$ be the residual of line L8. For every $\phi$ with $R(\phi) = 0$ and every run $\rho$ that satisfies $A$ at $\phi$, $\rho$ satisfies $C$ at $\phi$. Moreover, if $\mathrm{AF}(\phi) = 1$, no run satisfies $A$ at $\phi$.

**Fact 1 (satisfaction is being above).** For a binary value $b$ and $a \in L$, $a \sqsubseteq b$ exactly when $a = \mathrm{X}$ or $a = b$. A constraint $(t, u, e, g)$ contributes X when $g(\phi) = 0$ and the binary value $e(\phi)$ when $g(\phi) = 1$. So $\rho$ satisfies $F$ at $\phi$ exactly when each contribution is below $\rho_t(u)$. A set of values is below $\rho_t(u)$ exactly when its join is, because the join is the least upper bound. Hence $\rho$ satisfies $F$ at $\phi$ if and only if $\delta_F(\phi)(t, u) \sqsubseteq \rho_t(u)$ for all $t$ and $u$.

**Fact 2 (monotone gates).** The dual-rail gate of line L5 is monotone and agrees with $\mathrm{op}$ on binary arguments. For NOT the rails swap, which keeps $\sqsubseteq$. For AND the one-rail is $\bigwedge_i a_{i,1}$ and the zero-rail is $\bigvee_i a_{i,0}$. Both are positive in the rails, so raising any rail of an argument from 0 to 1 can only raise the rails of the result, and $\sqsubseteq$ is the rail-wise order. OR is the dual. For XOR the rails are built by the recurrence $o' = o a_0 \vee z a_1$, $z' = o a_1 \vee z a_0$ from $(o, z) = (0, 1)$, which is again positive in all rails. NAND, NOR and XNOR swap the rails at the end. On binary arguments the rails of each argument are $(b, \neg b)$, and each formula then gives $(\mathrm{op}(b), \neg\mathrm{op}(b))$. The tests check monotonicity on all argument tuples of $L$. On arguments in $\{\mathrm{X}, 0, 1\}$ they also check that the result is the exact ternary extension: binary exactly when all completions of the X arguments agree.

**Lemma (the defining trajectory is below every run).** If $\rho$ satisfies $A$ at $\phi$, then $\tau_t(u) \sqsubseteq \rho_t(u)$ for every $t \le d$ and every node $u$.

*Proof.* By induction on $t$, and inside a time on the order of lines L3, L4, L5: inputs, then latches, then gates in topological order. Each line that writes $\tau_t(u)$ sets it to a join. It is enough to show that each joined term is below $\rho_t(u)$, since the join of values below a binary value $b$ is below $b$.

- Line L3: the term is $\delta_A(\phi)(t, u)$, which is below $\rho_t(u)$ by Fact 1, since $\rho$ satisfies $A$. For inputs and for latches at time 0 this is the only term.
- Line L4, $t > 0$: the new term is $\tau_{t-1}(\mathrm{next}(s))$. By induction at time $t - 1$ it is below $\rho_{t-1}(\mathrm{next}(s)) = \rho_t(s)$.
- Line L5: the new term is $\widehat{\mathrm{op}}(u)$ of the fanin values $\tau_t(f)$. Each fanin is an input, a latch or an earlier gate, so its value is final and $\tau_t(f) \sqsubseteq \rho_t(f)$ by induction. By Fact 2, $\widehat{\mathrm{op}}(u)(\tau_t(f)_f) \sqsubseteq \widehat{\mathrm{op}}(u)(\rho_t(f)_f) = \mathrm{op}(u)(\rho_t(f)_f) = \rho_t(u)$.

No later line changes $\tau_t(u)$. $\square$

**Proof of the claim.** First let $\mathrm{AF}(\phi) = 1$. Line L6 gives some $t$ and $u$ with $\tau_t(u) = \top$. If a run $\rho$ satisfied $A$ at $\phi$, the Lemma would give $\top \sqsubseteq \rho_t(u)$, but no binary value is above $\top$. So no run satisfies $A$ at $\phi$, and the assertion holds at $\phi$ without content.

Now let $R(\phi) = 0$ and $\mathrm{AF}(\phi) = 0$, so $\mathrm{OK}(\phi) = 1$. Line L7 gives $\delta_C(\phi)(t, u) \sqsubseteq \tau_t(u)$ for all $t \le d$ and $u$, where $d$ bounds the times of $C$ by line L1. Let $\rho$ satisfy $A$ at $\phi$. By the Lemma and transitivity, $\delta_C(\phi)(t, u) \sqsubseteq \rho_t(u)$ for all $t$ and $u$, and by Fact 1 $\rho$ satisfies $C$ at $\phi$. If $R(\phi) = 0$ and $\mathrm{AF}(\phi) = 1$, the first case applies. $\blacksquare$

**What is not claimed.** The check is not complete for binary runs. With $z = a \vee \neg a$ and no constraint on $a$, line L5 gives $\tau_0(z) = \widehat{\mathrm{OR}}(\mathrm{X}, \mathrm{X}) = \mathrm{X}$, so the consequent "$z$ is 1" fails although every run has $z = 1$. Seger and Bryant (1995) prove that the check is exact for the ternary circuit model: it passes exactly when every ternary trajectory above $\delta_A$ is above $\delta_C$. This page relies on that result only for the remark and does not prove it. One case of completeness for binary runs follows from the Lemma. If $A$ sets every input at every time $t \le d$ and every latch at time 0 to an expression with guard 1, then at $\phi$ there is exactly one run $\rho$ that satisfies $A$. Each $\tau_t(u)$ is then binary or $\top$. When it is binary it equals $\rho_t(u)$, by the Lemma and induction. So OK is false at $\phi$ exactly when $\rho$ breaks $C$. The tests check this case against all runs.
