**Setting.** The lattice $L = \{\mathrm{X}, 0, 1, \top\}$, the dual-rail encoding, the circuit model and the gate tables $\widehat{\mathrm{op}}$ are those of [the STE proof](/symbolic-trajectory-evaluation/). We use two facts proved there. Fact 1: a binary state $\rho_t$ meets a set of constraints $F$ at $\phi$ exactly when $\delta(F)(\phi) \sqsubseteq \rho_t$ at every node. Fact 2: each $\widehat{\mathrm{op}}$ is monotone and agrees with $\mathrm{op}$ on binary arguments. A ternary state is a map from nodes to $L$. States are ordered node by node, and the meet $\sqcap$ and join $\sqcup$ are taken node by node. The meet is the AND of the rails: on $L$ it is the greatest lower bound, with $0 \sqcap 1 = \mathrm{X}$ and $\top \sqcap a = a$. Fix an assignment $\phi$. All statements are at $\phi$, and the BDD operations act point by point, so it is enough to argue for one $\phi$.

For a state $\sigma$ write $\mathrm{empty}(\sigma)$ if some node of $\sigma$ is $\top$. Let $\mathrm{norm}(\sigma, b)$ be the state with every node $\top$ if $b$ or $\mathrm{empty}(\sigma)$ holds, and $\sigma$ otherwise. Let $F$ map an assignment of states to edges, $\mathrm{sim}$, to the states $\mathrm{new}$ of lines L4 to L7:

$$\mathrm{pre}_e = I_e \sqcap \bigsqcap_{\mathrm{dst}(e') = \mathrm{src}(e)} \mathrm{sim}(e'), \qquad \sigma_e = \mathrm{close}\bigl(\delta(\mathrm{ant}(e)) \sqcup \mathrm{shift}(\mathrm{pre}_e)\bigr), \qquad F(\mathrm{sim})(e) = \mathrm{norm}(\sigma_e, \mathrm{empty}(\mathrm{pre}_e)).$$

Here $I_e$ is the all-X state if $\mathrm{src}(e) = v_0$ and the all-$\top$ state otherwise, $\mathrm{shift}(p)$ has $p(\mathrm{next}(s))$ at each latch $s$ and X elsewhere, and $\mathrm{close}$ is line L6, which joins each gate in topological order with $\widehat{\mathrm{op}}$ of its fanins.

**Lemma 1 (monotone round).** If $\mathrm{sim} \sqsubseteq \mathrm{sim}'$ at every edge and node, then $F(\mathrm{sim}) \sqsubseteq F(\mathrm{sim}')$.

*Proof.* Meet and join are monotone in each argument, so $\mathrm{pre}_e \sqsubseteq \mathrm{pre}'_e$ and $\mathrm{shift}(\mathrm{pre}_e) \sqsubseteq \mathrm{shift}(\mathrm{pre}'_e)$. The map $\mathrm{close}$ is monotone by induction over the gates in topological order: each gate value is a join of its old value and $\widehat{\mathrm{op}}$ of values that are already ordered, and both operations are monotone by Fact 2. So $\sigma_e \sqsubseteq \sigma'_e$. For $\mathrm{norm}$: the only element above $\top$ is $\top$, so $\mathrm{empty}(\sigma)$ and $\sigma \sqsubseteq \sigma'$ give $\mathrm{empty}(\sigma')$, and the same holds for $\mathrm{pre}$. If $\mathrm{norm}$ sets $F(\mathrm{sim}')(e)$ to all $\top$, the claim holds since everything is below $\top$. Otherwise neither $\sigma'_e$ nor $\mathrm{pre}'_e$ is empty, hence neither $\sigma_e$ nor $\mathrm{pre}_e$ is, and both results are the unchanged $\sigma_e \sqsubseteq \sigma'_e$. $\square$

**Lemma 2 (termination).** The loop of lines L2 to L8 stops after at most $2 N E + 1$ rounds, where $N$ is the number of nodes and $E$ the number of edges, and on exit $\mathrm{sim} = F(\mathrm{sim})$.

*Proof.* Let $\mathrm{sim}_0$ be all $\top$ (line L1) and $\mathrm{sim}_{n+1} = F(\mathrm{sim}_n)$. Then $\mathrm{sim}_1 \sqsubseteq \mathrm{sim}_0$, since $\top$ is the greatest element. If $\mathrm{sim}_{n+1} \sqsubseteq \mathrm{sim}_n$, Lemma 1 gives $\mathrm{sim}_{n+2} \sqsubseteq \mathrm{sim}_{n+1}$. So the sequence goes down at every node of every edge. Every chain in $L$ that goes strictly down has at most 3 elements ($\top$, a binary value, X), so at $\phi$ each of the $N E$ values changes at most twice. If $\mathrm{sim}_{n+1} = \mathrm{sim}_n$ at $\phi$, then $\mathrm{sim}_{n+2} = F(\mathrm{sim}_{n+1}) = F(\mathrm{sim}_n) = \mathrm{sim}_{n+1}$ at $\phi$, because $F$ at $\phi$ depends only on the values at $\phi$. So at each $\phi$ the changing rounds come first and number at most $2 N E$. The loop stops at the first round that changes nothing at any $\phi$, which is round $2 N E + 1$ or earlier, and line L8 stops only when $\mathrm{new} = \mathrm{sim}$, that is $F(\mathrm{sim}) = \mathrm{sim}$. $\square$

**Lemma 3 (the fixed point is below every run).** Let $\mathrm{sim} = F(\mathrm{sim})$. Let $e_0 e_1 \cdots e_k$ be a path with $\mathrm{src}(e_0) = v_0$ and $\mathrm{dst}(e_{i}) = \mathrm{src}(e_{i+1})$, and let $\rho$ be a binary run that meets $\mathrm{ant}(e_i)$ at time $i$ for all $i \le k$. Then $\mathrm{sim}(e_k) \sqsubseteq \rho_k$.

*Proof.* By induction on $k$. Write $e = e_k$.

First, $\mathrm{pre}_e \sqsubseteq \rho_{k-1}$ at every node when $k > 0$, and $\mathrm{shift}(\mathrm{pre}_e) \sqsubseteq \rho_k$ at every node for every $k$. For $k = 0$, $\mathrm{src}(e) = v_0$, so $\mathrm{pre}_e \sqsubseteq I_e$, which is all X, and $\mathrm{shift}(\mathrm{pre}_e)$ is all X. For $k > 0$, $e_{k-1}$ is an edge into $\mathrm{src}(e)$, so $\mathrm{pre}_e \sqsubseteq \mathrm{sim}(e_{k-1}) \sqsubseteq \rho_{k-1}$ by the induction hypothesis. Then $\mathrm{shift}(\mathrm{pre}_e)(s) = \mathrm{pre}_e(\mathrm{next}(s)) \sqsubseteq \rho_{k-1}(\mathrm{next}(s)) = \rho_k(s)$ at each latch, and X elsewhere.

Next, $\delta(\mathrm{ant}(e)) \sqsubseteq \rho_k$ by Fact 1. A join of values below a binary value is below it, so the argument of $\mathrm{close}$ is below $\rho_k$. Going through the gates in topological order, each gate $u$ gets the join of a value below $\rho_k(u)$ and $\widehat{\mathrm{op}}(u)$ of fanin values below the $\rho_k$ values of the fanins. By Fact 2 the second term is below $\mathrm{op}(u)(\rho_k \text{ of the fanins}) = \rho_k(u)$. So $\sigma_e \sqsubseteq \rho_k$.

Last, no binary value is above $\top$, so neither $\sigma_e$ nor $\mathrm{pre}_e$ (when $k > 0$) has a $\top$ node. When $k = 0$, $\mathrm{pre}_e \sqsubseteq I_e$ is all X, which is not empty. So $\mathrm{norm}$ returns $\sigma_e$, and $\mathrm{sim}(e) = F(\mathrm{sim})(e) = \sigma_e \sqsubseteq \rho_k$. $\square$

**Theorem (soundness).** Let $\mathrm{sim}$ be the result of the loop. If, at $\phi$, $\delta(\mathrm{cons}(e)) \sqsubseteq \mathrm{sim}(e)$ for every edge $e$ (the residual of line L9 is 0 at $\phi$), then the graph holds at $\phi$ under the strong semantics.

*Proof.* By Lemma 2, $\mathrm{sim} = F(\mathrm{sim})$. Take a path $e_0 \cdots e_k$ from $v_0$ and a run $\rho$ that meets $\mathrm{ant}(e_i)$ at time $i$ for $i \le k$. Lemma 3 gives $\mathrm{sim}(e_k) \sqsubseteq \rho_k$, so $\delta(\mathrm{cons}(e_k)) \sqsubseteq \rho_k$ by transitivity, and by Fact 1 $\rho$ meets $\mathrm{cons}(e_k)$ at time $k$. $\blacksquare$

**Remarks.** Lemma 3 uses only $\mathrm{sim} = F(\mathrm{sim})$, so any fixed point gives a sound check. The loop finds the greatest fixed point in the information order, which is the most precise one: by Lemma 1 and induction, every fixed point $s$ has $s = F^n(s) \sqsubseteq F^n(\top) = \mathrm{sim}_n$ for all $n$. The check is not complete. The meet at a vertex is only an upper bound, in the set order, of the union of the state sets of the in-edges, and X loses information as in STE. If the graph is a chain and the antecedents fix every input at every step and every latch at the first step, then at each $\phi$ exactly one run takes each edge. By Lemma 3 and induction, each $\mathrm{sim}(e_k)$ is then that run's binary state $\rho_k$, and the check is exact. The tests check this case against enumeration of all runs.
