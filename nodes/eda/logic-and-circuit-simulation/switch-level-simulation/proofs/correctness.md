---
title: The steady state of a component is exact for binary switches and monotone with X, and the rounds bound every binary run
proves: [correctness]
status: full
---

**Setting.** Fix a component $P$ and the values val of all nodes. Lines L9 to L14 refer to STEADY on the page. Each transistor of $P$ has a state in $\{0, 1, X\}$ from its gate. Let $G_D$ be the graph of the transistors in state 1 and $G_P$ the graph of the transistors in state 1 or X, so $G_D \subseteq G_P$. A *source* is either the charge of a storage node $m$, with strength $\kappa(m)$ and value $\mathrm{val}(m)$, entering at $m$, or an input node $u$ joined to a storage node $w$ by a transistor of strength $\gamma$, giving strength $\min(\omega, \gamma) = \gamma$ and value $\mathrm{val}(u)$ at $w$. A path is a source followed by a walk through storage nodes of $P$ along transistors. Its *prefix strength* at a node $m$ on it is the least of the source strength and the strengths of the transistors passed so far. Prefix strengths do not increase along a path.

Let $S(n)$ be the largest prefix strength at $n$ over all paths in $G_D$ that end at $n$. A path in a graph $G$ is *dominant* in $G$ if its prefix strength at each node $m$ it passes is $S_G(m)$. For binary transistor states $G_D = G_P$, and the steady state $\sigma(n)$ is the least upper bound of the values of the sources of the dominant paths that end at $n$.

**Lemma 1 (widest paths).** The function `widest` with seeds and an optional floor returns, for each node $w$, the largest prefix strength at $w$ over the paths whose prefix strength at every node $m$ they pass is at least the floor of $m$, or NONE if there is none. Without a floor this is $S$ when run on $G_D$ (line L10).

*Proof.* This is Dijkstra's algorithm in the order "largest first" for the path value "least strength so far", filtered by the floor. The filter $p \mapsto p$ if $p \ge \mathrm{floor}(w)$, else NONE, does not decrease when $p$ grows, and $\min(\cdot, \gamma)$ does not either. Claim: when a node $u$ is taken from the heap the first time, its label $B(u)$ is final. Every node still in the heap or not reached has a label of at most $B(u)$, because the heap gives the largest first. Take any admissible path to $u$ and the first node $x$ on it that was not yet taken. The prefix strength at $x$ is at most the label of $x$, since the predecessor of $x$ on the path was taken and relaxed its edge to $x$ with a label at least the prefix strength there (by induction on the order of taking), or $x$ is the first node of the path and gets its seed. So the prefix strength at $x$ is at most $B(u)$, and it can only fall from $x$ to $u$. Labels are always prefix strengths of admissible paths, so $B(u)$ is the largest. $\square$

**Lemma 2 (a dominant path to every node).** For every node $n$ of $P$ there is a path in $G_D$ that is dominant in $G_D$ and ends at $n$, and its source is in the seeds of line L10.

*Proof.* Follow the predecessor that set the final label of each node in the search of line L10 back to a seed. Along this chain the label of each node equals the least of the label of its predecessor and the transistor strength between them, so the prefix strength at each node is its final label $S(m)$. $\square$

**Theorem 1 (exact for binary switches).** If every transistor of $P$ is in state 0 or 1, STEADY returns $\sigma(n)$ for every node $n$, also when some sources have the value X.

*Proof.* Now $G_P = G_D$. Every prefix strength at $m$ is at most $S(m)$, by the definition of $S$. So the floor test of line L12, prefix strength at least $S(m)$, holds exactly when the prefix strength equals $S(m)$, that is, on dominant paths. By Lemma 1, $\mathrm{reach}_b(n) \ne$ NONE exactly when a dominant path from a source of value $b$ or X ends at $n$. By Lemma 2 at least one dominant path ends at $n$, so at least one of $\mathrm{reach}_0(n)$, $\mathrm{reach}_1(n)$ is set. If only $\mathrm{reach}_1(n)$ is set, every dominant path comes from a source of value 1, so $\sigma(n) = 1$, which line L13 returns. The case of 0 is the same. If both are set, either two dominant paths have values 0 and 1, or one has value X, and in both cases $\sigma(n) = X$. $\square$

**Theorem 2 (monotone).** Let val and val' agree on vdd and gnd and satisfy $\mathrm{val} \sqsubseteq \mathrm{val'}$ at every node. Then $\mathrm{STEADY}(P, \mathrm{val})(n) \sqsubseteq \mathrm{STEADY}(P, \mathrm{val'})(n)$ for every $n$.

*Proof.* The state of a transistor is monotone in its gate value, so each state under val is $\sqsubseteq$ its state under val'. A transistor in state 1 under val' is in state 1 under val, because only 1 is below 1. So $G'_D \subseteq G_D$ and, by the definition of $S$ as a maximum, $S' \le S$. A transistor that is not open under val is not open under val', so $G_P \subseteq G'_P$. A source of value $b$ or X under val has value $b$ or X under val'. Now take a path counted in $\mathrm{reach}_b(n)$ under val: it lies in $G_P \subseteq G'_P$, its source qualifies under val', and its prefix strength at each $m$ is at least $S(m) \ge S'(m)$. So it is counted in $\mathrm{reach}'_b(n)$. Let $R(n) = \{b : \mathrm{reach}_b(n) \ne \mathrm{NONE}\}$. We have shown $R(n) \subseteq R'(n)$, and $R(n)$ is not empty: the path of Lemma 2 lies in $G_D \subseteq G_P$, has prefix strength $S(m)$ at each $m$, and its source has a value 0, 1 or X. Line L13 maps $\{0\}$ to 0, $\{1\}$ to 1 and $\{0, 1\}$ to X, and this map is monotone from sets under inclusion to values under $\sqsubseteq$. $\square$

**Corollary (soundness).** Let $c$ be a binary completion of val: $c(m) = \mathrm{val}(m)$ where val is binary and $c(m) \in \{0, 1\}$ elsewhere. Then $\sigma_c(n) \sqsubseteq \mathrm{STEADY}(P, \mathrm{val})(n)$, where $\sigma_c$ is the steady state of the definition under $c$. So a 0 or 1 from STEADY is the steady-state value for every completion.

*Proof.* Under $c$ every transistor is in state 0 or 1, so $\sigma_c = \mathrm{STEADY}(P, c)$ by Theorem 1, and $c \sqsubseteq \mathrm{val}$ gives the claim by Theorem 2. $\square$

**Theorem 3 (rounds).** Let $\Phi$ map val to the values obtained by applying STEADY to every component with the input nodes fixed. Then SIMULATE computes $\mathrm{val}_r = \Phi(\mathrm{val}_{r-1})$ in round $r$, and when its queue is empty, $\mathrm{val}_r$ is a fixed point of $\Phi$. If $c_0 \sqsubseteq v_0$, the runs $c_r = \Phi(c_{r-1})$ and $v_r = \Phi(v_{r-1})$ satisfy $c_r \sqsubseteq v_r$ for all $r$. So if the run from $v_0$ settles in $T$ and the run from a binary completion $c_0$ of $v_0$ settles in $B$, then $B \sqsubseteq T$.

*Proof.* STEADY on $P$ reads only the values of the nodes of $P$ and of the gates of its transistors, and the fixed input nodes. Line L7 queues every component with such a value changed in the round before. Invariant: after round $r$, every component $Q$ that is not in the queue satisfies $\mathrm{STEADY}(Q, \mathrm{val}_r) = \mathrm{val}_r|_Q$. If $Q$ was solved in round $r$, then $\mathrm{val}_r|_Q = \mathrm{STEADY}(Q, \mathrm{val}_{r-1})$, and nothing it reads changed, so this equals $\mathrm{STEADY}(Q, \mathrm{val}_r)$. If $Q$ was not solved in round $r$, the invariant after round $r-1$ gives $\mathrm{STEADY}(Q, \mathrm{val}_{r-1}) = \mathrm{val}_{r-1}|_Q = \mathrm{val}_r|_Q$, and again nothing it reads changed. Round 1 solves every component. So in every round the components left out would return their present values, and the round equals $\Phi$. An empty queue means nothing changed, so $\Phi(\mathrm{val}_r) = \mathrm{val}_r$. By Theorem 2, $\Phi$ is monotone, and induction on $r$ gives $c_r \sqsubseteq v_r$. If both runs settle, at rounds $k$ and $k'$, take $r \ge \max(k, k')$: $B = c_r \sqsubseteq v_r = T$. $\square$

Theorem 3 compares runs of the same unit-delay model. It does not say that a real circuit, with its own delays, behaves like any of these runs; inside a component the model takes every change as instant. The X pessimism shown on the page (an n and a p transistor in parallel, both gated by X) is a case where the inclusion of the Corollary is strict.
