---
title: Fragment merging elects one leader with at most 5n(⌊log₂ n⌋ + 1) + 6m + n − 1 messages
proves: [correctness, termination, complexity]
status: full
---

**Claim.** Run FRAGMENT-ELECTION, the form with global phases on the page, on a connected network with $n \ge 1$ processes, $m$ links and distinct identifiers, with the weight $w(u, v) = (\min(\mathrm{id}(u), \mathrm{id}(v)), \max(\mathrm{id}(u), \mathrm{id}(v)))$. Then (a) at the start of every phase, every fragment is a subtree of the unique minimum spanning tree $T^*$ with exactly one root; (b) the number of fragments at least halves in every phase that does not end the run, so there are at most $\lfloor \log_2 n \rfloor + 1$ phases; (c) the run ends with one fragment equal to $T^*$, whose root is the only leader, and every process learns it; (d) the run sends at most $5n(\lfloor \log_2 n \rfloor + 1) + 6m + (n - 1)$ messages; (e) if every message takes at most one time unit and each step of a phase is given its worst-case time, the run takes $O(n \log n)$ time.

This proof covers the form with global phases. It does not cover the asynchronous level rules of GHS or Awerbuch's changes for the time.

**Weights.** Two different links differ in at least one end, so their pairs of end identifiers differ: all weights are distinct. Hence $T^*$ is unique, and the *cut property* holds: for every set $S$ of processes with $\emptyset \ne S \ne V$, the lightest link with exactly one end in $S$ belongs to $T^*$.

**Lemma 1 (the minimum outgoing link).** In a phase, let $\mathcal{F}$ be a fragment that has a link to another fragment. After L3 and L4, its root knows the lightest link with exactly one end in $\mathcal{F}$.

*Proof.* At the time of the tests, every process knows the name of its fragment, because the INITIATE broadcast of L2 has ended. A test over a link inside $\mathcal{F}$ gets REJECT and a test over a link that leaves $\mathcal{F}$ gets ACCEPT, so each process $v$ finds the lightest link at $v$ that leaves $\mathcal{F}$, provided no such link was skipped. Tree links are inside $\mathcal{F}$. A rejected link joined two processes of one fragment when it was rejected; fragments only merge, never split, so both ends are still in one fragment, which is $\mathcal{F}$ if one end is in $\mathcal{F}$. So no outgoing link is skipped, and the tests of $v$ stop at its lightest outgoing link. The convergecast of L4 takes the minimum over all processes of $\mathcal{F}$, which is the lightest outgoing link of $\mathcal{F}$. $\square$

**Part (a).** Induction on the phases. At the start, every fragment is one process, a subtree of $T^*$ with itself as root. Assume (a) at the start of a phase. By Lemma 1 and the cut property with $S = \mathcal{F}$, every chosen link belongs to $T^*$. So the union of the fragments and the chosen links is a subgraph of $T^*$, a forest, and each of its components is a subtree of $T^*$. Take a component made of $F \ge 2$ old fragments. Since it is a tree whose old fragments are connected subtrees, it has exactly $F - 1$ chosen links between them. Each of the $F$ fragments chose one link, and every chosen link in the component was chosen by at least one of its two fragments, so by counting, exactly one link was chosen by both fragments at its ends; no link is chosen by more than two fragments, since it has two ends. L7 makes the end with the larger identifier of that link the only root. $\square$

**Part (b).** In a phase that does not end the run, every fragment has an outgoing link, because the network is connected and there are at least two fragments, and it chooses one, so it lies in a component with at least two fragments. So the number of fragments after the phase is at most half of the number before. After $k$ such phases there are at most $n / 2^k$ fragments, so at most $\lfloor \log_2 n \rfloor$ phases merge, and one more phase ends the run.

**Part (c).** By part (b), the run reaches a phase that starts with a single fragment. Its root finds no outgoing link (L5), because every link has both ends in it. By part (a) the fragment is a subtree of $T^*$ that spans all $n$ processes, so it is $T^*$. Before that phase, every fragment had an outgoing link, so L5 elected no one. The root sends LEADER down the tree, so every process learns it, and exactly one process is the leader.

**Part (d).** HELLO: one message per link end, $2m$. In a phase with $F$ fragments: INITIATE goes once down each tree link, $n - F$ messages; REPORT goes once up each tree link, $n - F$; CHANGE goes along a path inside one fragment, at most $|\mathcal{F}| - 1$ messages for $\mathcal{F}$, so at most $n - F$; CONNECT, at most one per fragment, $F$. Each process has at most one test that gets ACCEPT, because it stops there, so at most $2n$ TEST and ACCEPT messages. This is at most $3(n - F) + F + 2n \le 5n$ per phase. A test that gets REJECT puts the link in the rejected set of both ends, and a rejected link is never tested again, so each link has at most one rejected test from each end over the whole run, at most $4m$ TEST and REJECT messages; in the code, which handles the tests one after the other, it is at most $2m$. Finally, LEADER sends $n - 1$ messages. With part (b), the total is at most $2m + 5n(\lfloor \log_2 n \rfloor + 1) + 4m + (n - 1)$.

**Termination.** By part (b) the number of phases is finite, and by part (d) every phase sends finitely many messages, so every run ends, with the outputs of part (c).

**Part (e).** In a phase, INITIATE and REPORT go along paths of at most $n - 1$ links, CHANGE along at most $n - 1$ links and CONNECT over one link, and a process makes at most $\deg(v) \le n - 1$ tests, one after the other, each taking two time units. So a phase takes at most $5n$ time units, and by part (b) the run takes at most $5n(\lfloor \log_2 n \rfloor + 1)$ time units, plus $n$ for the HELLO exchange and the announcement. $\blacksquare$
