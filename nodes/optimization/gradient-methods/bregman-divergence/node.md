The Bregman divergence of a differentiable [convex function](/convex-function/) $\psi$ measures how far $\psi(x)$ lies above the tangent plane of $\psi$ at $y$. For $\psi = \frac{1}{2}\lVert x\rVert^2$ it is half the squared Euclidean distance, and for the negative [entropy](/shannon-entropy/) it is the Kullback-Leibler divergence. It is not symmetric and has no triangle inequality, but it has a three-point identity that replaces the law of cosines in convergence proofs. Bregman (1967) introduced it to define projections onto convex sets, and [mirror descent](/mirror-descent/) uses it in place of the squared distance.

## Definition

Let $\psi : \mathbb{R}^n \to (-\infty, +\infty]$ be convex, and differentiable on the interior of its domain, $\operatorname{int}\operatorname{dom}\psi \ne \emptyset$. The **Bregman divergence** generated by $\psi$ is

$$D_\psi(x, y) = \psi(x) - \psi(y) - \langle \nabla\psi(y), x - y\rangle, \qquad x \in \operatorname{dom}\psi,\ y \in \operatorname{int}\operatorname{dom}\psi.$$

The second argument must be a point where $\psi$ has a [gradient](/gradient/). The function $\psi$ is called the generating function, the distance generating function, or the mirror map.

### Basic properties

**Nonnegative.** $D_\psi(x, y) \ge 0$, because a differentiable convex function lies above each of its tangent planes. If $\psi$ is strictly convex, then $D_\psi(x, y) = 0$ only for $x = y$. If $\psi$ is $\sigma$-strongly convex with respect to a norm $\lVert\cdot\rVert$ ([strong convexity](/strong-convexity/)), then $D_\psi(x, y) \ge \frac{\sigma}{2}\lVert x - y\rVert^2$, which is the definition of strong convexity written with $D_\psi$.

**Linear in the generator.** $D_{a\psi + b\phi} = aD_\psi + bD_\phi$ for $a, b \ge 0$. An affine function generates $D = 0$, so $\psi$ and $\psi + \langle c, x\rangle + d$ give the same divergence.

**Convex in the first argument.** For fixed $y$, $x \mapsto D_\psi(x, y)$ is $\psi$ minus an affine function, so it is convex. In the second argument it is in general not convex.

**Three-point identity.** For $x \in \operatorname{dom}\psi$ and $y, z \in \operatorname{int}\operatorname{dom}\psi$,

$$D_\psi(x, y) + D_\psi(y, z) - D_\psi(x, z) = \langle \nabla\psi(z) - \nabla\psi(y), x - y\rangle.$$

Write out the three divergences. The values $\psi(x)$, $\psi(y)$ and $\psi(z)$ cancel, and the gradient terms are $-\langle\nabla\psi(y), x - y\rangle - \langle\nabla\psi(z), y - z\rangle + \langle\nabla\psi(z), x - z\rangle = \langle\nabla\psi(z) - \nabla\psi(y), x - y\rangle$. For $\psi = \frac{1}{2}\lVert\cdot\rVert^2$ this is the law of cosines.

**Bregman projection and the Pythagorean inequality.** Let $C$ be closed and convex, and let $p = \operatorname{argmin}_{x \in C} D_\psi(x, y)$ be the Bregman projection of $y$ onto $C$ (it exists and is unique when $\psi$ is strictly convex and, for example, $C \cap \operatorname{dom}\psi$ is compact). If $p$ is in the interior of the domain, then for all $x \in C$

$$D_\psi(x, p) + D_\psi(p, y) \le D_\psi(x, y).$$

The optimality condition for $p$ is $\langle\nabla\psi(p) - \nabla\psi(y), x - p\rangle \ge 0$ for all $x \in C$. The three-point identity with the points $(x, p, y)$ gives $D_\psi(x, p) + D_\psi(p, y) - D_\psi(x, y) = \langle\nabla\psi(y) - \nabla\psi(p), x - p\rangle \le 0$.

**The mean is the best representative.** Let $X$ be a random vector in $\operatorname{int}\operatorname{dom}\psi$ with [expected value](/expected-value/) $m = \mathbb{E}X$ in the interior, and let $\mathbb{E}\psi(X)$ be finite. For each $u$ in the interior,

$$\mathbb{E}D_\psi(X, u) - \mathbb{E}D_\psi(X, m) = D_\psi(m, u).$$

The terms $\mathbb{E}\psi(X)$ cancel, and $\mathbb{E}\langle\nabla\psi(m), X - m\rangle = 0$; what is left is $\psi(m) - \psi(u) - \langle\nabla\psi(u), m - u\rangle$. So the mean minimizes $u \mapsto \mathbb{E}D_\psi(X, u)$ for every Bregman divergence, which is why $k$-means works with any of them (Banerjee et al. 2005).

**Duality.** If $\psi$ is a Legendre function (strictly convex and essentially smooth), then $\nabla\psi^* = (\nabla\psi)^{-1}$ for the [convex conjugate](/convex-conjugate/) $\psi^*$, and $D_\psi(x, y) = D_{\psi^*}(\nabla\psi(y), \nabla\psi(x))$. The order of the arguments swaps.

## Examples and non-examples

**Squared Euclidean distance.** $\psi(x) = \frac{1}{2}\lVert x\rVert^2$ has $\nabla\psi(y) = y$ and $D_\psi(x, y) = \frac{1}{2}\lVert x - y\rVert^2$. It is the only common example that is symmetric.

**Mahalanobis distance.** $\psi(x) = \frac{1}{2}x^\top Ax$ with $A$ [positive definite](/positive-definite-matrix/) gives $D_\psi(x, y) = \frac{1}{2}(x - y)^\top A(x - y)$.

**Kullback-Leibler divergence.** The negative entropy $\psi(x) = \sum_i x_i\log x_i$ on $\mathbb{R}^n_{\ge 0}$ has $\nabla\psi(y)_i = \log y_i + 1$, so

$$D_\psi(x, y) = \sum_i \Big(x_i\log\frac{x_i}{y_i} - x_i + y_i\Big).$$

On the probability simplex the last two terms cancel, and $D_\psi(p, q) = \sum_i p_i\log(p_i/q_i)$. For $p = (0.5, 0.5)$ and $q = (0.9, 0.1)$, $D_\psi(p, q) = 0.5108$ and $D_\psi(q, p) = 0.3681$, so the divergence is not symmetric. On the simplex the entropy is $1$-strongly convex with respect to $\lVert\cdot\rVert_1$, so $D_\psi(p, q) \ge \frac{1}{2}\lVert p - q\rVert_1^2$ (Pinsker's inequality).

**Itakura-Saito divergence.** The Burg entropy $\psi(x) = -\sum_i\log x_i$ on $\mathbb{R}^n_{>0}$ gives $D_\psi(x, y) = \sum_i (x_i/y_i - \log(x_i/y_i) - 1)$. In one variable, $D_\psi(2, 1) = 0.3069$ and $D_\psi(1, 2) = 0.1931$. It depends only on the ratios $x_i/y_i$, so it does not change when both arguments are scaled.

**No triangle inequality.** With $\psi(x) = \frac{1}{2}x^2$ on $\mathbb{R}$, $D_\psi(0, 2) = 2$, but $D_\psi(0, 1) + D_\psi(1, 2) = \frac{1}{2} + \frac{1}{2} = 1$.

**Non-example: a linear generator.** For $\psi(x) = \langle c, x\rangle$, $D_\psi = 0$ for all pairs, so it does not separate points. Strict convexity is what makes $D_\psi(x, y) = 0$ imply $x = y$.

**Non-example: a nonconvex generator.** For $\psi(x) = -x^2$, the formula gives $-(x - y)^2 < 0$ for $x \ne y$. It is not a divergence.

**Non-example: the Euclidean distance itself.** $\lVert x - y\rVert$ is not $D_\psi$ for any $\psi$ that is differentiable on an open set. For fixed $y$, $D_\psi(\cdot, y)$ is $\psi$ minus an affine function, so it is differentiable at $x = y$, but $\lVert x - y\rVert$ is not.

**Non-example: a kink in the generator.** For $\psi(x) = \lvert x\rvert$, the gradient at $y = 0$ does not exist, so $D_\psi(x, 0)$ is not defined. Each choice of a [subgradient](/subgradient/) $g \in [-1, 1]$ gives a different value $\lvert x\rvert - gx$.

## Related definitions

- **Mirror map.** In [mirror descent](/mirror-descent/), $\psi$ is the mirror map, $\nabla\psi$ moves a point to the dual space, and the step is a Bregman projection. With the entropy on the simplex the step is a multiplicative update, as in [multiplicative weights](/multiplicative-weights-update/).
- **Bregman proximal operator.** Replace $\frac{1}{2}\lVert u - x\rVert^2$ by $D_\psi(u, x)$ in the [proximal operator](/proximal-operator/). The [proximal point method](/proximal-point-method/) and the [proximal gradient method](/proximal-gradient-method/) have Bregman versions.
- **Relative smoothness.** A function $f$ is $L$-smooth relative to $\psi$ if $f(x) \le f(y) + \langle\nabla f(y), x - y\rangle + LD_\psi(x, y)$ for all $x, y$, which is the same as $L\psi - f$ being convex. This replaces the Lipschitz gradient condition in the descent lemma (Bauschke, Bolte and Teboulle 2017).
- **Bregman function.** Censor and Lent (1981) listed the conditions on $\psi$ (strict convexity, continuity, bounded level sets of $D_\psi(x, \cdot)$ and convergence conditions) under which Bregman's projection method converges. A function that meets them is a Bregman function.
- **Fisher information.** For an exponential family with log-partition function $A$, the KL divergence between two members is $D_A$ with the arguments in the natural parameters swapped, and the Hessian of $A$ is the [Fisher information matrix](/fisher-information-matrix/).
