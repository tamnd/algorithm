## Definition

A rational system of linear inequalities $Ax \le b$ is *totally dual integral* (TDI) if, for each integral vector $c$ for which

$$\max\{c^T x : Ax \le b\}$$

is finite, the [dual linear program](/dual-linear-program/)

$$\min\{y^T b : y^T A = c^T,\ y \ge 0\}$$

has an integral optimal solution $y$.

TDI is a property of the *system*, not of the polyhedron $P = \{x : Ax \le b\}$: two systems with the same $P$ can differ, one TDI and one not. The definition asks for an integral optimal dual, not only an integral optimal value.

**The integrality theorem (Edmonds and Giles, 1977).** If $Ax \le b$ is TDI and $b$ is integral, then $P$ is an integral polyhedron.

*Proof for pointed $P$.* For each integral $c$ with a finite maximum, an integral optimal $y$ gives the integer value $y^T b$, so $\max_P c^T x$ is an integer. Let $\bar x$ be a vertex. Since $\bar x$ is a vertex of a rational polyhedron, there is an integral $c$ for which $\bar x$ is the unique optimum, and then $c$ lies in the interior of the normal cone of $\bar x$. For a large integer $K$, both $Kc$ and $Kc + e_j$ lie in that interior, so $\bar x$ is optimal for both. Then $\bar x_j = (Kc + e_j)^T \bar x - (Kc)^T \bar x$ is a difference of two integers. $\square$

The proof shows the stronger statement of Edmonds and Giles: if $\max_P c^T x$ is an integer for each integral $c$ for which it is finite, then $P$ is integral. The nonpointed case reduces to this by working modulo the lineality space.

**Hilbert bases.** A finite set $H$ of integer vectors is a *Hilbert basis* if each integer vector in the cone generated by $H$ is a nonnegative integer combination of $H$. A system $Ax \le b$ is TDI if and only if, for each face $F$ of $P$, the rows of $A$ that are tight on $F$ form a Hilbert basis. Each rational cone has a Hilbert basis, and if the cone is pointed it has a unique minimal one.

**Every polyhedron has a TDI system.** Giles and Pulleyblank (1979) proved that each rational polyhedron $P$ can be written as $\{x : Ax \le b\}$ with $A$ integral and the system TDI. If $P$ is integral, $b$ can be chosen integral too. So for integral polyhedra, TDI is a matter of choosing the right inequalities: add the Hilbert basis of each normal cone.

**Rounding the right side.** If $Ax \le b$ is TDI and $A$ is integral, then the [Chvátal closure](/chvatal-closure/) of $P$ is $\{x : Ax \le \lfloor b \rfloor\}$. This is Schrijver's route to the fact that the closure of a rational polyhedron is a polyhedron.

## Examples and non-examples

**A system that is not TDI, and one that is.** Both systems below describe the cone $P = \{x \in \mathbb{R}^2 : x_1 \le -|x_2|\}$, whose only vertex is the origin:

$$\text{(S1)}\quad x_1 + x_2 \le 0,\quad x_1 - x_2 \le 0; \qquad \text{(S2)}\quad x_1 + x_2 \le 0,\quad x_1 - x_2 \le 0,\quad x_1 \le 0.$$

The maximum of $c^T x$ over $P$ is finite exactly when $c$ lies in the cone generated by $(1, 1)$ and $(1, -1)$, that is, $|c_2| \le c_1$. Then the maximum is 0, and each dual feasible $y$ is optimal. For S1 with $c = (1, 0)$, the dual equations $y_1 + y_2 = 1$, $y_1 - y_2 = 0$ force $y = (1/2, 1/2)$, so S1 is not TDI. In fact S1 fails exactly for the integral $c$ in the cone with $c_1 + c_2$ odd. For S2, each such $c$ with $c_2 \ge 0$ is $c_2 (1, 1) + (c_1 - c_2)(1, 0)$, and symmetrically for $c_2 < 0$, so S2 is TDI. The rows $(1,1)$, $(1,-1)$, $(1,0)$ form a Hilbert basis of the cone, and the redundant inequality $x_1 \le 0$ is what makes the system TDI.

**Totally unimodular systems.** If $A$ is [totally unimodular](/total-unimodularity/), then $Ax \le b$ is TDI for each $b$: the dual has the matrix $A^T$, which is TU, so it has an integral optimal vertex for integral $c$. This covers flows and bipartite matching, where the [Hoffman-Kruskal theorem](/hoffman-kruskal-theorem/) already gives integrality.

**Matching (Cunningham and Marsh, 1978).** For a graph $G = (V, E)$, the system

$$x \ge 0, \qquad x(\delta(v)) \le 1 \ \ (v \in V), \qquad x(E(S)) \le \lfloor |S|/2 \rfloor \ \ (S \subseteq V,\ |S| \text{ odd})$$

is TDI. For the triangle and $c = (1, 1, 1)$, the dual $\min \sum_v y_v + y_S$ subject to covering each edge has the integral optimum $y_S = 1$ for $S = V$, with value 1. The matrix is not TU, as the triangle shows, but integrality of the [matching polytope](/matching-polytope/) follows from TDI. The integral dual is a min-max theorem: the Tutte-Berge formula for the size of a largest matching.

**Edmonds and Giles: submodular flows.** The constraint systems of submodular flows are TDI. This one framework gives integral min-max theorems for flows, matroid intersection and directed cuts, such as the Lucchesi-Younger theorem.

**A polyhedron given by a non-TDI system.** The example S1 shows that an integral polyhedron can be given by a system that is not TDI. Integrality of $P$ alone says nothing about the duals.

## Related definitions

- **[Total unimodularity](/total-unimodularity/).** A property of a matrix that makes $Ax \le b$ TDI for every $b$. TDI is weaker and depends on $b$.
- **Box-TDI.** A system $Ax \le b$ is box-TDI if $Ax \le b$, $\ell \le x \le u$ is TDI for all rational $\ell$ and $u$. Submodular flow systems are box-TDI.
- **Hilbert basis.** The algebraic object behind TDI: a system is TDI exactly when its tight rows at each face form a Hilbert basis.
- **Integral polyhedron.** A polyhedron equal to its [integer hull](/integer-hull/). TDI with integral $b$ is a sufficient condition, and every integral polyhedron has some TDI description with integral $b$.
- **[Chvátal closure](/chvatal-closure/).** For a TDI system with integral $A$, it is obtained by rounding down the right side.
- **[Subadditive duality](/subadditive-duality/).** The general duality for integer programs, of which the integral LP duals of TDI systems are a special case.
