Farkas' lemma says that a system of linear inequalities has no solution exactly when some nonnegative combination of its rows reads $0 \le -1$, up to scaling. So infeasibility, which is a claim about all points, always has a short certificate: a vector of multipliers that anyone can check by matrix multiplication. The lemma is a *theorem of the alternative*: of two linear systems, exactly one has a solution. It is the main tool behind [strong duality](/strong-duality/), and geometrically it says that a point outside a finitely generated cone can be separated from the cone by a hyperplane.

## Statement

Let $A \in \mathbb{R}^{m \times n}$ and $b \in \mathbb{R}^m$.

**Theorem (inequality form).** Exactly one of the following holds:

1. there is $x \in \mathbb{R}^n$ with $Ax \le b$;
2. there is $y \in \mathbb{R}^m$ with $y \ge 0$, $y^\top A = 0$ and $y^\top b < 0$.

**Theorem (equality form).** Exactly one of the following holds:

1. there is $x \in \mathbb{R}^n$ with $Ax = b$ and $x \ge 0$;
2. there is $y \in \mathbb{R}^m$ with $A^\top y \ge 0$ and $b^\top y < 0$.

**Theorem (mixed form).** Exactly one of the following holds:

1. there is $x \ge 0$ with $Ax \le b$;
2. there is $y \ge 0$ with $A^\top y \ge 0$ and $b^\top y < 0$.

**Geometric form.** The equality form says: $b$ lies in the cone $\{Ax : x \ge 0\}$ generated by the columns of $A$, or there is a hyperplane $\{z : y^\top z = 0\}$ with all columns on one side ($A^\top y \ge 0$) and $b$ strictly on the other ($b^\top y < 0$).

With rational data, a certificate $y$ can be chosen rational, with size polynomial in the size of $(A, b)$.

## In plain words

Suppose a list of linear limits has no common solution. Then you can prove it in a way that anyone can check: multiply each limit by a nonnegative number and add them up, so that all the unknowns cancel and what is left says that zero is at most a negative number. That is plainly false, so the limits cannot all hold. Farkas' lemma says that such a proof always exists. Either the system has a solution, or it has this kind of proof of having none, and never both.

## Proof

*At most one holds.* In the inequality form, if $Ax \le b$ and $y$ is as in 2, then $0 = y^\top A x \le y^\top b < 0$, because $y \ge 0$ preserves the inequalities. This is a contradiction.

*At least one holds.* The proof is [Fourier-Motzkin elimination](/fourier-motzkin-elimination/), by induction on $n$. For $n = 0$ the system reads $0 \le b_i$ for each row. If it fails, some $b_i < 0$, and $y = e_i$ is a certificate.

For $n \ge 1$, split the rows by the sign of the coefficient of $x_n$: the set $P$ with $a_{in} > 0$, $N$ with $a_{in} < 0$, and $Z$ with $a_{in} = 0$. Build a new system in $x_1, \ldots, x_{n-1}$: keep each row of $Z$, and for each pair $p \in P$, $q \in N$ add the row

$$(-a_{qn}) \cdot (\text{row } p) + a_{pn} \cdot (\text{row } q),$$

in which the coefficient of $x_n$ is $-a_{qn} a_{pn} + a_{pn} a_{qn} = 0$. Each new row is a combination of the old rows with nonnegative multipliers.

*Claim.* The new system $A' x' \le b'$ has a solution if and only if $Ax \le b$ has one. If $x$ solves the old system, its first $n - 1$ coordinates solve each new row, since each new row is a nonnegative combination of rows that $x$ satisfies. Conversely, let $x'$ solve the new system. Each row $p \in P$ says $x_n \le u_p(x') = (b_p - \sum_{j < n} a_{pj} x'_j)/a_{pn}$, and each row $q \in N$ says $x_n \ge \ell_q(x') = (b_q - \sum_{j < n} a_{qj} x'_j)/a_{qn}$. The combined row for $(p, q)$, divided by the positive number $a_{pn}(-a_{qn})$, is exactly $\ell_q(x') \le u_p(x')$. So $\max_q \ell_q(x') \le \min_p u_p(x')$, with the conventions $\max \emptyset = -\infty$ and $\min \emptyset = +\infty$, and any $x_n$ in this interval gives a solution $(x', x_n)$ of the old system, since the rows of $Z$ do not involve $x_n$.

Now suppose $Ax \le b$ has no solution. By the claim, neither does $A' x' \le b'$, and by induction there is $y' \ge 0$ with $y'^\top A' = 0$ and $y'^\top b' < 0$. Each row of $(A' \mid b')$ is $w^\top (A \mid b)$ for a vector $w \ge 0$ whose coefficient on $x_n$ is zero, as shown above. Let $W$ be the matrix with these vectors as rows, so $(A' \mid b') = W (A \mid b)$, and put $y = W^\top y' \ge 0$. Then $y^\top A$ has zero coefficients on $x_1, \ldots, x_{n-1}$ because $y'^\top A' = 0$, and on $x_n$ because each $w$ cancels $x_n$. Also $y^\top b = y'^\top b' < 0$. So $y$ is a certificate.

*Equality form.* Write $Ax = b$, $x \ge 0$ as $Ax \le b$, $-Ax \le -b$, $-x \le 0$. If it has no solution, the inequality form gives $u, v, w \ge 0$ with $A^\top u - A^\top v - w = 0$ and $b^\top u - b^\top v < 0$. Put $y = u - v$. Then $A^\top y = w \ge 0$ and $b^\top y < 0$. Conversely, $Ax = b$, $x \ge 0$ and $A^\top y \ge 0$ give $b^\top y = x^\top A^\top y \ge 0$, so both cannot hold.

*Mixed form.* Write the system as $Ax \le b$, $-x \le 0$ and apply the inequality form: $u, w \ge 0$ with $A^\top u - w = 0$, $b^\top u < 0$, so $y = u$ has $A^\top y = w \ge 0$. The converse is as before.

*Rational size.* Elimination with rational data gives rational multipliers. A certificate of small size exists by a vertex argument: the set of $y \ge 0$ with $y^\top A = 0$ and $y^\top b = -1$ is a nonempty polyhedron in $\{y \ge 0\}$, so it has a vertex, and a vertex has size polynomial in the input by [Cramer's rule](/cramers-rule/). $\blacksquare$

## Consequences

- **Strong duality.** Applied to the system "dual feasible and $b^\top y \le \gamma$", the lemma gives the [strong duality theorem](/strong-duality/); see the proof there.
- **Certificates of infeasibility.** A solver that reports an infeasible LP can return a Farkas vector, and the user can check it without trusting the solver. Phase 1 of the [two-phase simplex method](/two-phase-simplex-method/), the [Fourier-Motzkin](/fourier-motzkin-elimination/) implementation on this site, and homogeneous interior point methods all produce one.
- **Linear feasibility is in NP and coNP.** A solution and a Farkas vector are both short certificates, which made [linear feasibility](/linear-feasibility/) a [good characterization](/good-characterization/) long before it was known to be in P.
- **Separation of cones.** The geometric form is the polyhedral case of the [separating hyperplane theorem](/separating-hyperplane-theorem/), with no topology needed. It also leads to the [Minkowski-Weyl theorem](/minkowski-weyl-theorem/) and, with [Carathéodory's theorem](/caratheodory-theorem/), to the closedness of finitely generated cones.
- **Optimality conditions.** The [KKT conditions](/kkt-conditions/) for problems with linear constraints follow from the lemma: at a local optimum, no feasible direction improves the objective, and Farkas turns this into multipliers.
- **Other alternatives.** The same method proves Gordan's theorem ($Ax < 0$ has a solution, or $y^\top A = 0$ for some $y \ge 0$, $y \ne 0$) and Motzkin's transposition theorem for mixed strict and weak inequalities.

## Tightness

**A certificate.** The system $x_1 + x_2 \le 1$, $-x_1 \le -2$, $-x_2 \le 0$ (that is, $x_1 + x_2 \le 1$, $x_1 \ge 2$, $x_2 \ge 0$) has no solution. The multipliers $y = (1, 1, 1)$ add the rows to $0 \cdot x_1 + 0 \cdot x_2 \le 1 - 2 + 0 = -1$.

**Strict inequalities.** The lemma is about weak inequalities. The system $x_1 < 0$, $-x_1 < 0$ is infeasible, but the only $y \ge 0$ with $y^\top A = 0$ is $y_1 = y_2$, which gives $y^\top b = 0$, not $< 0$. Strict systems need Motzkin's version, where the certificate may also have $y^\top b = 0$ with a positive weight on a strict row.

**Integer solutions.** The lemma fails for integer variables: $2x_1 = 1$ has no integer solution, but it has the real solution $1/2$, so no Farkas vector exists. Integer systems of equations need a different certificate (a $y$ with $y^\top A$ integral and $y^\top b$ not integral), and integer systems of inequalities have no short certificate unless NP = coNP.

**Nonlinear systems.** $x_1^2 \le -1$ has no solution, but it is not linear, and no combination of linear rows proves it. Convex systems need a constraint qualification for a similar result.

**Infinite systems.** For infinitely many inequalities the lemma can fail. The system $x_1 \ge k$ for all integers $k \ge 1$ is infeasible, but every finite subsystem is feasible. A finite certificate would make a finite subsystem infeasible by the easy direction, so no certificate exists.

## History

Gyula (Julius) Farkas published versions of the lemma from 1894 on, in work on Fourier's principle of mechanical equilibrium, and gave the full proof in 1902. Hermann Minkowski proved a related result in 1896, and the lemma is sometimes called the Farkas-Minkowski lemma. The elimination method goes back to Joseph Fourier in 1826 and was rediscovered by Theodore Motzkin in his 1936 thesis. After 1947 the lemma became the standard route to LP duality, and it is the prototype of the theorems of the alternative that now appear throughout optimization.
