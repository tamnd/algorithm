---
title: Seidel's algorithm is correct and runs in expected O(n! m) time
proves: [correctness, complexity]
status: full
---

**Setting.** Let $B$ be the box $-M \le x_j \le M$, $h_1, \ldots, h_m$ the constraints in the order of line L3, $Q_i = B \cap h_1 \cap \cdots \cap h_i$, and $\Phi(x) = (c^\top x, x_1, \ldots, x_n)$. Write $x \prec y$ if $\Phi(x)$ is lexicographically less than $\Phi(y)$. Since $\Phi$ is linear and its last $n$ entries are the coordinates, $\Phi$ is injective, and $\prec$ is a total order on $\mathbb{R}^n$. In a recursive call, the objectives are the restrictions of these $n + 1$ linear functions, and the list still contains every remaining coordinate (substitution does not change $x_j$ for $j \ne k$), so the same holds there.

**Claim 1 (a unique optimum).** If $Q_i \ne \emptyset$, it has exactly one $\prec$-least point $x_i$. Proof: $Q_i$ is a nonempty polytope. Its set of minimizers of $c^\top x$ is a nonempty face, the minimizers of $x_1$ on that face form a nonempty face, and so on. After the $n$ coordinates the face is a single point. Line L2 returns $x_0$: on the box, each coordinate is set by the first of the $n + 1$ functions that depends on it, which is the lexicographic minimum on a product of intervals. Line L1 is the case $n = 1$ by the same argument.

**Claim 2 (the step).** Let $Q_i \ne \emptyset$. If $x_{i-1}$ satisfies $h_i$, then $x_i = x_{i-1}$. If not, then $a_i^\top x_i = b_i$. Proof: In the first case $x_{i-1} \in Q_i \subseteq Q_{i-1}$, and it is least in the larger set. In the second case, suppose $a_i^\top x_i < b_i$. The segment $z(t) = x_i + t(x_{i-1} - x_i)$, $0 \le t \le 1$, lies in $Q_{i-1}$ by convexity, and $a_i^\top z(1) > b_i$, so some $t^* \in (0, 1)$ has $a_i^\top z(t^*) = b_i$ and $z(t^*) \in Q_i$. Now $\Phi(z(t^*)) = \Phi(x_i) + t^* (\Phi(x_{i-1}) - \Phi(x_i))$. Since $x_{i-1} \preceq x_i$ and $x_{i-1} \ne x_i$, the vector $\Phi(x_{i-1}) - \Phi(x_i)$ is lexicographically negative, so $z(t^*) \prec x_i$, which contradicts the choice of $x_i$.

So if $x_{i-1}$ violates $h_i$, then $x_i$ is the least point of $Q_{i-1} \cap \{a_i^\top x = b_i\}$, and if that set is empty, so is $Q_i$. The substitution of line L6 maps the hyperplane one to one onto $\mathbb{R}^{n-1}$. It maps $Q_{i-1} \cap \{a_i^\top x = b_i\}$ onto the set of the smaller problem: the earlier constraints and the two box constraints of $x_k$ become its rows, and the box of the other coordinates stays. Each objective changes by a constant, so the order $\prec$ is kept. By induction on $n$, the call returns $x_i$ or INFEASIBLE correctly. If $Q_{i-1}$ is already empty, an earlier step returned INFEASIBLE. If $a_i = 0$ and $b_i < 0$, then $Q_i = \emptyset$, as the code reports. By induction on $i$, line L8 returns $x_m$, and INFEASIBLE is returned exactly when $Q_m = \emptyset$.

**Claim 3 (the box).** Let the data be integers of absolute value at most $K$, let $P = \{x : Ax \le b\}$, $H = (nK)^n$ and $M = 2nKH^2 + H + 1$. Then $P = \emptyset$ exactly when $Q_m = \emptyset$; $c^\top x$ is unbounded below on $P$ exactly when $c^\top x_m < -nKH$; and otherwise $x_m$ is optimal for $P$.

Proof: A minimal face of a nonempty polyhedron is $\{x : A_I x = b_I\}$ for some rows $I$. Choose $r = \operatorname{rank} A_I$ independent rows and $r$ columns with a nonsingular $r \times r$ submatrix, and set the other variables to $0$. By Cramer's rule each $x_j$ is a quotient of two integer determinants of order $r \le n$, the denominator is at least $1$ in absolute value, and by Hadamard's bound the numerator is at most $(\sqrt{r} K)^r \le H$. So every nonempty polyhedron given by such data has a point with $|x_j| \le H$ in each minimal face. If $P \ne \emptyset$, it has such a point, which lies in $B$, so $Q_m \ne \emptyset$. If $c^\top x$ is bounded below on $P$, the optimal set is a face of $P$, and a minimal face in it gives an optimal point $x^\circ$ with $|x^\circ_j| \le H < M$. So $\min_{Q_m} c^\top x = c^\top x^\circ \ge -nKH$, and $x_m$ is optimal for $P$. If it is unbounded, the polyhedron $\{d : Ad \le 0, c^\top d \le -1\}$ is nonempty, and the same argument gives a point $d = (\det_j / \det)_j$. Then $d' = |\det|\, d$ is an integer vector with $|d'_j| \le H$, $A d' \le 0$ and $c^\top d' \le -1$. With $x^\circ \in P$, $|x^\circ_j| \le H$ and $t = (M - H)/H$, the point $x^\circ + t d'$ lies in $P \cap B$ and has $c^\top x \le nKH - t < nKH - 2nKH = -nKH$. So $c^\top x_m < -nKH$.

**Claim 4 (backwards analysis).** For each $i$, the probability that line L6 runs at step $i$ is at most $n / i$. Proof: Condition on the set $S$ of the first $i$ constraints; then $h_i$ is uniform in $S$. Fix $\varepsilon > 0$ so small that, for every subset $T \subseteq S$ with $B \cap T \ne \emptyset$, the least point of $B \cap T$ is the unique minimizer of $c_\varepsilon^\top x$ with $c_\varepsilon = c + \sum_j \varepsilon^j e_j$ (finitely many polytopes, each with finitely many vertices). By the optimality condition at the vertex $x_i$, $-c_\varepsilon$ is a nonnegative combination of the normals of the constraints that are tight at $x_i$, and by Carathéodory's theorem at most $n$ of them suffice. Let $T$ be the members of $S$ among them, so $|T| \le n$. Then $x_i$ minimizes $c_\varepsilon^\top x$ over $B \cap T$, so $x_i$ is the least point of $B \cap T$. If $h_i \notin T$, then $B \cap T \supseteq Q_{i-1} \supseteq Q_i$, so $x_i \preceq x_{i-1} \preceq x_i$, and $x_{i-1} = x_i$ satisfies $h_i$; no call happens. So a call needs $h_i \in T$, with probability at most $|T|/i \le n/i$. If $Q_i = \emptyset$, the run ends at step $i$ at the latest, which costs at most one call.

**Claim 5 (time).** Let $T_n(r)$ bound the expected number of operations on any input of $r$ constraints in $n$ variables, and let $a$ be a constant such that a test at line L5 costs at most $an$, and the substitution of a call at step $i$ at most $an(i + n)$. Then $T_1(r) \le ar$, and by Claim 4 and linearity of expectation,
$$T_n(m) \le anm + \sum_{i=1}^{m} \frac{n}{i}\big(an(i + n) + T_{n-1}(i + 1)\big).$$
The call at step $i$ has $i - 1$ earlier constraints and two from the box. We show by induction that $T_n(m) \le C_n m + D_n L^n$ with $L = 1 + \ln(m + 1)$, where $C_1 = a$, $D_1 = 0$. Use $\sum_{i \le m} 1/i \le L$ and $T_{n-1}(i + 1) \le C_{n-1}(i + 1) + D_{n-1} L^{n-1}$:
$$T_n(m) \le \big(an + an^2 + nC_{n-1}\big) m + \big(an^3 + nC_{n-1} + nD_{n-1}\big) L^n.$$
So $C_n = nC_{n-1} + a(n + n^2)$ and $D_n$ depends only on $n$. Divide by $n!$: $C_n/n! = C_{n-1}/(n-1)! + a(n + n^2)/n!$, and since $\sum_k (k + k^2)/k! = 3e$, we get $C_n \le (1 + 3e)\, a\, n!$. For fixed $n$, $L^n = o(m)$, so the expected time is $O(n!\, m)$. $\blacksquare$
