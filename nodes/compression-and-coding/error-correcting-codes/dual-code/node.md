The dual code $C^\perp$ of a [linear code](/linear-code/) $C$ of length $n$ is the set of all words of length $n$ whose inner product with every codeword of $C$ is zero. If $C$ has dimension $k$, then $C^\perp$ has dimension $n - k$, its generator matrix is a [parity-check matrix](/parity-check-matrix/) of $C$, and the reverse. Unlike orthogonal complements over the real numbers, $C$ and $C^\perp$ can overlap or even be equal, and the codes with $C = C^\perp$ include some of the best codes known.

## Definition

**Notation.** $C$ is an $[n, k, d]_q$ linear code over $\mathrm{GF}(q)$ with $k \times n$ generator matrix $G$, so $c = m G$, and parity-check matrix $H$, so $H c^T = 0$. Vectors are rows. The inner product of $x, y \in \mathrm{GF}(q)^n$ is

$$x \cdot y = x_1 y_1 + x_2 y_2 + \cdots + x_n y_n = x y^T \in \mathrm{GF}(q).$$

The **dual code** of $C$ is

$$C^\perp = \{\, x \in \mathrm{GF}(q)^n : x \cdot c = 0 \text{ for all } c \in C \,\}.$$

It is enough to test the rows of $G$: $x \in C^\perp$ if and only if $G x^T = 0$, because each codeword is a combination of the rows. So $C^\perp$ is the [null space](/nullspace/) of $G$, a linear code.

**Basic facts.**

1. $\dim C^\perp = n - k$. *Proof.* $C^\perp$ is the null space of $G$, which has rank $k$, so by the [rank-nullity theorem](/rank-nullity-theorem/) its dimension is $n - k$. $\blacksquare$
2. $(C^\perp)^\perp = C$. *Proof.* Each $c \in C$ is orthogonal to all of $C^\perp$, so $C \subseteq (C^\perp)^\perp$. Both have dimension $n - (n - k) = k$, so they are equal. $\blacksquare$
3. $H$ is a parity-check matrix of $C$ if and only if $H$ is a generator matrix of $C^\perp$. So the pair $(G, H)$ of $C$ is the pair $(H, G)$ of $C^\perp$, and $G H^T = 0$ says each row of $G$ is orthogonal to each row of $H$. From a systematic $G = [I_k \mid P]$, the dual is generated by $[-P^T \mid I_{n-k}]$.
4. **Dual distance and orthogonal arrays.** Let $d^\perp$ be the minimum distance of $C^\perp$. Since $G$ is a parity-check matrix of $C^\perp$, every $d^\perp - 1$ columns of $G$ are independent (see [parity-check matrix](/parity-check-matrix/)). So for any $t \le d^\perp - 1$ positions, the map $m \mapsto (m G)$ restricted to those positions is onto $\mathrm{GF}(q)^t$, and each of the $q^t$ patterns appears in exactly $q^{k - t}$ codewords. The codewords form an orthogonal array of strength $d^\perp - 1$.
5. **Weights.** The weight distribution of $C$ fixes that of $C^\perp$. This is the [MacWilliams identity](/macwilliams-identity/).

**Self-orthogonal and self-dual codes.** $C$ is **self-orthogonal** when $C \subseteq C^\perp$, which holds if and only if $G G^T = 0$, that is, all rows of $G$ are orthogonal to each other and to themselves. This needs $k \le n - k$. $C$ is **self-dual** when $C = C^\perp$, which holds if and only if $C$ is self-orthogonal and $n = 2k$.

- Over $\mathrm{GF}(2)$, $x \cdot x = \mathrm{wt}(x) \bmod 2$, so every codeword of a self-orthogonal binary code has even weight. If $G G^T = 0$ and every row of $G$ has a weight divisible by 4, then every codeword has a weight divisible by 4, because $\mathrm{wt}(x + y) = \mathrm{wt}(x) + \mathrm{wt}(y) - 2\, |\mathrm{supp}(x) \cap \mathrm{supp}(y)|$ and the overlap is even when $x \cdot y = 0$. Such codes are called doubly even.
- Over $\mathrm{GF}(3)$, $x_i^2 = 1$ for $x_i \ne 0$, so $x \cdot x = \mathrm{wt}(x) \bmod 3$, and every codeword of a self-orthogonal ternary code has a weight divisible by 3.

## Examples and non-examples

**Examples.**

- **Repetition and even weight codes.** The dual of the $[n, 1, n]$ [repetition code](/repetition-code/) is the $[n, n - 1, 2]$ even weight code: $x \cdot (1, \ldots, 1) = 0$ says $x$ has an even number of ones.
- **Hamming and simplex codes.** The dual of the $[7, 4, 3]$ [Hamming code](/hamming-code/) is the $[7, 3, 4]$ [simplex code](/simplex-code/), generated by the parity-check matrix of the Hamming code. Its 7 nonzero codewords all have weight 4. The simplex code is self-orthogonal (its generator matrix has $G G^T = 0$) and lies inside the Hamming code, but it is not self-dual, since $3 \ne 7 - 3$.
- **Extended Hamming code.** Add an overall parity bit to the Hamming code. The $[8, 4, 4]$ code has $G G^T = 0$ and $n = 2k$, so it is self-dual. Its weight distribution is $1, 14, 1$ at the weights $0, 4, 8$: doubly even.
- **Extended Golay code.** The binary [Golay code](/golay-code/) of length 23 with generator polynomial $1 + x^2 + x^4 + x^5 + x^6 + x^{10} + x^{11}$, extended by a parity bit, is a self-dual $[24, 12, 8]$ code. Its weight distribution is $1, 759, 2576, 759, 1$ at the weights $0, 8, 12, 16, 24$, all divisible by 4.
- **Small self-dual codes.** $\{00, 11\}$ is a self-dual $[2, 1, 2]$ code: $11 \cdot 11 = 1 + 1 = 0$ in $\mathrm{GF}(2)$. Over $\mathrm{GF}(3)$, the tetracode with rows $1011$ and $0112$ is a self-dual $[4, 2, 3]_3$ code: $1011 \cdot 1011 = 3 = 0$, $0112 \cdot 0112 = 6 = 0$ and $1011 \cdot 0112 = 3 = 0$ modulo 3.
- **Reed-Muller codes.** The dual of the [Reed-Muller code](/reed-muller-code/) $\mathrm{RM}(r, m)$ is $\mathrm{RM}(m - r - 1, m)$.

**Non-examples.**

- **Not a complement.** Over the real numbers, $V \cap V^\perp = \{0\}$ and $V + V^\perp$ is the whole space. Over a finite field both can fail: in $\{00, 11\}$ the word $11$ is orthogonal to itself, and $C \cap C^\perp = C$. Arguments that project a word onto $C$ along $C^\perp$ do not work in general.
- **Not self-orthogonal.** The repetition code $\{000, 111\}$ has $111 \cdot 111 = 3 = 1$ in $\mathrm{GF}(2)$. A codeword of odd weight is never orthogonal to itself over $\mathrm{GF}(2)$.
- **The Hamming code is not self-orthogonal.** The rows $1000110$ and $0100011$ of its generator matrix have the inner product 1, since they share only the sixth position. The row $1000110$ also has odd weight, so it is not orthogonal to itself.
- **The Hermitian dual.** Over $\mathrm{GF}(4)$, quantum code constructions often use the Hermitian inner product $\sum x_i y_i^2$. The Hermitian dual is a different code from the dual on this page.
- **Walsh codes.** In CDMA, "orthogonal codes" are sets of $\pm 1$ sequences with zero real correlation, such as the rows of a Hadamard matrix. That use of the words is not about the dual of a linear code.
