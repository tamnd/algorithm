---
title: The baseline JPEG decoder recovers the quantized coefficients exactly, and the decoded image obeys an error bound set by the quantization table
proves: [correctness]
status: full
---

**Setup.** The input is a greyscale image with samples in $\{0, \ldots, 255\}$, padded to whole $8 \times 8$ blocks by repeating the last row and column. For one block, let $s$ be the 64 samples minus 128, so $-128 \le s_i \le 127$. Let $T$ be the FDCT of A.3.3 as a linear map on $\mathbb{R}^{64}$, $F = T s$, and let $Q$ be the quantization table with entries $1 \le Q_k \le 255$. The encoder computes $S_k = \mathrm{round}(F_k / Q_k)$ (line L5), the decoder computes $R_k = S_k Q_k$, then $r = T^{-1} R$, and outputs $\hat x_i = \mathrm{clamp}_{[0, 255]}(\mathrm{round}(r_i + 128))$ (line L14).

**Lemma 1 (the DCT is orthonormal).** The 1D matrix $M_{u x} = \frac{C_u}{2} \cos\frac{(2x+1) u \pi}{16}$, with $C_0 = 1/\sqrt 2$ and $C_u = 1$ otherwise, is orthogonal, and $T = M \otimes M$. So $T^{-1} = T^{\mathsf T}$ and $\|T v\|_2 = \|v\|_2$ for every $v$.

*Proof.* For $u \ne u'$, $\sum_{x=0}^{7} \cos\frac{(2x+1)u\pi}{16} \cos\frac{(2x+1)u'\pi}{16} = 0$, and the sum of squares is 8 for $u = 0$ and 4 for $u \ne 0$; with the factors $C_u^2/4$ each row has norm 1. The formula of A.3.3, $F(v, u) = \frac14 C_u C_v \sum_{x, y} s(y, x) \cos\frac{(2x+1)u\pi}{16} \cos\frac{(2y+1)v\pi}{16}$, is $M s M^{\mathsf T}$ for $s$ as an $8 \times 8$ matrix, which is $(M \otimes M)$ applied to the samples. A Kronecker product of orthogonal matrices is orthogonal. $\square$

**Lemma 2 (the values fit the baseline categories).** $|S_0| \le 1024$, so every DC difference has category at most 11, and $|S_k| \le 1020$ for $k \ge 1$, so every AC value has category at most 10.

*Proof.* Row 0 of $T$ is the constant $1/8$, so $F_0 = \frac18 \sum_i s_i \in [-1024, 1016]$ and, since $Q_0 \ge 1$, $|S_0| \le 1024$. A difference of two such values is at most 2040 in absolute value, below $2^{11}$. For $k \ge 1$, row $k$ of $T$ is orthogonal to row 0, so $F_k = \langle t_k, s + \tfrac12 \mathbf 1 \rangle$ where $t_k$ is that row. Each entry of $s + \frac12 \mathbf 1$ lies in $[-127.5, 127.5]$, so by the Cauchy-Schwarz inequality $|F_k| \le \|t_k\|_2 \cdot 8 \cdot 127.5 = 1020$, and $|S_k| \le \mathrm{round}(1020) = 1020 < 2^{10}$. $\square$

**Lemma 3 (the entropy-coded layer is lossless).** For every image, the decoder of lines L11 to L13 recovers, block by block, exactly the sequence of values $S$ that lines L5 to L8 coded.

*Proof.* The bytes are first undone: the encoder writes a 0x00 after each 0xFF byte of entropy-coded data (F.1.2.3), and no byte 0xFF that it writes is followed by any other value, so the reader that drops each 0x00 after 0xFF returns the exact bit string, followed by the padding 1-bits. The Huffman tables of Annex C are prefix codes: Figure C.2 gives the codes of each length as consecutive integers, and moves to the next length by adding one and shifting left, so no code is a prefix of a later one. The procedure DECODE (F.2.2.3) reads one bit at a time and stops at the first length $\ell$ at which the value read is at most MAXCODE$[\ell]$. Codes of length $\ell$ are the integers from MINCODE$[\ell]$ to MAXCODE$[\ell]$, and a prefix of length $\ell$ of a longer code is greater than MAXCODE$[\ell]$ by the shift rule, so DECODE stops exactly at the end of the codeword that the encoder wrote and returns its symbol.

For one block, the encoder writes the category $s$ of the DC difference and the $s$ low bits of the difference (minus one if negative); EXTEND inverts this map on $\{-(2^s - 1), \ldots, 2^s - 1\} \setminus (-2^{s-1}, 2^{s-1})$, which is exactly the set of values of category $s$. Adding the difference to the previous DC value, which the decoder holds as the encoder did (both start at 0), gives $S_0$. For the AC values, each symbol RRRRSSSS with $S \ne 0$ means RRRR zeros and then one value of category SSSS, ZRL means 16 zeros, and EOB means that the rest is zero. The encoder writes ZRL only before a nonzero value and EOB only after the last nonzero value when it is not at position 63, so the decoder's counter $k$ follows the encoder's position and stops at 64 or at EOB with all 63 values placed. By induction over the blocks, the decoder holds the same DC predictor and the same position in the bit string at the start of each block. The header segments give the decoder the same tables and image size as the encoder. $\square$

**Theorem (error bound).** Let $B = \frac12 \sqrt{\textstyle\sum_k Q_k^2}$. For every padded block, $\|x - \hat x\|_2 \le B + 4$, and every decoded sample has $|x_i - \hat x_i| \le B + \frac12$. So when the height and width are multiples of 8, the mean squared error of the image is at most $(B + 4)^2 / 64$.

*Proof.* By Lemma 3 the decoder has the true $S$. Rounding gives $|F_k / Q_k - S_k| \le \frac12$, so $|F_k - R_k| \le Q_k / 2$ and $\|F - R\|_2 \le B$. By Lemma 1, $\|s - r\|_2 = \|T^{\mathsf T}(F - R)\|_2 = \|F - R\|_2 \le B$. Rounding $r_i + 128$ moves each value by at most $\frac12$, which adds at most $\sqrt{64 \cdot \frac14} = 4$ to the norm by the triangle inequality, and at most $\frac12$ to one sample, whose error before rounding is at most $\|s - r\|_2$. Clamping to $[0, 255]$ moves a value toward the interval that contains $x_i$, so it does not increase $|x_i - \hat x_i|$. When the sides are multiples of 8 there is no padding, the image is the union of its blocks, and its squared error is the sum of the block errors, each at most $(B + 4)^2$. $\blacksquare$

When a side is not a multiple of 8, the decoder crops the padded blocks, and the kept part of a block can hold most of that block's error, so only the per-sample bound $B + \frac12$ applies to the cropped image.

For the table K.1, $\sum_k Q_k^2 = 288\,028$, which gives MSE at most 1158.9 and PSNR at least 17.49 dB. When all $Q_k = 1$, the bound is MSE at most 1 and PSNR at least 48.13 dB. The bound covers the worst case; smooth images do much better, because most $F_k$ are far smaller than $Q_k$ and then $|F_k - R_k| = |F_k|$.
