---
title: The CABAC engine keeps its registers in bounds, its decoder returns every bin, and the stream has at most nine bits more than the coded information
proves: [correctness, termination, length]
status: full
---

Notation. A *shift* is one doubling of the coding interval: one pass of the loop at L10 to L14, or line L17 of a bypass bin. Let $s$ be the number of shifts so far. Next to the registers, consider an exact coder with an unbounded integer $A$: it starts with $A = 0$, adds what line L5 or L22 adds to $low$, and at each shift sets $A \leftarrow 2A$ (plus $range$ at line L17 for a bypass 1). The coding interval at step $s$ is $[A, A + range)$, in units of $2^{-(s + 10)}$. Let $W$ be the integer whose binary digits are the bits given to PUT-BIT so far, the first one (which line L15 does not write) included, and let $o$ be the value of $outstanding$.

**Lemma 1 (bounds).** Before and after each bin, $256 \le range \le 510$ and $low + range \le 1024$. Each LPS and each MPS part is nonempty.

*Proof.* At L1, $range = 510$ and $low = 0$. Line L2 picks the column $q$ for which $256 + 64q \le range \le 319 + 64q$. In Table 9-44, each entry of column $q$ of the states 0 to 62 is less than $256 + 64q$, and at least 6, so $0 < rLPS < range$ and both parts are nonempty. A split keeps the new interval inside the old one, so $low + range \le 1024$ still holds. In a pass of L10 to L14, $range < 256$. If $low < 256$, then $low + range < 512$. If $low \ge 512$, then after the subtraction $low + range \le 512$. Otherwise $256 \le low < 512$, so $low + range < 768$, and after the subtraction $low + range < 512$. In all three cases the doubling at L14 gives $low + range \le 1024$. The loop stops at the first $range \ge 256$, and $range \le 2 \cdot 255 = 510$. A bypass bin does not change $range$. Line L17 gives $low + range \le 2048$ with the new $low$, and the three cases of L18 to L20 bring it back to at most 1024 in the same way. A terminate 0 bin at L21 takes 2 from $range$ and renormalizes. $\square$

**Lemma 2 (the output).** After each step, $A = W \cdot 2^{10 + o} + low + 512 (2^o - 1)$, and $W$ has $s - o$ digits.

*Proof.* At the start both sides are 0. A split adds the same amount to $A$ and to $low$. Consider a pass of L10 to L14 and write $A' = 2A$. In the middle case (L13), $low' = 2(low - 256)$ and $o' = o + 1$, and $W 2^{11 + o} + 2low - 512 + 512(2^{o+1} - 1) = 2A$. If $low \ge 512$ (L12), PUT-BIT appends 1 and $o$ zeros, so $W' = W 2^{o+1} + 2^o$ and $o' = 0$, and $W' 2^{10} + 2(low - 512) = W 2^{11+o} + 2^{10+o} + 2low - 1024 = 2A$. If $low < 256$ (L11), PUT-BIT appends 0 and $o$ ones, so $W' = W 2^{o+1} + 2^o - 1$, and $W' 2^{10} + 2low = 2A$. The bypass cases at L18 to L20 are the same computation with the doubling done first and the bounds 1024 and 512. Each shift adds one digit to $W$ or one to $o$. $\square$

So the bits of $W$ are a prefix of the final stream, and the outstanding bits are resolved by the next call to PUT-BIT. The first digit of $W$ is 0: before the first shift, $A + range \le 510 < 512$, so the interval lies in the lower half and every later interval is inside it. This is why line L15 can drop it.

**Lemma 3 (the end).** Let $s$ be the number of shifts before the final terminate bin. The stream has exactly $s + 9$ bits, the last of them 1, and its value, read as a number at scale $s$, lies in the interval of that bin.

*Proof.* Line L22 makes the interval $[A + range - 2, A + range)$ and sets $range = 2$. The renormalization doubles it 7 times, to width 256, so $s_f = s + 7$ and the 7 low bits of $low$ are 0. Then PUT-BIT($\lfloor low/512 \rfloor \bmod 2$) leaves, by the computation of Lemma 2 without the doubling, $A = W 2^9 + r$ with $r \in \{0, 128, 256, 384\}$. The two last bits are $c = \lfloor r/128 \rfloor$ with its low bit set to 1, so $128c$ is $r$ or $r + 128$, and $W 2^9 + 128c \in [A, A + 256)$. The bits are $W$ ($s_f + 1$ digits with the dropped one) and $c$, so the stream has $s_f + 3 - 1 = s + 9$ bits. Followed by seven 0 bits, it has the value $W 2^9 + 128c$ at scale $s_f$, which is in the final interval. Dropping the 7 low bits gives its value at scale $s$, inside the interval of the terminate bin. $\square$

**Theorem 1 (correctness).** For any sequence of decision, bypass and terminate bins that ends with a terminate 1, with the same initial contexts on both sides, the decoder returns every bin and reads exactly the bits of the stream.

*Proof.* Let $T_j$ be the integer value of the first $j + 10$ bits of the stream, the dropped 0 included, with 0 bits after the end. The intervals are nested: the interval after a shift lies inside the double of the interval before it. By Lemma 3, $T_s$ is in the interval of the final terminate bin. Since $\lfloor T_{j+1} / 2 \rfloor = T_j$, going back shift by shift shows that $T_j$ lies in the interval $[A_j, A_j + range_j)$ of every step. The decoder starts with $offset = T_0$ (L24), and it shifts in one bit whenever the encoder shifts (L28, L30 and L33), so by induction $offset = T_j - A_j$, where $A_j$ is the value of the exact coder. At a decision bin, $T_j$ lies in the MPS part $[A_j, A_j + range - rLPS)$ or in the LPS part above it, so the test $offset \ge range - rLPS$ at L26 gives the bin of the encoder, and lines L26 and L27 update $offset$, $range$ and the context as the encoder does. The same holds for a bypass bin at L31, whose parts are $[2A, 2A + range)$ and $[2A + range, 2A + 2 range)$, and for a terminate bin at L33. After the last bin the decoder has read $9 + s$ bits, which by Lemma 3 is the length of the stream. $\square$

**Theorem 2 (length).** Let $p_i$ be the probability that the coder gives bin $i$: $rLPS/range$ or $1 - rLPS/range$ for a decision bin, $\tfrac12$ for a bypass bin, $2/range$ or $1 - 2/range$ for a terminate bin. Then the stream has at most $\sum_i \lg(1/p_i) + 9$ bits, the final terminate bin included.

*Proof.* Each bin multiplies the width by $p_i$, and each shift doubles it, so before the final terminate bin, $510 \cdot \prod_{i} p_i \cdot 2^s = range \le 510$. So $s \le \sum_i \lg(1/p_i)$ over these bins, and by Lemma 3 the stream has $s + 9$ bits. The final bin adds a nonnegative term to the sum. $\square$

**Termination.** Each bin does a constant amount of work apart from the loops at L10 and L28. Each pass doubles $range$, which is at least 2 when the loop starts, so a loop makes at most 7 passes. PUT-BIT writes the outstanding bits once each, so the total work is linear in the number of bins plus the length of the stream. $\blacksquare$
