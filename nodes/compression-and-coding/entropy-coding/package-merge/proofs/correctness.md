---
title: Correctness of package-merge
proves: [correctness]
status: full
---

Let $w_1 \le w_2 \le \cdots \le w_n$ be non-negative weights with $n \ge 2$, and let $L$ be a limit with $2^L \ge n$. We show that PACKAGE-MERGE returns lengths $l_i \le L$ that satisfy the Kraft inequality and minimize $\sum_i w_i l_i$. The proof follows Larmore and Hirschberg (1990): a reduction to a coin problem, a greedy lemma for that coin problem, and a check of the expansion step.

**The coin problem.** For each symbol $i$ and each depth $d = 1, \ldots, L$ there is a coin $(i, d)$ with face value $2^{-d}$ and cost $w_i$. A *coin set* is a set $S$ of coins with total face value exactly $n - 1$. Its cost is the sum of the costs of its coins. For a coin set $S$, let $l_i(S)$ be the number of coins of symbol $i$ in $S$.

**Lemma 1.** (a) For each coin set $S$, the lengths $l_i = l_i(S)$ satisfy $1 \le l_i \le L$ and $\sum_i 2^{-l_i} \le 1$, and $\sum_i w_i l_i$ is the cost of $S$. (b) For each list of lengths $1 \le l_i \le L$ with $\sum_i 2^{-l_i} = 1$, the set $\{(i, d) : d \le l_i\}$ is a coin set with cost $\sum_i w_i l_i$. (c) Some optimal length-limited code has $\sum_i 2^{-l_i} = 1$. So the least cost of a coin set equals the least cost of a length-limited code, and an optimal coin set gives optimal lengths.

*Proof.* (a) The $l_i$ coins of symbol $i$ have distinct face values among $2^{-1}, \ldots, 2^{-L}$, so their total is at most $2^{-1} + \cdots + 2^{-l_i} = 1 - 2^{-l_i}$. Summing over $i$, $n - 1 \le n - \sum_i 2^{-l_i}$, so $\sum_i 2^{-l_i} \le 1$. A symbol with $l_i = 0$ would add $2^0 = 1$ to this sum, and the other $n - 1 \ge 1$ symbols add a positive amount, so $l_i \ge 1$. Each coin of symbol $i$ costs $w_i$, so the cost is $\sum_i w_i l_i$. (b) The total face value is $\sum_i (1 - 2^{-l_i}) = n - 1$. (c) Take an optimal code with $\sum_i 2^{-l_i} < 1$ and let $m$ be its longest length. The sum is a multiple of $2^{-m}$, so it is at most $1 - 2^{-m}$. Shortening one codeword of length $m$ by one bit adds $2^{-m}$ and keeps the sum at most 1, and it does not raise the cost. Repeat; the sum grows each time and is bounded, so this ends with a sum of exactly 1. $\square$

**Items.** Generalize coins to *items*: an item has a face value $2^{-d}$, a cost, and a set of coins, and different items in one list have disjoint sets of coins. A coin is an item, and a *package* of two items of face value $2^{-d}$ is an item of face value $2^{-(d-1)}$ whose cost and coins are the sums and unions of the two. The list $Q_k$ of the algorithm holds items of face value $2^{-(L - k + 1)}$: the coins of that face value, and the packages of consecutive pairs of $Q_{k-1}$, sorted by cost.

**Lemma 2 (greedy pairing).** Let $X$ be a multiple of $2^{-(d-1)}$, and consider the problem of choosing, from a set of items of face values $2^{-1}, \ldots, 2^{-d}$, a subset of total face value $X$ at least cost. Let $s_1 \le s_2 \le \cdots$ be the items of the smallest face value $2^{-d}$, sorted by cost. Replace them by the packages $(s_1, s_2), (s_3, s_4), \ldots$ of face value $2^{-(d-1)}$, and drop a last unpaired item. The least cost of the new problem equals the least cost of the old problem, and each solution of the new problem expands into a solution of the old problem with the same cost.

*Proof.* Expanding packages into their two items keeps the face value and the cost, so the old optimum is at most the new one. For the other direction, take an optimal old solution $T$. All items of face value larger than $2^{-d}$ are multiples of $2^{-(d-1)}$, and so is $X$, so $T$ has an even number $2k$ of items of face value $2^{-d}$. If $T$ uses some $s_j$ but not some $s_i$ with $i < j$, swapping them keeps the face value and does not raise the cost. So we may assume that $T$ uses exactly $s_1, \ldots, s_{2k}$, which are the first $k$ packages. So $T$ is also a solution of the new problem with the same cost. $\square$

**Theorem.** PACKAGE-MERGE returns optimal lengths.

*Proof.* Start with all coins, $X = n - 1$ and $d = L$. Lines L2 to L4 apply Lemma 2 for $d = L, L - 1, \ldots, 2$: the items of face value $2^{-d}$ are the list $Q_{L - d + 1}$, sorted by cost, and their packages are merged with the coins of face value $2^{-(d-1)}$ to form the next list. Since $X = n - 1$ is an integer, it is a multiple of each $2^{-(d-1)}$ with $d \ge 1$, so each step is valid. After the last step, all items have face value $\frac12$, and a subset of total face value $n - 1$ is a set of $2n - 2$ items. The cheapest such set is the $2n - 2$ cheapest items of $Q_L$, which line L5 takes. The list $Q_L$ has at least $2n - 2$ items: with $b_k = 2n - |Q_k|$ we have $b_1 = n$ and $b_k = n - \lfloor (2n - b_{k-1}) / 2 \rfloor = \lceil b_{k-1} / 2 \rceil$, so $b_L = \lceil n / 2^{L-1} \rceil \le 2$ because $n \le 2^L$. By Lemma 2 again, expanding this set gives an optimal coin set, and by Lemma 1 its counts $l_i$ are optimal lengths.

It remains to see that lines L6 to L9 compute these counts. Suppose that the expansion takes the first $r$ items of $Q_k$. The coins in $Q_k$ appear in the order of the sorted weights, so the coins among the first $r$ items are the coins of the $c$ lightest symbols, each of which gets one more unit of length (line L8). The packages in $Q_k$ also appear in the order in which they were made, so the $r - c$ packages among the first $r$ items are the first $r - c$ packages, which consist of the first $2(r - c)$ items of $Q_{k-1}$ (line L9). By induction from $k = L$ down to $k = 1$, the counts are those of the expanded set. $\square$

**Complexity.** The list $Q_k$ has at most $n + \lfloor |Q_{k-1}| / 2 \rfloor < 2n$ items, so each pass of lines L2 to L4 takes $O(n)$ time with a linear merge, and lines L6 to L9 take $O(n)$ time per level. The total is $O(nL)$ time, plus $O(n \log n)$ for the sort, and $O(nL)$ space for the leaf and package flags.
