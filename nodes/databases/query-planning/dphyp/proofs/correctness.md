---
title: DPhyp emits every csg-cmp pair of a hypergraph once, with final plans for both halves, and finds the cheapest plan without cross products
proves: [correctness]
status: full
---

**Setting.** The hypergraph $H$ has the relations $v_0, \ldots, v_{n-1}$ and a set of hyperedges. A hyperedge is an unordered pair $\{u, w\}$ of disjoint nonempty sets of relations. A hyperedge *links* two disjoint sets $A$ and $B$ if one of its sides is inside $A$ and the other side is inside $B$. A set of relations is *connected* if it has one relation, or if it is the union of two disjoint connected sets that a hyperedge links. A *csg-cmp pair* is an unordered pair $\{S_1, S_2\}$ of disjoint connected sets that a hyperedge links. A plan *without cross products* is a leaf, or a join of two plans without cross products whose sets a hyperedge links. The cost of a join is $c(P_1) + c(P_2) + j(|S_1|, |S_2|, |S_1 \cup S_2|)$, where the sizes depend only on the sets. $B_i = \{v_j : j \le i\}$, and $\min(S)$ is the smallest index in $S$.

For sets $S$ and $X$, a *candidate* is a side $w$ of a hyperedge whose other side $u$ is inside $S$, with $w$ disjoint from $S \cup X$. $N(S, X)$ holds the member with the smallest index of each candidate that contains no other candidate. Every candidate $w$ contains a candidate with no smaller candidate inside it, so $w$ contains a member of $N(S, X)$. $N(S, X)$ is disjoint from $S \cup X$. Lines L7, L9, L16 and L18 go through the nonempty subsets of $N$ in increasing order as integers, so every subset comes before its proper supersets. Line L8 and the call EMIT-CSG of line L3 are the *visits* of a set; line L13 and the test of line L17 are the visits of a set in the complement search.

**Lemma 1 (cuts).** If $T$ is connected and $S$ is a nonempty proper subset of $T$, a hyperedge links $S$ and $T - S$.

*Proof.* By induction on $|T|$. Write $T = T_1 \cup T_2$ with $T_1$ and $T_2$ connected and linked by a hyperedge $e$. If $S \cap T_1$ is a nonempty proper subset of $T_1$, the induction hypothesis gives a hyperedge with one side in $S \cap T_1 \subseteq S$ and the other in $T_1 - S \subseteq T - S$. The same holds for $T_2$. Otherwise $S$ contains all or none of $T_1$, and all or none of $T_2$. As $S$ is nonempty and not all of $T$, $S = T_1$ or $S = T_2$, and $e$ links $S$ and $T - S$. $\square$

**Lemma 2 (the recursive search).** Let $S$ be nonempty and $S \subseteq X$. The call ENUMERATE-CSG-REC$(S, X)$ visits each set at most once, and each visited set $T$ has $T \supsetneq S$ and $T \cap X = S$. It visits every connected $T$ with $T \supsetneq S$ and $T \cap X = S$. If $U \subsetneq T$ are two visited sets, $U$ is visited first. The same holds for the sets that ENUMERATE-CMP-REC$(S_1, S, X)$ tests at line L17.

*Proof.* The two procedures make the same calls and visit the same sets, so we prove it for the first one, by induction on the number of relations outside $X$. Let $N = N(S, X)$. Line L8 visits $S \cup S'$ for each nonempty $S' \subseteq N$. The call of line L9 for $S'$ visits, by induction, sets $T'$ with $T' \supsetneq S \cup S'$ and $T' \cap (X \cup N) = S \cup S'$, so $T' \cap N = S'$ and $T'$ is not inside $X \cup N$. The sets of line L8 are inside $X \cup N$. So no set is visited twice, and since $N \cap X = \emptyset$, each visited set meets $X$ only in $S$.

Let $T$ be connected with $T \supsetneq S$ and $T \cap X = S$. By Lemma 1 a hyperedge has one side $u \subseteq S$ and the other side $w \subseteq T - S$. Then $w$ is disjoint from $S \cup X$, so it is a candidate and contains a member of $N$. So $S' = T \cap N$ is not empty. If $T = S \cup S'$, line L8 visits $T$. Otherwise $T \supsetneq S \cup S'$ and $T \cap (X \cup N) = S \cup S'$, and the call of line L9 for $S'$, whose $X$ is larger, visits $T$ by induction. Lemma 1 is the only place where the proof uses that $T$ is connected; $S$ need not be connected.

For the order, let $U \subsetneq T$ be visited, with $S'_U = U \cap N \subseteq S'_T = T \cap N$. If line L8 visits $T$, then $U \subseteq X \cup N$, so line L8 visits $U$ too, for a smaller subset. If a call of line L9 visits $T$ and line L8 visits $U$, then $U$ comes first, because the loop of line L7 ends before the loop of line L9 starts. If both come from calls of line L9, then $S'_U = S'_T$ and the induction hypothesis applies to that call, or $S'_U \subsetneq S'_T$ and the call for $S'_U$ comes first. $\square$

**Lemma 3 (the main loop).** The iteration of line L2 for $i$ visits $\{v_i\}$ first and then, each at most once, sets with smallest index $i$. It visits every connected set with smallest index $i$. If $U \subsetneq T$ are visited in it, $U$ is visited first.

*Proof.* Apply Lemma 2 with $S = \{v_i\}$ and $X = B_i$: a set $T \supsetneq \{v_i\}$ meets $B_i$ only in $v_i$ exactly when its smallest index is $i$. Line L3 visits $\{v_i\}$ before line L4 starts. $\square$

**Lemma 4 (complements).** Suppose that EMIT-CSG$(S_1)$ runs, with $m = \min(S_1)$, at a time when $\mathrm{best}$ holds every connected set with smallest index above $m$ and holds only connected sets. Then it calls EMIT-CSG-CMP$(S_1, S_2)$, each exactly once, for the connected sets $S_2$ that are disjoint from $S_1$, have smallest index above $m$, and are linked to $S_1$ by a hyperedge.

*Proof.* Let $X = S_1 \cup B_m$ and $N = N(S_1, X)$ (lines L10 and L11). For $v_i \in N$, let $X_i = X \cup (B_i \cap N)$, which contains $v_i$. The iteration of line L12 for $v_i$ tests $\{v_i\}$ at line L13, and by Lemma 2 for ENUMERATE-CMP-REC$(S_1, \{v_i\}, X_i)$ it tests, each at most once, sets $T \supsetneq \{v_i\}$ with $T \cap X_i = \{v_i\}$, including all connected ones. Each set tested in this iteration contains $v_i$ and no other member of $B_i \cap N$, so $v_i$ is its member of $N$ with the smallest index. Hence different iterations test different sets.

Let $S_2$ be a set as in the lemma. Some hyperedge has one side in $S_1$ and the other side $w$ in $S_2$. As $S_2$ is disjoint from $S_1$ and from $B_m$, $w$ is a candidate, so $S_2$ meets $N$. Let $v_i$ be the member of $S_2 \cap N$ with the smallest index. Then $S_2 \cap X_i = \{v_i\}$, so the iteration for $v_i$ tests $S_2$. The set is in $\mathrm{best}$ by the assumption (a single relation is there by line L1), and a hyperedge links it to $S_1$, so line L13 or line L17 calls EMIT-CSG-CMP$(S_1, S_2)$. Conversely, a call happens only for a tested set that is in $\mathrm{best}$, so connected, and linked to $S_1$; it is disjoint from $X$, so from $S_1$, and its indexes are all above $m$. $\square$

**Lemma 5 (final plans).** The following hold at every point of the run.

(a) Every set in $\mathrm{best}$ is connected.

(b) When line L8 visits a set $T$, every csg-cmp pair with union $T$ has been used by EMIT-CSG-CMP already.

(c) At the start of the iteration of line L2 for $i$, every connected set with smallest index above $i$ is in $\mathrm{best}$, and every csg-cmp pair whose union has smallest index above $i$ has been used.

(d) Every csg-cmp pair is used at most once, as $(S_1, S_2)$ with $\min(S_1) < \min(S_2)$, during EMIT-CSG$(S_1)$.

*Proof.* (a) EMIT-CSG-CMP$(S_1, S_2)$ runs only when both sets are in $\mathrm{best}$ and a hyperedge links them, so their union is connected if both are. (d) EMIT-CSG-CMP is called only from EMIT-CSG$(S_1)$ with $S_2$ disjoint from $B_{\min(S_1)}$, and Lemma 4 gives each $S_2$ once per call. EMIT-CSG$(S_1)$ runs at most once, because a set is visited at most once (Lemma 3) and the sets that line L8 visits have at least two relations, while line L3 visits single relations.

(b) and (c) together, by induction over the run. (c) holds for $i = n - 1$, as there is nothing above. Assume (c) for $i$, and consider the sets that the iteration for $i$ visits, in order. Let $T$ be visited at line L8, and let $\{U_1, U_2\}$ be a csg-cmp pair with union $T$ and $\min(U_1) = i$. Then $U_1 \subsetneq T$ is connected with smallest index $i$, so by Lemma 3 it is visited, and before $T$. If $U_1 = \{v_i\}$, line L3 calls EMIT-CSG$(U_1)$. Otherwise $U_1$ has at least two relations, so it is the union of some csg-cmp pair; by (b) for $U_1$ that pair has been used, so $U_1$ is in $\mathrm{best}$ and line L8 calls EMIT-CSG$(U_1)$. By (a) and (c), Lemma 4 applies to this call, and it uses $\{U_1, U_2\}$, because $U_2$ has smallest index above $i$. This call ends before $T$ is visited, which proves (b) for $T$. At the end of the iteration, every connected set $T$ with smallest index $i$ and two or more relations has been visited at line L8 (Lemma 3), so all pairs with union $T$ have been used by (b). Such a set has at least one pair, so $T$ is in $\mathrm{best}$, and $\{v_i\}$ is there by line L1. This is (c) for $i - 1$. $\square$

So every csg-cmp pair is used exactly once: at most once by (d), and at least once by the argument for (b) and (c). When EMIT-CSG-CMP$(S_1, S_2)$ runs, all pairs with union $S_1$ have been used (by (b), or $S_1$ is a single relation), and all pairs with union $S_2$ have been used (by (c), as $\min(S_2) > \min(S_1)$).

**Theorem.** If $H$ is connected, line L5 returns a cheapest plan without cross products for all $n$ relations. If $H$ is not connected, the set of all relations never enters $\mathrm{best}$.

*Proof.* Let $\mathrm{opt}(S)$ be the least cost of a plan without cross products for a connected set $S$. We show that after all pairs with union $S$ are used, $\mathrm{best}[S]$ is a plan for $S$ without cross products of cost $\mathrm{opt}(S)$. For a single relation this holds by line L1. Every entry that line L21 stores joins two stored plans whose sets a hyperedge links, so it is a plan without cross products for its set. Take a cheapest plan $Q$ for $S$ with $|S| \ge 2$. Its last join combines plans $Q_1$ and $Q_2$ for sets $S_1$ and $S_2$. By induction on the plan, the set of every plan without cross products is connected, so $\{S_1, S_2\}$ is a csg-cmp pair, and it is used. At that moment $\mathrm{best}[S_1]$ and $\mathrm{best}[S_2]$ are final, so by induction on $|S|$ they cost $\mathrm{opt}(S_1) \le c(Q_1)$ and $\mathrm{opt}(S_2) \le c(Q_2)$. Line L20 tries both orders of the inputs and the join term depends only on the sets, so one candidate costs at most $c(Q) = \mathrm{opt}(S)$, and line L21 keeps a plan of that cost or less. No plan is cheaper than $\mathrm{opt}(S)$. If $H$ is connected, the set of all relations is connected, so it is in $\mathrm{best}$ at the end by (c). If $H$ is not connected, (a) keeps it out of $\mathrm{best}$. $\blacksquare$

**Notes.** The test at line L8 is needed: Lemma 2 visits sets that are not connected, for example $S \cup \{\min(w)\}$ when $w$ has two or more relations. The proof uses about $N(S, X)$ only that it is disjoint from $S \cup X$ and that every candidate contains one of its members; keeping only the candidates with no smaller candidate inside makes $N$ smaller and does not change the result. For a graph whose hyperedges all have one relation on each side, every visited set is connected, and the run makes the same calls as DPccp.

**Work.** In the main loop each set is visited at most once, so there are at most $2^n$ visits. In the complement search for $S_1$, each set disjoint from $S_1$ is tested at most once. So the number of tests is at most the number of pairs of disjoint sets, which is less than $3^n$. Each call of a recursive procedure belongs to a visited or tested set, and computes one neighborhood. With $m$ hyperedges and the sets stored as bitmasks, one neighborhood takes $O(m^2)$ steps in the code of this page, which removes the candidates that contain another one by comparing pairs; a link test takes $O(m)$ steps and a size takes $O(n + m)$ steps. A connected hypergraph has $m \ge n - 1$, because each join of the recursive definition needs a hyperedge that crosses it and no other join of the same split tree. So the work is $O(3^n m^2)$, and the table holds at most $2^n$ plans.
