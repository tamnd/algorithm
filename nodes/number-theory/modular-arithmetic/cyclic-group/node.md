A **cyclic group** is a group that some single element generates: every element is a power of it. The integers under addition and the [additive group modulo n](/additive-group-modulo-n/) are cyclic, and every cyclic group has the same structure as one of these two. The multiplicative group of residues modulo a prime is cyclic too, and its generators are the [primitive roots](/primitive-root/). Cyclic groups are fully understood: their subgroups, the [orders](/multiplicative-order/) of their elements and their generators can all be read off from the divisors of the group order. This is why [Diffie-Hellman](/diffie-hellman/) and other systems based on the [discrete logarithm problem](/discrete-logarithm-problem/) work in cyclic groups.

## Definition

Let $G$ be a group, written multiplicatively with identity $1$. For $g \in G$ the **cyclic subgroup generated by $g$** is

$$\langle g \rangle = \{\, g^k : k \in \mathbb{Z} \,\},$$

where $g^0 = 1$ and $g^{-k} = (g^{-1})^k$. It is a [subgroup](/subgroup/), because $g^j g^k = g^{j+k}$ and $(g^k)^{-1} = g^{-k}$.

**Definition.** $G$ is **cyclic** if $G = \langle g \rangle$ for some $g \in G$. Such a $g$ is a **generator** of $G$. In additive notation, $\langle g \rangle = \{ k g : k \in \mathbb{Z} \}$.

The **order** of $g$ is the least $t \ge 1$ with $g^t = 1$, or $\infty$ if there is none. The order of $g$ equals the number of elements of $\langle g \rangle$. If the order is $t < \infty$, then $g^j = g^k$ if and only if $j \equiv k \pmod t$, so $\langle g \rangle = \{1, g, g^2, \ldots, g^{t-1}\}$ with no repeats.

**Classification.** Let $G = \langle g \rangle$.

- If $g$ has infinite order, then $k \mapsto g^k$ is an isomorphism from $(\mathbb{Z}, +)$ to $G$.
- If $g$ has order $n$, then $k \bmod n \mapsto g^k$ is an isomorphism from $(\mathbb{Z}/n\mathbb{Z}, +)$ to $G$.

So up to isomorphism there is one cyclic group of each order $n \ge 1$, written $C_n$ or $\mathbb{Z}_n$, and one infinite cyclic group, $\mathbb{Z}$.

**Basic properties.** Let $G = \langle g \rangle$ be cyclic of order $n$.

- $G$ is abelian, because $g^j g^k = g^{j+k} = g^k g^j$.
- The element $g^k$ has order $n / \gcd(n, k)$. So $g^k$ is a generator if and only if $\gcd(k, n) = 1$, and $G$ has $\varphi(n)$ generators, where $\varphi$ is [Euler's totient](/euler-totient/).
- Every subgroup of $G$ is cyclic. For each positive divisor $d$ of $n$ there is exactly one subgroup of order $d$, namely $\langle g^{n/d} \rangle$, and there are no others.
- For each $d \mid n$, $G$ has exactly $\varphi(d)$ elements of order $d$. Summing over $d$ gives $\sum_{d \mid n} \varphi(d) = n$, the [totient divisor sum](/totient-divisor-sum/).
- An element $h \in G$ is a generator if and only if $h^{n/p} \ne 1$ for each prime $p$ that divides $n$. This is how generators are tested when the factorization of $n$ is known.
- Every group of prime order $p$ is cyclic, generated by any element other than $1$, by [Lagrange's theorem](/lagranges-theorem-group-theory/).

## Examples and non-examples

- **The integers.** $(\mathbb{Z}, +)$ is cyclic with the two generators $1$ and $-1$.
- **Residues under addition.** $(\mathbb{Z}_n, +)$ is cyclic, generated by $1$. Its generators are the residues coprime to $n$; for $n = 12$ they are $1, 5, 7, 11$. See [additive group modulo n](/additive-group-modulo-n/).
- **Units modulo a prime.** $\mathbb{Z}_7^* = \{1, \ldots, 6\}$ is cyclic, generated by $3$: the powers $3^1, \ldots, 3^6$ are $3, 2, 6, 4, 5, 1$ modulo $7$. In $\mathbb{Z}_{19}^*$, of order $18$, the element $2$ is a generator, since $2^9 \equiv 18$ and $2^6 \equiv 7$ are not $1$; its powers $2^k$ with $\gcd(k, 18) = 1$ give the $\varphi(18) = 6$ generators $2, 3, 10, 13, 14, 15$. The element $7$ is not a generator, since $7^6 \equiv 1 \pmod{19}$, so it has order $3$. More generally, $\mathbb{Z}_n^*$ is cyclic if and only if $n = 1, 2, 4, p^k$ or $2p^k$ for an odd prime $p$ ([existence of primitive roots](/primitive-roots-existence/)).
- **Roots of unity.** The complex $n$-th roots of unity $e^{2\pi i k/n}$ form a cyclic group of order $n$ under multiplication, generated by $e^{2\pi i/n}$. The same holds for the rotations of a regular $n$-gon.
- **Finite fields.** The nonzero elements of every finite field form a cyclic group. More generally, every finite subgroup of the multiplicative group of a field is cyclic.
- **Non-example: $\mathbb{Z}_2 \times \mathbb{Z}_2$.** This group has four elements, and each one other than the identity has order $2$, so no element has order $4$.
- **Non-example: $\mathbb{Z}_8^*$ and $\mathbb{Z}_{15}^*$.** In $\mathbb{Z}_8^* = \{1, 3, 5, 7\}$ every element squares to $1$, so no element has order $4$; this group is isomorphic to $\mathbb{Z}_2 \times \mathbb{Z}_2$. In $\mathbb{Z}_{15}^*$, of order $8$, every element satisfies $x^4 \equiv 1$, so no element has order $8$.
- **Non-example: non-abelian groups.** The [symmetric group](/symmetric-group/) $S_3$ is not abelian, so it is not cyclic, although each of its proper subgroups is.
- **Non-example: the rationals.** $(\mathbb{Q}, +)$ is not cyclic. If $q \ne 0$ generated it, then $q/2$ would be an integer multiple $kq$, which forces $k = 1/2$.

## Related definitions

- [Finite group](/finite-group/) and [subgroup](/subgroup/): the general notions that a cyclic group specializes.
- [Additive group modulo n](/additive-group-modulo-n/): the standard model of the cyclic group of order $n$.
- [Multiplicative order](/multiplicative-order/): the order of an element of $\mathbb{Z}_n^*$, which is the size of the cyclic subgroup it generates.
- [Primitive root](/primitive-root/): a generator of $\mathbb{Z}_n^*$ when this group is cyclic.
- [Multiplicative group modulo n](/multiplicative-group-modulo-n/): cyclic exactly for $n = 1, 2, 4, p^k, 2p^k$, and a product of cyclic groups in general.
- [Lagrange's theorem](/lagranges-theorem-group-theory/): in a finite group, the order of each element divides the group order.
- [Discrete logarithm problem](/discrete-logarithm-problem/): given a generator $g$ and $h = g^k$, find $k$; this inverts the isomorphism from $\mathbb{Z}_n$ to $G$.
