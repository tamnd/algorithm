We use the pseudocode of the page. $D > 1$ is a squarefree integer with $D \equiv 2, 3 \pmod 4$, so $\mathcal{O} = \mathbb{Z}[\sqrt D]$ is the ring of integers of $K = \mathbb{Q}(\sqrt D)$. Let $s = \lfloor\sqrt D\rfloor$, let $\varepsilon > 1$ be the fundamental unit, and let $R = \ln\varepsilon$. An ideal $[Q, P + \sqrt D]$ is the $\mathbb{Z}$-module spanned by $Q$ and $P + \sqrt D$, with $Q > 0$ and $Q \mid D - P^2$. For $\mu \in K^\ast$ we write $|\mu|$ for the absolute value in the real embedding with $\sqrt D > 0$. The scale is $N > 0$, $S = NR$, and the registers have sizes $A$ and $q$.

**Facts about reduced ideals.** We use these standard facts (see *Solving the Pell Equation* by Jacobson and Williams).

1. The ideal $[Q, P + \sqrt D]$ is reduced if some $P' \equiv P \pmod Q$ has $0 < P' \le s$ and $s - P' < Q \le s + P'$. A reduced ideal has $Q < 2\sqrt D$, so there are finitely many.
2. For a reduced $\mathfrak{b} = [Q, P + \sqrt D]$ with $P \in (s - Q, s]$, let $a = \lfloor (P + s)/Q \rfloor$, $P' = aQ - P$ and $Q' = (D - P'^2)/Q$. Then $\mathfrak{b}' = [Q', P' + \sqrt D] = \mu\mathfrak{b}$ with $\mu = (P' + \sqrt D)/Q > 1$, and $\mathfrak{b}'$ is reduced. This step is a bijection on the reduced ideals, and its inverse has $Q = (D - P'^2)/Q'$.
3. The reduced ideals of one ideal class form one cycle under this step. For any ideal $\mathfrak{c}$, the reduced ideals $\nu\mathfrak{c}$ with $\nu \in K^\ast$ are exactly the ideals of the cycle of its class. Going once around the cycle multiplies by $\varepsilon$, so the values $\ln|\nu|$ that belong to one reduced ideal form a coset $\ln|\nu_0| + R\mathbb{Z}$.
4. For any ideal, repeated steps $\mathfrak{b} \mapsto \mu\mathfrak{b}$ with $\mu = (P' + \sqrt D)/Q$ and $P' \equiv -P \pmod Q$ reach a reduced ideal. The implementation chooses $P'$ centered when $Q > 2s$ and in $(s - Q, s]$ otherwise.
5. The principal cycle is the cycle of $(1) = [1, s + \sqrt D]$. Its $k$-th ideal is $\theta_k\mathcal{O}$ with $\theta_k = p_{k-1} + q_{k-1}\sqrt D$ from the convergents of $\sqrt D$, and $\delta_k = \ln\theta_k$ increases from $\delta_0 = 0$ to $\delta_\ell = R$ at the period $\ell$.

The products of the generators $Q_1, P_1 + \sqrt D$ of $I_1$ and $Q_2, P_2 + \sqrt D$ of $I_2$ span $I_1 I_2$, and their Hermite normal form is $w[Q, P + \sqrt D]$ for an integer $w$, so $I_1 I_2 = w\,[Q, P + \sqrt D]$.

**Lemma 1 (powers with distances).** For each $a \ge 0$ the routine for $I^a$ returns a reduced ideal $J_a$ and a real $e_a$ with $J_a = \mu_a I^a$ and $\ln|\mu_a| = e_a$.

*Proof.* For $a = 0$, $J_0 = (1)$ and $e_0 = 0$. If $J_{a-1} = \mu_{a-1}I^{a-1}$, then $J_{a-1}I = \mu_{a-1}I^a = w\,\mathfrak{c}$, so $\mathfrak{c} = (\mu_{a-1}/w) I^a$. Each reduction step of Fact 4 multiplies by a known $\mu$ and adds $\ln|\mu|$. So $J_a = \mu_a I^a$ with $\ln|\mu_a| = e_{a-1} - \ln w + \sum \ln|\mu|$, which is the value the routine returns. $\square$

**The function.** For $a \in \mathbb{Z}$ and real $x$, let $G(a, x) = (\mathfrak{b}, d)$, where $\mathfrak{b} = \nu I^a$ is the reduced ideal of the class of $I^a$ with the largest $d = \ln|\nu| \le x$. By Fact 3, the pairs $(\mathfrak{b}, \ln|\nu|)$ are discrete in $x$ and repeat with period $R$, so $G$ is well defined. The oracle computes $g(a, k) = (\mathfrak{b}, \lfloor k - Nd \rfloor)$ for $G(a, k/N) = (\mathfrak{b}, d)$. It starts at $J_a$ with distance $e_a$ from Lemma 1, steps back until the distance is at most 0, and then steps forward. By Facts 2 and 3 this visits the reduced ideals of the class in the order of their distances, so it finds $G(a, k/N)$ for $0 \le k < q$.

**Lemma 2 (the hidden lattice).** Let $\Lambda = \{(m, -N\ln|\beta|) : m \in \mathbb{Z},\ \beta \in K^\ast,\ I^m = \beta\mathcal{O}\}$. Let $\tilde g(a, y) = (\mathfrak{b}, \lfloor y - Nd\rfloor)$ for $G(a, y/N) = (\mathfrak{b}, d)$ and real $y$, so $g(a, k) = \tilde g(a, k)$.

1. $\Lambda$ is a lattice in $\mathbb{Z} \times \mathbb{R}$, generated by $(0, S)$ and $(m_0, -N\ln|\beta_0|)$, where $m_0$ is the order of the class of $I$ and $I^{m_0} = \beta_0\mathcal{O}$.
2. $\tilde g((a, y) + \lambda) = \tilde g(a, y)$ for every $\lambda \in \Lambda$.
3. If $\tilde g(a, y) = \tilde g(a', y')$, then $(a' - a, y' - y + \xi) \in \Lambda$ for some $|\xi| < 1$.
4. $I$ is principal if and only if $\Lambda$ holds a point $(1, -N\delta)$. Then $I = \alpha\mathcal{O}$ with $\ln|\alpha| = \delta$, and $g(a, k) = \tilde g(0, k + aN\delta)$.

*Proof.* (1) $I^m$ is principal exactly when $m_0 \mid m$, and for $m = 0$ the elements $\beta$ are the units $\pm\varepsilon^u$, which give $(0, uS)$. If $I^m = \beta\mathcal{O} = \beta'\mathcal{O}$, then $\beta'/\beta$ is a unit, so the second coordinates differ by a multiple of $S$. (2) Let $\lambda = (m, -N\ln|\beta|)$. The reduced ideals $\nu I^{a + m} = \nu\beta I^a$ are the reduced ideals of the class of $I^a$, with $\ln|\nu\beta| = \ln|\nu| + \ln|\beta|$. So $G(a + m, x - \ln|\beta|) = (\mathfrak{b}, d - \ln|\beta|)$ when $G(a, x) = (\mathfrak{b}, d)$, and the offset $\lfloor y - N\ln|\beta| - N(d - \ln|\beta|)\rfloor = \lfloor y - Nd\rfloor$ is the same. (3) Equal ideals $\mathfrak{b} = \nu I^a = \nu' I^{a'}$ give $I^{a' - a} = (\nu/\nu')\mathcal{O}$, so $(a' - a, -N\ln|\nu/\nu'|) \in \Lambda$. Equal offsets give $|(y' - Nd') - (y - Nd)| < 1$ with $d = \ln|\nu|$ and $d' = \ln|\nu'|$, which is the claim with $\xi = -(y' - y) + N(d' - d)$. (4) $(1, -N\delta) \in \Lambda$ means $I = \beta\mathcal{O}$ with $\ln|\beta| = \delta$. The last formula is part (2) applied $a$ times with $\lambda = (1, -N\delta)$, read backwards. $\square$

So $g$ is periodic on $\mathbb{Z} \times \mathbb{Z}$ up to the rounding of part (3), in the same weak sense as the function of Hallgren's algorithm for Pell's equation. The lattice $\Lambda$ is the image of the group of the $\beta$ with $\beta\mathcal{O}$ a power of $I$ under $\beta \mapsto (m, -N\ln|\beta|)$, which is the $S$-unit group of the method of Biasse and Song in the case where $S$ is replaced by the single ideal $I$.

**Lemma 3 (the output distribution).** One run of lines L4 to L7 gives $(b, c)$ with probability

$$P(b, c) = \frac{1}{(Aq)^2}\sum_v \Big|\sum_{g(a, k) = v} e^{2\pi i(ab/A + kc/q)}\Big|^2,$$

where $v$ runs over the values of $g$ on $a < A$, $k < q$.

*Proof.* Line L4 gives $(Aq)^{-1/2}\sum_{a,k}|a\rangle|k\rangle|0\rangle$, and line L5 writes an injective code of $g(a, k)$ into the target. After line L6 the amplitude of $|b\rangle|c\rangle|v\rangle$ is $(Aq)^{-1}\sum_{g(a,k) = v} e^{2\pi i(ab/A + kc/q)}$. The states $|v\rangle$ are orthogonal, so the probabilities add over $v$. $\square$

The points of a level set lie within distance 1 of a coset of $\Lambda$ by Lemma 2, so $P$ puts its weight near the dual lattice $\{(\beta, \gamma) : \beta m + \gamma\eta \in \mathbb{Z} \text{ for all } (m, \eta) \in \Lambda\}$. For a principal $I$, this means $c \approx jq/S$ for an integer $j$ and $b/A \approx cN\delta/q \pmod 1$. Call a sample *good* if $c' = c$ or $c' = c - q$, taken in $(-q/2, q/2]$, has $\mathrm{round}(c'S/q) \ne 0$, and the distance from $b/A - c'N\delta/q$ to the nearest integer is at most $1/A$. A lower bound on the probability of a good sample follows from Hallgren's analysis for $A$, $q$ and $N$ of polynomial size. The theorem below does not depend on this bound, which only controls the number of rounds.

**Lemma 4 (the candidates).** Let $I = \alpha\mathcal{O}$ be principal with $\delta = \ln|\alpha| \in [0, R)$, and let $(b, c)$ be a good sample. Then one candidate $t$ of line L8 has $|t - \delta| \le w$ with $w = q/(|c'|NA)$.

*Proof.* Write $b/A - c'N\delta/q = n + \eta$ with $n \in \mathbb{Z}$ and $|\eta| \le 1/A$. With $u = q/(c'N)$ this gives $\delta = (b/A - n)u - \eta u$, so $t = (b/A - n)u$ has $|t - \delta| = |\eta u| \le |u|/A = w$. Since $\delta \in [0, R)$, $t \in [-w, R + w)$, and line L8 lists every $(b/A + m)u$ in this interval. $\square$

**Theorem.** If the algorithm returns $\theta$, then $I = \theta\mathcal{O}$. If $I$ is not principal, the algorithm returns "not principal". If $I$ is principal, each round with a good sample returns a generator $\theta$ with $\ln\theta = \delta \in [0, R)$, so the probability of the wrong answer "not principal" is at most $(1 - p)^T$, where $p$ is the probability of a good sample and $T$ is the number of rounds.

*Proof.* Line L9 lists only reduced principal ideals $J = \theta\mathcal{O}$ of the principal cycle with their generators from Fact 5, and line L10 returns only if $J = I$ as ideals. So a returned $\theta$ generates $I$. If $I$ is not principal, it is not on the principal cycle, line L10 never holds, and the algorithm returns at line L12. If $I$ is principal, $I = \theta_k\mathcal{O}$ is on the principal cycle with $\delta = \delta_k \in [0, R)$, by Facts 3 and 5. For a good sample, Lemma 4 gives a candidate $t$ with $|t - \delta| \le w$, so line L9 lists $I$ and line L10 returns $\theta_k$. The rounds are independent, which gives the bound. $\square$

The answer does not depend on floating-point accuracy beyond the window test of line L9. The ideals are compared as integer pairs $(Q, P \bmod Q)$, and the generator is an integer pair $(x, y)$ with $x^2 - Dy^2 = \pm Q$ and $x \equiv yP \pmod Q$.
