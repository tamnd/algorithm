The ideal class group of a number field $K$ is the group of its fractional ideals modulo the principal ones. It is a finite abelian group, and its order is the class number $h_K$, which measures how far the ring of integers is from having unique factorization of elements. The computational problem is to find its structure as a product of cyclic groups, with generators. Classical methods are subexponential under the generalized Riemann hypothesis (GRH), and quantum algorithms run in polynomial time under GRH.

## In plain words

In ordinary whole numbers, every number splits into primes in only one way. In many number fields this fails: one number can split in two different ways. Mathematicians fix this by working with ideals, which are sets of numbers that act like ideal factors.

Some ideals come from a single number and some do not. The class group sorts ideals into classes, where two ideals are in the same class when one is the other times a number. The number of classes, the class number, tells how badly unique factorization fails. If it is one, factorization works as usual.

The task is to find the class group and its shape. Classical computers find it only slowly for large fields. Quantum computers can find it fast, because the class group hides a repeating pattern.

## Definition

Let $K$ be a number field of degree $n$ with ring of integers $\mathcal{O}_K$ and discriminant $\Delta_K$. The nonzero fractional ideals form a free abelian group $I_K$ under multiplication, generated by the prime ideals. The principal ideals $\alpha\mathcal{O}_K$ form a subgroup $P_K$. The **ideal class group** is

$$\mathrm{Cl}_K = I_K / P_K,$$

and the **class number** is $h_K = |\mathrm{Cl}_K|$, which is finite. The exact sequence

$$1 \to \mathcal{O}_K^\ast \to K^\ast \to I_K \to \mathrm{Cl}_K \to 1$$

links the class group to the [unit group](/unit-group/). The input is $K$, given by a defining polynomial and an integral basis. The output is the class number and the structure

$$\mathrm{Cl}_K \cong \mathbb{Z}/d_1 \times \cdots \times \mathbb{Z}/d_k, \qquad d_1 \mid d_2 \mid \cdots \mid d_k,$$

with ideals $\mathfrak{a}_1, \dots, \mathfrak{a}_k$ whose classes generate the factors. The size of the input is measured by $n$ and $\log|\Delta_K|$.

**Quadratic fields and forms.** For a negative discriminant $\Delta$, the class group of the order of discriminant $\Delta$ is isomorphic to the group of classes of primitive positive definite forms $ax^2 + bxy + cy^2$ with $b^2 - 4ac = \Delta$, under Gauss composition. Every class contains exactly one **reduced** form, with $|b| \le a \le c$ and $b \ge 0$ when $|b| = a$ or $a = c$. So $h(\Delta)$ is the number of reduced forms.

## Variants

- **The class number only.** Find $h_K$ without the group structure. For quadratic fields it follows from the analytic class number formula and an approximation of an L-function, together with the regulator for real fields.
- **Orders.** The class group of a non-maximal order, such as the order of discriminant $\Delta f^2$, is defined in the same way with invertible ideals. CSIDH uses such groups.
- **Discrete logarithms in the class group.** Given a class and the generators, find its coordinates. This is the [principal ideal problem](/principal-ideal-problem/) when the class is trivial.
- **Gauss's class number problem.** The name class number problem also refers to a different question: find all imaginary quadratic fields with a given class number. Heegner, Baker and Stark showed that $h = 1$ holds exactly for $\mathbb{Q}(\sqrt{-d})$ with $d = 1, 2, 3, 7, 11, 19, 43, 67, 163$, and later work by Goldfeld, Gross and Zagier made the problem effective for every $h$.
- **Fixed degree or any degree.** Classical results usually treat $n$ as fixed. The quantum result of Biasse and Song is polynomial in $n$ as well.

## Examples

**$\Delta = -20$, the field $\mathbb{Q}(\sqrt{-5})$.** The reduced forms are $x^2 + 5y^2$ and $2x^2 + 2xy + 3y^2$, so $h = 2$. The ideal $(2, 1 + \sqrt{-5})$ is not principal, and $6 = 2 \cdot 3 = (1 + \sqrt{-5})(1 - \sqrt{-5})$ shows two different factorizations into irreducible elements.

**$\Delta = -23$.** The reduced forms are $(1, 1, 6)$, $(2, 1, 3)$ and $(2, -1, 3)$, so $h = 3$ and $\mathrm{Cl} \cong \mathbb{Z}/3$. The two forms with $a = 2$ are inverse to each other.

**$\Delta = -84$.** The reduced forms are $(1, 0, 21)$, $(2, 2, 11)$, $(3, 0, 7)$ and $(5, 4, 5)$. All four are their own inverses, so $\mathrm{Cl} \cong \mathbb{Z}/2 \times \mathbb{Z}/2$. The form $(3, 0, 7)$ shows the factorization $21 = 3 \cdot 7$.

**Other quadratic examples.** The class numbers of the discriminants $-47$ and $-71$ are 5 and 7, so these groups are cyclic of prime order. The discriminant $-163$ has class number 1. The real field $\mathbb{Q}(\sqrt{10})$ has class number 2.

**The class number formula.** For $\Delta < -4$, $h(\Delta) = -\frac{1}{|\Delta|}\sum_{a=1}^{|\Delta|} \left(\frac{\Delta}{a}\right) a$, with the Kronecker symbol. For $\Delta = -23$ this sum gives 3.

## Known algorithms

**Classical.**

- **Counting reduced forms.** For a negative discriminant, list the reduced forms $(a, b, c)$ with $a \le \sqrt{|\Delta|/3}$. With modular square roots for $b^2 \equiv \Delta \pmod{4a}$, this takes about $|\Delta|^{1/2}$ steps up to logarithmic factors.
- **Shanks' baby-step giant-step.** Find the orders of random classes with [baby-step giant-step](/baby-step-giant-step/) near an estimate of $h$ from the class number formula. This takes about $|\Delta|^{1/4}$ steps, up to logarithmic factors. For real quadratic fields the same idea works in the infrastructure and also finds the regulator.
- **The relation method.** Choose a factor base of prime ideals of small norm. Under GRH, a bound of Bach says that the primes of norm at most $12(\ln|\Delta_K|)^2$ generate $\mathrm{Cl}_K$. Collect relations, elements whose principal ideals factor over the base, as rows of an integer matrix. The [Smith normal form](/smith-normal-form/) of a full-rank relation matrix gives the group structure, and the analytic class number formula checks that enough relations were found. Hafner and McCurley gave a version for imaginary quadratic fields with expected time $\exp((\sqrt 2 + o(1))\sqrt{\ln|\Delta| \ln\ln|\Delta|})$ under GRH. Buchmann extended the method to fixed degree, and the regulator comes out at the same time.
- **The Minkowski bound.** Without GRH, every class contains an integral ideal of norm at most $\frac{n!}{n^n}(\frac{4}{\pi})^{r_2}\sqrt{|\Delta_K|}$, so the primes up to this bound generate $\mathrm{Cl}_K$. This gives an unconditional method, but the bound is exponential in $\log|\Delta_K|$.

**Quantum.**

- **Imaginary quadratic fields.** Reduced forms give a unique encoding of each class and composition is efficient, so the class group is a finite abelian group with efficient operations. Under GRH, small primes generate it, and quantum order finding and an abelian hidden subgroup algorithm find its structure in polynomial time. See [quantum class group algorithm](/quantum-class-group-algorithm/).
- **Real quadratic fields.** Classes have no unique reduced representative. Hallgren (2002) used the cycle of reduced ideals and distances to compute the class group in polynomial time under GRH.
- **Constant degree.** Hallgren (2005) extended this to fields of constant degree.
- **Any degree.** Biasse and Song (2016) computed the class group in time polynomial in $n$ and $\log|\Delta_K|$, under GRH, by computing $S$-unit groups. See [quantum principal ideal algorithm](/quantum-principal-ideal-algorithm/).

## Bounds

For imaginary quadratic fields, $h(\Delta) = O(\sqrt{|\Delta|}\log|\Delta|)$, and Siegel's theorem gives $h(\Delta) = |\Delta|^{1/2 + o(1)}$. So the group can have order exponential in $\log|\Delta|$, and listing its elements is not polynomial. For fields of fixed degree, the Brauer-Siegel theorem says that $\ln(h_K R_K)$ grows like $\ln\sqrt{|\Delta_K|}$, and for real quadratic fields $R$ often takes most of this, so $h$ is often small. The best known classical algorithms are subexponential, and there is no known classical polynomial-time algorithm even for imaginary quadratic fields.

## Reductions

- **From factoring.** For an odd $N$ that is not a prime power, the elements of order 2 in the class group of discriminant $-4N$ are the ambiguous classes, and their forms such as $(a, 0, c)$ or $(a, a, c)$ reveal factors of $N$. For a fundamental discriminant, genus theory says that the 2-rank is one less than the number of its prime factors. So computing the class group factors $N$. [Shanks' square forms factorization](/shanks-squfof/) uses the same idea on the real side.
- **To the principal ideal problem.** Deciding whether an ideal is principal is the question whether its class is trivial. Given the structure of $\mathrm{Cl}_K$ and a discrete logarithm in it, the principal ideal problem follows, and the converse holds with relation methods.
- **With the unit group.** Relation methods find $\mathrm{Cl}_K$ and the units together, because the kernel of the relation matrix gives units. The $S$-unit group gives both at once.
- **Regulator and class number.** For real quadratic fields, the class number formula gives the product $hR$. So the class number and the regulator determine each other.

## Applications

- **Cryptography in class groups.** Groups of unknown order from imaginary quadratic fields appear in the Buchmann-Williams key exchange, in verifiable delay functions and in encryption schemes. Computing the class group breaks their assumptions.
- **CSIDH.** [CSIDH](/csidh/) uses the action of the class group of an imaginary quadratic order on supersingular elliptic curves. Knowing the structure of this group, which was computed classically for the CSIDH-512 parameters, makes the scheme faster and allows signature schemes. A quantum class group algorithm alone does not break CSIDH, which rests on a hidden shift problem.
- **Primality proving.** [ECPP](/ecpp/) builds curves with complex multiplication by a quadratic order, and the degree of the class polynomial it needs is the class number.
- **Number theory.** Class groups are central to Diophantine questions such as Fermat's last theorem for regular primes, to class field theory, and to the Cohen-Lenstra heuristics on the distribution of class groups.
