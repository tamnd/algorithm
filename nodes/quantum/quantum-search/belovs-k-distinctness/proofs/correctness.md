We use the notation of the page: $N$ input values, the promise of at most one $k$-collision $M = \{a_1 < \cdots < a_k\}$ in a positive input, $r_s = N^{\rho_s}$, and Theorem 2 of Belovs's paper (Reichardt; Lee, Mittal, Reichardt, Špalek and Szegedy), which we do not prove again: a feasible solution $X_1, \ldots, X_N$ of the dual adversary bound with objective $A$ gives a bounded-error algorithm with $O(A)$ queries.

**Claim.** (a) With $\rho_1$ from L1 and $\rho_s$ from L2, all $k$ terms of the cost (12) equal $N^{\rho_1}$, and $\rho_1 = 1 - 2^{k-2}/(2^k - 1) = 3/4 - 1/(4(2^k - 1))$. (b) For $k = 2$, the matrices of the learning graph satisfy $\sum_{j: x_j \ne y_j} X_j[x, y] = 1$ for every positive $x$ and negative $y$, they are positive semidefinite, and the objective is $O(r + \sqrt{N} + N/\sqrt{r})$, which is $O(N^{2/3})$ for $r = N^{2/3}$. (c) For $k \ge 3$, the fault-tolerant learning graph of Section 6 of the paper is feasible (Lemma 9 of the paper, cited and not proved here), and its objective is (12) up to a factor that depends only on $k$.

*Proof.* **Part (a).** Let $\delta = 1 - \rho_1$. Line L2 gives $1 - \rho_s = (1 - \rho_{s-1})/2$, so $1 - \rho_s = \delta/2^{s-1}$ for $s = 1, \ldots, k - 1$. In (12), with $r_s = N^{\rho_s}$, the first term has the exponent $\rho_1$. For $2 \le s \le k - 1$, the term $r_s\sqrt{r_1 \cdots r_{s-1}/N^{s-1}}$ has the exponent
$$\rho_s + \tfrac12\Big(\sum_{i<s}\rho_i - (s-1)\Big) = 1 - \frac{\delta}{2^{s-1}} - \frac{\delta}{2}\sum_{i=1}^{s-1}\frac{1}{2^{i-1}} = 1 - \frac{\delta}{2^{s-1}} - \delta\Big(1 - \frac{1}{2^{s-1}}\Big) = 1 - \delta = \rho_1.$$
The last term $\sqrt{N^k/(r_1 \cdots r_{k-1})}$ has the exponent
$$\tfrac12\Big(k - \sum_{i=1}^{k-1}\rho_i\Big) = \tfrac12\Big(1 + \delta\sum_{i=1}^{k-1}\frac{1}{2^{i-1}}\Big) = \tfrac12 + \delta\Big(1 - \frac{1}{2^{k-1}}\Big).$$
This equals $1 - \delta$ if and only if $\delta(2 - 2^{1-k}) = 1/2$, that is $\delta = 2^{k-2}/(2^k - 1)$, which is the value of L1. Then $\rho_1 = (2^k - 1 - 2^{k-2})/(2^k - 1) = (3 \cdot 2^{k-2} - 1)/(2^k - 1)$, and $3/4 - 1/(4(2^k - 1)) = (3 \cdot 2^k - 4)/(4(2^k - 1))$ is the same number. So the sum (12) is $k N^{\rho_1}$. Also $\rho_{k-1} = 1 - 1/(2^k - 1) < 1$, so $r_1 + \cdots + r_{k-1} = O(N^{\rho_{k-1}}) = o(N)$ and the sets fit for large $N$.

**Part (b).** For $k = 2$ there are no covered elements, and two inputs *agree* on a set $T$ if they are equal on $T$. The internal randomness is a set $R$ of size $r$, and the arcs are: on stage I.1, for every $R$ and $0 \le \ell < r$, the arc from the first $\ell$ elements of $R$ that loads the next element of $R$; on stage II.1, for every $R$ and $j \notin R$, the arc from $R$ that loads $j$; on stage II.2, for every set $S$ of size $r + 1$ and $j \notin S$, the arc from $S$ that loads $j$. For a positive $x$ with the pair $\{a_1, a_2\}$ and a set $R$ disjoint from it, the path of $x$ and $R$ takes the $r$ arcs of stage I.1 for $R$, then the arc from $R$ that loads $a_1$, then the arc from $R \cup \{a_1\}$ that loads $a_2$. Each such arc carries the flow $q = 1/\binom{N-2}{r}$. An arc of stage II.2 from $S$ determines $R = S \setminus \{a_1\}$, so no arc lies on two paths of $x$.

An arc $e$ from the set $T$ that loads $j$, with weight $w_e$, adds to $X_j$ the matrix $q\psi\psi^*$ for each assignment of values to $T$, where $\psi[z] = 1/\sqrt{w_e}$ if $f(z) = 1$, $z$ has these values on $T$ and $e$ is on a path of $z$; $\psi[z] = \sqrt{w_e}$ if $f(z) = 0$ and $z$ has these values on $T$; and $\psi[z] = 0$ otherwise. Each $q\psi\psi^*$ is positive semidefinite, so each $X_j$ is a sum of positive semidefinite matrices and is positive semidefinite.

Fix a positive $x$ and a negative $y$. The entry $X_j[x, y]$ is $q$ times the number of arcs that load $j$, lie on a path of $x$, and start at a set on which $x$ and $y$ agree. Fix one path, with the loaded sets $\emptyset = T_0 \subset T_1 \subset \cdots \subset T_{r+2} = R \cup \{a_1, a_2\}$, where arc $i$ loads $t_i$ from $T_{i-1}$. The inputs agree on $T_0$. They do not agree on $T_{r+2}$: otherwise $y_{a_1} = x_{a_1} = x_{a_2} = y_{a_2}$, and $y$ would be positive. Let $i$ be the first index where they do not agree on $T_i$. Then they agree on $T_{i-1}$ and $x_{t_i} \ne y_{t_i}$, so arc $i$ counts in the sum for $j = t_i$. An arc $i' < i$ loads $t_{i'}$ with $x_{t_{i'}} = y_{t_{i'}}$, so it does not count for any $j$ with $x_j \ne y_j$, and an arc $i' > i$ starts at a set on which they do not agree. So each path gives exactly $q$. There are $\binom{N-2}{r}$ paths of $x$, one for each $R$, and the sum is $\binom{N-2}{r} q = 1$.

The objective. For a positive $z$, each arc on a path of $z$ gives $q/w_e$ to $\sum_j X_j[z, z]$: the $\binom{N-2}{r}$ paths give $r \cdot 1 + 1/w_{\mathrm{II.1}} + 1/w_{\mathrm{II.2}} = r + \sqrt{N} + N/\sqrt{r}$ with the weights of L6, $w_{\mathrm{II.1}} = N^{-1/2}$ and $w_{\mathrm{II.2}} = \sqrt{r}/N$. For a negative $z$, every arc gives $q w_e$. With $c = \binom{N}{r}/\binom{N-2}{r} = N(N-1)/((N-r)(N-r-1))$, the sum over the $r\binom{N}{r}$ arcs of stage I.1, the $(N - r)\binom{N}{r}$ arcs of stage II.1 and the $(N - r - 1)\binom{N}{r+1}$ arcs of stage II.2 is
$$c\Big(r + \frac{N - r}{\sqrt{N}} + \frac{(N-r)(N-r-1)}{r+1}\cdot\frac{\sqrt{r}}{N}\Big) \le c\Big(r + \sqrt{N} + \frac{N}{\sqrt{r}}\Big).$$
For $r \le N/2$ and $N \ge 4$ we have $c \le 12$, so the objective is $O(r + \sqrt{N} + N/\sqrt{r})$. At $r = N^{2/3}$ this is $O(N^{2/3})$. This proves (b).

**Part (c).** For $k \ge 3$, the learning graph of Table 2 fails: if $y_b = x_{a_1}$ for some $b \in S_i$ with $i > 1$, then $b$ is covered on $y$ before $a_1$ is loaded and uncovered after, so $x$ and $y$ can stop agreeing on an arc that loads $a_1$ with $x_{a_1} = y_{a_1}$, and the path then gives 0 (Section 5.3 of the paper). A negative $y$ has at most $k - 1$ such elements $b$. Section 6 of the paper splits each set into parts labeled by subsets, and Lemma 9 proves, by inclusion and exclusion over the faulty parts, that for each choice of the randomness the arcs taken for $x$ still give exactly $q$ to the sum. The number of parts depends only on $k$, so the objective is (12) times a factor that depends only on $k$. With part (a), the objective is $O(N^{\rho_1})$.

**Conclusion.** By Theorem 2, the feasible solution gives a bounded-error algorithm with $O(N^{1 - 2^{k-2}/(2^k - 1)})$ queries under the promise. The promise is removed by running it on random subsets of sizes $(2k/(2k+1))^i N$, with a constant-factor loss, as in the Variants section of the page. $\blacksquare$
