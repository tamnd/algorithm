We use the pseudocode UNIFY of the page and the definitions below. The proof has three parts. Part 1 describes the answer as the least congruence on the nodes of the two inputs. Part 2 shows that this answer is the least upper bound under subsumption, which is Shieber's definition of unification. Part 3 shows that UNIFY computes the least congruence, finds every clash, and stops.

## Definitions

A feature structure $A$ is a finite set of nodes with a root $r_A$, a partial function $\delta_A(x, f)$ that gives the value of feature $f$ at node $x$, and a partial atom label $\mathrm{atom}(x)$. A node with an atom has no features. A node with no atom and no feature is empty. Cycles and shared nodes (reentrancy) are allowed. We assume that every node is reachable from the root.

$A$ subsumes $D$, written $A \sqsubseteq D$, if there is a map $h$ from the nodes of $A$ to the nodes of $D$ with $h(r_A) = r_D$, with $h(\delta_A(x, f)) = \delta_D(h(x), f)$ whenever $\delta_A(x, f)$ is defined (so the right side is defined too), and with $\mathrm{atom}(h(x)) = \mathrm{atom}(x)$ whenever $\mathrm{atom}(x)$ is defined. Because every node is reached by a path from the root and each step of a path is forced, $h$ is unique if it exists. This is the same as Shieber's definition in terms of paths: every path of $A$ is a path of $D$, every atom value of a path of $A$ is the same in $D$, and two paths that lead to one node of $A$ lead to one node of $D$.

Let the inputs $A$ and $B$ have disjoint node sets, and let $U$ be their union, with $n$ nodes and $e$ arcs in all. An equivalence relation $\equiv$ on $U$ is a unifying congruence if

1. $r_A \equiv r_B$, and
2. if $x \equiv y$ and both $\delta(x, f)$ and $\delta(y, f)$ are defined, then $\delta(x, f) \equiv \delta(y, f)$.

It is consistent if no class holds two nodes with different atoms, and no class holds a node with an atom and a node with a feature. The intersection of unifying congruences is a unifying congruence, and the relation that puts all of $U$ in one class is one, so there is a least one. Call it $\theta$.

If $\theta$ is consistent, the quotient $U/\theta$ is a feature structure: its nodes are the classes, its root is the class of $r_A$, the value of $f$ at a class $C$ is the class of $\delta(x, f)$ for any $x \in C$ that has $f$ (condition 2 makes this independent of the choice), and the atom of $C$ is the atom of its members, if any. Consistency makes the atoms well defined and keeps atoms and features apart. We keep only the classes reachable from the root.

## Part 1 and 2: the quotient is the least upper bound

**Lemma 1.** If $\theta$ is consistent, then $A \sqsubseteq U/\theta$ and $B \sqsubseteq U/\theta$.

*Proof.* Map each node to its class. The root of $A$ goes to the root class, and the root of $B$ goes there too because $r_A \,\theta\, r_B$. Arcs and atoms are kept by the definition of the quotient. ∎

**Lemma 2.** If $A \sqsubseteq D$ and $B \sqsubseteq D$ for some feature structure $D$, then $\theta$ is consistent and $U/\theta \sqsubseteq D$.

*Proof.* Let $h_A$ and $h_B$ be the two maps into $D$, and let $h$ be their union on $U$. Define $x \sim y$ if $h(x) = h(y)$. This is an equivalence relation. It holds for $r_A$ and $r_B$, because both go to $r_D$. If $x \sim y$ and both have $f$, then $h(\delta(x, f)) = \delta_D(h(x), f) = \delta_D(h(y), f) = h(\delta(y, f))$, so condition 2 holds. Hence $\sim$ is a unifying congruence and $\theta \subseteq {\sim}$.

A class of $\theta$ lies inside a class of $\sim$, so all its nodes go to one node $z$ of $D$. If two of them had different atoms, $z$ would carry both. If one had an atom and another had a feature, $z$ would carry an atom and a feature. Neither is possible in $D$, so $\theta$ is consistent. The map $[x] \mapsto h(x)$ is well defined on $U/\theta$ because $\theta \subseteq {\sim}$, and it keeps the root, the arcs and the atoms because $h$ does. So $U/\theta \sqsubseteq D$. ∎

Lemmas 1 and 2 say that, when $\theta$ is consistent, $U/\theta$ is subsumed by both inputs and subsumes every structure that both inputs subsume. This is Shieber's definition of the unification $A \sqcup B$. When $\theta$ is not consistent, Lemma 2 says that no structure is subsumed by both inputs, so unification must fail.

## Part 3: UNIFY computes $\theta$

Let $P$ be the partition of the union-find forest (two nodes are in one block if they have the same root). Let $\approx$ be the equivalence relation generated by $P$ and by the pairs on the stack. We show four invariants, true at the test of line L2.

- (I1) ${\approx} \subseteq \theta$.
- (I2) For every block with root $x$, every member $y$ and every feature $f$ of $y$, the table $\mathrm{arcs}(x)$ has an entry for $f$, and $\mathrm{arcs}(x)[f] \approx \delta(y, f)$. If some member has an atom, $\mathrm{atom}(x)$ is that atom.
- (I3) Every block of $P$ is consistent, and $\mathrm{arcs}(x)$ is empty for a root $x$ whose block has no member with a feature.
- (I4) $r_A \approx r_B$.

**Start.** Line L1 puts the pair $(r_A, r_B)$ on the stack. Every block is a single node with its own atom and features. (I1) holds because $r_A \,\theta\, r_B$. (I2) and (I3) hold because each node is its own root and an input node with an atom has no features. (I4) holds by the pair on the stack.

**A step that does not merge.** Line L3 pops $(u, v)$ and finds the roots $x$ and $y$. If $x = y$ (line L4), then $u$ and $v$ were already in one block, so removing the pair does not change $\approx$. All invariants stay true.

**A clash.** Suppose line L5 finds a clash between the roots $x$ and $y$. By (I1), $u \,\theta\, v$, so $x$ and $y$ and their blocks lie in one class of $\theta$. By (I2) and (I3), a root atom is the atom of a member, and a non-empty table means that a member has a feature. So the class of $\theta$ holds two different atoms, or an atom and a feature. Then $\theta$ is not consistent, and by Lemma 2 failure is the right answer.

**A merge.** Otherwise lines L6 to L12 join the blocks of $x$ and $y$. The pair $(u, v)$ leaves the stack, but $u$ and $v$ are now in one block, so $\approx$ does not lose it. The new pairs are $(\mathrm{big}[f], \mathrm{small}[f])$ for each feature $f$ in both tables. By (I2) there are members $m_1$ and $m_2$ of the two blocks with $\mathrm{big}[f] \approx \delta(m_1, f)$ and $\mathrm{small}[f] \approx \delta(m_2, f)$. We have $m_1 \,\theta\, m_2$ by (I1), so $\delta(m_1, f) \,\theta\, \delta(m_2, f)$ by condition 2, and the new pair is in $\theta$. So (I1) holds. For (I2), a feature in one table only moves to the merged table with the same value, and a feature in both keeps the value of the big table, which is now $\approx$ to the value of the small table through the new pair. The atom of the new root is the atom of one of the old roots (line L7), and there was no clash, so it is the atom of every member that has one. (I3) holds because there was no clash: the two blocks do not hold different atoms, and they do not hold an atom on one side and a feature on the other. (I4) holds because $\approx$ never loses a pair.

**The end.** When the stack is empty, $\approx$ is $P$. By (I4), $r_A$ and $r_B$ are in one block. By (I2), if two members $y$ and $y'$ of one block both have $f$, then $\delta(y, f) \approx \mathrm{arcs}(x)[f] \approx \delta(y', f)$, so they are in one block. So $P$ is a unifying congruence and $\theta \subseteq P$. With (I1), $P = \theta$. By (I3), $\theta$ is consistent. The roots, their atoms and their tables are exactly the quotient $U/\theta$: the class of a root $x$ has the atom $\mathrm{atom}(x)$, and its value for $f$ is the block of $\mathrm{arcs}(x)[f]$. Line L13 returns the root of the block of $r_A$, which is the root of the quotient. By Lemmas 1 and 2 this is the unification.

## Termination

Each pass of the loop pops one pair. A pair is pushed only at line L10, and each push removes one entry of the small table, which is then dropped at line L12. The tables hold at most $e$ entries in all at the start and never gain new entries, so there are at most $e$ pushes, and the loop runs at most $e + 1$ times. A merge joins two blocks, so there are at most $n - 1$ merges.

## Cost

The loop makes at most $2(e + 1)$ finds and $n - 1$ unions. With union by rank and path compression they cost $O((n + e)\,\alpha(n))$ in all (Tarjan 1975), where $\alpha$ is the inverse Ackermann function.

The table work at a merge is one lookup for each entry of the small table. Take a merge with a small table of size $s$, a big table of size $L \ge s$, and $c$ shared features. It moves $s - c$ entries and drops $c$. The merged table has $L + s - c$ entries. If $c > s/2$, the moves are fewer than the drops, and over the whole run there are at most $e$ drops. If $c \le s/2$, each moved entry goes from a table of size $s$ to a table of size at least $L + s/2 \ge 1.5\,s$. A table that holds an entry never gets smaller (a big table becomes a table of size $L + s - c \ge L$), and no table has more than $e$ entries. So each entry moves at most $\log_{1.5} e$ times in merges of the second kind. The table work is $O(e \log e)$ lookups and inserts in all, each of expected constant time with hash tables. The total time is $O((n + e)\,\alpha(n) + e \log e)$ expected.

When every complex node has the same fixed set of features, as for first-order terms where both nodes carry the same function symbol, every entry of the small table is shared, nothing moves, and the bound becomes $O((n + e)\,\alpha(n))$, the bound of Huet's algorithm.
