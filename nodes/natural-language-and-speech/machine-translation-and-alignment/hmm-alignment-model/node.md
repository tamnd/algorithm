The HMM alignment model treats a [word alignment](/word-alignment/) as the hidden state sequence of a [hidden Markov model](/hidden-markov-model/). The states are the positions $1, \ldots, l$ of the target sentence $e$. As the model reads the source sentence $f = f_1 \ldots f_m$ from left to right, it moves from the position aligned to $f_{j-1}$ to the position aligned to $f_j$, and the probability of the move depends only on its width $a_j - a_{j-1}$. Each state emits its source word from the table $t(f \mid e)$ of [IBM Model 1](/ibm-model-1/). So the model prefers alignments in which neighbouring source words go to neighbouring target words, which neither Model 1 nor [Model 2](/ibm-model-2/) can express. Because it is an HMM, the sum over all alignments and the best alignment are exact by the [forward-backward](/forward-backward-algorithm/) and [Viterbi](/viterbi-algorithm/) algorithms in $\Theta(m l^2)$ time per pair. Vogel, Ney and Tillmann (1996) proposed the model, and Och and Ney (2003) added the null word.

## The machine

**Variables.** A pair is $f = f_1 \ldots f_m$ and $e = e_1 \ldots e_l$, with the null word $e_0$. An alignment is $a = a_1 \ldots a_m$ with $a_j \in \{0, \ldots, l\}$, in the direction $p(f \mid e)$: source word $j$ is generated by target word $a_j$. The reverse direction is a different model and gives different alignments; the two are often combined by [grow-diag-final](/grow-diag-final-symmetrization/).

**Parameters.**

- $t(f \mid e)$, with a row for the null word;
- a weight $c(d) \ge 0$ for each jump width $d$; for a sentence of length $l$ the jump from position $r$ to position $i$ has probability $c(i - r) / \sum_{i'=1}^{l} c(i' - r)$ (Vogel et al. 1996);
- the null probability $p_0$, a fixed number. The code uses $p_0 = 0.2$, the value of Och and Ney (2003).

**The null word.** A source word aligned to the null word has no target position, so the next jump needs another starting point. Och and Ney (2003) double the state set: state $i + l$ is "null, after position $i$". From a state that remembers position $r$ (the real state $r$ or the null state $r + l$), the model goes to the null state of $r$ with probability $p_0$, or to a real position $i$ with probability $(1 - p_0)$ times the jump probability from $r$ to $i$. This page writes $r_j$ for the last real position aligned at or before $j$. The code also puts a virtual position $r_0 = 0$ in front of the sentence, so the first word uses the jump from 0, and it keeps a null state for that position too. Then

$$p(f, a \mid e) = \prod_{j=1}^{m} p(a_j \mid r_{j-1}, l) \, t(f_j \mid e_{a_j}), \qquad p(i \mid r, l) = \begin{cases} p_0 & i = 0, \\ (1 - p_0) \dfrac{c(i - r)}{\sum_{i'=1}^{l} c(i' - r)} & i \ge 1. \end{cases}$$

For example, with $l = 3$, $r = 1$, $c(0) = 1$, $c(1) = 4$, $c(2) = 2$ and $p_0 = 0.2$, the next word goes to position 1, 2 or 3 with probabilities $0.8 \cdot 1/7$, $0.8 \cdot 4/7$ and $0.8 \cdot 2/7$, that is 0.114, 0.457 and 0.229, and to the null word with probability 0.2.

**Standing assumptions.** The jump probabilities depend on the width only, not on the words or the absolute position. Each source word depends only on the target word of its state. A state path with nonzero probability is fixed by the alignment, so sums over state paths are sums over alignments.

**Training.** EM is [Baum-Welch](/baum-welch-algorithm/) with tied transition parameters. One round, in log space:

```pseudo id=main
HMM-ALIGNMENT-EM-ROUND(corpus, t, c)
L1  for each pair (f, e) in the corpus do
L2      α ← the forward table of ln probabilities, from the jumps out of position 0
L3      β ← the backward table of ln probabilities
L4      ln p(f | e) ← ln Σ_s exp α_m(s)
L5      for each j and state s: add γ_j(s) = exp(α_j(s) + β_j(s) - ln p(f | e)) to c_t(f_j, word of s)
L6      for each j and real position i: add the expected number of jumps r → i at j to N(r, i, l)
L7  t(f | e) ← c_t(f, e) / Σ_f' c_t(f', e)
L8  c' ← the count update: c'(d) proportional to Σ over i - r = d of N(r, i, l)
L9  c ← the best of c and c', improved by gradient ascent on Q(ln c), keeping only steps that raise Q
L10 return t and c
```

Lines L2 to L4 are the [forward algorithm](/forward-algorithm/) and the backward pass of the HMM, with the [log-sum-exp](/log-sum-exp-trick/) helper of the area, so that long sentences do not underflow. Line L6 needs the forward value at $j - 1$, the jump, the emission and the backward value at $j$. Line L7 is the exact M step for $t$.

**The jump step.** The M step for $c$ maximizes $Q(c) = \sum_{r, i, l} N(r, i, l) \ln \bigl( c(i - r) / \sum_{i'} c(i' - r) \bigr)$. The rows $r$ have different normalizers, so the simple count update of line L8 is not the maximizer. From uniform $c$ and uniform $t$, every row of posteriors is uniform and uniform $c$ is optimal, but small widths occur in more rows, so the count update favours them and lowers $Q$; the tests show such a case. In $\theta = \ln c$, $Q$ is a linear function minus a sum of log-sum-exp terms, so it is concave, and line L9 climbs it with backtracking steps. The round is then a generalized EM step, and the likelihood never decreases.

**Example.** Twelve pairs in which every target word $e_k$ is translated in place by $f_k$, with random words and lengths 2 to 5, trained from uniform $t$ and $c$ with the null word:

| round | log likelihood | share of $c(1)$ | $t(f_3 \mid e_3)$ |
|---|---|---|---|
| 0 | -68.09 | 0.10 | 0.167 |
| 2 | -37.90 | 0.15 | 0.578 |
| 4 | -14.13 | 0.57 | 0.936 |
| 6 | -7.73 | 0.95 | 1.000 |

In the first rounds $t$ learns the lexicon while $c$ stays near uniform. Then the jump of width 1 takes most of the weight. For the pair $f_3 f_1 f_1 f_4 \mid e_3 e_1 e_1 e_4$ the trained model gives the alignment $(1, 2, 3, 4)$. With the same $t$ and uniform jumps the two copies of $e_1$ tie, and the tie rule gives $(1, 2, 2, 4)$. These numbers are a measurement on a toy corpus.

## What it counts

The model assigns $p(f \mid e) = \sum_a p(f, a \mid e)$, a sum over $(l + 1)^m$ alignments. One step is one arithmetic operation on real numbers, as on the [real RAM](/real-ram/). With $2l + 1$ states and transitions that are dense among the real states, the costs per pair are:

| Task | Algorithm | Cost |
|---|---|---|
| $p(f \mid e)$ | forward algorithm | $\Theta(m l^2)$ |
| posteriors of links and jumps (E step) | forward-backward | $\Theta(m l^2)$ |
| best alignment $\arg\max_a p(a \mid f, e)$ | Viterbi algorithm | $\Theta(m l^2)$ |
| the same by enumeration | | $\Theta(m (l + 1)^m)$ |

The M step for $t$ is linear in the size of the counts. The jump step works on the counts $N(r, i, l)$, whose number is at most the number of distinct $(r, i, l)$ in the corpus.

## Relation to other models

- **Hidden Markov model.** The model is a [hidden Markov model](/hidden-markov-model/) whose states are target positions and whose outputs are source words. The transition matrix is different for each sentence length but tied through $c$, and the emission matrix is tied through $t$.
- **IBM Model 1.** With all $c(d)$ equal and no null word, every jump has probability $1/l$, and the model is Model 1 without the null word. The tests check this.
- **IBM Model 2.** In [Model 2](/ibm-model-2/) the position $a_j$ depends on $j$ and the lengths, not on $a_{j-1}$. Vogel et al. (1996) compare the two.
- **fast_align.** [fast_align](/fast-align/) keeps the independence of Model 2 and pulls links towards the diagonal. It is faster, with an E step of $\Theta(l m)$ per pair, but it cannot model a block of words that moves together.
- **IBM Models 3 and 4.** [Model 3](/ibm-model-3/) adds fertility, and Model 4 makes the position of a word depend on the position of the previous group, which is close to the jump idea. Their E steps are approximate. Och and Ney (2003) train Model 1, then the HMM, and use it to start Models 3 and 4.

## Known results in the model

- **Exact inference (theorem).** The forward algorithm computes the sum over all alignments, and the Viterbi algorithm the best alignment, in $\Theta(m l^2)$ per pair, because the alignment is a Markov chain over positions. The tests compare both with the enumeration of all alignments, and the link posteriors with the brute-force posteriors. So [word alignment](/word-alignment/) under this model is solvable exactly, unlike under Model 3, where the best alignment is NP-hard.
- **EM never decreases the likelihood (theorem).** This holds for the exact M step and for any step that does not lower $Q$. The tests check it round by round on random corpora with and without the null word.
- **The count update is not the M step (shown by example).** The simple update of line L8 can lower $Q$, as described above; the tests show a case. This is an observation of this page, not a claim of the papers.
- **Local maxima.** Like other HMMs, the model has a likelihood that is not concave in general, and EM reaches a local maximum. The usual start is the table $t$ of Model 1 (Och and Ney 2003).
- **Underflow.** A pair of 200 source words, each with probability $1/50$, has $p(f \mid e) = 50^{-200}$, which is 0 in double precision. The log-space forward pass returns $-200 \ln 50$; the tests check this.
