---
title: In the plane, parity patching makes every cell even, the signs then exist and are unique up to complement, closed input keeps its even-odd inside, and the contour is a set of closed curves around the inside points
proves: [correctness, termination]
status: full
---

**Setup.** The grid has $n_x \times n_y$ square cells of side $h$ and the grid points $(i, j)$, $0 \le i \le n_x$, $0 \le j \le n_y$, at the positions $(X_i + \varepsilon, Y_j + \varepsilon^2)$ for an infinitesimal $\varepsilon > 0$. The input is a finite list of segments with rational end points, all at distance at least $h$ from the border of the grid. A grid edge joins two neighbouring grid points. An edge is *inner* if it lies on two cells, and *outer* if it lies on the border of the grid. After line L2, an edge is *marked* if it crosses the input an odd number of times.

**Lemma 1 (general position).** No grid point lies on a segment of positive length, and no segment end point lies on a grid edge. So every meeting of a segment with a grid edge is a proper crossing at a point inside both, and `crossed_edges` assigns each such crossing to exactly one edge.

*Proof.* The point $(X + \varepsilon, Y + \varepsilon^2)$ lies on the line through $p \ne q$ if and only if $(X + \varepsilon - p_x)(q_y - p_y) - (Y + \varepsilon^2 - p_y)(q_x - p_x) = 0$. As a polynomial in $\varepsilon$ its coefficient of $\varepsilon$ is $q_y - p_y$ and of $\varepsilon^2$ is $-(q_x - p_x)$, which are not both zero, so it is not zero for small $\varepsilon > 0$. A rational end point cannot have the coordinate $Y + \varepsilon^2$ of a horizontal edge or $X + \varepsilon$ of a vertical edge. For the assignment, write the crossing of $pq$ with the line $y = Y_j + \varepsilon^2$ as $x = x_0 + \varepsilon^2 \, \Delta x / \Delta y$, where $x_0$ is the crossing with $y = Y_j$. Then $x > X_i + \varepsilon$ if and only if $x_0 > X_i$, since a tie leaves the sign of $-\varepsilon$, and $x < X_{i+1} + \varepsilon$ if and only if $x_0 \le X_{i+1}$. The intervals $(X_i, X_{i+1}]$ are disjoint and cover the line, so exactly one index fits. The vertical case is the same with the crossing $y = y_0 + \varepsilon \, \Delta y / \Delta x$: a tie $y_0 = Y_j$ goes up when $\Delta x \, \Delta y > 0$ and down otherwise. $\square$

By the margin, no segment reaches the outer grid lines, so no outer edge is ever marked.

**Lemma 2 (patching).** Let $B$ be the set of cells with an odd number of marked edges after line L2. Then $|B|$ is even, the loop of lines L4 and L5 ends, and afterwards every cell has an even number of marked edges. No outer edge changes.

*Proof.* As long as every marked edge is inner, each marked edge lies on exactly two cells, so the sum over all cells of the number of marked edges is twice the number of marked edges, and the number of cells with an odd count is even. The loop keeps the invariant that the set $\mathit{todo}$ of the code is exactly the set of cells that are odd at that moment, and that every marked edge is inner. Line L4 takes a cell $c$ of $\mathit{todo}$ and removes it. An odd number of cells of $\mathit{todo}$ remain, so at least one, and the grid of cells is connected, so the breadth-first search finds one of them, $d$. The search moves between cells only across inner edges, so line L5 changes only inner edges. Along the path $c = c_0, c_1, \ldots, c_r = d$, the edge between $c_{t-1}$ and $c_t$ changes its mark. A cell $c_t$ with $0 < t < r$ lies on two changed edges, so its parity stays. The cells $c$ and $d$ lie on one changed edge each, so their parity changes from odd to even. Each round removes two cells from $B$, and no cell outside $B$ becomes odd, so after $|B|/2$ rounds every cell is even. $\square$

**Lemma 3 (signs).** If every cell has an even number of marked edges, there is a function $s$ on the grid points with $s(a) \ne s(b)$ exactly for the marked edges $ab$. Line L6 computes one such function with the corner $(0, 0)$ outside, it is the only one with that value, and every grid point on the border of the grid is outside.

*Proof.* Line L6 is a breadth-first search of the grid graph from $(0, 0)$, and it sets $s(w) = s(v) \oplus [vw \text{ marked}]$ along the edges of its search tree. The grid graph is connected, so every point gets a value. For any edge $ab$, the tree paths from $(0, 0)$ to $a$ and to $b$ and the edge $ab$ make a closed walk $Z$, and $s(a) \oplus s(b) \oplus [ab \text{ marked}]$ is the parity of the number of marked edges in $Z$. Over $\mathrm{GF}(2)$, every closed walk in the grid graph is the sum of the boundaries of the cells it encloses, since the grid is a planar graph whose bounded faces are the cells, and the boundaries of the bounded faces span its cycle space. Each cell boundary has an even number of marked edges, so $Z$ does too, and $s(a) \oplus s(b) = [ab \text{ marked}]$. Any other function with this property differs from $s$ by a constant on the connected graph, so the value at $(0, 0)$ fixes it, and the complement is the only other one. The border points are joined to $(0, 0)$ by outer edges, which are not marked, so they share its value. $\square$

**Lemma 4 (closed input).** Suppose each end point appears in the list of segments an even number of times, as for any set of closed polygons, with or without self-intersections. Then line L3 finds no odd cell, and the sign of each grid point is its even-odd value: the parity of the number of segments that a ray from it to the right crosses.

*Proof.* Let $\chi(a)$ be the even-odd value of the grid point $a$. For an edge $ab$, let $R$ be a large number, and consider the closed polygon $a \to b \to b + (R, 0) \to a + (R, 0) \to a$, which runs along the edge, along the ray from $b$, along a short segment far to the right of the input, and back along the ray from $a$. By Lemma 1 and the perturbation, it meets the input only in proper crossings. The input is a sum of closed polygons over $\mathrm{GF}(2)$, because each end point has even degree. Two closed polygons in the plane in general position cross an even number of times, so the number of crossings of $ab$ with the input plus those of the two rays is even, and the edge $ab$ is marked if and only if $\chi(a) \ne \chi(b)$. Then the count of marked edges on each cell is the number of changes of $\chi$ around its four corners, which is even, so there are no odd cells. The function $\chi$ satisfies the condition of Lemma 3, and $\chi = 0$ at the corner $(0, 0)$, which is outside the bounding box of the input. By uniqueness, $s = \chi$. $\square$

**Lemma 5 (the contour).** After line L7, each output vertex is the start of exactly one segment and the end of exactly one, two segments meet only at common end points, and each grid point lies inside the output, by the even-odd rule, if and only if its sign is inside. Each segment has the inside points of its cell on its left.

*Proof.* In a cell, walk the four corners counterclockwise. The marked edges are exactly the edges where the sign changes, by Lemma 3, and the changes alternate between inside to outside and outside to inside. Line L7 joins each change from inside to outside to the next change back, so each marked edge of the cell is the start or the end of exactly one segment of the cell. An inner edge is walked in opposite directions by its two cells, so a change from inside to outside in one cell is a change back in the other. So the midpoint of each marked edge starts one segment and ends one segment. A segment joins midpoints of two edges of one cell, and in a cell with four marked edges the two segments cut off the two opposite outside corners, so they are disjoint. Segments of different cells lie in different closed cells, which share at most an edge, and on that edge the only output point is its midpoint. So the output is a set of disjoint closed polygons. Each output polygon crosses each marked edge once, at its midpoint, passing from one cell to the other, and crosses no unmarked edge, so its even-odd value changes across exactly the marked edges. The even-odd value of the output is 0 at $(0, 0)$, which lies outside all output polygons, and Lemma 3 gives that it equals $s$. For the orientation, a segment from the edge after an inside corner to the edge before the next inside corner turns around the outside corners between them on its right, so the inside corners of its cell are on its left. $\square$
