---
title: Point membership classification with neighborhoods is exact
proves: [correctness]
status: full
---

Let $T$ be a CSG tree in the plane whose leaves are convex polygons $P_1, \ldots, P_L$, each a closed regular set, and whose inner nodes are $\cup^*$, $\cap^*$ and $-^*$. Write $X_T$ for the set of the tree. For a node $T$ let $\Phi_T$ be the plain set formula of its subtree, with $\cup$, $\cap$ and $\setminus$ in place of the regularized operations, and with each leaf $P_i$ replaced by its interior. Fix a point $p$.

**Lemma 1 (local sectors).** Let $\Lambda$ be the set of edge lines of the leaves that pass through $p$, and $D$ the set of the $2|\Lambda|$ directions along them. There is $\varepsilon > 0$ such that, for each open sector $\sigma$ between consecutive directions of $D$ (the whole punctured disk if $D$ is empty), the set $C_\sigma = \{p + t d : d \in \sigma, 0 < t < \varepsilon\}$ lies in $\operatorname{int} P_i$ or in $E^2 \setminus P_i$, for each $i$.

*Proof.* Each edge line not through $p$ has a positive distance from $p$. Let $\varepsilon$ be less than the least of these distances. Then no edge line other than those of $\Lambda$ meets the disk $U$ of radius $\varepsilon$ around $p$. The set $C_\sigma$ is connected and meets no edge line, so each edge expression $\operatorname{orient}(a, b, x)$ has a constant nonzero sign on $C_\sigma$. A point of the plane is in $\operatorname{int} P_i$ exactly when all edge expressions of $P_i$ are positive, and outside $P_i$ when one is negative. So $C_\sigma$ is wholly in $\operatorname{int} P_i$ or wholly outside $P_i$. $\square$

Call the *true neighborhood* of $p$ in a closed regular set $Y$ the set of $\sigma$ with $C_\sigma \subseteq \operatorname{int} Y$.

**Lemma 2 (the formula on a sector).** For each node $T$ and each sector $\sigma$, $C_\sigma \subseteq \operatorname{int} X_T$ if $C_\sigma \subseteq \Phi_T$, and $C_\sigma \cap X_T = \emptyset$ otherwise.

*Proof.* Write $C = C_\sigma$; it is open. We show by induction on $T$ that $X_T \cap C$ is $C$ or empty, and that it is $C$ exactly when $C \subseteq \Phi_T$. By Lemma 1, $\Phi_T \cap C$ is $C$ or empty for every node. For a leaf, Lemma 1 gives $C \subseteq \operatorname{int} P_i = \Phi_T$ or $C \cap P_i = \emptyset$. For an inner node, $X_T = r(Y)$ with $Y = X_{\text{left}} \circ X_{\text{right}}$ for the plain operation $\circ$. By the induction hypothesis, $Y \cap C$ is $C$ or empty, and it is $C$ exactly when the plain operation of the two truth values is true, that is, when $C \subseteq \Phi_T$. If $Y \cap C = C$, then $C \subseteq \operatorname{int} Y \subseteq r(Y)$, because $C$ is open. If $Y \cap C = \emptyset$, then $\operatorname{int} Y \cap C = \emptyset$, and since $C$ is open, $\operatorname{cl}(\operatorname{int} Y) \cap C = \emptyset$. In the first case $C \subseteq X_T$ and $C$ is open, so $C \subseteq \operatorname{int} X_T$. $\square$

**Lemma 3 (leaves).** LEAF-NEIGHBORHOOD$(p, P_i)$ returns a list of breakpoints and labels such that a direction $d$ in a sector $\sigma$ of $D$ is labeled in exactly when $C_\sigma \subseteq \operatorname{int} P_i$.

*Proof.* If an edge expression of $P_i$ is negative at $p$, it stays negative on $U$, so every $C_\sigma$ is outside $P_i$, and the empty neighborhood is right. If all are positive, every $C_\sigma$ is inside, and the full disk is right. Otherwise let $E_0$ be the edges whose lines pass through $p$. For $x = p + t d$, the expression of an edge $(a, b)$ with $e = b - a$ through $p$ equals $t \cdot \operatorname{cross}(e, d)$, and the other expressions are positive on $U$. So $C_\sigma \subseteq \operatorname{int} P_i$ exactly when $\operatorname{cross}(e, d) > 0$ for all $e \in E_0$, at any $d \in \sigma$. The breakpoints $\pm e$ of the leaf are a subset of $D$, so each sector of $D$ lies in one sector of the leaf, and the leaf labels its sectors with this test at a sample direction. $\square$

**Lemma 4 (sample directions).** For breakpoints $u \ne v$ consecutive in counterclockwise order, the direction $s$ of line L7 lies strictly inside the open sector from $u$ to $v$.

*Proof.* If $\operatorname{cross}(u, v) > 0$, the sector is less than a half turn, and $\operatorname{cross}(u, u + v) = \operatorname{cross}(u, v) > 0$ and $\operatorname{cross}(u + v, v) = \operatorname{cross}(u, v) > 0$, so $u + v$ is inside. If $\operatorname{cross}(u, v) = 0$ and $u, v$ point opposite ways, the sector is the half-plane to the left of $u$, and $\operatorname{cross}(u, u^\perp) = |u|^2 > 0$ for $u^\perp = (-u_y, u_x)$. If $\operatorname{cross}(u, v) < 0$, the sector is more than a half turn, and its complement, the sector from $v$ to $u$, is less than a half turn and contains $u + v$ by the first case. So $-(u + v)$, which is opposite to a direction strictly inside a sector of less than a half turn, is not in the closed complement, and it lies in the sector from $u$ to $v$. If there is a single breakpoint $u$, the sector is the full turn without $u$, and $-u$ is in it. $\square$

**Theorem.** For every node $T$, CLASSIFY$(p, T)$ returns breakpoints and labels such that each $d$ in a sector $\sigma$ of $D$ is labeled in exactly when $C_\sigma \subseteq \operatorname{int} X_T$. PMC$(p, T)$ returns IN when $p \in \operatorname{int} X_T$, OUT when $p \notin X_T$, and ON when $p \in \partial X_T$.

*Proof.* By induction on the tree. For a leaf, lines L1 and L2 and Lemma 3 give the claim. For an inner node with operation $\circ$, the induction hypothesis holds for both children. Line L5 takes the union of their breakpoints, which is a subset of $D$, so each sector of $D$ lies in one sector $\tau$ of the merged list. By Lemma 4 the sample of line L7 is in $\tau$, so by the hypothesis line L8 sets the label of $\tau$ to $[C_\sigma \subseteq \operatorname{int} X_{\text{left}}] \circ [C_\sigma \subseteq \operatorname{int} X_{\text{right}}]$ for each sector $\sigma \subseteq \tau$ of $D$. By Lemma 2 applied to the children, $C_\sigma \subseteq \operatorname{int} X_{\text{left}}$ exactly when $C_\sigma \subseteq \Phi_{\text{left}}$, and the same for the right child. So the label is the truth of $C_\sigma \subseteq \Phi_T$, which by Lemma 2 is the truth of $C_\sigma \subseteq \operatorname{int} X_T$. Line L9 removes only breakpoints with equal labels on both sides, which does not change the label of any direction.

For PMC, let $N$ be the neighborhood of the root. If all labels are in, then $U \setminus \Lambda \subseteq X_T$. The set $X_T$ is closed and $U \setminus \Lambda$ is dense in $U$, so $U \subseteq X_T$ and $p \in \operatorname{int} X_T$. If no label is in, then by Lemma 2 every $C_\sigma$ misses $X_T$, so $X_T \cap U \subseteq \Lambda$. A closed regular set is the closure of its interior, and an open set inside the finite union of lines $\Lambda$ is empty, so $\operatorname{int} X_T \cap U = \emptyset$ and $p \notin \operatorname{cl}(\operatorname{int} X_T) = X_T$. If some labels are in and some are out, then $p$ is a limit of points of $\operatorname{int} X_T$, so $p \in X_T$, and also a limit of points outside $X_T$, so $p \notin \operatorname{int} X_T$. So $p \in \partial X_T$. $\blacksquare$

**Termination.** CLASSIFY calls itself once on each child, so it visits each node of the finite tree once. Each COMBINE loops once over a finite list of breakpoints.

**Segments.** For a segment from $a$ to $b$, let $t_0 = 0 < t_1 < \cdots < t_k = 1$ be its parameters at the crossings with the edge lines of all leaves. On an open piece $(t_j, t_{j+1})$ every edge expression has a constant sign or is zero all along, so the leaf neighborhoods of its points are the same, and by the theorem so is the class against $X_T$. So the class of one point of each piece and the classes of the split points give the exact classification of the segment.
