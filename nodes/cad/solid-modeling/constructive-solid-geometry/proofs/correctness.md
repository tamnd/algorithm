---
title: The octant mask classifies every point exactly against the regularized solid of a CSG tree of axis-aligned boxes
proves: [correctness, termination]
status: full
---

We use the pseudocode of the page. A tree $T$ is built from closed boxes with $lo < hi$ on each axis and integer corners, the operations $\cup$, $\cap$, $\setminus$ and motions $x \mapsto R x + t$ with $R$ a signed permutation matrix of determinant 1 and $t$ an integer vector. Write $[T]$ for the ordinary value of the formula, with the ordinary set operations on closed boxes, and $T^*$ for the regularized value. The point $p$ has rational coordinates. For $s \in \{-1, +1\}^3$ and $\varepsilon > 0$ let $p_s(\varepsilon) = p + \varepsilon s$.

**Lemma 1 (the leaf planes).** Every face of every box, moved by the motions above it, lies on a plane $x_j = c$ with $c$ an integer. So $[T]$ is a finite union of sets of the form $\prod_j I_j$ where each $I_j$ is a point, an open interval or a closed interval with integer ends, and its value changes only across such planes.

*Proof.* A signed permutation maps the plane $x_j = c$ to a plane $x_{j'} = \pm c$, and an integer translation keeps the right side an integer. The faces of a box lie on such planes. The rest follows by induction on the tree, since unions, intersections and differences of products of intervals with integer ends are finite unions of such products. $\square$

Let $\delta(p) > 0$ be the distance from $p$ to the nearest integer plane $x_j = c$ that does not contain $p$; it exists because the coordinates of $p$ are rational, and for $0 < \varepsilon < \delta(p)$ the point $p_s(\varepsilon)$ is on no integer plane and on the same side of each integer plane through $p$ as every other $p_{s'}(\varepsilon')$ with $s'$ having the signs of $s$ and $0 < \varepsilon' < \delta(p)$. Call the set of such points the octant $O_s$. It is open, and by Lemma 1 it is wholly inside or wholly outside $[T]$ for every tree $T$, because no plane on which $[T]$ can change crosses it.

**Lemma 2 (MASK).** MASK($T$, $p$) $= \{s : O_s \subseteq [T]\}$.

*Proof.* By induction on $T$. For a box, $O_s \subseteq [lo, hi]$ holds exactly when for each axis $j$, the points $p_j + \varepsilon s_j$ with $0 < \varepsilon < \delta(p)$ lie in $[lo_j, hi_j]$. If $lo_j < p_j < hi_j$ this is true for both signs, since $lo_j$ and $hi_j$ are integers and so at distance at least $\delta(p)$ from $p_j$ or equal to it. If $p_j = lo_j$, it is true only for $s_j = +1$, because $lo_j < hi_j$; if $p_j = hi_j$, only for $s_j = -1$; and if $p_j$ is outside $[lo_j, hi_j]$, it is false. This is line L1. For an operation, each $O_s$ is wholly in or out of $[A]$ and of $[B]$, so $O_s \subseteq [A] \cup [B]$ exactly when $O_s \subseteq [A]$ or $O_s \subseteq [B]$, and similarly for $\cap$ and $\setminus$, which are lines L3 to L6. For a motion, $p + \varepsilon s \in \{R x + t : x \in [A]\}$ exactly when $R^T(p - t) + \varepsilon R^T s \in [A]$, since $R^{-1} = R^T$. The vector $R^T s$ is again in $\{-1, +1\}^3$, the point $R^T(p - t)$ is rational, and the octant of $R^T s$ at $R^T(p - t)$ is the image of $O_s$ under the inverse motion, so the induction hypothesis for $A$ gives line L2. $\square$

**Lemma 3 (the regularized value near $p$).** Let $U$ be the open ball of radius $\delta(p)$ around $p$. Then $\operatorname{int} [T] \cap U$ and $\operatorname{int} T^* \cap U$ contain the same octants, and $p \in T^*$ exactly when some $O_s \subseteq [T]$, and $p \in \operatorname{int} T^*$ exactly when all eight $O_s \subseteq [T]$.

*Proof.* Let $N$ be the union of the integer planes through $p$; $U \setminus N$ is the union of the eight octants. By fact 7 of the regularized set operations page, $T^* = r([T])$, where $r(X) = \operatorname{cl}(\operatorname{int} X)$. An octant is open, so if it lies in $[T]$ it lies in $\operatorname{int}[T]$, and so in $r([T])$. If an octant does not lie in $[T]$, it is disjoint from $[T]$, so it is an open set disjoint from $\operatorname{int}[T]$, and it is disjoint from $\operatorname{cl}(\operatorname{int}[T])$ too. So inside $U \setminus N$, $T^*$ is the union of the octants in MASK. Now $N \cap U$ has empty interior, so $\operatorname{int} [T] \cap U \subseteq \operatorname{cl}(\operatorname{int}[T] \cap (U \setminus N))$, which is the closure of the union of the inside octants, intersected with $U$. If some octant is inside, $p$ is in its closure, so $p \in T^*$. If none is, $\operatorname{int}[T] \cap U = \emptyset$, so $p \notin \operatorname{cl}(\operatorname{int}[T]) = T^*$. If all eight are inside, the closure of their union contains $U$, so $U \subseteq T^*$ and $p \in \operatorname{int} T^*$. If some octant $O_s$ is not inside, it is disjoint from $T^*$ by the argument above, and $p$ is in its closure, so $p$ is a limit of points outside $T^*$, and $p \notin \operatorname{int} T^*$. $\square$

**Theorem.** CLASSIFY($T$, $p$) returns IN if $p \in \operatorname{int} T^*$, ON if $p \in \partial T^*$, and OUT if $p \notin T^*$. It stops after $O(n)$ steps for a tree of $n$ nodes.

*Proof.* By Lemma 2, line L7 computes $\{s : O_s \subseteq [T]\}$. By Lemma 3, the mask is empty exactly when $p \notin T^*$, full exactly when $p \in \operatorname{int} T^*$, and otherwise $p \in T^* \setminus \operatorname{int} T^* = \partial T^*$, since $T^*$ is closed. Lines L8 to L10 return these answers. Each call of MASK on a node makes at most two calls on its children and a constant amount of other work, and the tree is finite, so the recursion stops after one visit per node. $\square$

**Corollary (general position).** If $p$ is on no integer plane, then MASK($T$, $p$) is empty or full, and CLASSIFY($T$, $p$) is IN exactly when $p \in [T]$.

*Proof.* Then no integer plane passes through $p$, so the ball $U$ meets no plane on which $[T]$ changes, and $U$ is wholly in or out of $[T]$; the mask is full or empty by Lemma 2, and $p \in [T]$ exactly when it is full. $\square$

The tests check the theorem against an independent brute force. By Lemma 1 the regularized solid is the union of the closed unit cells $c + [0, 1]^3$ whose centres lie in $[T]$, and the octant $O_s$ at a point $p$ of the half-integer grid lies in the cell that contains $p + s/4$. The tests compare the mask with these cells at random half-integer points of random trees, and the class with the ordinary formula at random points with denominator 7, which lie on no integer plane. $\blacksquare$
