---
title: The plane section of a quadric CSG solid is the same Boolean tree of exact conics, and the polygon output is within the tolerance
proves: [correctness, termination]
status: full
---

**Setting.** A leaf is a symmetric $4 \times 4$ matrix $Q$, and the leaf solid is $S_Q = \{p \in \mathbb R^3 : \hat p^{\mathsf T} Q \hat p \le 0\}$ with $\hat p = (x, y, z, 1)$. A tree $T$ is a leaf or $(\mathrm{op}, T_1, T_2)$ with op in $\{\cup, \cap, \setminus\}$, and its solid $S(T)$ is defined by the same recursion. For a height $Z$ let $\Pi_Z = \{(x, y, Z)\}$, and identify $\Pi_Z$ with $\mathbb R^2$. Lines L1 and L2 build the tree $T_Z$ with each leaf $Q$ replaced by the $3 \times 3$ matrix $M = \text{SECTION}(Q, Z)$:
$$M_{ij} = Q_{ij}\ (i, j \le 2),\qquad M_{i3} = M_{3i} = Q_{i3} Z + Q_{i4}\ (i \le 2),\qquad M_{33} = Q_{33} Z^2 + 2 Q_{34} Z + Q_{44}.$$
The set of a conic leaf is $C_M = \{(x, y) : \bar p^{\mathsf T} M \bar p \le 0\}$ with $\bar p = (x, y, 1)$, and $S(T_Z)$ is built from these sets by the same operations.

**Claim.**

1. $S(T_Z) = S(T) \cap \Pi_Z$ as point sets, and every entry of every $M$ is rational when $Q$ and $Z$ are rational.
2. CLASSIFY returns the right type for an ellipse leaf, its center $c$ and the value $f_c$ at the center, and the squared semi-axes are $-f_c / \lambda_1$ and $-f_c / \lambda_2$, where $\lambda_1, \lambda_2$ are the eigenvalues of the $2 \times 2$ block.
3. For an ellipse with largest semi-axis $a$ and a tolerance $0 < \text{tol} < a$, the polygon of POLYLINE has $n$ vertices on the ellipse, with $n$ the least integer at least 3 such that $a(1 - \cos(\pi/n)) \le \text{tol}$, and its Hausdorff distance from the ellipse is at most tol.
4. The algorithm stops after $O(|T|)$ exact operations for the tree and $O(|T| \sum n_i)$ float operations for the polygons.

**Step 1 (one leaf).** Let $p = (x, y, Z)$ and $\bar p = (x, y, 1)$. Write $\hat p^{\mathsf T} Q \hat p = \sum_{i, j} Q_{ij} \hat p_i \hat p_j$ and split the indices into $\{1, 2\}$, $\{3\}$ and $\{4\}$, with $\hat p_3 = Z$ and $\hat p_4 = 1$. The terms with $i, j \le 2$ give $\sum_{i,j \le 2} Q_{ij} \bar p_i \bar p_j$. The terms with one index $i \le 2$ and the other in $\{3, 4\}$ give $2 \sum_{i \le 2} (Q_{i3} Z + Q_{i4}) \bar p_i$, by symmetry of $Q$. The terms with both indices in $\{3, 4\}$ give $Q_{33} Z^2 + 2 Q_{34} Z + Q_{44}$. This sum is $\bar p^{\mathsf T} M \bar p$ term by term. So $\hat p^{\mathsf T} Q \hat p = \bar p^{\mathsf T} M \bar p$ for every $(x, y)$, and $C_M = S_Q \cap \Pi_Z$. The entries of $M$ are sums and products of entries of $Q$ and of $Z$, so they are rational when the input is rational.

**Step 2 (the tree).** By induction on $T$. For a leaf this is step 1. For an inner node, intersection with a fixed set distributes over the three operations:
$$(A \cup B) \cap \Pi = (A \cap \Pi) \cup (B \cap \Pi),\quad (A \cap B) \cap \Pi = (A \cap \Pi) \cap (B \cap \Pi),\quad (A \setminus B) \cap \Pi = (A \cap \Pi) \setminus (B \cap \Pi).$$
With the induction hypothesis for $T_1$ and $T_2$ this gives $S(T_Z) = S(T) \cap \Pi_Z$. This proves claim 1.

The claim is about the plain set operations. A CAD kernel uses regularized operations, which take the closure of the interior of the result. Regularization does not commute with the section. The ball $x^2 + y^2 + z^2 \le 25$ meets the plane $z = 5$ in the single point $(0, 0)$, and its leaf conic is $x^2 + y^2 \le 0$, which is that point. The regularized 2D set of a point is empty. So at a plane that touches a face, the exact set of claim 1 can have parts of lower dimension, and the printer must drop them. The membership test of the code is the set of claim 1.

**Step 3 (CLASSIFY).** Write the conic as $f(x) = x^{\mathsf T} A x + 2 b^{\mathsf T} x + f_0$ with $A$ the $2 \times 2$ block, $b = (M_{13}, M_{23})$ and $f_0 = M_{33}$. If $\det A \ne 0$, the gradient $2(A x + b)$ is zero exactly at $c = -A^{-1} b$, which is the formula of the code by Cramer's rule. Substitute $x = c + w$: $f = w^{\mathsf T} A w + 2 w^{\mathsf T}(A c + b) + c^{\mathsf T} A c + 2 b^{\mathsf T} c + f_0 = w^{\mathsf T} A w + f_c$, because $A c + b = 0$ and $c^{\mathsf T} A c = -b^{\mathsf T} c$, so $f_c = f_0 + b^{\mathsf T} c$. If $\det A > 0$ and $A_{11} > 0$, then $A$ is positive definite and $\{w^{\mathsf T} A w \le -f_c\}$ is an ellipse with center $c$ if $f_c < 0$, the point $c$ if $f_c = 0$, and empty if $f_c > 0$. In the orthonormal eigenbasis of $A$ the set is $\lambda_1 w_1^2 + \lambda_2 w_2^2 \le -f_c$, so the squared semi-axes are $-f_c/\lambda_1$ and $-f_c/\lambda_2$. Their product is $f_c^2 / \det A$ and their sum is $-f_c \operatorname{tr}(A) / \det A$, both rational. This proves claim 2. The other types are reported but give no loop in the code.

**Step 4 (the polygon).** Let the ellipse be $E = \{c + L u : |u| = 1\}$ with $L = [a_1 e_1,\ a_2 e_2]$, $e_1 \perp e_2$ unit vectors and $a = a_1 \ge a_2$. Then $|L v| \le a |v|$ for every $v$. The polygon $P$ has the vertices $c + L u_k$ with $u_k = (\cos(2\pi k/n), \sin(2\pi k/n))$, so its vertices are on $E$, and $P$ is the image under $x \mapsto c + L x$ of the regular $n$-gon $P_0$ inscribed in the unit circle.

Pair each point of the unit circle with a point of $P_0$ along the same ray from the origin. On the arc between $u_k$ and $u_{k+1}$, the point at angle $\theta$ from the middle of the arc, with $|\theta| \le \pi/n$, pairs with the point of the chord at distance $\rho = \cos(\pi/n)/\cos\theta$ from the origin, and $\cos(\pi/n) \le \rho \le 1$. This pairing is a bijection between the circle and the boundary of $P_0$, because every ray from the origin meets each of them once. For a pair $(u, \rho u)$ the image points differ by $L((1 - \rho) u)$, of length at most $a(1 - \rho) \le a(1 - \cos(\pi/n))$. So every point of $E$ has a point of $P$ within that distance, and every point of $P$ has a point of $E$ within it. The Hausdorff distance is at most $a(1 - \cos(\pi/n))$, which is at most tol by the choice of $n$. For tol $< a$ the value $1 - \text{tol}/a$ is in $(0, 1)$, the smallest real $n$ with $\cos(\pi/n) \ge 1 - \text{tol}/a$ is $\pi / \arccos(1 - \text{tol}/a)$, and $n$ is its ceiling, at least 3. The code adds 1 to $n$ while the float test fails, which only increases $n$. This proves claim 3.

**Step 5 (termination and cost).** SECTION does a fixed number of exact operations on one leaf, and lines L1 and L2 visit each node once. CLASSIFY is a fixed number of operations. Membership of one point visits each node once. POLYLINE makes $n_i$ vertices for leaf $i$, and the trimming test of line L7 classifies each vertex against the tree in $O(|T|)$ time. No step loops without bound, so the algorithm stops. This proves claim 4.

**What is not proved.** The trimming of line L7 keeps the vertices that are on the boundary of the layer. It works with floats and a small $\varepsilon$, and near a point where two conics cross, the kept run ends at the last vertex before the crossing, up to one edge away from it. The exact crossing points are the roots of a quartic and are not computed here. The bound of claim 3 is for a full ellipse, not for a trimmed run.
