---
title: With a step-over of at most twice the tool radius and a last contour pass, the zigzag path cuts exactly the dilated region
proves: [correctness, termination]
status: full
---

**Setting.** $C$ is a closed polygon with holes: its boundary $\partial C$ is the union of the edges of a finite set of rings, and a point not on $\partial C$ is in $C$ when a horizontal ray from it crosses $\partial C$ an odd number of times, counted by the half-open rule below. Let $y_{\min}$ and $y_{\max}$ be the smallest and largest $y$ of a vertex, $s > 0$ the step-over, $r > 0$ the tool radius, and $y_k = y_{\min} + s/2 + ks$ for $k = 0, \dots, K - 1$, where $K$ is the number of values with $y_k < y_{\max}$. $D_r$ is the closed disk of radius $r$ at the origin. The path $\Gamma$ is the set of points on the strokes that DIRECTION-PARALLEL returns.

**Claim.** (a) The algorithm stops, and each interval of line L1 is cut exactly once. (b) $\Gamma \subseteq C$. (c) If $s \le 2r$, every point of $C$ is within $s/2$ of $\Gamma$, and $\Gamma \oplus D_r = C \oplus D_r$.

**The half-open rule.** For a line $y = c$ and a vertex $v$, let $\pi(v)$ be true when $v_y > c$. An edge $uv$ is counted when $\pi(u) \ne \pi(v)$, and its crossing is the point of the edge at height $c$. Around each ring, $\pi$ changes an even number of times, so the number $m$ of counted edges is even. For a point $p$ on the line and not on $\partial C$, no crossing has $x = p_x$, since that crossing would be a point of an edge equal to $p$. The ray test counts the crossings with $x > p_x$, and the crossings with $x < p_x$ number $m$ minus that, which has the same parity.

**Lemma 1 (intervals).** Let $x_0 \le x_1 \le \dots \le x_{m-1}$ be the sorted crossings on the line $L$ at height $c$. Then each closed interval $[x_{2i}, x_{2i+1}]$ lies in $C$, and $C \cap L \subseteq \bigcup_i [x_{2i}, x_{2i+1}] \cup \partial C$. *Proof.* Each $x_j$ is a point of an edge, so it is in $\partial C \subseteq C$. Let $p \in L$ with $p \notin \partial C$. By the half-open rule, $p \in C$ if and only if the number of crossings left of $p$ is odd, that is, if and only if $x_{2i} < p_x < x_{2i+1}$ for some $i$. So the open intervals hold exactly the points of $C \cap L$ that are not on $\partial C$, and the closed intervals add only points of $\partial C$. The code drops the intervals of length zero, whose single point is on $\partial C$. $\square$

**Lemma 2 (segment test).** SEGMENT-IN-REGION$(a, b)$ returns true if and only if the segment $ab$ lies in $C$. *Proof.* The code collects the parameters $t \in [0, 1]$ of all points where $ab$ meets an edge: the crossing point when the two segments are not parallel, and the projections of the edge ends that lie on $ab$ when they are collinear. Parallel edges that are not collinear do not meet $ab$. So every point of $ab \cap \partial C$ either has a collected parameter or lies on a collinear edge whose ends are collected. Take two consecutive parameters $t_0 < t_1$ and the open piece between them. If a collinear edge overlaps the piece, the edge ends are outside the open piece, so the edge covers all of it, and the piece lies in $\partial C \subseteq C$; its midpoint is on $\partial C$, and the closed point test returns true. Otherwise the open piece does not meet $\partial C$. It is connected, so it lies wholly in the interior of $C$ or wholly outside $C$, and its midpoint decides which. The ends $a$ and $b$ and all the collected points are tested or are on $\partial C$. $\square$

**Proof of (a).** Each run of the body of line L4 marks the current interval as used in line L5. That interval is unused when it becomes current: line L3 takes an unused interval, and line L8 takes one from the unused candidates of line L6. So each interval is cut once, and the loop of line L2 stops when none is unused. There are at most $m/2$ intervals per line and $K$ lines, so this takes a finite number of steps.

**Proof of (b).** The strokes are made of three kinds of segments. Each cut along an interval lies in $C$ by Lemma 1. Each link was accepted by the segment test, so it lies in $C$ by Lemma 2. The passes of line L9 run along the edges, which are in $\partial C$.

**Proof of (c).** Every edge is on $\Gamma$, so $\partial C \subseteq \Gamma$. By Lemma 1 and part (a), every point of $C \cap L_k$ is on a cut interval or on $\partial C$, so $C \cap L_k \subseteq \Gamma$ for each pass line $L_k$.

Let $p \in C$. If $p \in \partial C$, its distance to $\Gamma$ is 0. Otherwise $p$ is an interior point. Put $y_{-1} = y_0 - s$ and $y_K = y_{K-1} + s$, two heights that are not pass lines, with $y_{-1} < y_{\min}$ and $y_K \ge y_{\max}$. Since $y_{\min} \le p_y \le y_{\max}$, there is a $k$ with $-1 \le k \le K - 1$ and $y_k \le p_y \le y_{k+1}$.

Walk up from $p$ to height $y_{k+1}$ along the vertical segment $\sigma$. If $\sigma$ meets $\partial C$, the first such point is on $\Gamma$ at distance at most $y_{k+1} - p_y$. If not, $\sigma$ is a connected set that starts at an interior point and does not meet $\partial C$, so it lies in the interior of $C$. Its top end is then an interior point at height $y_{k+1}$. All vertices have $y \le y_{\max}$, so no interior point has $y \ge y_{\max}$; hence $y_{k+1} < y_{\max}$ and $k + 1 \le K - 1$, so the top end lies on the pass line $L_{k+1}$ and in $C$, which puts it on $\Gamma$. In both cases $\Gamma$ has a point within $y_{k+1} - p_y$ of $p$. The same walk downward, with $y_{-1} < y_{\min}$ in place of $y_K \ge y_{\max}$, gives a point of $\Gamma$ within $p_y - y_k$. The two distances add up to $y_{k+1} - y_k = s$, so one of them is at most $s/2$.

Now let $s \le 2r$. By (b), $\Gamma \oplus D_r \subseteq C \oplus D_r$. Conversely, let $x = c + v$ with $c \in C$ and $|v| \le r$. If $x \in C$, it is within $s/2 \le r$ of $\Gamma$. If $x \notin C$, the segment from $c$ to $x$ is connected and joins a point of $C$ to a point outside it, so it meets $\partial C$ at a point $b$, and $|x - b| \le |x - c| \le r$ with $b \in \Gamma$. So $x \in \Gamma \oplus D_r$. $\blacksquare$

**Remark.** The contour pass is needed. In the walk above, the first boundary point that $\sigma$ meets is on $\Gamma$ only because line L9 runs along every edge. Without it, a thin part of $C$ that lies between two pass lines and does not meet either of them gets no pass, and the test file gives such a tongue.
