---
title: Every pair of neighbouring passes has a computed scallop height of at most the target, each step is maximal up to the bisection width, and the method stops
proves: [correctness, termination]
status: full
---

**Setting.** The profile is $p(t) = (t, f(t))$ on $[a, b]$ with $f$ continuously differentiable, unit normal $n(t) = (-f'(t), 1)/\sqrt{1 + f'(t)^2}$, tool radius $r > 0$ and target $h > 0$. The tool circle of the pass at $t$ has center $c(t) = p(t) + r\,n(t)$. Write $H(t, t')$ for the value that SCALLOP returns for the passes $t < t'$; it is $+\infty$ when the circles do not meet. The proof is about $H$ as computed. How well $H$ matches the true height of the ridge is a question of the golden-section search, which the tests measure.

**Claim.** (a) If ISO-SCALLOP returns $a = t_0 < t_1 < \dots < t_N = b$, then $H(t_{i-1}, t_i) \le h$ for $i = 1, \dots, N$. (b) For $i < N$, there is a $t^+ \in (t_i, b]$ with $t^+ - t_i \le (b - a)2^{-60}$ and $H(t_{i-1}, t^+) > h$, so no pass much farther than $t_i$ keeps the computed height at most $h$ in the same bracket. (c) If there is a $\delta_0 > 2(b-a)2^{-60}$ with $H(t, t') \le h$ whenever $0 < t' - t \le \delta_0$, the method stops after at most $\lceil 2(b - a)/\delta_0 \rceil + 2$ passes. (d) Line L8 returns a point at distance $r$ from both centers.

**Proof of (d).** Let $d = |c_1 - c_0|$ with $0 < d < 2r$ and $m$ the midpoint. The point $m + s k u$, with $u$ the unit vector perpendicular to $c_1 - c_0$ and $k = \sqrt{r^2 - d^2/4}$, has distance $\sqrt{d^2/4 + k^2} = r$ from both centers, for $s = \pm 1$. The sign is chosen so the point lies on the side of the line $c_0 c_1$ that faces away from $n(t_0) + n(t_1)$, the side of the surface.

**Proof of (a) and (b).** Line L2 runs the body only when $H(t, b) > h$ for the current pass $t$. Line L3 starts with $lo = t$ and $hi = \min(t + w_0, b)$. While $H(t, hi) \le h$ it sets $lo \leftarrow hi$ and doubles the step. This keeps the invariant $H(t, lo) \le h$ for $lo > t$, and it stops at the latest when $hi = b$, because $H(t, b) > h$. So after line L3, $lo < hi$, $H(t, hi) > h$, and either $lo = t$ or $H(t, lo) \le h$. Each bisection step of line L4 replaces $lo$ or $hi$ by the midpoint and keeps both facts, and halves $hi - lo$, so after 60 steps $hi - lo \le (b - a)2^{-60}$. The code then checks $lo > t$, so $H(t, lo) \le h$, and $lo$ becomes the next pass, with $t^+ = hi$. The last pair $(t_{N-1}, b)$ is added by line L6 only when $H(t_{N-1}, b) \le h$. The passes grow strictly, because each new one is $lo > t$.

**Proof of (c).** Under the assumption, every trial point $hi$ with $hi - t \le \delta_0$ has $H(t, hi) \le h$, so at the end of line L3 and during line L4, $hi > t + \delta_0$. At the end, $lo \ge hi - (b - a)2^{-60} > t + \delta_0/2$. So each pass is more than $\delta_0/2$ past the last one, and the passes before $b$ number at most $2(b - a)/\delta_0 + 1$. The loop of line L3 doubles a positive step until it reaches $b$, so it stops; line L4 runs 60 times. $\blacksquare$

**The cylinder.** On a convex cylinder of radius $R$, the tool centers lie on the circle of radius $R + r$ around the axis. For two contacts at angles $\pm\theta/2$ from a line through the axis, the cusp lies on that line by symmetry, at distance $\rho = R + h$ from the axis. It is $r$ from both centers, so the law of cosines gives $r^2 = (R + r)^2 + \rho^2 - 2(R + r)\rho\cos(\theta/2)$, which is the closed form of the code. On a concave cylinder with $R > r$, the centers lie on the circle of radius $R - r$ and the cusp at distance $R - h$, with the same equation. The tests compare the passes with these angles.

**What is assumed.** Part (c) needs the computed height to be at most $h$ for short steps. For a smooth profile without gouging, the height of a short step $w$ is about $w^2/(8r)$ times a factor that depends on the curvature, so the assumption holds, but this proof does not bound $\delta_0$ for a general profile. The method also does not prove that $H$ grows with $t'$; parts (a) and (b) do not need it.
