---
title: A perfect matching of the convex dual graph gives a conforming quad mesh, and the minimum cost perfect matching is found exactly
proves: [correctness, termination]
status: full
---

**What is proved and what is not.** Four results are proved here: the parity rule for quad meshes, the fact that a perfect matching of the dual graph gives a conforming quad mesh of the same region (and every quad mesh made by merging pairs comes from one), the reduction from minimum cost perfect matching to maximum weight matching of the largest size, and the termination of the code. The optimality of Edmonds' weighted blossom algorithm itself is a classical theorem; it is stated with an outline of its primal-dual proof, and the tests check it against a brute force over all matchings. Not proved, because it is false in general: that a perfect matching always exists, and any bound on the quality of the quads.

**Setting.** $T$ is a conforming triangle mesh: counterclockwise triangles with exact coordinates, no directed edge used twice, and no vertex inside an edge. The convex dual graph $G$ has one node per triangle and one edge for each pair of triangles $(u, v, k)$ and $(v, u, l)$ that share the edge $uv$ and whose union, the quad $(u, l, v, k)$, is strictly convex. Its cost is an integer $c \ge 0$.

**Theorem 1 (parity).** In a mesh of a planar region by $Q$ quads, in which every edge lies in one quad (a boundary edge) or two quads (an interior edge), the number $E_b$ of boundary edges is even.

*Proof.* Count pairs (quad, edge of that quad), the edge sides. Each quad has 4 edges, so there are $4Q$ pairs. Each interior edge is in two pairs and each boundary edge in one, so $4Q = 2E_i + E_b$. Then $E_b = 4Q - 2E_i$ is even. $\square$

The same count for the triangles gives $3|T| = 2E_i' + E_b$. A merge does not change the boundary, so a triangle mesh with an odd number of boundary edges has an odd number of triangles, and it cannot be merged into quads. In general, $|T|$ must be even (L1).

**Theorem 2 (a perfect matching is a quad mesh).** Let $M$ be a perfect matching of $G$. Replace each matched pair by its quad. The result is a conforming mesh of the same region by $|T|/2$ strictly convex counterclockwise quads, with the same vertices and the same boundary edges. Conversely, every set of quads that partitions $T$ into pairs of neighbours with strictly convex unions is a perfect matching of $G$.

*Proof.* Each triangle is in exactly one pair, so the quads number $|T|/2$, and each quad is the union of its two triangles, so the quads cover the same region with disjoint interiors and the same total area. A quad $(u, l, v, k)$ is strictly convex by the definition of $G$, and it is counterclockwise because $k$ is left of $u \to v$ and $l$ right of it. Its four directed edges $u \to l$, $l \to v$, $v \to k$, $k \to u$ are directed edges of its two triangles. The only edges that disappear are the two directions of the shared edge $uv$, which belong to this pair alone. So every directed edge of the new mesh is a directed edge of $T$, used once, and an edge of $T$ that is not a matched diagonal keeps both of its sides, or its one side on the boundary. The vertices of the quads are vertices of $T$, and no vertex lies inside a quad edge, because that edge is an edge of the conforming mesh $T$. So the quad mesh is conforming, and its boundary edges are those of $T$. For the converse, each pair is an edge of $G$, and the pairs cover each triangle once, which is a perfect matching. $\square$

So the merges of $T$ into convex quads are exactly the perfect matchings of $G$, and the best merge for a cost that adds over the quads is a minimum cost perfect matching.

**Lemma 3 (the reduction).** Let $n = |T|$, $C = 1 + \max c$, $K = nC$, and give each edge the weight $w = K + C - c$. Then every maximum weight matching has the largest size. If $G$ has a perfect matching, every maximum weight matching is a minimum cost perfect matching; if a maximum weight matching is not perfect, $G$ has no perfect matching.

*Proof.* Each weight lies in $(K, K + C]$, because $0 \le c < C$. A matching of size $s$ weighs at most $s(K + C)$, and a matching of size $s + 1$ weighs more than $(s + 1)K = sK + nC \ge s(K + C)$, since $s \le n$. So a heavier matching never has a smaller size, and a maximum weight matching has the largest size. If a perfect matching exists, the largest size is $n/2$, every matching of that size is perfect, and for a perfect matching $M$, $w(M) = (K + C)\,n/2 - c(M)$. So the largest weight is the smallest cost. If a maximum weight matching is not perfect, the largest size is below $n/2$. $\square$

**Theorem 4 (Edmonds, 1965).** The weighted blossom algorithm returns a maximum weight matching.

*Outline of the classical proof.* The algorithm keeps dual values $y_v$ for vertices and $z_B \ge 0$ for odd sets $B$ (the blossoms) such that every edge has slack $y_i + y_j + \sum_{B \ni i, j} z_B - w_{ij} \ge 0$, and every matched edge and every edge inside a blossom on the current tree paths has slack 0. It grows alternating trees on tight edges only, shrinks odd cycles of tight edges into blossoms, and augments along tight paths. When no tight edge helps, it changes the duals by the largest step that keeps them feasible; the four kinds of steps bring a vertex dual of an outer vertex to zero, make an edge from a tree to a free vertex tight, make an edge between two outer vertices tight, or bring the dual of an inner blossom to zero so it can be expanded. When a vertex dual reaches zero, its vertex can stay free at no loss, and the phase ends. At the end, the matching and the duals satisfy the complementary slackness conditions of the linear program of Edmonds' matching polytope, so the matching is optimal. The full proof is in Edmonds (1965) and in the textbooks of Korte and Vygen and of Schrijver.

*What the code adds.* The weights are integers and are doubled, so the starting vertex duals are even. Every dual step is a vertex dual, the dual of a blossom, the slack of an edge, or half the slack of an edge between two outer vertices; the code asserts that this slack is even, so all dual values stay integers and every comparison is exact. The code also has a mode that maximises the size first; Lemma 3 does not need it, and the tests check it separately. The tests compare the code with a brute force over all matchings on 150 random graphs of up to 9 vertices, in both modes, and with a brute force over all perfect matchings on 150 random graphs and on 56 triangle meshes of at most 12 triangles. A separate run on 3000 random graphs of up to 10 vertices found no difference.

**Termination.** Each augmentation adds one edge to the matching, so there are at most $n/2 + 1$ phases. Within a phase, each dual step labels a new vertex or blossom, makes a new blossom, expands a blossom, or ends the phase, so a phase has $O(n)$ dual steps, as Galil shows, and each step costs $O(n + m)$ in this code. For the dual graph, $m \le 3n/2$, so the whole run is $O(n^3)$. The dual graph and the merge are linear. So BLOSSOM-QUAD always stops.

**What is not proved.** A perfect matching need not exist. The test case is a triangle with one ear on each side: the convex dual graph is a star with three leaves, and two of the leaves can never be matched. The code then reports failure; a full mesher must change the triangle mesh. Also, the matching minimises the sum of costs, which is a measure of the average quad, not of the worst: no bound on the angles of the worst quad is proved, and a perfect matching can be forced to use poor quads. The quality of the result depends on the triangle mesh, and it is measured case by case.
