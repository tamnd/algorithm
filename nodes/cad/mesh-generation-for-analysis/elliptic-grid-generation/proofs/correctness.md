The page makes two kinds of claims. Part A is about the procedure ELLIPTIC-GRID as it runs. Part B is about the continuous map that the discrete equations approximate. It rests on the Radó-Kneser-Choquet theorem, which is cited with its proof, and it says what the discrete grid does not inherit.

## Part A: the procedure

**Claim A.** Let the sides $B, T, L, R$ meet at common corners, let $0 < \omega < 2$, $\mathrm{tol} > 0$ and $K \ge 1$. Then ELLIPTIC-GRID:

1. returns a grid whose boundary points are the input side points;
2. stops after at most $K$ sweeps;
3. returns "converged" only if every interior point satisfies $\lvert G_{ij}(x)_k - x_{ij,k} \rvert < \mathrm{tol}$ for both coordinates $k$, where $G_{ij}(x)$ is the value of L5 to L8 at $(i, j)$ for the returned grid;
4. with $P = Q = 0$ and exact arithmetic, if the side points are evenly spaced samples of an affine map $A(u, v) = a + b u + c v$, returns the grid $x_{ij} = A(i/M, j/N)$ after one sweep.

**Step 1 (the discrete equation).** At an interior point, with unit index spacing, L5 to L7 compute $x_\xi = (x_{i+1,j} - x_{i-1,j})/2$, $x_\eta = (x_{i,j+1} - x_{i,j-1})/2$, $\alpha = |x_\eta|^2$, $\beta = x_\xi \cdot x_\eta$, $\gamma = |x_\xi|^2$, $J = \det(x_\xi, x_\eta)$ and the cross difference $X = (x_{i+1,j+1} - x_{i+1,j-1} - x_{i-1,j+1} + x_{i-1,j-1})/4$. None of these depend on $x_{ij}$. The discrete equation is

$$\alpha (x_{i+1,j} - 2 x_{ij} + x_{i-1,j}) - 2 \beta X + \gamma (x_{i,j+1} - 2 x_{ij} + x_{i,j-1}) + J^2 (P_{ij} x_\xi + Q_{ij} x_\eta) = 0.$$

It is linear in $x_{ij}$ with coefficient $-2(\alpha + \gamma)$. If $\alpha + \gamma > 0$, its unique solution for $x_{ij}$ with the neighbours fixed is the value $G_{ij}$ of L8, and the left side equals $2(\alpha + \gamma)(G_{ij} - x_{ij})$. So $G_{ij} - x_{ij}$ is the residual of the equation divided by $2(\alpha + \gamma)$. If $\alpha + \gamma = 0$, then $x_{i+1,j} = x_{i-1,j}$ and $x_{i,j+1} = x_{i,j-1}$, the grid has collapsed there, and the code stops with an error.

**Step 2 (parts 1 and 2).** L1 builds the initial grid by transfinite interpolation, whose boundary points are the side points. The code copies them, so that float rounding cannot move them. The loops of L3 and L4 run over $1 \le i \le M - 1$ and $1 \le j \le N - 1$ only, so no boundary point is written later. This is part 1. The loop of L2 runs at most $K$ times. Each sweep and each residual of L10 visits $(M - 1)(N - 1)$ points with a constant number of operations, and every exit is a return. This is part 2.

**Step 3 (part 3).** L10 computes $r = \max_{ij} \max_k \lvert G_{ij}(x)_k - x_{ij,k} \rvert$ on the grid after the sweep, with the same formula as L5 to L8. L11 returns "converged" only if $r < \mathrm{tol}$. By Step 1, this bounds the residual of every discrete equation by $2(\alpha + \gamma)\,\mathrm{tol}$ at that point. In floating point, the bound holds for the computed values of $G_{ij}$. The tests check it again with a separate formula for the discrete equation.

**Step 4 (part 4).** TFI reproduces data that are linear in each parameter, as proved on the [transfinite interpolation page](/transfinite-interpolation-grid/), so the initial grid is $x_{ij} = A(i/M, j/N)$. Then $x_\xi = b/M$ and $x_\eta = c/N$ at every interior point, all second differences and the cross difference $X$ vanish, and the discrete equation with $P = Q = 0$ reads $0 = 0$. So $G_{ij} = x_{ij}$ at every point, the first sweep changes nothing, $r = 0 < \mathrm{tol}$, and the procedure returns after one sweep. $\blacksquare$

## Part B: the continuous map

**Theorem (Radó-Kneser-Choquet).** Let $\mathbb{D}$ be the open unit disk, let $\Omega \subset \mathbb{R}^2$ be a bounded convex domain whose boundary is a Jordan curve $\Gamma$, and let $\varphi : \partial \mathbb{D} \to \Gamma$ be a homeomorphism. Let $F$ be the harmonic extension of $\varphi$ to $\mathbb{D}$, the Poisson integral of each coordinate. Then $F$ is a one-to-one harmonic map of $\mathbb{D}$ onto $\Omega$, and its Jacobian does not vanish in $\mathbb{D}$.

This is the theorem as stated and proved in Duren, *Harmonic Mappings in the Plane*, in the chapter "Harmonic Mappings onto Convex Regions" (p. 29, with Choquet's proof on p. 31). Duren allows a more general boundary function, which only makes the theorem stronger. We use it without a full proof here. Its proof, in Kneser's form, goes as follows. For a line $a x + b y = c$, the harmonic function $h = a F_1 + b F_2 - c$ has boundary values that change sign at most twice on the circle, because a line meets the boundary of a convex domain in at most two points or in one segment. If $\nabla h$ vanished at some point $z_0$, the level set $\{h = h(z_0)\}$ would leave $z_0$ in at least four arcs, which by the maximum principle reach the circle and separate regions where $h - h(z_0)$ alternates in sign, so the boundary values of $h - h(z_0)$ would change sign at least four times. So $a \nabla F_1 + b \nabla F_2 \ne 0$ for all $(a, b) \ne 0$, which says that the rows of the Jacobian matrix are independent. A map with a nonvanishing Jacobian whose boundary map runs once around $\Gamma$ is one to one, by a degree argument.

**Winslow's equations.** If $\xi(x, y)$ and $\eta(x, y)$ are harmonic and the map $(\xi, \eta)$ has an inverse $x(\xi, \eta)$, then the inverse satisfies $\alpha x_{\xi\xi} - 2 \beta x_{\xi\eta} + \gamma x_{\eta\eta} = 0$ for both coordinates. This follows from the chain rule with $\xi_x = y_\eta / J$, $\xi_y = -x_\eta / J$, $\eta_x = -y_\xi / J$ and $\eta_y = x_\xi / J$, as derived by Winslow and in Thompson, Warsi and Mastin. These are the equations that ELLIPTIC-GRID discretizes with $P = Q = 0$.

**Where convexity is needed.** In the claim below, the convex set is the rectangle $R$, the target of $(\xi, \eta)$, and the physical domain can be any Jordan domain. If instead $x$ and $y$ are taken harmonic in $(\xi, \eta)$, so that the map goes from $R$ onto $\Omega$, then the theorem needs $\Omega$ convex, and on a non-convex $\Omega$ that map can fold. With control functions $P, Q \ne 0$, $\xi$ and $\eta$ are not harmonic and the theorem does not apply.

**What the discrete grid does not inherit.** The claim below is about the exact solution of a differential equation. ELLIPTIC-GRID solves a finite difference approximation of it on a fixed grid, and no theorem says that the discrete solution has positive cells. The discrete equations have no maximum principle of the kind the proof of the theorem needs, because their coefficients depend on the solution. What holds is a conditional statement: if the discrete solutions converge to the smooth map $x$ in $C^1$ on a compact set $K$ inside the domain, then for a fine enough grid the cells in $K$ have positive corner Jacobians, since the Jacobian of $x$ is bounded away from 0 on $K$. Near the boundary, and especially at a reentrant corner, the Jacobian of $x$ tends to 0 or to infinity, and this argument gives nothing. The test file has such a case: on a domain with a boundary angle of about $349°$, the discrete grid converges to a residual below $10^{-10}$ and still has two cells that are not convex. So the grid must be checked with exact orientation signs, which is what CHECK does.

**Claim B.** Let $\Omega$ be a bounded domain whose boundary is a Jordan curve, convex or not. Let $s : \partial \Omega \to \partial R$ be a homeomorphism onto the boundary of the rectangle $R = [0, M] \times [0, N]$ that maps the four sides of the block to the four sides of $R$. Let $\xi, \eta$ be the harmonic functions on $\Omega$ with boundary values $s$. Then $(\xi, \eta)$ is a one-to-one map of $\Omega$ onto the interior of $R$ with nonvanishing Jacobian. Its inverse $x(\xi, \eta)$ is smooth with nonvanishing Jacobian, so its grid lines, the level curves of $\xi$ and of $\eta$, never cross or touch in $\Omega$.

**Proof.** By the Riemann mapping theorem there is a conformal map $\psi : \mathbb{D} \to \Omega$, and by Carathéodory's theorem it extends to a homeomorphism of $\partial \mathbb{D}$ onto $\partial \Omega$, because $\partial \Omega$ is a Jordan curve. A harmonic function composed with a holomorphic map is harmonic, so $(\xi, \eta) \circ \psi$ is the harmonic extension to $\mathbb{D}$ of the homeomorphism $s \circ \psi : \partial \mathbb{D} \to \partial R$. The rectangle $R$ is convex, so by the theorem, $(\xi, \eta) \circ \psi$ is one to one onto the interior of $R$ with nonvanishing Jacobian. Since $\psi$ is one to one and conformal, with nonvanishing derivative, $(\xi, \eta) = ((\xi, \eta) \circ \psi) \circ \psi^{-1}$ is one to one on $\Omega$ with nonvanishing Jacobian. By the inverse function theorem its inverse is smooth with nonvanishing Jacobian. Two lines of the same family, $\xi = a_1$ and $\xi = a_2$ with $a_1 \ne a_2$, never meet because $\xi$ is a function. A line $\xi = a$ and a line $\eta = b$ meet in exactly one point, because the map is one to one, and they cross there at a nonzero angle, because the gradients of $\xi$ and $\eta$ are independent. $\blacksquare$
