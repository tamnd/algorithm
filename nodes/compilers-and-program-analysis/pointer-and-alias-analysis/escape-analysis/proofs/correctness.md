---
title: An object of a NONE site is unreachable from outside its activation, and an object of a site that is not GLOBAL is never seen by another thread
proves: [correctness, termination, complexity]
status: full
---

**Setting.** A program is a set of methods. Each method $m$ has parameters, locals and a list of statements of the forms of the page: `new`, copy, load, store, global load, global store, call, start and `ret`. A *run* starts with one thread whose stack holds one frame of the main method. A *frame* is an activation of a method: it holds the values of its locals and parameters, and a return slot that `ret y` sets. A step picks a thread and either runs the next statement of its top frame, skips it, or pops the top frame when its body is done and puts the return slot into the destination local of the frame below. A call pushes a frame with the argument values as parameters. A start makes a new thread with one such frame. Skipping models branches, so the runs include every path of every control flow of the bodies. Each object $o$ has the site $site(o)$ of the `new` that made it. An object $o'$ is *reachable* from $o$ if a chain of fields leads from $o$ to $o'$, and reachable from a frame or a global if it is reachable from a value it holds.

$pts$ is the least solution of the inclusion constraints of the points-to stage (line L1): $s \in pts(m.x)$ for $x = $ `new` at $s$ in $m$; $pts(m.y) \subseteq pts(m.x)$ for a copy; for $x = y.f$, $pts(s.f) \subseteq pts(m.x)$ for every $s \in pts(m.y)$; for $x.f = y$, $pts(m.y) \subseteq pts(s.f)$ for every $s \in pts(m.x)$; $pts(g) \subseteq pts(m.x)$ and $pts(m.y) \subseteq pts(g)$ for the global forms; $pts(m.a_i) \subseteq pts(n.p_i)$ for each argument of a call or start of $n$; $pts(ret_n) \subseteq pts(m.x)$ for $x = n(\ldots)$; and $pts(m.y) \subseteq pts(ret_m)$ for `ret y` in $m$. The *heap closure* $cl(X)$ of a set $X$ of sites is the least superset of $X$ that contains $pts(s.f)$ for every $s$ in it and every field $f$. Let

$$G = cl\Big(\bigcup_g pts(g) \cup \bigcup_{\text{start } n(a_1, \ldots)\text{ in } m} pts(m.a_i)\Big), \qquad E_m = cl\Big(pts(ret_m) \cup \bigcup_i pts(m.p_i)\Big).$$

Lines L2 to L10 set $state(s) = $ GLOBAL if $s \in G$, ARG if $s \in E_m \setminus G$ for the method $m$ of $s$, and NONE otherwise.

**Lemma 1 (the points-to stage is sound).** At every moment of every run: if a local $x$ of a frame of $m$ holds $o$, then $site(o) \in pts(m.x)$; if field $f$ of $o$ holds $o'$, then $site(o') \in pts(site(o).f)$; if global $g$ holds $o$, then $site(o) \in pts(g)$; and if the return slot of a frame of $m$ holds $o$, then $site(o) \in pts(ret_m)$. So if $o'$ is reachable from $o$, then $site(o') \in cl(\{site(o)\})$.

*Proof.* By induction on the steps. At the start nothing holds an object. Each step writes one place, and the value written is covered by the constraint of its statement, using the induction hypothesis for the place it was read from: a call writes parameters, covered by the argument constraints; a pop writes the destination local, covered by the return constraint; a load reads $o.f$ with $site(o) \in pts(m.y)$, and a store writes $o.f$ with $site(o) \in pts(m.x)$. A skipped step writes nothing. The claim about reachability follows by induction on the length of the chain of fields. $\square$

**The frontier argument.** Fix a run, a time interval $[t_0, t_1]$, a set $I$ of frames called *inside*, and a set $B$ of sites with $cl(B) = B$. At each moment let $In$ be the objects reachable from inside frames, and $Out$ the objects reachable from globals or from frames that are not inside. Assume:

1. a frame joins $I$ only when an inside frame calls, the new frame is the callee, and no frame leaves $I$ except by its return;
2. at $t_0$, every object in $In \cap Out$ has its site in $B$;
3. $pts(g) \subseteq B$ for every global $g$, and $pts(m.a) \subseteq B$ for every argument $a$ of every start in every method;
4. no inside frame returns into a frame that is not inside before $t_1$.

**Lemma 2 (frontier).** Under these assumptions, at every moment of $[t_0, t_1]$: (P) every object in $In \cap Out$ has its site in $B$; and (Q) every object in $Out$ that an inside frame made during the interval has its site in $B$.

*Proof.* Both hold at $t_0$: (P) by assumption 2, and (Q) because nothing is made yet. Consider one step. A step that only removes references, such as a skip, a pop or the overwrite of a value, can only shrink $In$ and $Out$, which keeps both claims, with one exception: a pop that writes the return value, treated below. For the other steps, note first that adding a reference from an object or root outside $Out$ does not change $Out$.

*A step of an inside frame.* A `new` adds a fresh object to $In$ only. A copy, a load or a `ret` writes into an inside frame a value that is already in $In$, so neither set changes. A call pushes an inside frame with values already in $In$ (assumption 1). A pop of an inside frame into an inside frame writes a value of $In$ into $In$ (assumption 4 excludes the other case). A store $x.f = y$ writes into $o_x \in In$ the object $o_y \in In$. If $o_x \notin Out$, $Out$ does not change. If $o_x \in Out$, then $site(o_x) \in B$ by (P), the new objects of $Out$ are reachable from $o_x$ after the step, and by Lemma 1 their sites are in $cl(B) = B$. A global load brings the object of $g$, and the objects reachable from it, into $In$; they have sites in $cl(pts(g)) \subseteq B$ by Lemma 1 and assumption 3. A global store and a start make the objects reachable from the value or the arguments reachable from a global or from a new frame that is not inside, and their sites are in $cl(pts(g))$ or $cl(pts(m.a)) \subseteq B$ by assumption 3. In every case each object that joins $Out$ or $In \cap Out$ has its site in $B$.

*A step of a frame that is not inside.* It is a frame of another thread, or a frame below the inside frames that is not on top, and only top frames run. A `new` adds a fresh object to $Out$, not made by an inside frame. A copy, a load, a global load or a global store moves values that are already in $Out$, so $Out$ does not grow, and $In$ does not change. A call, a start or a pop puts values of $Out$ into frames that are not inside. A store $x.f = y$ with $o_x, o_y \in Out$ does not grow $Out$, and if $o_x \in In$, the new objects of $In$ are reachable from $o_x$, whose site is in $B$ by (P), so their sites are in $B$ by Lemma 1. $\square$

**Theorem 1 (threads).** If $state(s) \neq$ GLOBAL, then no object of site $s$ is ever reachable from a global or from a frame of a thread other than the thread that made it.

*Proof.* Let thread $T$ make $o$ with $site(o) = s \notin G$. Take $I$ = all frames of $T$, from the start of $T$ to the end of the run, and $B = G$, which is closed. Assumption 1 holds, since frames of $T$ come only from calls in $T$. Assumption 3 holds by the definition of $G$. Assumption 4 holds, since the first frame of $T$ has no frame below it. For assumption 2, at the start of $T$ the inside objects are those reachable from the start arguments, whose sites are in $G$. By (Q) of Lemma 2, $o \notin Out$ at every moment, and $Out$ is exactly the set of objects reachable from globals or from other threads. $\square$

**Theorem 2 (activations).** If $state(s) =$ NONE for a site $s$ of method $m$, then each object $o$ of site $s$, made by an activation $A$ of $m$, is reachable only from $A$ and the frames that $A$ calls while $A$ runs, and from no root at all after $A$ returns. So $o$ can be allocated in the frame of $A$.

*Proof.* Here $s \notin G \cup E_m$. Let $t_0$ be the push of $A$ and $t_1$ the moment just before its pop. Take $I$ = $A$ and every frame pushed above $A$ while $A$ is on the stack, and $B = G \cup E_m$, which is closed as a union of closed sets. Assumption 1 holds because only the top frame of $T$ calls. Assumption 3 holds since $G \subseteq B$. Assumption 4 holds since only $A$ returns into a frame below $A$, and that happens after $t_1$. For assumption 2, at $t_0$ the inside objects are those reachable from the parameters of $A$, with sites in $cl(\bigcup_i pts(m.p_i)) \subseteq E_m$ by Lemma 1. Every object of site $s$ is made by a frame of $m$, and $A$ is inside, so by (Q), $o \notin Out$ during $[t_0, t_1]$: no global, no other thread and no frame below $A$ reaches it.

At the pop of $A$, the return slot holds an object $r$ with $site(r) \in pts(ret_m)$, and the objects reachable from $r$ have sites in $E_m$ by Lemma 1, so $o$ is not among them. After the pop, every root is a root that was outside before, or the destination local that now holds $r$. So no root reaches $o$. A step can only create a reference to an object that some root reaches, so $o$ stays unreachable for the rest of the run. $\square$

**Theorem 3 (termination and cost).** Let $n$ be the number of nodes of the constraint graph (locals, return values, globals and pairs of a site and a field), $h$ the number of sites and $s$ the total size of the statements, counting each argument. The analysis stops and takes $O(n^2 h + s h)$ time and $O(n^2 + n h + s)$ space.

*Proof.* Each node's set only grows inside the $h$ sites, so there are at most $n h$ insertions, and the worklist stops. With difference propagation each pair of a node and a site is sent along each out-edge of the node once, and there are at most $n^2$ distinct edges, so propagation costs $O(n^2 h)$. Each new edge first sends the whole set of its source, $O(h)$, for $O(n^2 h)$ in total. Each pair of a load or store statement and a site of its base pointer is handled once, for $O(s h)$ edge requests. The heap closure of a set of sites visits each site once and each element of each set $pts(s.f)$ once, which is $O(n h)$. It runs once for $G$ and once for each method, and there are at most $n$ methods, since each has a return node, so this part is $O(n^2 h)$. The space holds the edges, the sets and the statements. $\blacksquare$
