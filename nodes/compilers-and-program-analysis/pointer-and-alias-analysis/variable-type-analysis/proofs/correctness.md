title: Variable type analysis computes the least type assignment of its graph, and its pruned call graph is sound and inside the initial graph
proves: [correctness, termination, complexity]

**Setting.** The program, $C \le D$, $\mathrm{decl}$, $\mathrm{LOOKUP}$ and *well typed* are as in the proof of [class hierarchy analysis](/class-hierarchy-analysis/). The program has no reflection, no native code and no classes loaded at run time. The initial graph $(R_0, E_0)$ is *sound*: every method that a run enters is in $R_0$, and every call of a run from site $s$ to method $T$ has $(s, T) \in E_0$. It is also *closed under targets*: $main \in R_0$, every site of an edge of $E_0$ lies in a method of $R_0$, and every target of an edge of $E_0$ is in $R_0$. The results of class hierarchy analysis and of rapid type analysis have both properties.

The graph $G$ has a node $M.v$ for each variable $v$ of each method $M \in R_0$, and a node $f$ for each field name. Its edges come from lines L2 to L4: $M.y \to M.x$ for `x = y` in $M$; $f \to M.x$ for `x = y.f`; $M.z \to f$ for `y.f = z`; and for each edge $(s, T) \in E_0$ with $s$: `x = y.m(z)` in $M$, the edges $M.y \to T.this$, $M.z \to T.p$ and $T.ret \to M.x$. The seed of a node $M.x$ is the set of classes $C$ with `x = new C()` in $M$ (line L5); other seeds are empty. A *type assignment* $\tau$ maps each node to a set of classes. It is a *solution* if $\mathrm{seed}(v) \subseteq \tau(v)$ for every node and $\tau(v) \subseteq \tau(w)$ for every edge $v \to w$.

**Lemma 1 (the least solution).** Let $\tau^*(w) = \bigcup \{\mathrm{seed}(v) : v \text{ reaches } w \text{ in } G\}$, where every node reaches itself. Then $\tau^*$ is the least solution.

*Proof.* $\tau^*$ is a solution: $\mathrm{seed}(w) \subseteq \tau^*(w)$, and for an edge $v \to w$, every node that reaches $v$ also reaches $w$. Let $\tau$ be any solution, and let $v$ reach $w$ along a path $v = v_0 \to v_1 \to \dots \to v_k = w$. Then $\mathrm{seed}(v) \subseteq \tau(v_0) \subseteq \tau(v_1) \subseteq \dots \subseteq \tau(w)$. So $\tau^* \subseteq \tau$. $\square$

**Lemma 2 (lines L6 to L8 compute it).** Lines L6 to L8 stop and give every node $w$ the set $\tau^*(w)$.

*Proof.* Tarjan's algorithm gives the strongly connected components, each as a list, in an order where a component comes after all components that it reaches. Line L7 takes them in the reverse order, which is a topological order of the component graph. Two nodes of one component reach each other, so they reach the same nodes and are reached by the same nodes, and $\tau^*$ is the same on both. Let $c$ be a component and $\sigma(c)$ the union of the seeds of its nodes. We show by induction in the topological order that when line L7 reaches $c$, the set of $c$ is $\bigcup \{\sigma(c') : c' \text{ reaches } c\}$. Every component $c' \ne c$ that reaches $c$ reaches it through a last edge $u \to w$ with $u$ in a component $c''$ that reaches $c$ and $w$ in $c$. The component $c''$ comes before $c$, so line L8 has already added its set, which by induction holds $\sigma(c')$. Line L8 only adds sets of components that reach $c$, so nothing more enters. The set of $c$ never changes after $c$ is processed, because no later component has an edge into $c$. Each loop is over a finite list, so the lines stop. $\square$

**Lemma 3 (the run invariant).** In every run, at every moment: if a variable $v$ of a live frame of method $M$ holds an object of class $C$, then $C \in \tau^*(M.v)$; and if the field $f$ of any object holds an object of class $C$, then $C \in \tau^*(f)$.

*Proof.* By induction over the steps of the run. At the start, all variables and fields hold null. Every frame belongs to a method that the run entered, which is in $R_0$ by soundness of the initial graph, so its nodes exist. `x = new C()` in $M$ puts $C$ into $x$, and $C \in \mathrm{seed}(M.x)$. `x = y` copies a value of $y$, and the edge $M.y \to M.x$ carries its class. `x = y.f` reads the field $f$ of some object, whose class is in $\tau^*(f)$ by the induction hypothesis, and the edge $f \to M.x$ carries it. `y.f = z` writes the value of $z$ into a field $f$, and the edge $M.z \to f$ carries its class. A call at $s$: `x = y.m(z)` in $M$ that enters $T$ has $(s, T) \in E_0$ by soundness. It binds $this$ in the new frame to the value of $y$ and $p$ to the value of $z$, and the edges $M.y \to T.this$ and $M.z \to T.p$ carry their classes. When it returns, it writes the value of $T.ret$ into $x$, and the edge $T.ret \to M.x$ carries its class. Since $\tau^*$ is a solution, each class lands in the set of the node that receives it. $\square$

**Theorem 1 (soundness).** Let $(R, E)$ be the result of lines L9 and L10. Every method that a run enters is in $R$, and every call of a run from site $s$ to $T$ has $(s, T) \in E$.

*Proof.* By induction over the calls of the run. The run starts in $main \in R$. Take a call at site $s$: `x = y.m(z)` in a frame of method $M$, on a receiver of class $C$, that enters $T = \mathrm{LOOKUP}(C, m)$. The frame of $M$ was entered earlier, so $M \in R$ by the induction hypothesis. By soundness of the initial graph, $(s, T) \in E_0$. By Lemma 3, $C \in \tau^*(M.y)$, and by type safety (Lemma 4 of the proof of class hierarchy analysis), $C \le \mathrm{decl}(y) \le \mathrm{decl}(m)$. So line L9 keeps $(s, T)$. Line L10 searches from $main$ along the kept edges, and $s$ lies in $M \in R$, so the search adds $(s, T)$ to $E$ and $T$ to $R$. $\square$

**Theorem 2 (inside the initial graph, and monotone).** $E \subseteq E_0$ and $R \subseteq R_0$. If $R_0 \subseteq R_0'$ and $E_0 \subseteq E_0'$, then the result for $(R_0, E_0)$ is inside the result for $(R_0', E_0')$.

*Proof.* Line L9 keeps a subset of $E_0$. Line L10 starts at $main \in R_0$ and follows edges of $E_0$, whose targets are in $R_0$. For the second part, the graph for $(R_0', E_0')$ contains every node, edge and seed of the graph for $(R_0, E_0)$, so by Lemma 1 its least solution is pointwise larger. Then line L9 keeps a superset, and the search of line L10 reaches a superset. With the initial graph of rapid type analysis, this gives $\mathrm{VTA} \subseteq \mathrm{RTA} \subseteq \mathrm{CHA}$, where the second inclusion is Theorem 3 of the proof of rapid type analysis. $\square$

**Theorem 3 (cost).** Let $n$ be the size of the program, $K$ the number of classes and $P = |E_0|$. The algorithm runs in $O((n + P) K)$ time.

*Proof.* $G$ has at most $n + F$ nodes, for $F \le n$ field names, and at most $n + 3P$ edges, since each statement gives at most one edge and each edge of $E_0$ gives at most three. Lines L1 to L5 build it in $O(n + P)$. Tarjan's algorithm takes $O(n + P)$. Line L8 runs once per edge, and each union of sets of at most $K$ classes takes $O(K)$ with bit vectors. Line L9 checks at most $K$ classes per edge of $E_0$, with a dispatch table, in $O(P K)$. Line L10 is a graph search over at most $P$ edges. The total is $O((n + P) K)$. $\blacksquare$
