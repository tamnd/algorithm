We use the notation and Lemmas 1 to 4 and Theorem 2 of the [correctness proof](correctness.md). The grammar $G$ is fixed, has no useless symbols, and its table has no conflict. Let $N$ be the number of states, $|V|$ the number of nonterminals, and $m_G \ge 1$ the largest length of a right side. A *step* is one pass through the loop of lines L19 to L24.

**Lemma A (a run on a sentence).** Let $w$ be any input, and let the parser make at least $t$ steps on it. Let $u$ be the input read before step $t$ and $a$ the next symbol then. There is a sentence $w' \in L(G)$ that begins with $u$ followed by $a$ (or $w' = u$ if $a = \$$) such that the run on $w'$ begins with the same $t$ steps.

*Proof.* Step $t$ uses an entry of ACTION$[\mathrm{st}(\gamma), a]$, where $\gamma$ is the string of stack symbols. The entry comes from an item of $\mathrm{st}(\gamma)$, which by Lemma 4 is valid for $\gamma$ through $S' \Rightarrow^*_{rm} \delta A x \Rightarrow_{rm} \delta\alpha\beta x$ with $\gamma = \delta\alpha$. By Lemma 3, $\gamma \Rightarrow^* u$, and $\beta$ derives some terminal string $y$, so $w' = u y x$ is a sentence. For a shift, $\beta$ begins with $a$, so $y$ does; for a reduce or accept, $\beta = \varepsilon$ and $a$ is the first symbol of $x\$$. The first $t$ steps read only $u$ and look only at symbols of $u$ and at $a$, so they are the same on $w'$. $\square$

**Lemma B (small parse trees).** Let $T$ be the unique parse tree of a sentence (unique by Theorem 2). A subtree of $T$ whose yield is empty has fewer than $c_\varepsilon = (m_G + 1)^{|V|}$ nodes. A subtree with a yield of length $\ell \ge 1$ has at most $c \, \ell$ inner nodes, where $c = 2|V|(1 + m_G c_\varepsilon)$.

*Proof.* If a path in a subtree with empty yield had two nodes with the same label $A$, replacing the subtree of the upper one by the subtree of the lower one would give a second parse tree of the same sentence. So each path has at most $|V|$ inner nodes, each with at most $m_G$ children, and the subtree has at most $\sum_{i \le |V|} m_G^i < c_\varepsilon$ nodes.

For a yield of length $\ell \ge 1$, the spans of the nodes with a nonempty yield form a laminar family of nonempty intervals of $\ell$ positions, which has at most $2\ell - 1$ members. Two nodes with the same nonempty span are an ancestor and a descendant, and every node between them has that span too. If two of them had the same label, removing the part between them would give a second tree of the same sentence. So each span has at most $|V|$ nodes, and there are at most $(2\ell - 1)|V|$ nodes with a nonempty yield. Every other inner node lies in a maximal subtree with empty yield, whose root is a child of a node with a nonempty yield. There are at most $m_G (2\ell - 1)|V|$ such subtrees, each with fewer than $c_\varepsilon$ nodes. The total is at most $(2\ell - 1)|V|(1 + m_G c_\varepsilon) \le c\,\ell$. $\square$

**Lemma C (short runs of empty symbols).** At each step on any input, a block of consecutive stack symbols that all derive $\varepsilon$ in the run (their part of $u$ in Lemma 3 is empty) has fewer than $N$ symbols.

*Proof.* Let the stack symbols be $X_1 \cdots X_m$, and let $X_{k+1}, \ldots, X_{k+r}$ be such a block. By Lemma 3, the input read after $X_j$ was pushed is the part of $u$ derived from $X_{j+1} \cdots X_m$. So no shift happened between the push of $X_{k}$ (or the start, if $k = 0$) and the push of $X_{k+r}$, and the lookahead $b$ stayed the same. Let $\tau_j$ be the time just after the push of $X_{k+j}$, for $0 \le j \le r$. Between $\tau_j$ and the end, the stack never becomes shorter than $k + j$, because $X_{k+j}$ is still on it.

Suppose that the top states at $\tau_j$ and $\tau_{j'}$ are the same state $q$, for some $j < j'$. From $\tau_j$ on, as long as no shift happens and the stack stays above height $k + j$, each action depends only on the states above height $k + j$, on $q$, and on $b$. So from $\tau_{j'}$ the parser repeats, one level higher, the steps it made from $\tau_j$, reaches the top state $q$ again without a shift, and does so forever. Take the sentence $w'$ of Lemma A for the current step: its run agrees with this run up to the current step and has the same lookahead $b$ at this position, so it is infinite. This contradicts Theorem 2. Hence the $r + 1$ top states at $\tau_0, \ldots, \tau_r$ are distinct, and $r < N$. $\square$

**Theorem (time and space of the parse).** On an input of length $n$, the parser stops after at most $(n + 1) + c \, n + c_\varepsilon (n + 1)(N + 1) = O(n)$ steps. The stack never holds more than $n + 1 + (n + 1) N = O(n)$ states.

*Proof.* Take any step $t$, with stack symbols $X_1 \cdots X_m$, input read $u$, and the sentence $w'$ of Lemma A with its tree $T'$. Since the run on $w'$ begins with the same $t$ steps, Theorem 2 says that each reduction so far made an inner node of $T'$, and that these nodes are exactly the inner nodes of the subtrees of $T'$ rooted at $X_1, \ldots, X_m$. Their yields split $u$. At most $|u| \le n$ of the $X_j$ have a nonempty yield, and by Lemma C the others form at most $|u| + 1$ blocks of fewer than $N$ symbols each. So $m \le n + (n + 1) N$, plus the state 0 at the bottom, which bounds the stack. By Lemma B, the subtrees with nonempty yields have at most $c\,|u| \le c\,n$ inner nodes in total, and the others at most $c_\varepsilon m$. There are at most $n$ shifts, because $\$$ is never shifted, and at most one accept, so $t$ is bounded by the number in the statement. This bound does not depend on $t$, so the run is finite. A step does $O(1)$ work, apart from popping at most $m_G$ states, so the time is $O(n)$ for the fixed grammar. $\blacksquare$

The constant in $O(n)$ grows with $N$, which can be exponential in $|G|$. For a sentence the count is smaller: by Theorem 2 the steps are the $n$ shifts, the inner nodes of the tree, and the accept, and by Lemma B there are at most $c\,n + c_\varepsilon$ inner nodes.

**The cost of the construction.** Let $M$ be the number of LR(1) items. A production $A \to \alpha$ has $1 + |\alpha|$ dot positions, so $M \le |G|(\sigma + 1)$. A CLOSURE puts each of at most $M$ items on the work list once. For an item $[A \to \alpha \cdot B\beta, a]$ it computes FIRST$(\beta a)$ in $O(|\beta|\,\sigma)$ time from the FIRST sets, which are computed once in advance, and then for each of at most $\sigma + 1$ lookaheads it scans the productions of $B$, $O(|G|)$ work. So one CLOSURE takes $O(M |G| \sigma) = O(|G|^2 \sigma^2)$ time. A state has at most $|G|$ symbols after a dot; for each, line L17 forms the kernel in $O(M)$ time and closes it, and line L6 looks the set up in a trie of flag vectors of length $M$, in $O(M)$ time. A state therefore costs $O(|G|^3 \sigma^2)$, and lines L1 to L8 cost $O(N |G|^3 \sigma^2)$. Lines L9 to L13 look at each item of each state once, $O(N M)$ time. The ACTION table has $N(\sigma + 1)$ entries and the GOTO table $N |V| \le N |G|$ entries, so the tables take $O(N(|G| + \sigma))$ space.
