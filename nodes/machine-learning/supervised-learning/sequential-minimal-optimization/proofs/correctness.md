We use the pseudocode of the page, with exact arithmetic, a positive semidefinite $K$, and $\varepsilon = 0$ in lines L20 and L21. So line L21 refuses only steps with $a_2 = \alpha_2$, and line L20 takes an end only when its $W$ is strictly larger. Write $F_i = \sum_j \alpha_j y_j K_{ij} - y_i$, so that $E_i = F_i + b$, and note that $\partial W/\partial \alpha_i = 1 - y_i \sum_j \alpha_j y_j K_{ij} = -y_i F_i$.

**Lemma 1 (feasibility).** After every call of TAKESTEP, $0 \le \alpha_i \le C$ for each $i$ and $\sum_i \alpha_i y_i = 0$.

*Proof.* At line L1, $\alpha = 0$ is feasible. A step changes only $\alpha_1$ and $\alpha_2$. Line L22 gives $y_1 a_1 + y_2 a_2 = y_1 \alpha_1 + s y_1 (\alpha_2 - a_2) + y_2 a_2 = y_1 \alpha_1 + y_2 \alpha_2$, because $s y_1 = y_2$. So the sum $\sum_i \alpha_i y_i$ does not change. If $y_1 \ne y_2$, then $a_1 = a_2 + (\alpha_1 - \alpha_2)$, and $a_2 \in [L, H]$ with $L = \max(0, \alpha_2 - \alpha_1)$, $H = \min(C, C + \alpha_2 - \alpha_1)$ gives $0 \le a_2 \le C$ and $0 \le a_1 \le C$. If $y_1 = y_2$, then $a_1 = (\alpha_1 + \alpha_2) - a_2$, and $L = \max(0, \alpha_1 + \alpha_2 - C)$, $H = \min(C, \alpha_1 + \alpha_2)$ give the same. Lines L19 and L20 always choose $a_2 \in [L, H]$. $\square$

**Lemma 2 (the step is optimal on the segment).** Let $\Lambda = \{(\alpha_1 + s(\alpha_2 - t), t) : t \in [L, H]\}$ be the feasible segment for the pair, with the other multipliers fixed. Lines L19 and L20 choose $a_2$ with $W$ maximal over $\Lambda$, and if $a_2 \ne \alpha_2$ then $W$ strictly increases.

*Proof.* Let $\omega(t)$ be $W$ at the point of $\Lambda$ with $\alpha_2 = t$. Moving $\alpha_2$ by $\delta$ moves $\alpha_1$ by $-s\delta$, so

$$\omega'(\alpha_2) = \frac{\partial W}{\partial \alpha_2} - s \frac{\partial W}{\partial \alpha_1} = -y_2 F_2 + s y_1 F_1 = y_2 (F_1 - F_2) = y_2 (E_1 - E_2),$$

and $\omega''(t) = -(K_{11} + K_{22} - 2 s^2 K_{12}) = -\eta$, since $s^2 = 1$. So $\omega$ is a quadratic with $\omega(t) = \omega(\alpha_2) + y_2 (E_1 - E_2)(t - \alpha_2) - \tfrac12 \eta (t - \alpha_2)^2$. If $\eta > 0$, it is strictly concave with maximum at $t^\ast = \alpha_2 + y_2 (E_1 - E_2)/\eta$; a strictly concave function of one variable increases up to $t^\ast$ and decreases after it, so its maximum on $[L, H]$ is at the clipped point of line L19, and it is the unique maximizer on the segment. Since $\alpha_2 \in [L, H]$ is also a candidate, $\omega(a_2) \ge \omega(\alpha_2)$, with equality only if $a_2 = \alpha_2$. If $\eta = 0$, $\omega$ is linear, its maximum on $[L, H]$ is at an end, and line L20 takes the end with the strictly larger value when the ends differ; if they are equal, $\omega$ is constant and line L20 keeps $\alpha_2$. A positive semidefinite $K$ gives $\eta = \lVert \varphi(x_1) - \varphi(x_2) \rVert^2 \ge 0$, so there are no other cases. $\square$

**Lemma 3 (the threshold).** After line L23, if $0 < a_1 < C$ then $E_1 = 0$, and if $0 < a_2 < C$ then $E_2 = 0$.

*Proof.* After the step, $f$ changes by $\Delta f(x) = y_1 (a_1 - \alpha_1) k(x_1, x) + y_2 (a_2 - \alpha_2) k(x_2, x) + (b_{\text{new}} - b)$. With $b_{\text{new}} = b_1$, the new error at $x_1$ is $E_1 + y_1 (a_1 - \alpha_1) K_{11} + y_2 (a_2 - \alpha_2) K_{12} + b_1 - b = 0$ by the definition of $b_1$. The same holds for $b_2$ at $x_2$. If both $a_1$ and $a_2$ are free, then both new errors are linear in $b_{\text{new}}$ with slope 1, and the new $f$ is optimal on the segment, so by Lemma 2 its derivative $y_2(E_1 - E_2)$ is 0 at an interior maximum; hence $b_1 = b_2$, and both errors are 0. $\square$

**Lemma 4 (a violating pair always gives a step).** Call $i$ an *up* point if $y_i = 1, \alpha_i < C$ or $y_i = -1, \alpha_i > 0$, and a *down* point if $y_i = 1, \alpha_i > 0$ or $y_i = -1, \alpha_i < C$. If $i$ is an up point, $j$ is a down point, and $F_j > F_i$, then TAKESTEP on the pair $\{i, j\}$, in either order, succeeds.

*Proof.* For small $t > 0$, the point $\alpha + t(y_i e_i - y_j e_j)$ is feasible: the sum $\sum \alpha_k y_k$ changes by $t(y_i^2 - y_j^2) = 0$, and the up and down conditions are exactly what is needed for $\alpha_i + y_i t$ and $\alpha_j - y_j t$ to stay in $[0, C]$. This point lies on the segment $\Lambda$ of the pair (both lines keep $y_i \alpha_i + y_j \alpha_j$ fixed), so $L < H$ and line L17 passes. The slope of $W$ in this direction is $y_i(-y_i F_i) - y_j(-y_j F_j) = F_j - F_i > 0$. So the maximum of $W$ on $\Lambda$ is strictly larger than the current value, and by Lemma 2 the step moves $\alpha_2$; line L21 accepts it. $\square$

**Lemma 5 (some point sees the violation).** Point $i$ passes the test of line L10 with threshold $b$ if and only if $b \ge -F_i - \tau$ when $i$ is an up point and $b \le -F_i + \tau$ when $i$ is a down point. Hence, if there are an up point $i$ and a down point $j$ with $F_j - F_i > 2\tau$, then for every $b$ at least one of $i$ and $j$ fails the test of line L10.

*Proof.* With $r_i = y_i E_i = y_i (F_i + b)$, the case $y_i = 1$ gives: $r_i < -\tau$ and $\alpha_i < C$ means an up point with $b < -F_i - \tau$; $r_i > \tau$ and $\alpha_i > 0$ means a down point with $b > -F_i + \tau$. The case $y_i = -1$ gives: $r_i < -\tau$ and $\alpha_i < C$ means a down point with $b > -F_i + \tau$; $r_i > \tau$ and $\alpha_i > 0$ means an up point with $b < -F_i - \tau$. This is the first claim. For the second, a $b$ that passes both points satisfies $-F_i - \tau \le b \le -F_j + \tau$, so $F_j - F_i \le 2\tau$. $\square$

**Theorem.** Assume that SMO returns at line L8 (not by a limit on the passes). Then the returned $\alpha$ is feasible, $W(\alpha) \ge W(\alpha')$ for every earlier iterate $\alpha'$, and $\max\{F_j - F_i : i \text{ up}, j \text{ down}\} \le 2\tau$. In particular, there is a threshold $b^\ast$ such that every point satisfies the KKT conditions within $\tau$, and with $\tau = 0$ the returned $\alpha$ is optimal.

*Proof.* Feasibility is Lemma 1, and monotonicity is Lemma 2. The loop of lines L3 to L7 exits only when $\text{changed} = 0$ and $\text{examineAll}$ is false. The flag becomes false only at line L7 right after a pass over all points, and if a later pass over the non-bound points has $\text{changed} = 0$, line L7 sets it to true again, which forces another pass over all points. So the loop exits only after a full pass with $\text{changed} = 0$, in which $\alpha$ and $b$ did not change. Suppose an up point $i$ and a down point $j$ had $F_j - F_i > 2\tau$ at the end of that pass. By Lemma 5, one of them, say $i_2$, fails the test of line L10 for the current $b$, so EXAMINE($i_2$) reaches line L13, which tries every partner, including the other point of the pair. By Lemma 4 that call of TAKESTEP succeeds, unless an earlier call in lines L11 to L13 already succeeded. Either way EXAMINE returns 1, which contradicts $\text{changed} = 0$. Hence $F_j - F_i \le 2\tau$ for all such pairs. Then the interval $[\max_{i \text{ up}} (-F_i) - \tau, \min_{j \text{ down}} (-F_j) + \tau]$ is not empty, and any $b^\ast$ in it passes the test of line L10 at every point by Lemma 5. With $\tau = 0$ these are the KKT conditions of the dual, which are sufficient for optimality because the dual is a concave maximization with linear constraints. $\blacksquare$

**Remarks.** The theorem is about the returned $\alpha$ and the existence of a good threshold; the $b$ that SMO returns is the one of line L23, which may differ from $b^\ast$. This is the inefficiency that Keerthi et al. (2001) fixed with two thresholds. The theorem does not show that SMO stops; with $\varepsilon > 0$ it does stop, because every accepted step increases $W$ by an amount bounded below while $W$ is bounded above, but then the guarantee holds only up to the refused small steps. The implementation also caps the number of passes.
