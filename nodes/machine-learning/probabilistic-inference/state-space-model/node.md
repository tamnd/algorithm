A state-space model is a probabilistic model of a sequence $y_1, \ldots, y_T$ of observations that are generated by a hidden state $x_0, x_1, \ldots, x_T$. The state is a [Markov chain](/markov-chain/): $x_t$ depends on the past only through $x_{t-1}$. Each observation depends only on the state at the same time. In the common additive form, $x_t = f(x_{t-1}) + q_t$ and $y_t = h(x_t) + r_t$ with independent noise terms $q_t$ and $r_t$. Two cases have exact and fast inference: when the state takes finitely many values the model is a [hidden Markov model](/hidden-markov-model/) (HMM), and when $f$ and $h$ are linear and the noise is Gaussian it is a linear dynamical system (LDS), also called a linear Gaussian state space model. Most other cases need approximations. The main questions about the hidden state are [filtering](/filtering/), prediction and [smoothing](/smoothing/).

## The machine

**Ingredients.** A state space $\mathcal X$ (for example $\{1, \ldots, K\}$ or $\mathbb R^n$), an observation space $\mathcal Y$, and three distributions:

- an initial distribution $p(x_0)$,
- a transition kernel $p(x_t \mid x_{t-1})$, the dynamics,
- an observation model $p(y_t \mid x_t)$, the likelihood.

Each may depend on $t$ and on known inputs $u_t$. The parameters $\theta$ of these distributions are fixed during inference and learned from data in a separate step.

**Generative process.** Draw $x_0 \sim p(x_0)$. For $t = 1, \ldots, T$, draw $x_t \sim p(x_t \mid x_{t-1})$ and then $y_t \sim p(y_t \mid x_t)$. The joint density factors as

$$p(x_{0:T}, y_{1:T}) = p(x_0) \prod_{t=1}^{T} p(x_t \mid x_{t-1})\, p(y_t \mid x_t).$$

As a [graphical model](/graphical-model/) this is a chain $x_0 \to x_1 \to \cdots \to x_T$ with one leaf $y_t$ hanging from each $x_t$. Two [conditional independence](/conditional-independence/) properties follow and drive all inference. First, given $x_t$, the future $(x_{t+1:T}, y_{t+1:T})$ is independent of the past $(x_{0:t-1}, y_{1:t})$. Second, given $x_t$, the observation $y_t$ is independent of everything else. The observations alone are not Markov: $y_t$ depends on the whole past of $y$ through the hidden state.

**Additive noise form.** Many models are written as

$$x_t = f(x_{t-1}) + q_t, \quad q_t \sim \mathcal N(0, Q), \qquad y_t = h(x_t) + r_t, \quad r_t \sim \mathcal N(0, R),$$

with independent noise terms. This is the form used by the [extended](/extended-kalman-filter/) and [unscented](/unscented-kalman-filter/) Kalman filters. The general form $x_t = f(x_{t-1}, q_t)$, $y_t = h(x_t, r_t)$ allows non-additive and non-Gaussian noise.

**The linear Gaussian case (LDS).** With matrices $A$ ($n \times n$) and $H$ ($m \times n$),

$$x_0 \sim \mathcal N(m_0, P_0), \qquad x_t = A x_{t-1} + q_t, \quad q_t \sim \mathcal N(0, Q), \qquad y_t = H x_t + r_t, \quad r_t \sim \mathcal N(0, R).$$

Every joint, marginal and conditional of $(x_{0:T}, y_{1:T})$ is then Gaussian, so each posterior is described by a mean and a [covariance matrix](/covariance-matrix/).

**The discrete case (HMM).** With $\mathcal X = \{1, \ldots, K\}$, the transition kernel is a $K \times K$ stochastic matrix and the observation model is any family of distributions indexed by the state. Every posterior over one state is a vector of $K$ probabilities.

**A worked case.** Take a scalar LDS with $A = 1/2$, $Q = 3/4$, $H = 1$, $R = 1$, started in its [stationary distribution](/stationary-distribution/). The stationary variance solves $P = A^2 P + Q$, so $P = (3/4)/(1 - 1/4) = 1$, and $\mathrm{Cov}(x_t, x_{t+k}) = 2^{-k}$. The observations then have $\mathrm{Var}(y_t) = 1 + 1 = 2$ and $\mathrm{Cov}(y_t, y_{t+k}) = 2^{-k}$ for $k \ge 1$. Their correlation is $1/4$ at lag 1 and halves at each further lag. This is the autocovariance of an ARMA(1,1) process: an AR(1) signal hidden in white noise is not an AR(1) process.

## What it counts

The model fixes what is unknown (the states $x_{0:T}$ and maybe $\theta$) and what is seen ($y_{1:T}$). Inference asks for one of these quantities:

| query | target | name |
|---|---|---|
| filtering | $p(x_t \mid y_{1:t})$ | online estimate of the current state |
| prediction | $p(x_{t+k} \mid y_{1:t})$, $k \ge 1$ | forecast of a future state |
| fixed-interval smoothing | $p(x_t \mid y_{1:T})$ for all $t \le T$ | offline estimate of each past state |
| fixed-lag smoothing | $p(x_{t-L} \mid y_{1:t})$ | estimate with a delay of $L$ steps |
| MAP path | $\arg\max_{x_{0:T}} p(x_{0:T} \mid y_{1:T})$ | most likely hidden path |
| likelihood | $p(y_{1:T}) = \prod_t p(y_t \mid y_{1:t-1})$ | model evidence, for learning and comparison |

The cost of an inference method is measured in the number of time steps $T$ and the size of the state: the number of states $K$ for an HMM, the dimensions $n$ and $m$ for an LDS, and the number of particles $N$ for Monte Carlo methods. Methods that run in time linear in $T$ do so because of the chain structure: each step passes a summary of the past, a message, to the next step.

## Relation to other models

- **[Hidden Markov model](/hidden-markov-model/).** The state-space model with a finite state space. Some authors use "hidden Markov model" for the general model on any state space, as in Cappé, Moulines and Rydén (2005), and "state space model" for the continuous case.
- **Linear dynamical system.** The linear Gaussian case. It is the model of the [Kalman filter](/kalman-filter/) and of factor analysis over time. Every ARMA process can be written as an LDS, which is how time series software computes ARMA likelihoods.
- **[Dynamic Bayesian network](/dynamic-bayesian-network/).** A state-space model whose state is a vector of variables with a sparse dependence structure inside each time slice and between slices. Any DBN can be flattened into a state-space model with a product state space, at the cost of a state space that grows exponentially with the number of variables.
- **[Hidden semi-Markov model](/hidden-semi-markov-model/).** The state stays in place for an explicit random duration. It becomes a state-space model if the remaining duration is added to the state.
- **[Gaussian process](/gaussian-process/) regression in time.** A Gaussian process on the real line with a Matérn covariance of half-integer order is the output of a linear stochastic differential equation, so it is an LDS after discretization. Kalman filtering and smoothing then do GP regression in $O(T)$ time instead of $O(T^3)$.
- **Switching LDS.** A discrete Markov chain selects which linear Gaussian model is active at each step. Exact inference is exponential in $T$, so approximations are used.
- **Recurrent neural networks.** A deterministic $x_t = f(x_{t-1}, u_t)$ with no noise is a state-space model with point-mass transitions. Deep state-space models put neural networks in $f$ and $h$ and keep the noise.

## Known results in the model

- **Filtering recursion.** For every state-space model, $p(x_t \mid y_{1:t}) \propto p(y_t \mid x_t) \int p(x_t \mid x_{t-1})\, p(x_{t-1} \mid y_{1:t-1})\, dx_{t-1}$. This follows from [Bayes' theorem](/bayes-theorem/) and the two conditional independences; see [filtering](/filtering/).
- **Exact filtering for HMMs.** The [forward algorithm](/forward-algorithm/) computes all filtering distributions and $p(y_{1:T})$ in $O(T K^2)$ time. The [forward-backward algorithm](/forward-backward-algorithm/) gives all smoothing marginals and the [Viterbi algorithm](/viterbi-algorithm/) the MAP path, both in $O(T K^2)$.
- **Exact filtering for LDS.** The posterior stays Gaussian, and the Kalman filter computes it in $O(T(n^3 + n^2 m + n m^2 + m^3))$ time. The [Rauch-Tung-Striebel smoother](/rauch-tung-striebel-smoother/) gives all smoothing marginals in the same order of time. Kalman (1960) showed that the filter mean is also the best linear estimate when the noise is not Gaussian but has the same first two moments.
- **No finite summary in general.** For most nonlinear or non-Gaussian models the filtering distribution has no finite-dimensional sufficient statistic, so exact filtering is not possible. Linearization (EKF), sigma points (UKF), and Monte Carlo ([particle filter](/particle-filter/), [sequential Monte Carlo](/sequential-monte-carlo/)) give approximations.
- **Stationary state.** In an LDS with all eigenvalues of $A$ inside the unit circle, the state has a stationary distribution $\mathcal N(0, P_\infty)$ where $P_\infty$ solves the discrete [Lyapunov equation](/lyapunov-equation/) $P = A P A^\top + Q$. Under observability and controllability conditions the Kalman filter covariance converges to a fixed matrix that solves the discrete algebraic Riccati equation, which gives the steady-state filter with a constant gain.
- **Identifiability up to a change of basis.** For any invertible $M$, the LDS $(A, Q, H, R, m_0, P_0)$ and $(M A M^{-1}, M Q M^\top, H M^{-1}, R, M m_0, M P_0 M^\top)$ give the same distribution of $y_{1:T}$. So the state is defined only up to a linear change of coordinates. The same holds for HMMs up to a relabeling of the states.
- **Learning.** Maximum likelihood parameters are found by [expectation maximization](/expectation-maximization/): Baum-Welch for HMMs, and EM with the Rauch-Tung-Striebel smoother for an LDS (Shumway and Stoffer, 1982). The likelihood $p(y_{1:T})$ from the filter also allows direct gradient methods.
