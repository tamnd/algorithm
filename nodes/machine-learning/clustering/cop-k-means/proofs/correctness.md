title: COP-k-means returns only clusterings that satisfy every constraint, and it can fail on feasible inputs
proves: [correctness]

We use the pseudocode of the page. The input is a list of $n$ points, an integer $k$, a set $\mathrm{ML}$ of must-link pairs, a set $\mathrm{CL}$ of cannot-link pairs, $k$ initial centers and an order $\pi$ of the points. A labeling $\ell$ satisfies a set of constraints if $\ell(a) = \ell(b)$ for each must-link pair and $\ell(a) \ne \ell(b)$ for each cannot-link pair.

**Lemma 1 (closure).** Let $\overline{\mathrm{ML}}$ contain all pairs of distinct points in one ML component (a class of the equivalence relation generated by $\mathrm{ML}$), and let $\overline{\mathrm{CL}}$ contain all pairs $\{a, b\}$ such that some pair $\{a', b'\} \in \mathrm{CL}$ has $a'$ in the component of $a$ and $b'$ in the component of $b$. A labeling satisfies $(\mathrm{ML}, \mathrm{CL})$ if and only if it satisfies $(\overline{\mathrm{ML}}, \overline{\mathrm{CL}})$.

*Proof.* The closed sets contain the given sets, so one direction is clear. Conversely, let $\ell$ satisfy $\mathrm{ML}$ and $\mathrm{CL}$. Two points of one component are joined by a path of ML pairs, and $\ell$ is equal along each pair of the path, so $\ell$ is constant on each component. For $\{a, b\} \in \overline{\mathrm{CL}}$ with the witness $\{a', b'\} \in \mathrm{CL}$, we get $\ell(a) = \ell(a') \ne \ell(b') = \ell(b)$. $\square$

From now on the check at line L4 uses the closed sets, as in the implementation.

**Lemma 2 (safety).** If COP-k-means returns a labeling, it satisfies $\mathrm{ML}$ and $\mathrm{CL}$.

*Proof.* A labeling is returned only at line L8, after a pass of lines L3 to L5 that labeled every point; a pass that meets a point with no allowed cluster returns failure at L5 instead. Take a pair $\{a, b\} \in \overline{\mathrm{ML}}$ and say that $\pi$ puts $a$ before $b$. When $b$ is labeled, $a$ already has its final label for this pass, and line L4 accepts for $b$ only a cluster $c$ with $c = \ell(a)$. So $\ell(a) = \ell(b)$. The same argument for a pair in $\overline{\mathrm{CL}}$ gives $\ell(b) \ne \ell(a)$. So the labeling satisfies the closed sets, and by Lemma 1 also $\mathrm{ML}$ and $\mathrm{CL}$. $\square$

**Lemma 3 (must-link alone never fails).** If $\mathrm{CL} = \emptyset$, no pass returns failure.

*Proof.* We show by induction over a pass that all labeled points of one ML component have the same label. At the start no point is labeled. When the point $i$ comes, either no other point of its component is labeled, and then every cluster is allowed, because $\overline{\mathrm{CL}}$ is empty; or the labeled points of its component all have one label $c$, and then $c$ is allowed. So $i$ gets a label, and that label is $c$ in the second case, which keeps the invariant. $\square$

**Lemma 4 (no constraints).** If $\mathrm{ML} = \mathrm{CL} = \emptyset$, COP-k-means makes the same steps as Lloyd's algorithm for [k-means](/k-means/) with the same initial centers and the same rule for ties.

*Proof.* With no constraints, line L4 never rejects a cluster, so each point goes to its nearest center, and the order $\pi$ does not matter. Lines L6 and L7 are the update and the stopping rule of Lloyd's algorithm. $\square$

**Lemma 5 (termination).** COP-k-means stops after at most $T$ passes, where $T$ is the cap on the number of passes.

*Proof.* Each pass either returns at L5, stops at L7 because the labeling did not change, or counts toward the cap $T$. $\square$

The cap is necessary in this form of the argument. In Lloyd's algorithm the assignment step gives each point its nearest center, so it does not increase the sum of squared distances, and the update step does not increase it either. Here line L4 assigns greedily in the order $\pi$, and the greedy labeling can cost more than the labeling of the previous pass, which was feasible too. So the usual proof that the objective decreases does not apply. When the labeling does not change at L7, the centers are the means of the clusters of a feasible labeling, and the next pass would give the same labeling again, so the output is a fixed point.

**Lemma 6 (failure on a feasible input).** There are inputs that have a feasible clustering on which COP-k-means returns failure.

*Proof.* Take three points $a = 0$, $b = 10$, $c = 5$ on the line, $k = 2$, $\mathrm{ML} = \emptyset$, $\mathrm{CL} = \{\{a, c\}, \{b, c\}\}$, initial centers $0$ and $10$, and the order $a, b, c$. Line L4 puts $a$ in cluster 1 and $b$ in cluster 2, each at distance 0 from its center. Then $c$ cannot join cluster 1, because of $a$, or cluster 2, because of $b$, and line L5 returns failure. The labeling $\{a, b\}, \{c\}$ satisfies both constraints. $\square$

**Theorem.** COP-k-means stops. When it returns a labeling, the labeling satisfies all must-link and cannot-link constraints. With no constraints it is Lloyd's algorithm, and with must-link constraints only it always returns a labeling. With cannot-link constraints it can return failure although a feasible clustering exists.

*Proof.* Lemmas 5, 2, 4, 3 and 6. $\blacksquare$
