We use the pseudocode of the page. Let $D$ be the $n$ points, $m_{\mathrm{pts}} \ge 1$ and $m_{\mathrm{clSize}} \ge 1$. The core distance $\mathrm{core}(x)$ is the distance from $x$ to its $m_{\mathrm{pts}}$-th nearest point, $x$ itself counted, and we assume $\mathrm{core}(x) > 0$ for each $x$. The mutual reachability distance is $d_m(x, y) = \max(\mathrm{core}(x), \mathrm{core}(y), \mathrm{dist}(x, y))$ for $x \ne y$. For a level $w > 0$ let $G_w$ be the graph whose vertices are the points with $\mathrm{core}(x) < w$ and whose edges are the pairs with $d_m(x, y) < w$, and let $T_w$ be the same graph with only the edges of the spanning tree $T$ of line L2.

**Lemma 1 (DBSCAN\* at each level).** For $\varepsilon > 0$, a point is a DBSCAN core point at $(\varepsilon, m_{\mathrm{pts}})$ if and only if $\mathrm{core}(x) \le \varepsilon$, and two core points $x, y$ are at distance at most $\varepsilon$ if and only if $d_m(x, y) \le \varepsilon$. So the DBSCAN\* clusters at $\varepsilon$ (the components of the core graph, with every non-core point as noise) are the components of the graph with the vertices $\mathrm{core}(x) \le \varepsilon$ and the edges $d_m \le \varepsilon$.

*Proof.* The $m_{\mathrm{pts}}$-th smallest distance from $x$ is at most $\varepsilon$ if and only if at least $m_{\mathrm{pts}}$ points lie within $\varepsilon$. A maximum is at most $\varepsilon$ if and only if each of its terms is. $\square$

**Lemma 2 (the tree keeps all components).** Let $T$ be a minimum spanning tree of the complete graph on $D$ with the weights $d_m$. For each $w$, $T_w$ and $G_w$ have the same vertices and the same components.

*Proof.* Each edge of $T_w$ is an edge of $G_w$, so the components of $T_w$ refine those of $G_w$. Take an edge $\{x, y\}$ of $G_w$. If it is in $T$, it is in $T_w$. If not, the path from $x$ to $y$ in $T$ together with $\{x, y\}$ forms a cycle, and by the cycle property of minimum spanning trees each edge $\{a, b\}$ on the path has $d_m(a, b) \le d_m(x, y) < w$. Its ends satisfy $\mathrm{core}(a) \le d_m(a, b) < w$, so the whole path lies in $T_w$, and $x, y$ are in one component of $T_w$. $\square$

**Lemma 3 (finitely many levels).** The vertex set of $G_w$ changes only when $w$ passes a core distance, and by Lemma 2 its components change only when $w$ passes a core distance or a weight of $T$. Let $L$ be the set of these values. For two consecutive values $w' < w$ of $L$, the graphs $G_v$ for $w' < v \le w$ have the same components, and they equal the DBSCAN\* clusters at each $\varepsilon \in [w', w)$ by Lemma 1. Above the largest value of $L$, $G_v$ is connected.

*Proof.* The first sentence is direct. By Lemma 2 the components of $G_v$ are those of $T_v$, which depend only on which tree edges and which vertices pass the test $< v$. Both tests give the same answer for all $v$ in $(w', w]$. The graph with the tests $\le \varepsilon$ equals $G_v$ for $v$ just above $\varepsilon$, which lies in $(w', w]$ when $\varepsilon \in [w', w)$. $\square$

**Lemma 4 (the condensed tree).** Lines L7 to L15 visit the values of $L$ from high to low. For each active cluster $C$ at the level $w$, line L11 splits $C$ into its components in $G_w$, and the components with fewer than $m_{\mathrm{clSize}}$ points are spurious. Then exactly one of these holds. (a) One component holds all of $C$: nothing happens (line L12). (b) Exactly one component is big: the other points of $C$ leave $C$ as noise at $\lambda = 1/w$, and $C$ shrinks (line L13). (c) No component is big: all points of $C$ leave at $1/w$ and $C$ ends (line L14). (d) Two or more components are big: all points of $C$ leave at $1/w$, $C$ ends, and each big component is a new cluster born at $1/w$ (lines L14 and L15). This is the rule of Campello et al. for the condensed hierarchy, so the clusters of the output are the clusters of the condensed DBSCAN\* hierarchy.

*Proof.* By Lemma 3 it is enough to look at the levels in $L$, because between them no component changes. An active cluster is always a whole component of the graph at the previous level. Since the components of $G_v$ only split as $v$ decreases (the graphs are nested), the components of $G_w$ that meet $C$ lie inside $C$. The four cases cover all counts of big components. $\square$

**Lemma 5 (the selection).** For a cluster $C$ of the condensed tree let $\mathrm{best}(C)$ be the largest total stability of a set of clusters in the subtree of $C$ in which no cluster is an ancestor of another (an antichain). Then $\mathrm{best}(C) = S(C)$ for a leaf, and $\mathrm{best}(C) = \max(S(C), \sum_{C'} \mathrm{best}(C'))$ over the children $C'$ otherwise. Lines L16 to L20 compute this, and the clusters they return form an antichain of this value.

*Proof.* An antichain in the subtree of $C$ either holds $C$, and then nothing else, or does not hold $C$, and then it is a union of antichains, one in the subtree of each child, which can be chosen independently because clusters in different child subtrees are never ancestors of each other. The best value of the second kind is the sum of the $\mathrm{best}(C')$. Line L16 visits each child before its parent, so the recursion is evaluated bottom up, and the set kept with each value is an antichain of that value by the same case split. For the root, when a single cluster is not allowed, only the second kind is admitted, which is the same recursion with $S(\mathrm{root})$ left out. $\square$

**Theorem.** The labels of line L6 are the flat clustering that Campello et al. define: among the antichains of the condensed tree, one of the largest total stability $\sum_C S(C)$, where $S(C) = \sum_{x \in C} (\lambda_{\max}(x, C) - \lambda_{\min}(C))$ and $\lambda_{\max}(x, C)$ is the value at which $x$ leaves $C$. The points in no selected cluster are noise.

*Proof.* Lemma 4 shows that line L3 builds the condensed tree with the birth and exit values used in the definition of $S$, line L4 evaluates $S$, and Lemma 5 shows that line L5 selects an antichain of the largest value. Each stability is at least $0$, because a point leaves a cluster at a $\lambda$ at least the birth of the cluster. So a best antichain can always be extended, without loss, until each path from a leaf to the root (or to a child of the root) meets it, which is the form of the constraint in the paper. Line L6 labels the members of the selected clusters, and these are disjoint because the clusters form an antichain. $\square$

**Ties and the choice of the tree.** Lemma 2 holds for every minimum spanning tree, and all edges of one weight are removed at the same level in Lemma 4, so the output does not depend on which minimum spanning tree line L2 returns. When $S(C)$ equals the sum for its children, line L18 keeps $C$.

**Cost.** Line L1 sorts $n$ distances for each point, $O(n^2 (d + \log n))$ time. Line L2 is the dense form of Prim's algorithm on the complete graph, $O(n^2 d)$ time and $O(n)$ extra space. $|L| \le 2n - 1$, and each level runs a union-find over at most $n - 1$ tree edges and touches each active point once, so lines L7 to L15 take $O(n^2 \alpha(n))$ time. The exit values are stored once for each point and each cluster that holds it, at most $O(n^2)$ values, and lines L16 to L20 take time linear in the size of the tree.
