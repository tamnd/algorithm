title: Geometric grouping and the configuration LP give OPT + O(log^2 OPT) bins
proves: [correctness]
status: full

**Setting.** Items have sizes in $(0, 1]$. For a multiset $I$ of sizes, $\text{SIZE}(I)$ is the sum of the sizes and $\text{LP}(I)$ is the value of the configuration LP of the problem page, with configurations that allow any number of copies of a size. The LP has an optimum, since it is feasible (one bin per item) and bounded below by 0. Line L4 is assumed to return an optimal vertex. Let $k = 4$, $g = \min(1/2, 1/\text{SIZE}(I))$ and $\lambda = \log_2 \max(2, \text{SIZE}(I))$. A multiset $A$ is *dominated* by a multiset $B$ if there is an injection $\phi : A \to B$ with each $a \le \phi(a)$.

**Lemma 1 (bounds on the LP).** $\text{SIZE}(I) \le \text{LP}(I) \le \text{OPT}(I)$.

*Proof.* A packing gives the 0-1 point with $x_C$ equal to the number of its bins of configuration $C$, of value OPT. For each feasible $x$, $\text{SIZE}(I) = \sum_t b_t v_t \le \sum_t v_t \sum_C a_{C,t} x_C = \sum_C x_C \sum_t a_{C,t} v_t \le \sum_C x_C$. $\square$

**Lemma 2 (domination).** If $A$ is dominated by $B$, then $\text{LP}(A) \le \text{LP}(B)$.

*Proof.* The dual of $\text{LP}(A)$ is $\max \sum_{a \in A} w(a)$ over weights $w \ge 0$ on the distinct sizes of $A$, with $\sum_t a_t w(v_t) \le 1$ for each configuration $a$ of the sizes of $A$. Let $w$ be an optimal dual for $A$, so its value is $\text{LP}(A)$ by strong duality. For a size $u$ of $B$ let $w'(u) = \max \{ w(v) : v \text{ a size of } A, \ v \le u \}$, or 0 if there is none. Then $w'$ is feasible for the dual of $\text{LP}(B)$: a configuration of $B$ uses sizes $u_1, \ldots, u_r$ with $\sum u_t \le 1$, counted with repetition. Replace each $u_t$ with a size $v_t \le u_t$ of $A$ attaining $w'(u_t)$, or drop it if $w'(u_t) = 0$. The result is a configuration of $A$, since $\sum v_t \le 1$ and copies are unbounded, so $\sum_t w'(u_t) = \sum_t w(v_t) \le 1$. Its value is $\sum_{b \in B} w'(b) \ge \sum_{a \in A} w'(\phi(a)) \ge \sum_{a \in A} w(a) = \text{LP}(A)$, since $w' \ge 0$ and $w'(\phi(a)) \ge w(a)$ as $a \le \phi(a)$. By weak duality, $\text{LP}(B) \ge \text{LP}(A)$. $\square$

**Lemma 3 (grouping).** In each round, $J'$ is dominated by $J$, so $\text{LP}(J') \le \text{LP}(J)$. The number $d$ of distinct sizes of $J'$ satisfies $d \le 2 \, \text{SIZE}(J) / k$. The discarded items of the round have total size at most $k (\log_2(1/g) + 1) \le k(\lambda + 1)$.

*Proof.* In class $l$, the sorted items are cut into groups $G_1, G_2, \ldots$ of $q = k \cdot 2^l$ items, except that the last may be smaller. Each item of $G_{t}$ for $t \ge 2$ is rounded up to $\max G_t \le \min G_{t-1}$, and $|G_t| \le |G_{t-1}|$. So mapping $G_t$ into $G_{t-1}$ one to one maps each rounded item to a true item at least as large. Over all classes this is an injection from $J'$ into $J$, which proves the domination, and Lemma 2 gives the LP bound. Each kept group gives one distinct size. If class $l$ has $n_l \ge 1$ items, it has at most $\lceil n_l / q \rceil - 1 < n_l / q$ kept groups, and $n_l < 2^{l+1} \, \text{SIZE}_l$, where $\text{SIZE}_l$ is the size of the class, since each item is larger than $2^{-l-1}$. So the class gives fewer than $2 \, \text{SIZE}_l / k$ sizes, and summing over the classes gives $d \le 2 \, \text{SIZE}(J)/k$. The group $G_1$ of class $l$ has at most $k \cdot 2^l$ items of size at most $2^{-l}$, so size at most $k$. Every large item has size at least $g$, and class $l$ is nonempty only if $2^{-l} \ge g$, so the classes are $l = 0, \ldots, \lfloor \log_2(1/g) \rfloor$. If $\text{SIZE}(I) \ge 2$, then $\log_2(1/g) = \lambda$; otherwise $\log_2(1/g) = 1 = \lambda$. $\square$

**Lemma 4 (one round).** Let $x$ be the vertex of line L4, $P$ the number of bins opened by line L5, and $J_{\text{next}}$ the set of line L6. Then $P \le \text{LP}(J') - \text{LP}(J_{\text{next}}) \le \text{LP}(J) - \text{LP}(J_{\text{next}})$, and $\text{SIZE}(J_{\text{next}}) < d$ if $J_{\text{next}} \ne \emptyset$.

*Proof.* Line L5 opens $\sum_C \lfloor x_C \rfloor$ bins, or fewer if some would be empty, so $P \le \sum_C \lfloor x_C \rfloor$. They hold $\min(b_t, \sum_C \lfloor x_C \rfloor a_{C,t})$ items of size $v_t$ of $J'$. So the leftover count of size $v_t$ is $\max(0, b_t - \sum_C \lfloor x_C \rfloor a_{C,t}) \le \sum_C (x_C - \lfloor x_C \rfloor) a_{C,t}$, by the row $t$ of the LP. So the fractional parts $z_C = x_C - \lfloor x_C \rfloor$ are feasible for the LP of the leftover items at their rounded sizes, after removing from each configuration the sizes that are no longer present, which keeps it a configuration. The true sizes are at most the rounded ones, so by Lemma 2, $\text{LP}(J_{\text{next}}) \le \sum_C z_C = \text{LP}(J') - \sum_C \lfloor x_C \rfloor \le \text{LP}(J') - P$. With Lemma 3 this gives the first claim. A vertex of an LP with $d$ rows (besides $x \ge 0$) has at most $d$ nonzero values, so at most $d$ values of $z$ are nonzero, each less than 1. If $J_{\text{next}} \ne \emptyset$, some $z_C > 0$, so $\sum_C z_C < d$, and Lemma 1 gives $\text{SIZE}(J_{\text{next}}) \le \text{LP}(J_{\text{next}}) < d$. $\square$

**Lemma 5 (rounds).** The loop of line L2 ends after at most $\log_2(\text{SIZE}(I)/g) + 1 \le 2\lambda + 1$ rounds.

*Proof.* Let $J_1, J_2, \ldots$ be the sets at the start of the rounds. By Lemmas 3 and 4 with $k = 4$, $\text{SIZE}(J_{t+1}) < 2 \, \text{SIZE}(J_t)/4 = \text{SIZE}(J_t)/2$ while $J_{t+1} \ne \emptyset$. So $\text{SIZE}(J_t) < \text{SIZE}(I) / 2^{t-1}$ for $t \ge 2$. If round $t$ happens, $J_t$ has an item of size at least $g$, so $g < \text{SIZE}(I)/2^{t-1}$ and $t < \log_2(\text{SIZE}(I)/g) + 1$. If $\text{SIZE}(I) \ge 2$, then $\log_2(\text{SIZE}(I)/g) = 2\lambda$. If $\text{SIZE}(I) < 2$, then $g = 1/2$ and $\log_2(2 \, \text{SIZE}(I)) < 2 = 2\lambda$. $\square$

**Lemma 6 (first fit).** (a) When first fit packs a list into some given bins and opens new ones, at most one new bin has load at most $1/2$ at the end. (b) When first fit packs items of size less than $g$ and opens at least one new bin, every bin except the last one opened has load more than $1 - g$ at the end.

*Proof.* (a) Suppose new bins $B$ and $B'$, with $B$ opened first, both end with load at most $1/2$. The item that opened $B'$ has size at most $1/2$, and when it came, $B$ had load at most $1/2$, since loads only grow. So it fit in $B$, and first fit would not have opened $B'$. (b) When the last new bin was opened, by an item of size $s < g$, every other bin had load more than $1 - s > 1 - g$, and loads only grow. $\square$

**Theorem.** The algorithm returns a valid packing with at most $\max \big( \text{LP}(I) + 8(2\lambda + 1)(\lambda + 1) + 1, \ \text{SIZE}(I) + 3 \big)$ bins, which is $\text{OPT} + O(\log^2 \text{OPT})$.

*Proof.* Validity: each bin of line L5 holds true items no larger than the rounded sizes of a configuration, so its load is at most 1, and first fit never overfills a bin. Every item is placed: large items are packed in line L5 or discarded, since the loop ends by Lemma 5, and lines L7 and L8 place the discarded and the small items.

Count: by Lemma 4, the rounds open at most $\sum_t (\text{LP}(J_t) - \text{LP}(J_{t+1})) = \text{LP}(J_1) - 0 \le \text{LP}(I)$ bins in total, by telescoping and Lemma 2 with $J_1 \subseteq I$. By Lemmas 3 and 5, the set $D$ of discarded items has $\text{SIZE}(D) \le 4(\lambda + 1)(2\lambda + 1)$. By Lemma 6(a), line L7 opens at most $2 \, \text{SIZE}(D) + 1$ new bins, since all but one of them hold more than $1/2$ of $D$. So after line L7 there are at most $\text{LP}(I) + 8(2\lambda + 1)(\lambda + 1) + 1$ bins. If line L8 opens no bin, this is the final count. Otherwise, by Lemma 6(b), the final count $B$ satisfies $(B - 1)(1 - g) < \text{SIZE}(I)$. If $\text{SIZE}(I) \ge 2$, then $g = 1/\text{SIZE}(I)$ and $\text{SIZE}(I)/(1 - g) = \text{SIZE}(I) + 1 + 1/(\text{SIZE}(I) - 1) \le \text{SIZE}(I) + 2$. If $\text{SIZE}(I) < 2$, then $g = 1/2$ and $\text{SIZE}(I)/(1 - g) = 2 \, \text{SIZE}(I) < \text{SIZE}(I) + 2$. Either way $B < \text{SIZE}(I) + 3$.

Finally $\text{LP}(I) \le \text{OPT}$ and $\text{SIZE}(I) \le \text{OPT}$ by Lemma 1, and $\lambda \le \log_2 \max(2, \text{OPT})$, so the count is $\text{OPT} + O(\log^2 \text{OPT})$. $\blacksquare$

**Remark.** If the LP of line L4 is solved only to within an additive 1, as in the polynomial version of Karmarkar and Karp, Lemma 4 loses 1 bin per round, which adds at most $2\lambda + 1$ bins in total.
