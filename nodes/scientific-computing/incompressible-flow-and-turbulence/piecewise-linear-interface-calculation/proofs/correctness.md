---
title: The PLIC reconstruction keeps the volume, and the PLIC update conserves volume, keeps 0 <= F <= 1, and moves a band exactly
proves: [correctness]
status: full
---

We use the notation of the page. In cell coordinates $(x, y) \in [0, 1]^2$ the reconstructed fluid is $\{n_xx + n_yy \le \beta\}$, and a sweep has the constant Courant number $c = |w|\Delta t/\Delta x \le 1$ along each line of cells. We claim, in exact arithmetic:

1. For $(n_x, n_y) \ne 0$ and $0 \le f \le 1$, the line constant $\beta$ of line L4 cuts off exactly the area $f$ of the unit square.
2. A sweep keeps the sum of the fractions, and if all fractions are in $[0, 1]$ before the sweep, they are in $[0, 1]$ after it. So a run conserves the total volume exactly and keeps $0 \le F \le 1$.
3. If the fluid is a band $x_0 < x < x_1$ and both the band and the gap have width at least $2\Delta x$, an $x$ sweep moves the band exactly by $w\Delta t$.

**Claim 1.** First reduce to nonnegative components. If $n_x < 0$, put $x' = 1 - x$; then $n_xx = |n_x|x' + n_x$. Doing the same for $y$ gives $n_xx + n_yy = |n_x|x' + |n_y|y' + \min(n_x, 0) + \min(n_y, 0)$, and the map $(x, y) \mapsto (x', y')$ maps the square to itself and keeps areas. Divide by $s = |n_x| + |n_y| > 0$ and swap the axes if needed, which also keeps areas. The set becomes $\{m_1x + m_2y \le a\}$ with $0 \le m_1 \le m_2$, $m_1 + m_2 = 1$ and $\beta = sa + \min(n_x, 0) + \min(n_y, 0)$, as in the code. So it is enough to show that the $a$ of the code gives area $f$ for this set.

Let $A(a)$ be the area of $\{m_1x + m_2y \le a\} \cap [0, 1]^2$. For $m_1 > 0$ and $0 \le a \le m_1$, the set is the triangle with legs $a/m_1$ and $a/m_2$, so $A(a) = a^2/(2m_1m_2)$. For $m_1 \le a \le m_2$, the line crosses the sides $x = 0$ and $x = 1$ at $y = a/m_2$ and $y = (a - m_1)/m_2$, both in $[0, 1]$, so the set is a trapezoid of area $(a - m_1/2)/m_2$. (If $m_1 = 0$, only this case occurs and $A(a) = a$.) The set and its complement are mapped to each other by $(x, y) \mapsto (1 - x, 1 - y)$, which takes $m_1x + m_2y \le a$ to $m_1x + m_2y \ge 1 - a$. So $A(1 - a) = 1 - A(a)$, which covers $a \ge m_2$.

The code puts $g = \min(f, 1 - f) \le \frac12$. If $g \le m_1/(2m_2) = A(m_1)$, it takes $a = \sqrt{2m_1m_2g} \le m_1$, and $A(a) = g$ by the first case. Otherwise it takes $a = m_2g + m_1/2$, which is at least $m_1$ because $g > m_1/(2m_2)$ and at most $\frac12 \le m_2$ because $g \le \frac12$, so $A(a) = g$ by the second case. If $f \le \frac12$, then $g = f$ and we are done. If $f > \frac12$, then $g = 1 - f$, the code replaces $a$ by $1 - a$, and the symmetry gives $A(1 - a) = 1 - g = f$.

**Claim 2.** The flux $q$ of line L6 is the area of the fluid polygon inside the strip of width $c$ next to the face. Since the strip is part of the cell, $q \le c$; since the polygon has area $f$ by Claim 1, $q \le f$; and the void in the strip, $c - q$, is at most the void in the cell, $1 - f$. Full and empty cells use $q = cf$, which is $0$ or $c$ and satisfies the same bounds. The code also clamps $q$ to $[\max(0, c - (1 - f)), \min(c, f)]$, so the bounds hold even after rounding. From here the proof is that of the [volume of fluid page](/volume-of-fluid-method/): each cell is the donor of exactly one face and the acceptor of exactly one face of its line, line L7 moves each flux from donor to acceptor, so the sum is kept, and for a cell $F' = F - q_{\text{out}} + q_{\text{in}}$ with $0 \le F - q_{\text{out}}$ and $F - q_{\text{out}} + q_{\text{in}} \le F - (c - 1 + F) + c = 1$. Induction over the sweeps gives the claim for a run.

**Claim 3.** Take $w > 0$. The fractions do not depend on $j$, so in Youngs' stencil the $y$ difference is $0$ and $n_y = 0$, and $n_x = -4(F_{i+1} - F_{i-1})$. Full and empty donors give the exact fluxes $c$ and $0$. Consider the cell $[a, a + \Delta x]$ that contains the front edge $x_1$ in its interior. Its left neighbor ends at $a > x_1 - \Delta x \ge x_0 + \Delta x$, so it lies inside the band and is full; its right neighbor starts at $a + \Delta x$ and ends at $a + 2\Delta x \le x_1 + 2\Delta x$, which is inside the gap, so it is empty. So $n_x > 0$, and by Claim 1 the fluid of the cell is reconstructed as $\{x \le f\}$ in cell coordinates, which is exactly the fluid of the band in this cell. The same argument at the back edge gives $n_x < 0$ and the set $\{x \ge 1 - f\}$, again exact. So the reconstructed fluid equals the true fluid in every cell, and the strip areas are the exact fluxes. The new fractions are those of the band moved by $c\Delta x = w\Delta t$, which again has widths of at least $2\Delta x$, so the claim repeats. The $y$ sweeps with $v = 0$ do nothing. $\blacksquare$
