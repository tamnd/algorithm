The element-free Galerkin (EFG) method solves a boundary value problem with the [Galerkin method](/galerkin-method/) on a set of scattered nodes, without elements. Each node $I$ has a weight function $w_I$ with compact support of radius $d_I$. At any point $x$, a moving least squares (MLS) fit of a polynomial basis $p(x)$ to the nodal parameters, weighted by the $w_I(x)$, defines the shape functions $\phi_I(x)$. They reproduce every polynomial in the basis exactly, they are as smooth as the weights, and they need only the nodes whose supports cover $x$. The stiffness matrix is assembled by Gauss quadrature on a background grid of cells that does not need to match the nodes. The shape functions do not satisfy $\phi_I(x_J) = \delta_{IJ}$, so Dirichlet conditions are imposed weakly, with Lagrange multipliers, a penalty or [Nitsche's method](/nitsche-method/). The method suits problems where a mesh is a burden: large deformations, crack growth and adaptive refinement by adding nodes.

## In plain words

A finite element program joins the points of a model into small triangles or boxes, and it must keep this mesh valid as the model changes. The element-free Galerkin method keeps only the points. Each point has a small zone of influence. To know the solution at some place, the method looks at the points whose zones cover that place and fits a straight line, or a parabola, through their values, giving more weight to the closer ones. This fit gives smooth shape functions with no mesh. The price is that the shape functions are not simple polynomials, so they are hard to integrate exactly. Also, the value of the solution at a point is not exactly the number stored at that point, so the fixed values at the boundary need extra equations.

## The problem

**Input.** An interval $[a, b]$ (the code is one dimensional, the method is not), a load $f$, Dirichlet values $u(a) = u_a$ and $u(b) = u_b$, nodes $a = x_1 < \ldots < x_n = b$ with support radii $d_I$, a polynomial basis $p(x)$ of size $m$ ($p = (1, x)$ or $(1, x, x^2)$), and background cells with a Gauss rule.

**Output.** Coefficients $a_I$ such that $u_h(x) = \sum_I \phi_I(x)\,a_I$ approximates the solution of $-u'' = f$, $u(a) = u_a$, $u(b) = u_b$, together with the multipliers $\lambda$ at the two ends.

**The MLS shape functions.** At a point $x$, minimize $\sum_I w_I(x)\,(p(x_I)^\top c - a_I)^2$ over $c \in \mathbb R^m$ and set $u_h(x) = p(x)^\top c(x)$. With the moment matrix $A(x) = \sum_I w_I(x)\,p(x_I)\,p(x_I)^\top$ this gives

$$\phi_I(x) = p(x)^\top A(x)^{-1}\,w_I(x)\,p(x_I), \qquad \phi_I' = \gamma'^\top w_I\,p(x_I) + \gamma^\top w_I'\,p(x_I),$$

where $\gamma = A^{-1} p$ and $\gamma' = A^{-1}(p' - A'\gamma)$. $A(x)$ is nonsingular when at least $m$ supports cover $x$ with nodes in general position. The weight here is the cubic spline $w(r) = \tfrac23 - 4r^2 + 4r^3$ for $r \le \tfrac12$, $w(r) = \tfrac43 - 4r + 4r^2 - \tfrac43 r^3$ for $\tfrac12 < r < 1$, and $0$ after, with $r = |x - x_I|/d_I$. It is twice continuously differentiable.

**The discrete problem.** Find $(a, \lambda)$ with

$$\begin{pmatrix} K & G \\ G^\top & 0 \end{pmatrix}\begin{pmatrix} a \\ \lambda \end{pmatrix} = \begin{pmatrix} F \\ g \end{pmatrix}, \qquad K_{IJ} = \int_a^b \phi_I'\phi_J'\,dx, \quad F_I = \int_a^b \phi_I f\,dx, \quad G_{Ib} = \phi_I(x_b),$$

where $x_b \in \{a, b\}$ and $g = (u_a, u_b)$.

## The algorithm

```pseudo id=main
EFG-1D(nodes x_I, radii d_I, basis p, cells, f, u_a, u_b)
L1  for each Gauss point (x_Q, w_Q) of the background cells
L2      find the nodes with |x_Q - x_I| < d_I; compute phi_I(x_Q) and phi_I'(x_Q) by MLS
L3      f_Q <- f(x_Q)
L4      K[I, J] <- K[I, J] + w_Q phi_I' phi_J'; F[I] <- F[I] + w_Q phi_I f_Q
L5  for each end x_b in {a, b}: G[I, b] <- phi_I(x_b) for the nodes that cover x_b
L6  solve the saddle point system [K G; G^T 0] [a; lambda] = [F; g]
L7  u_h(x) <- sum over the nodes that cover x of phi_I(x) a_I
L8  return u_h, u_h' and lambda
```

The multipliers are the boundary fluxes: $\lambda_a = u'(a)$ and $\lambda_b = -u'(b)$, up to the discretization error.

## Example

**Shape functions at a node.** Take the nodes $0, 0.1, \ldots, 1$, the linear basis and $d_I = 0.25$. At $x = 0.5$ the nodes $0.3, \ldots, 0.7$ have $r = 0.8, 0.4, 0, 0.4, 0.8$, and the weights are $\tfrac{4}{375}, \tfrac{106}{375}, \tfrac{250}{375}, \tfrac{106}{375}, \tfrac{4}{375}$. The neighbourhood is symmetric about $x$, so in coordinates centred at $x$ the moment matrix is diagonal and $\phi_I = w_I/\sum_J w_J$:

$$\phi = \big(\tfrac{2}{235}, \tfrac{53}{235}, \tfrac{25}{47}, \tfrac{53}{235}, \tfrac{2}{235}\big) \approx (0.0085, 0.2255, 0.5319, 0.2255, 0.0085).$$

So $\phi_6(x_6) = 0.53$, not 1: the coefficient $a_6$ is not the value of $u_h$ at the node.

**The patch test and the quadrature.** With the same nodes, $f = 0$, $u(0) = 1$ and $u(1) = 3$, the exact solution $1 + 2x$ is in the span of the shape functions. The result depends on the quadrature. With 40 cells of width $h/4$, whose ends are the breakpoints of the weights, and 8 Gauss points, the error is $6 \times 10^{-15}$, the coefficients are the nodal values $1, 1.2, 1.4, \ldots$ and $\lambda = (2, -2)$. With one cell per node interval and 3 Gauss points, the error is $4.9 \times 10^{-5}$ in $u$ and $1.5 \times 10^{-3}$ in $u'$, because the rational shape functions are not integrated exactly. With nodal integration (trapezoid weights at the nodes) the error is $7.5 \times 10^{-3}$ in $u$ and $0.23$ in $u'$.

**Convergence.** For $u = \sin \pi x$ with uniform nodes, 4 cells per node interval and 5 Gauss points, the errors are:

| nodes | linear basis, $L^2$ | linear basis, $H^1$ | quadratic basis, $L^2$ | quadratic basis, $H^1$ |
|---|---|---|---|---|
| 11 | $1.22 \times 10^{-4}$ | $5.61 \times 10^{-3}$ | $8.26 \times 10^{-5}$ | $4.36 \times 10^{-3}$ |
| 21 | $1.65 \times 10^{-5}$ | $1.96 \times 10^{-3}$ | $1.29 \times 10^{-5}$ | $1.52 \times 10^{-3}$ |
| 41 | $3.38 \times 10^{-6}$ | $9.12 \times 10^{-4}$ | $1.79 \times 10^{-6}$ | $4.37 \times 10^{-4}$ |
| 81 | $8.17 \times 10^{-7}$ | $4.52 \times 10^{-4}$ | $2.33 \times 10^{-7}$ | $1.16 \times 10^{-4}$ |

The last observed orders are $2.05$ and $1.01$ for the linear basis and $2.94$ and $1.91$ for the quadratic basis (radius $3.5h$), as for finite elements of the same degree.

## Correctness

The proofs are in [the correctness proof](proofs/correctness.md).

- **Reproduction (theorem).** If $A(x)$ is nonsingular, $\sum_I \phi_I(x)\,q(x_I) = q(x)$ for every polynomial $q$ in the span of $p$, and the same holds for the derivatives. In particular the $\phi_I$ form a [partition of unity](/partition-of-unity/).
- **Linear exactness needs exact integration (theorem).** If the quadrature integrates $\phi_I'\,q'$ exactly for every $I$ and every linear $q$ (the integration constraint), the discrete solution is exact for a linear exact solution. This holds for the background cells of the fine run above to rounding error, and fails for nodal integration.
- **The constraints hold exactly (theorem).** The last rows of line L6 are $u_h(a) = u_a$ and $u_h(b) = u_b$.
- **Convergence (cited, and measured).** With exact integration and a regular node distribution the method converges like finite elements of the degree of the basis (Belytschko, Lu and Gu 1994, and the MLS approximation theory). The rates above are measurements.

## Complexity

In the [real-RAM model](/real-ram/), each of the $g$ quadrature points finds its $k$ neighbours (with a bucket grid, in constant expected time per neighbour), builds $A$ and $A'$ in $\Theta(k m^2)$, solves two $m \times m$ systems in $\Theta(m^3)$ and adds $k^2$ entries to $K$. So assembly costs $\Theta(g(k m^2 + m^3 + k^2))$. The matrix $K$ has about $n k$ nonzeros. A banded solve in one dimension costs $\Theta(n k^2)$. The reference code uses dense Gaussian elimination and is meant only for small examples. Compared with finite elements, $k$ is larger (5 here, against 2 for linear elements in one dimension) and $g$ must be larger for accurate integration, so EFG costs several times more per unknown.

## Properties

- **Smooth shape functions.** The $\phi_I$ have the smoothness of the weight, here $C^2$, so derivatives and stresses are continuous without any post-processing.
- **No Kronecker delta.** The coefficients are not the nodal values. Essential conditions need multipliers, a penalty, Nitsche's method, or a coupling with finite elements at the boundary.
- **Rational, not polynomial.** The shape functions are ratios of piecewise polynomials, so no Gauss rule integrates them exactly unless the cells match the breakpoints of the supports, and then only approximately.
- **Refinement by adding nodes.** New nodes need no connectivity. Only the supports must keep covering every point with enough nodes for $A$ to be nonsingular.

## Variants and improvements

- **Penalty and Nitsche boundary conditions.** Replace the multipliers by $\beta \int_\Gamma (u_h - g)v$ with a large $\beta$, or by Nitsche's consistent terms, which keep the system positive definite.
- **Stabilized conforming nodal integration (Chen and coauthors 2001).** Integrate smoothed strains over cells around each node. It satisfies the integration constraint, so the method passes the linear patch test with one point per node.
- **Reproducing kernel particle method.** A closely related construction of the shape functions as a corrected kernel. For the same basis and weights it gives the same functions as MLS.
- **Enrichment.** Add singular or discontinuous functions to the basis $p$, or cut the supports with a visibility criterion at a crack, for fracture mechanics.
- **Coupling with finite elements.** Use EFG only where the mesh would distort, and finite elements elsewhere, with blended shape functions in between.

## When to use it

Use it when a mesh is the main difficulty: crack propagation, large deformation and fragmentation, and adaptive refinement with nodes added or removed. For problems on a fixed geometry with small deformations, finite elements are cheaper and simpler, and they satisfy the boundary conditions directly. [Smoothed particle hydrodynamics](/smoothed-particle-hydrodynamics/) is the related collocation method for fluids, and [radial basis function interpolation](/radial-basis-function-interpolation/) is a global meshless fit with no moving weights.

## Pitfalls

- **Too few nodes in a support.** If fewer than $m$ supports cover a point, or the covering nodes are collinear in 2D, $A(x)$ is singular. Choose $d_I$ about $2$ to $4$ times the node spacing for the linear basis.
- **Weak quadrature.** Few Gauss points per cell, or cells that cut across the supports, give an integration error that can dominate the discretization error and break the patch test, as the example shows.
- **Nodal integration.** It is cheap, but it fails the patch test and allows spurious zero energy modes unless it is stabilized.
- **Treating coefficients as nodal values.** The value at node $I$ is $u_h(x_I) = \sum_J \phi_J(x_I)\,a_J$, not $a_I$. Plotting $a_I$ gives a wrong picture.
- **Large penalty parameters.** A penalty makes the system ill conditioned, while a small one does not enforce the boundary condition. Multipliers or Nitsche's method avoid the choice.

## History

Lancaster and Salkauskas in 1981 studied moving least squares for fitting surfaces to scattered data. Nayroles, Touzot and Villon in 1992 used MLS functions in a Galerkin method, the diffuse element method, but kept only part of the derivatives. Belytschko, Lu and Gu in 1994 used the full derivatives, imposed the boundary conditions with Lagrange multipliers and integrated on background cells, and named the method element-free Galerkin. Dolbow and Belytschko in 1999 studied the quadrature error, and Chen and coauthors in 2001 gave a nodal integration that meets the integration constraint.
