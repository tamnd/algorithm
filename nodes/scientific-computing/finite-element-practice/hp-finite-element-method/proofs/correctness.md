---
title: The 1D hp solver computes the Galerkin solution, and the geometric mesh with linear degrees converges like exp(-b sqrt N)
proves: [correctness]
status: full
---

**Setting.** The problem is $-u'' = f$ on $(0, 1)$ with $u(0) = u(1) = 0$, in the weak form: find $u \in H^1_0(0, 1)$ with $a(u, v) = \int_0^1 u'v' = \int_0^1 fv$ for all $v \in H^1_0$. The energy norm is $|v|_1 = a(v, v)^{1/2}$. A mesh $0 = x_0 < \cdots < x_n = 1$ has elements $K_i = [x_{i-1}, x_i]$ of length $h_i$, each with a degree $p_i \ge 1$. The space $V_h$ is the set of continuous functions in $H^1_0$ that are polynomials of degree at most $p_i$ on $K_i$. On $K_i$ the local coordinate is $\xi \in [-1, 1]$ with $x = x_{i-1} + h_i(\xi + 1)/2$. The basis is the hat functions $\phi_j$ at the interior nodes and the bubbles $\psi_{ik}(\xi) = (P_k(\xi) - P_{k-2}(\xi))/\sqrt{2(2k-1)}$, $k = 2, \ldots, p_i$, which are 0 outside $K_i$. HP-GEOMETRIC is lines L1 to L6 of the main page.

We prove four claims.

1. *(The solver.)* Lines L3 to L5 return the coefficients of the Galerkin solution $u_h \in V_h$, $a(u_h, v) = a(u, v)$ for all $v \in V_h$.
2. *(Error identity.)* $|u - u_h|_1^2 = |u|_1^2 - b^{\mathsf T}U$, where $b$ is the load vector and $U$ the coefficient vector.
3. *(Nodal exactness.)* $u_h(x_j) = u(x_j)$ at every node, for every choice of the degrees.
4. *(Exponential rate.)* Let $u = x^\alpha - x$ with $\tfrac12 < \alpha < 1$, so that $u \notin H^2$. For the geometric mesh $x_0 = 0$, $x_i = \sigma^{n-i}$ with $0 < \sigma < 1$, and the degrees $p_i = \max(1, \lceil\mu i\rceil)$ with $\mu > 0$, there are constants $C, b > 0$ that depend on $\alpha$, $\sigma$ and $\mu$ but not on $n$ such that $|u - u_h|_1 \le C\exp(-b\sqrt{N})$, where $N = \dim V_h$.

**Proof of 1.** The functions are a basis of $V_h$: on each element, the two linear functions $(1 \mp \xi)/2$ and the $\psi_{ik}$, $k = 2, \ldots, p_i$, span the polynomials of degree $p_i$, because $\psi_{ik}$ has degree exactly $k$. The bubbles are 0 at $\xi = \pm 1$, because $P_k(\pm 1) = P_{k-2}(\pm 1)$, so the functions are continuous. Now compute the stiffness matrix. The standard identity $(2k-1)P_{k-1} = P_k' - P_{k-2}'$ gives $\psi_{ik}'(\xi) = \sqrt{(2k-1)/2}\,P_{k-1}(\xi)$. With $dx = (h_i/2)\,d\xi$ and $d/dx = (2/h_i)\,d/d\xi$,
$$a(\psi_{ik}, \psi_{il}) = \frac{2}{h_i}\int_{-1}^{1}\psi_{ik}'\psi_{il}'\,d\xi = \frac{2}{h_i}\cdot\frac{\sqrt{(2k-1)(2l-1)}}{2}\int_{-1}^{1}P_{k-1}P_{l-1}\,d\xi = \frac{2}{h_i}\delta_{kl},$$
by $\int_{-1}^1 P_m^2 = 2/(2m+1)$ and the orthogonality of the Legendre polynomials. A hat function has a constant derivative on $K_i$, and $\int_{-1}^{1}P_{k-1} = 0$ for $k \ge 2$, so $a(\phi_j, \psi_{ik}) = 0$. Bubbles of different elements have disjoint supports. So the Galerkin matrix is block diagonal: a tridiagonal block for the hats, the usual P1 stiffness matrix with $1/h_i$ entries, and the diagonal $2/h_i$ for the bubbles. The hat block is symmetric and strictly diagonally dominant in its first and last rows and weakly in the others, and it is irreducible, so it is positive definite and the Thomas algorithm at line L4 runs without pivoting and solves it. Line L5 solves the diagonal part, $c_{ik} = (h_i/2)\,b_{ik}$. The loads are $b_j = a(u, \phi_j)$, which the code computes exactly from the values of $u$ at the nodes, since $\phi_j'$ is $\pm 1/h$, and $b_{ik} = a(u, \psi_{ik}) = \sqrt{(2k-1)/2}\int_{-1}^{1}u'(x(\xi))P_{k-1}(\xi)\,d\xi$. $\square$

**Proof of 2.** By claim 1, $a(u - u_h, u_h) = 0$. So $|u - u_h|_1^2 = a(u - u_h, u) = |u|_1^2 - a(u_h, u)$, and $a(u_h, u) = \sum_m U_m a(\text{basis}_m, u) = b^{\mathsf T}U$. $\square$

**Proof of 3.** Fix an interior node $x_j$. Let $g$ be the function in $H^1_0$ that is linear on $[0, x_j]$ and on $[x_j, 1]$, with $g(x_j) = 1$. Then for every $v \in H^1_0$, $a(v, g) = \int_0^{x_j} v'/x_j - \int_{x_j}^1 v'/(1 - x_j) = v(x_j)/x_j + v(x_j)/(1 - x_j)$, so $v(x_j) = c\,a(v, g)$ with $c = x_j(1 - x_j)$. The function $g$ is linear on each element, so $g \in V_h$. Galerkin orthogonality gives $u_h(x_j) = c\,a(u_h, g) = c\,a(u, g) = u(x_j)$. $\square$

**Proof of 4.** By claim 1, $u_h$ is the best approximation in the energy norm, $|u - u_h|_1 \le |u - v|_1$ for every $v \in V_h$. We build a good $v$ element by element, with $v = u$ at every node, so that the pieces join into a continuous function in $H^1_0$. On $K$ we take $v' = \Pi_{p-1}u'$, the $L^2(K)$ projection of $u'$ onto the polynomials of degree $p - 1$, and $v(x) = u(x_{\text{left}}) + \int_{x_{\text{left}}}^{x}v'$. The projection keeps the mean of $u'$, because constants are in the space, so $v = u$ at both ends. Then $|u - v|_{1, K} = \|u' - \Pi_{p-1}u'\|_{L^2(K)} \le h^{1/2}\inf_q\|u' - q\|_{L^\infty(K)}$, with the infimum over the polynomials of degree $p - 1$.

*The first element* $K_1 = [0, \sigma^{n-1}]$ has $p_1 \ge 1$. Here $v$ is at least as good as the linear interpolant, and $|u - v|_{1, K_1}^2 \le |u|_{1, K_1}^2 \le 2\int_0^{x_1}(\alpha^2x^{2\alpha - 2} + 1)\,dx \le C\,\sigma^{(n-1)(2\alpha - 1)}$. This uses $2\alpha - 1 > 0$, and the linear interpolant error is at most $|u|_{1,K_1}$ because it is the projection of $u'$ onto constants.

*Each other element* $K_i = [\sigma^{k+1}, \sigma^k]$ with $k = n - i$ has $h = \sigma^k(1 - \sigma)$ and left end $a = \sigma^{k+1}$, so $a/h = \sigma/(1 - \sigma)$ is the same for all of them. In the local coordinate, the only singularity of $u'(x) = \alpha x^{\alpha - 1} - 1$ is at $\xi_s = -1 - 2a/h = -(1 + \sigma)/(1 - \sigma)$, a fixed point left of $-1$. So $u'(x(\xi))$ is analytic inside the Bernstein ellipse with foci $\pm 1$ through $\xi_s$, with parameter $\rho = |\xi_s| + (\xi_s^2 - 1)^{1/2} > 1$. Fix $1 < r < \rho$. On the ellipse with parameter $r$, $|x| \ge c\,\sigma^k$ with $c > 0$ that depends only on $\sigma$ and $r$, so $|u'| \le C\sigma^{k(\alpha - 1)}$ there. The classical estimate for analytic functions (Bernstein) gives a polynomial $q$ of degree $p - 1$ with $\|u' - q\|_{L^\infty(K)} \le C\sigma^{k(\alpha - 1)}r^{-(p-1)}$. With the factor $h^{1/2} \le \sigma^{k/2}$,
$$|u - v|_{1, K_i} \le C\,\sigma^{(n - i)(\alpha - 1/2)}\,r^{-p_i + 1}.$$
*Sum.* Let $q = \max(\sigma^{\alpha - 1/2}, r^{-\mu}) < 1$. With $p_i \ge \mu i$, each term is at most $C r\,q^{n - i}q^{i} = Cr\,q^n$, and the first element also gives at most $Cq^{n-1}$. So $|u - u_h|_1^2 \le C\,n\,q^{2n}$, and $|u - u_h|_1 \le C\sqrt{n}\,q^n \le C'\tilde q^{\,n}$ for any $q < \tilde q < 1$. The dimension is $N = (n - 1) + \sum_i(p_i - 1) \le n + \mu n(n + 1)/2 \le C n^2$, so $n \ge \sqrt{N/C}$, and $|u - u_h|_1 \le C'\exp(-b\sqrt{N})$ with $b = |\ln\tilde q|/\sqrt{C}$. $\square$

**Remarks.** With $\alpha = 0.7$ and $\sigma = 0.15$, the factor $\sigma^{\alpha - 1/2} = 0.684$ predicts that each new layer cuts the error by about this factor. The reference run with $\mu = \tfrac12$ measures a factor of $0.47 \approx 0.684^2$ per two layers. The same proof with $p_i = 1$ on all elements shows why the geometric mesh alone stalls: the last element $[\sigma, 1]$ keeps an error that does not depend on $n$. In 2D the same construction, with geometric layers toward each corner of a polygon, gives $\exp(-bN^{1/3})$ for solutions that are piecewise analytic with corner singularities. That is the theorem of Babuska and Guo, and its proof needs weighted Sobolev spaces; this page does not reproduce it.
