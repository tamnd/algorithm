---
title: Enforced hill climbing returns valid plans, terminates, and is complete on dead-end free tasks
proves: [correctness, termination]
status: full
---

We use the notation and the pseudocode of the page. The state space is finite, with $n$ states reachable from $I$, and each state has at most $b$ successors. The heuristic $h$ maps states to the natural numbers or to $\infty$. A state is a *dead end* when no goal state is reachable from it. We assume two facts about $h$, which hold for the FF heuristic and for every heuristic that is $\infty$ only on states from which even the delete relaxation cannot reach the goal:

- (A1) if $h(t) = \infty$, then $t$ is a dead end;
- (A2) if $h(t) = \infty$ and $t'$ is a successor of $t$, then $h(t') = \infty$.

For the FF heuristic, (A1) holds because a real plan is a relaxed plan, and (A2) holds because every fact of $t'$ is reachable from $t$ in the relaxation, so a relaxed plan from $t'$ would give one from $t$.

**Lemma 1 (BETTER).** Let $s$ be a state with $h(s) < \infty$. BETTER$(s)$ stops after it generates at most $n b$ successors. If it returns $t$, then the recorded parents give a path of actions from $s$ to $t$, and $t$ is a goal state or $h(t) < h(s)$. If a state $t$ with this property is reachable from $s$, then BETTER$(s)$ returns such a state, and the returned path is a shortest path from $s$ to any such state.

*Proof.* Line L12 adds each state to seen at most once, and line L14 puts each state in the queue at most once, so line L10 removes at most $n$ states, and each one has at most $b$ successors. A state $t$ gets the parent $(u, a)$ only when $a$ leads from $u$ to $t$ (line L11), and $u$ was put in seen before $t$, so following parents from $t$ ends at $s$ and gives a path. Line L13 returns only states with the property.

Now let $t^*$ be a state with the property, at the least distance $d$ from $s$, and let $s = x_0, x_1, \ldots, x_d = t^*$ be a shortest path. For $j < d$, the state $x_j$ is not a goal and has $h(x_j) \ge h(s)$, by the choice of $d$. So $h(x_j) < \infty$ for $j < d$: for $j = 0$ by assumption, and for $j \ge 1$ because $h(x_j) = \infty$ would give $h(x_d) = \infty$ by (A2), and $x_d$ is then a dead end by (A1), not a goal, with $h(x_d) = \infty \ge h(s)$, which contradicts the property of $t^*$. Breadth-first search with the queue of lines L9 to L14 removes states in the order of their distance from $s$ in the graph of states it may expand. Every $x_j$ with $j < d$ may be expanded, so the search generates $x_d$ or an earlier state with the property, unless it returns before. Every state it returns at line L13 is generated by a state at distance at most $d - 1$, so the path to it has length at most $d$, and by the choice of $d$ exactly $d$. $\square$

**Theorem 1 (soundness).** If ENFORCED-HILL-CLIMBING returns $\pi$, then $\pi$ leads from $I$ to a goal state.

*Proof.* Line L6 appends a path from the current state $s$ to the new state $s'$ (Lemma 1), and line L6 makes $s'$ the current state. So, by induction on the iterations, the plan always leads from $I$ to the current state. The loop of line L3 ends only when the current state is a goal. $\square$

**Theorem 2 (termination).** The algorithm stops after at most $h(I) + 1$ iterations of the loop, each of which generates at most $n b$ states. If $h(t) = 0$ only for goal states $t$, it stops after at most $h(I)$ iterations.

*Proof.* Each call of BETTER stops by Lemma 1. An iteration that returns a non-goal $s'$ has $h(s') < h(s)$, with integer values, so $h$ drops by at least 1. The values stay $\ge 0$, so at most $h(I)$ such iterations occur, and then one more iteration reaches a goal or fails. If $h$ is positive on non-goals, then $h(s) \ge 1$ in every iteration, so every iteration lowers $h$ by at least one or ends at a goal state, and there are at most $h(I)$ iterations. $\square$

**Theorem 3 (completeness on dead-end free tasks).** If no state reachable from $I$ is a dead end, then the algorithm returns a plan. This is Proposition 4 of Hoffmann and Nebel (2001).

*Proof.* $I$ is not a dead end, so $h(I) < \infty$ by (A1) and line L2 does not fail. Suppose an iteration fails at line L5 with current state $s$. By Theorem 1, $s$ is reachable from $I$, so it is not a dead end, and a goal state is reachable from $s$. That goal state has the property of Lemma 1, so BETTER$(s)$ returns a state, a contradiction. By Theorem 2, the loop ends, so it ends at a goal state. $\square$

**Remark (what is not guaranteed).** The plan need not be a shortest plan, and the algorithm can fail on a solvable task. Both come from the same cause: the step to $s'$ is never taken back. In the dead-end example of the page, the first iteration moves to the trap, and every state reachable from there has $h = \infty$, so BETTER fails although a plan from $I$ exists. In the blocks world example of the page, the plan has 8 actions and the shortest plan has 4.

**Remark (the original goal test).** Figure 3 of Hoffmann and Nebel (2001) stops when $h(s) = 0$ and searches only for $h(s') < h(s)$. That is the same algorithm when $h(t) = 0$ exactly for goal states, which is true for the FF heuristic. The test "$t$ is a goal" of line L13 makes Theorem 3 hold for any $h$ that satisfies (A1) and (A2).
