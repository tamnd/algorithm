---
title: The relaxed planning graph computes relaxed reachability, and its extraction returns a relaxed plan
proves: [correctness, termination]
status: full
---

We use the notation and the pseudocode of the page. The actions are $A$, the facts number $n$, the state is $s$ and the goal is $G$. Without deletes, applying an action can only add facts, so a relaxed state is a set that grows. Let $R_0 = s$ and $R_{i+1} = R_i \cup \bigcup \{\mathrm{add}(a) : \mathrm{pre}(a) \subseteq R_i\}$: the facts reachable in $i$ relaxed parallel steps.

**Lemma 1 (levels).** For every $i$ that BUILD reaches, $F_i = R_i$. For every fact $f \in F_i$, $\mathrm{level}(f) = \min \{ j : f \in R_j \}$, and this equals the unit-cost $h^{\max}(f)$, the least fixed point of $h(f) = 0$ for $f \in s$ and $h(f) = \min_{a : f \in \mathrm{add}(a)} (1 + \max_{p \in \mathrm{pre}(a)} h(p))$ otherwise, with the max over an empty set equal to 0.

*Proof.* $F_0 = s = R_0$. Suppose $F_i = R_i$. Line L3 takes the actions with $\mathrm{pre}(a) \subseteq F_i$ that are new at layer $i$. An action applicable at an earlier level $F_j \subseteq F_i$ added its effects to $F_{j+1} \subseteq F_i$, so leaving it out loses nothing. So $F_{i+1} = F_i \cup \mathrm{new} = R_{i+1}$. Line L6 sets $\mathrm{level}(f) = i + 1$ exactly for the facts of $R_{i+1} \setminus R_i$, so $\mathrm{level}(f)$ is the first $j$ with $f \in R_j$.

For $h^{\max}$: let $d(f) = \min \{ j : f \in R_j \}$. If $f \notin s$ and $d(f) = j$, some action $a$ with $\mathrm{pre}(a) \subseteq R_{j-1}$ adds $f$, so $\max_p d(p) \le j - 1$, and no achiever has all its preconditions in $R_{j-2}$, or $f$ would be in $R_{j-1}$. So $d$ satisfies the fixed point equation. Any function $h$ that satisfies it has $h(f) \le d(f)$ by induction on $d(f)$, through the achiever above. Conversely, by induction on $j$, a fact with $h(f) \le j$ is in $R_j$: its minimizing achiever has all preconditions with $h \le j - 1$, so they are in $R_{j-1}$. So $d \le h$, and $d$ is the least fixed point. $\square$

**Theorem 1 (build).** BUILD stops after at most $n$ layers. It returns the levels exactly when $G$ is reachable in the relaxed task, that is, when a relaxed plan for $G$ from $s$ exists.

*Proof.* Each layer that does not stop at line L5 adds at least one fact to $F_i$, and $F_i$ has at most $n$ facts, so at most $n$ layers are built. If the loop ends at line L2, then $G \subseteq F_m = R_m$. Applying, layer by layer, all actions of $A_0$, then all of $A_1$, and so on, in any order inside a layer, is a relaxed plan: each action of layer $i$ has its preconditions in $F_i$, which the earlier layers make true. If line L5 fires at level $i$, then $R_{i+1} = R_i$, so $R_j = R_i$ for all $j \ge i$, and $G \not\subseteq R_i$. Every relaxed plan of length $r$ reaches only facts of $R_r$, since each action of the sequence is applicable at a level no later than its index. So no relaxed plan reaches $G$. $\square$

**Theorem 2 (extraction).** If BUILD returns the levels, EXTRACT returns a sequence $\pi$ that is a relaxed plan for $G$ from $s$, with each action at most once. Hence $h^{\max}(G) \le h^+(s) \le |\pi|$, where $h^{\max}(G) = \max_{g \in G} \mathrm{level}(g)$, and $|\pi| = 0$ exactly when $G \subseteq s$.

*Proof.* *Well defined.* A goal $g$ in $G_i$ with $i \ge 1$ has $\mathrm{level}(g) = i$. Its level was set at line L6 because some action of $A_{i-1}$ adds it, so line L12 finds a candidate. Every precondition $p$ of an action of layer $i - 1$ has $\mathrm{level}(p) \le i - 1$, so the goals put into goal sets while level $i$ is processed lie at lower levels, and the loop of line L9 handles them later. In the same way, every action that needs a goal $p$ lies in a layer $\ge \mathrm{level}(p)$, so it is selected before $p$ is handled, and $\mathrm{need}(p)$ is final when line L11 tests $p$.

*No repeats.* An action $o$ is selected at layer $\mathrm{level}(o)$, for a goal $g$ at level $\mathrm{level}(o) + 1$ that it adds. Suppose it is selected a second time, for a goal $g'$. Then $g'$ is at the same level as $g$ and is handled after $g$. Every action that needs $g'$ lies in a layer $\ge \mathrm{level}(g') = \mathrm{level}(o) + 1$, so $\mathrm{need}(g')$ is a position after that of $o$, and $o$ adds $g'$. So line L11 skips $g'$, a contradiction.

*Relaxed plan.* Order the selected actions by position, as line L16 does. Take a selected action $o$ at position $q$ and a precondition $p$ of $o$. If $\mathrm{level}(p) = 0$, then $p \in s$. Otherwise line L15 put $p$ into $G_{\mathrm{level}(p)}$ with $\mathrm{need}(p) \le q$. When $p$ was handled, either line L11 found a selected action at a position before $\mathrm{need}(p) \le q$ that adds $p$, or line L13 selected an achiever of $p$ at layer $\mathrm{level}(p) - 1$. That layer is below the layer of $o$, which is $\ge \mathrm{level}(p)$, so the achiever's position is before $q$. In both cases an action earlier in $\pi$ adds $p$. Each top goal $g$ has $\mathrm{need}(g) = (m, 0)$, after every position, and is either in $s$ (level 0) or added by an action of $\pi$ in the same way. Without deletes, a fact added earlier stays true, so every action of $\pi$ is applicable in turn and $G$ holds at the end.

*Bounds.* $h^+(s) \le |\pi|$ because $\pi$ is a relaxed plan. For the lower bound, an action applied at index $j$ of any relaxed plan has its preconditions in $R_{j-1}$ by induction on $j$, so after $r$ actions only facts of $R_r$ are true. A relaxed plan reaching $g$ thus has length at least $\mathrm{level}(g)$. If $G \subseteq s$, all goals are at level 0, $m = 0$, and nothing is selected. If $G \not\subseteq s$, some goal is at a level $\ge 1$, and it is either skipped because a selected action adds it or it gets one, so $|\pi| \ge 1$. $\square$

**Remark (the literal marking).** If line L11 is replaced by "skip $g$ when a selected action adds $g$ at a level $\ge i - 1$", as a literal reading of Figure 2 of Hoffmann and Nebel (2001) gives, the step *relaxed plan* fails. The supplier of $p$ can be an action of the same layer as $o$ that was selected after $o$, so it comes after $o$ in the order of selection. The second example of the page is such a case, and there the result is not a relaxed plan and is shorter than $h^+$.
