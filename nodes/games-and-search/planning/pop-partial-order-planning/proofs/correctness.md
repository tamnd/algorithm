title: POP is sound, terminates, is complete within its bound, and with iterative deepening returns a plan with the fewest steps
proves: [correctness]
status: full

We use the pseudocode of the page. The task is a ground STRIPS task $(F, A, I, G)$. A plan is a sequence of actions that applies from $I$ and ends in a state that contains $G$. A partial plan $P$ has steps $0$ (START, with $\mathit{add} = I$), $1$ (FINISH, with $\mathit{pre} = G$) and other steps, each a copy of an action; an ordering relation $\prec$, the transitive closure of the constraints; and causal links $i \xrightarrow{p} j$ with $p \in \mathit{add}(i) \cap \mathit{pre}(j)$ and $i \prec j$. A linearization is a total order of the steps that extends $\prec$. Write $\mathrm{seq}(L)$ for the actions of a linearization $L$ without START and FINISH.

**Lemma 1 (soundness of a complete plan).** If $\prec$ is acyclic and $P$ has no open condition and no threat, then for every linearization $L$, $\mathrm{seq}(L)$ is a plan.

*Proof.* Let $L = (0, s_1, \ldots, s_m, 1)$ and let $x_t$ be the state after the first $t$ actions of $\mathrm{seq}(L)$, with $x_0 = I$. We show by induction on $t$ that the action $s_{t+1}$ applies in $x_t$; the same argument with FINISH in place of $s_{t+1}$ shows $G \subseteq x_m$. Take $p \in \mathit{pre}(s_{t+1})$. There is no open condition, so a link $i \xrightarrow{p} s_{t+1}$ exists, and $i$ comes before $s_{t+1}$ in $L$ because $i \prec s_{t+1}$. If $i$ is START, then $p \in I = x_0$. Otherwise $i = s_r$ for some $r \le t$, and $p \in (x_{r-1} \setminus \mathit{del}(s_r)) \cup \mathit{add}(s_r)$ because $p \in \mathit{add}(s_r)$, so $p \in x_r$. Now take a step $k = s_u$ with $r < u \le t$, or with $0 < u \le t$ if $i$ is START. It lies between $i$ and $s_{t+1}$ in $L$, so the orderings allow $i \prec k \prec s_{t+1}$: they cannot imply $k \prec i$ or $s_{t+1} \prec k$, since $L$ extends them. As there is no threat, $p \notin \mathit{del}(k)$. So no action between them removes $p$, and $p \in x_t$. $\square$

**Lemma 2 (termination).** For a fixed $n$, REFINE visits finitely many partial plans.

*Proof.* Each refinement does one of three things. It adds a new step, and there are at most $n$ of them on a branch, by line L13. It adds a link that ends at an open condition $(p, j)$; afterwards $(p, j)$ is not open and stays so, since links are never removed, and there are at most $(n + 1) \cdot q$ pairs $(p, j)$ for the largest precondition size $q$. Or it adds an ordering $k \prec i$ or $j \prec k$ for a threat. A threat exists only if neither $k \prec i$ nor $j \prec k$ holds, so the closure $\prec$ gets a new pair, and there are at most $(n + 2)^2$ pairs. So every branch has finite depth. Each node has finitely many resolvers. By König's lemma the tree is finite. $\square$

**Lemma 3 (the step bound).** If a plan exists, a plan with at most $2^{|F|} - 1$ actions exists. If $\sigma$ is a shortest plan, then no action $a$ of $\sigma$ has $\mathit{add}(a) \subseteq \mathit{pre}(a)$, and every precondition of an action of $\sigma$ is reachable when delete lists are ignored.

*Proof.* A shortest plan visits each state at most once, since a cycle could be cut out, and there are $2^{|F|}$ states, so it has at most $2^{|F|} - 1$ actions. STRIPS is monotone: if $x \subseteq y$ and $a$ applies in $x$, then $a$ applies in $y$ and $(x \setminus \mathit{del}(a)) \cup \mathit{add}(a) \subseteq (y \setminus \mathit{del}(a)) \cup \mathit{add}(a)$. If $a$ in $\sigma$ applies in $x$ and $\mathit{add}(a) \subseteq \mathit{pre}(a) \subseteq x$, the next state is a subset of $x$, so by monotonicity the rest of $\sigma$ also applies from $x$ and still reaches a superset of $G$. Removing $a$ gives a shorter plan, a contradiction. The last claim holds because every state that a plan visits is a subset of the facts that are reachable with delete lists ignored. $\square$

So the filter of the implementation keeps every action of a shortest plan.

**Lemma 4 (completeness).** Let $\sigma = (a_1, \ldots, a_m)$ be a plan whose actions are in the action set given to REFINE, with $m \le n$. Then REFINE with the bound $n$ returns a complete plan.

*Proof.* Put position 0 for START, positions $1, \ldots, m$ for $a_1, \ldots, a_m$ and position $m + 1$ for FINISH, and say that position 0 adds $I$. Call a partial plan $P$ *faithful* if there is a one-to-one map $\phi$ from its steps to the positions with these properties: $\phi(\text{START}) = 0$, $\phi(\text{FINISH}) = m + 1$, every other step $s$ is a copy of $a_{\phi(s)}$; $i \prec j$ implies $\phi(i) < \phi(j)$; and for every link $i \xrightarrow{p} j$, $\phi(i)$ is the last position before $\phi(j)$ that adds $p$.

The first plan is faithful. Let $P$ be faithful and have a flaw. We show that every flaw of $P$ has a resolver that gives a faithful plan. Then whatever flaw line L8 picks, its set $R$ holds a resolver that gives a faithful child. Follow such children from the root. By Lemma 2 this path is finite, so it ends at a faithful plan with no flaw, which line L7 returns. Depth-first search either reaches this plan or returns another complete plan before it.

*Open condition $(p, j)$.* Since $\sigma$ is a plan, $p$ holds before position $\phi(j)$. So some position before $\phi(j)$ adds $p$, because only a position that adds $p$ can make it true. Let $q$ be the last one. If $q = \phi(i)$ for a step $i$, then $j \prec i$ is false, since it would give $\phi(j) < \phi(i)$; so line L12 offers the link $i \xrightarrow{p} j$. Its new ordering $i \prec j$ agrees with $\phi$, and the closure of orderings that all agree with $\phi$ also agrees with $\phi$. If no step has position $q$, then $q \ne 0$, and the steps other than START and FINISH have distinct positions in $1, \ldots, m$, with $q$ unused. So $P$ has fewer than $m \le n$ such steps, and line L13 offers a new copy of $a_q$ linked to $j$. Extend $\phi$ by $q$.

*Threat $(k, i \xrightarrow{p} j)$.* We have $p \in \mathit{del}(k)$. Since $\phi$ is one to one, $\phi(k) \ne \phi(i), \phi(j)$. Suppose $\phi(i) < \phi(k) < \phi(j)$. If $p \in \mathit{add}(k)$, then $\phi(k)$ is a later position before $\phi(j)$ that adds $p$, against the choice of $\phi(i)$. If $p \notin \mathit{add}(k)$, then $p$ is false after position $\phi(k)$, and no position after it and before $\phi(j)$ adds $p$, so $p$ is false before $\phi(j)$, against the fact that $\sigma$ is a plan. So either $\phi(k) < \phi(i)$, and demotion $k \prec i$ agrees with $\phi$, or $\phi(k) > \phi(j)$, and promotion $j \prec k$ agrees with $\phi$. In both cases the new orderings agree with $\phi$, so they are acyclic, and line L10 keeps the resolver. $\square$

**Lemma 5 (the cut test).** If a round with bound $n$ ends with $\mathit{cut} = \mathit{false}$, then the round with any bound $n' > n$ visits the same partial plans and also fails.

*Proof.* The bound appears only in line L13. In the round with bound $n$, line L14 never ran, so at every open condition that the round met, either $P$ had fewer than $n$ steps, or no action adds $p$. In both cases line L13 gives the same set $R$ under the bound $n'$. So, node by node from the root, the two rounds compute the same flaws, the same numbers of resolvers, the same choice in line L8 and the same children. $\square$

**Theorem.** POP returns a complete plan whose every linearization is a plan, with the fewest steps of any plan, if a plan exists, and it returns failure otherwise.

*Proof.* By Lemma 1, any plan that POP returns has only valid linearizations. Suppose that a plan exists and let $L^*$ be the length of a shortest one, $\sigma$. By Lemma 3, $\sigma$ uses only actions that the filter keeps. For a round $n < L^*$, a complete plan with $m \le n$ steps would give a plan with $m < L^*$ actions by Lemma 1, so the round fails; it does not end the loop by line L5, because by Lemma 4 the round with bound $L^*$ succeeds, and by Lemma 5 a round with $\mathit{cut} = \mathit{false}$ would force all later rounds to fail. Also $L^* \le 2^{|F|} - 1$ by Lemma 3, so line L1 reaches the round $n = L^*$, and by Lemma 4 POP returns a complete plan in it. That plan has $m \le L^*$ steps and gives a plan with $m$ actions, so $m = L^*$. If no plan exists, no round returns a plan by Lemma 1, and the loop ends at line L5 or at line L6, after finitely many rounds by Lemma 2. $\square$
