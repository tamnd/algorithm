---
title: GRAPHPLAN returns a valid plan with the fewest parallel steps, and reports no plan exactly when none exists
proves: [correctness, termination]
status: full
---

We use the notation and the pseudocode of the page, and the results of the [planning graph proof](/planning-graph/proofs/correctness/). The task is $(F, A, I, G)$ with $n = |F|$. A step is a set of actions, applicable in a state, of which no two interfere (one deletes a precondition or an add effect of the other). We allow the empty step, which changes nothing. A set $g$ of facts is *reachable in $i$ steps* when some sequence of $i$ steps from $I$ ends in a state that contains $g$. Because empty steps are allowed, reachable in $i$ steps implies reachable in $i + 1$ steps.

We use one fact from the proof of Theorem 1 of the planning graph. Let $s$ be reachable in at most $k$ steps, let $S$ be a step applicable in $s$, and let $S^+$ be $S$ together with the no-ops of the facts of $s$ that no action of $S$ deletes. Then $S^+ \subseteq A_k$, and no two members of $S^+$ are mutex in $AM_k$.

**Lemma 1 (soundness of EXTRACT).** If EXTRACT$(g, i)$ returns $\pi$, then $\pi$ is a sequence of $i$ steps, and applying it from $I$ gives a state that contains $g$.

*Proof.* By induction on $i$. For $i = 0$ the call returns the empty plan. Every goal set passed to EXTRACT at level 0 is either $G$ with $G \subseteq P_0 = I$, or a union of preconditions of actions of $A_0$, which are in $P_0 = I$. So $g \subseteq I$.

Let $i \ge 1$ and suppose the call returns at line L13 with the set $S$ and the plan $\pi'$ for $g' = \bigcup_{a \in S} \mathrm{pre}(a)$. By induction, $\pi'$ has $i - 1$ steps and ends in a state $s \supseteq g'$. Let $T$ be the actions of $S$ that are not no-ops. Each $a \in T$ has $\mathrm{pre}(a) \subseteq g' \subseteq s$. No two members of $S$ are mutex (line L18), and mutex includes interference, so $T$ is a step. Take $f \in g$. Line L15 gives a member $a \in S$ that adds $f$. If $a$ is a real action, no other member $b$ of $S$ deletes $f$, because that would be an inconsistent effect and $a, b$ would be mutex. So $f$ is in the result. If $a$ is the no-op of $f$, then $f \in \mathrm{pre}(a) \subseteq s$, and no member $b$ deletes $f$, because that would delete a precondition of the no-op. So $f$ is in the result again. $\square$

**Lemma 2 (completeness of EXTRACT).** At any moment of the run, if $g$ is reachable in $i$ steps, then $g$ is not in nogood at level $i$, and a call EXTRACT$(g, i)$ returns a plan.

*Proof.* By induction on $i$, and inside it by induction on the time of the run. For $i = 0$, line L9 returns at once, and nothing is ever stored at level 0. Let $i \ge 1$ and let $s_0 = I, \ldots, s_i \supseteq g$ be the states of a run of steps $S_1, \ldots, S_i$. For each $f \in g$, pick $t(f) \in S_i$ that adds $f$ if there is one. Otherwise $f \in s_{i-1}$ and no action of $S_i$ deletes $f$, and we pick $t(f) = $ the no-op of $f$. All picks are in $S_i^+$, which is built from $s_{i-1}$, a state reachable in $i - 1$ steps. By the fact above, all picks are in $A_{i-1}$ and pairwise not mutex in $AM_{i-1}$.

Now follow ASSIGN. At each call, it takes the first open goal $f$ and tries every achiever of $f$ in $A_{i-1}$ that is not mutex with the picks so far. The achiever $t(f)$ is one of them, since all picks $t(\cdot)$ are pairwise not mutex. Follow the branch that adds $t(f)$ each time. It ends with a set $S \subseteq \{t(f) : f \in g\}$ that covers $g$, and ASSIGN yields it. Its preconditions $g'$ are contained in $s_{i-1}$, so $g'$ is reachable in $i - 1$ steps. By induction on $i$, $g'$ is not in nogood at level $i - 1$ and EXTRACT$(g', i - 1)$ returns a plan. So when the loop of line L11 reaches $S$, if it has not returned before, line L13 returns. The loop thus never ends with line L14, and $g$ is never added to nogood at level $i$. Line L10 cannot fire for $g$ by the same claim at earlier times. $\square$

**Theorem 1 (step optimality).** If the task has a plan, GRAPHPLAN returns a valid plan with the fewest parallel steps.

*Proof.* Let $k^*$ be the fewest steps of a plan. By the corollary of the planning graph proof, the goal does not hold at any level below $k^*$, and it holds at level $k^*$. So line L1 stops at a level $k_0 \le k^*$ (the graph does not level off before the goal holds, because after a level off all levels are equal and the goal holds at level $k^*$). Line L2 does not fire. By Lemma 1, any stage $k$ that succeeds gives a plan of $k$ steps, so no stage $k < k^*$ succeeds. By Lemma 2, stage $k^*$ succeeds. By Theorem 2 below, line L7 does not fire before it, because a plan exists. So GRAPHPLAN returns at stage $k^*$ with a plan of $k^*$ steps. None of its steps is empty, since dropping an empty step would give a plan of $k^* - 1$ steps. $\square$

**Theorem 2 (the termination test is sound).** If line L7 fires, the task has no plan.

*Proof.* Let $n$ be the level off: $P_n = P_{n+1}$ and $FM_n = FM_{n+1}$. Then all levels $j \ge n$ are equal, and so all action levels $A_j$, $AM_j$ and achiever lists for $j \ge n$ are equal. Hence ASSIGN$(g, i, \emptyset)$ yields the same sets for every $i \ge n + 1$. Define $\mathrm{child}(g)$ as the family of precondition sets $\bigcup_{a \in S} \mathrm{pre}(a)$ over the sets $S$ that ASSIGN$(g, n + 1, \emptyset)$ yields.

Suppose line L7 fires after stage $t$, with $n < t$. All stages up to $t$ failed. In a failed stage every call of EXTRACT fails, because a success at any level returns through line L13 all the way to the top. A failed call that does not stop at line L10 runs the loop of line L11 to the end, so it calls EXTRACT on every precondition set of every set that ASSIGN yields, and then adds its goal set at line L14. A failed call that stops at line L10 met a set that an earlier call explored in this way. So the goal sets stored at a level $i$ after stage $t$ are exactly the sets $g$ such that $(g, i)$ lies in the closure $C_{t'}$ of some stage $t' \le t$, where $C_{t'}$ is the smallest set that contains $(G, t')$ and contains $(g', i - 1)$ for each $(g, i)$ in it with $i \ge 1$ and each $g'$ that is a precondition set of a set that ASSIGN$(g, i, \emptyset)$ yields.

Let $D_0 = \{G\}$ and $D_{d+1} = \bigcup_{g \in D_d} \mathrm{child}(g)$. For $t' \ge n$, the sets of $C_{t'}$ at level $i$ with $n \le i \le t'$ are exactly $D_{t' - i}$, because every regression used between levels $t'$ and $n$ starts at a level $i \ge n + 1$ and uses child. The first stage is $k_0 \le n$: the goal holds at level $k_0$, and if $k_0 > n$, it would hold at level $n$ too. Stages $t' < n$ never reach level $n$. So the family stored at level $n$ after stage $t$ is $N_t = D_0 \cup D_1 \cup \cdots \cup D_{t-n}$, and after stage $t - 1 \ge n$ it is $N_{t-1} = D_0 \cup \cdots \cup D_{t-n-1}$.

Line L7 fires, so $N_t = N_{t-1}$, and $D_{t-n} \subseteq N_{t-1}$. Let $E = N_{t-1}$. Then $\mathrm{child}(E) = D_1 \cup \cdots \cup D_{t-n} \subseteq E$: the family $E$ is closed under child. Every member of $E$ is stored at level $n$, so by Lemma 2 it is not reachable in $n$ steps, and in particular it is not a subset of $I$ (a subset of $I$ is reachable in $n$ empty steps).

We claim no member of $E$ is reachable in any number of steps. Suppose some are, and let $g \in E$ be reachable in $j$ steps with $j$ as small as possible over all members. Since $g \not\subseteq I$, $j \ge 1$. As in the proof of Lemma 2, build the picks $t(f)$ from the last step, taken from $S_j^+$ in the state $s_{j-1}$. The state $s_{j-1}$ is reachable in $j - 1$ steps, so also in $k = \max(j - 1, n)$ steps. By the fact above, the picks are in $A_k$ and pairwise not mutex in $AM_k$, and these equal $A_n$ and $AM_n$ since $k \ge n$. So ASSIGN$(g, n + 1, \emptyset)$ yields a set $S$ of picks, and its preconditions $g'$ are contained in $s_{j-1}$. Then $g' \in \mathrm{child}(g) \subseteq E$ and $g'$ is reachable in $j - 1$ steps, against the choice of $j$. This proves the claim.

Since $k_0 \le n$, $G \in D_0 \subseteq E$, so $G$ is reachable in no number of steps, and the task has no plan. $\square$

**Theorem 3 (termination).** GRAPHPLAN stops on every task. If the task has no plan, it reports no plan.

*Proof.* Each call of EXTRACT recurses to a lower level, and ASSIGN has finitely many branches, so each stage stops. If a plan exists, Theorem 1 applies. Suppose no plan exists. If line L1 ends with a level off where the goal does not hold, line L2 reports no plan. Otherwise every stage fails, by Lemma 1. The graph levels off at some level $n$ by Theorem 2 of the planning graph proof. Each stage $t > n$ after which line L7 does not fire adds at least one new set to nogood at level $n$. These are subsets of $P_n$, so there are at most $2^{|P_n|} \le 2^n$ of them, and line L7 fires after at most $2^n + 1$ such stages. When the goal does not hold at the level off, line L2 is correct by the corollary of the planning graph proof. $\square$

**Remark.** Blum and Furst (1997, Theorem 3) prove the same test with the argument that above the level off each stage repeats the nogood sets of the stage before, one level higher. The closure $C_{t'}$ above is a precise form of that argument. It uses only that the search order is fixed and that every call of a failed stage fails, so it holds with or without the minimal action set rule and forward checking.
