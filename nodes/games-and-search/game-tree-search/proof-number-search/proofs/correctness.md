---
title: Proof-number search stops with the right answer and always expands a most-proving node
proves: [correctness, termination, complexity]
status: full
---

We use the pseudocode PNS of the page. The input is a finite AND/OR tree: each node is an OR node or an AND node, the types alternate, and each terminal node is *proved* or *disproved*. A node that is not terminal has at least one child. The *value* of a node in the full tree is defined from the leaves up: an OR node is proved when some child is proved, an AND node when all children are proved, and a node is disproved when it is not proved.

**The explored tree.** At any time PNS holds a subtree $T$ of the full tree that contains the root: the expanded nodes, all their children, and nothing else. A leaf of $T$ is a terminal node or a *frontier node* (not terminal and not expanded). Let $F(n)$ be the set of frontier nodes of $T$ below or at $n$.

For a set $P \subseteq F(n)$, evaluate the subtree of $n$ in $T$ with the frontier nodes in $P$ taken as proved and all other frontier nodes taken as disproved; call $P$ a *proof set* of $n$ if $n$ comes out proved. Dually, $D \subseteq F(n)$ is a *disproof set* of $n$ if $n$ comes out disproved when the nodes of $D$ are taken as disproved and all other frontier nodes as proved. Let
$$ p^*(n) = \min \{|P| : P \text{ a proof set of } n\}, \qquad d^*(n) = \min \{|D| : D \text{ a disproof set of } n\}, $$
with $\min \emptyset = \infty$.

The evaluation is *monotone*: taking more frontier nodes as proved never turns a proved node into a disproved one. This follows by induction on the height, since "some child" and "all children" are monotone conditions. So a superset of a proof set is a proof set, and a superset of a disproof set is a disproof set.

**Lemma 1 (meaning of the numbers).** If the rules of the page hold at every node of $T$, then $\mathrm{pn}(n) = p^*(n)$ and $\mathrm{dn}(n) = d^*(n)$ for every node $n$ of $T$. Moreover $\mathrm{pn}(n) = 0$ if and only if $\mathrm{dn}(n) = \infty$, and then $n$ is proved in the full tree; $\mathrm{dn}(n) = 0$ if and only if $\mathrm{pn}(n) = \infty$, and then $n$ is disproved in the full tree.

*Proof.* By induction on the height of $n$ in $T$. A proved terminal node has the empty set as a proof set and no disproof set, so $p^* = 0 = \mathrm{pn}$ and $d^* = \infty = \mathrm{dn}$; a disproved terminal node is the dual. A frontier node $n$ has $F(n) = \{n\}$: the empty set is not a proof set and $\{n\}$ is one, so $p^*(n) = 1$, and in the same way $d^*(n) = 1$.

Let $n$ be an expanded OR node with children $c_1, \ldots, c_k$, $k \ge 1$. The sets $F(c_i)$ are disjoint and their union is $F(n)$. A set $P$ is a proof set of $n$ exactly when $P \cap F(c_i)$ is a proof set of $c_i$ for some $i$, because the evaluation inside the subtree of $c_i$ depends only on $P \cap F(c_i)$. So $p^*(n) = \min_i p^*(c_i)$: a proof set of one child is a proof set of $n$, and every proof set of $n$ contains one of a child. A set $D$ is a disproof set of $n$ exactly when $D \cap F(c_i)$ is a disproof set of $c_i$ for every $i$, so the smallest one is a union of smallest disproof sets of the children, and $d^*(n) = \sum_i d^*(c_i)$, which is $\infty$ when some child has none. By the induction hypothesis these are the rules for $\mathrm{pn}$ and $\mathrm{dn}$ at an OR node. An AND node is the dual case, with sum and minimum exchanged.

For the second part: $p^*(n) = 0$ means that $n$ is proved when every frontier node is taken as disproved. By monotonicity $n$ is then proved under every choice of the frontier values, so there is no disproof set and $d^*(n) = \infty$. Conversely, if $d^*(n) = \infty$, then $F(n)$ is not a disproof set. Taking all of $F(n)$ as disproved is the same choice as taking the empty set as proved, so with that choice $n$ is proved, the empty set is a proof set, and $p^*(n) = 0$. One choice of frontier values is the true one, given by the full tree, so $p^*(n) = 0$ implies that $n$ is proved in the full tree. The statements for $\mathrm{dn}(n) = 0$ are the duals. $\square$

**Lemma 2 (the rules hold after each step).** Before each test of line L2, every node of $T$ satisfies the rules of the page.

*Proof.* Line L1 sets the numbers of the root by the rules, and $T$ is the root alone. Assume the rules hold before a step, which expands a frontier node $m$. Line L7 adds the children of $m$ and gives each the numbers of a terminal or a frontier node, as the rules require. Line L8 sets the numbers of $m$ by the rules. Only the ancestors of $m$ have a child whose numbers changed, so only they can now break a rule. Lines L9 to L14 visit the ancestors from the parent of $m$ upward and recompute each one from its children. If a node $n$ keeps its numbers in line L13, then every ancestor above $n$ has the same children with the same numbers as before the step, so it still satisfies its rule, and the loop may stop. Otherwise the loop goes on to the root. In both cases all nodes satisfy the rules at the end of the step. $\square$

**Lemma 3 (the selection ends at a frontier node).** If $0 < \mathrm{pn}(\text{root})$ and $0 < \mathrm{dn}(\text{root})$, the loop of lines L4 to L6 ends at a frontier node $m$, and every node $n$ on the path from the root to $m$ has $0 < \mathrm{pn}(n) < \infty$ and $0 < \mathrm{dn}(n) < \infty$.

*Proof.* By Lemmas 1 and 2, $\mathrm{dn}(\text{root}) \ne 0$ gives $\mathrm{pn}(\text{root}) \ne \infty$, and $\mathrm{pn}(\text{root}) \ne 0$ gives $\mathrm{dn}(\text{root}) \ne \infty$. So the root has both numbers in $(0, \infty)$. Let $n$ be an expanded node with both numbers in $(0, \infty)$. If $n$ is an OR node, line L5 picks a child $c$ with $\mathrm{pn}(c) = \mathrm{pn}(n)$, which exists because $\mathrm{pn}(n)$ is a minimum over the children; then $\mathrm{pn}(c) \in (0, \infty)$. The sum $\mathrm{dn}(n)$ is finite, so $\mathrm{dn}(c)$ is finite, and $\mathrm{dn}(c) \ne 0$ because $\mathrm{dn}(c) = 0$ would give $\mathrm{pn}(c) = \infty$ by Lemma 1. An AND node is the dual case with line L6. So every node on the path has both numbers in $(0, \infty)$. The path goes down the finite tree, so the loop ends, at a node that is not expanded. That node is not terminal, because terminal nodes have numbers $(0, \infty)$ or $(\infty, 0)$. So it is a frontier node. $\square$

**Theorem 1 (termination and correctness).** PNS stops after at most $N$ steps, where $N$ is the number of interior nodes of the full tree, and it returns true exactly when the root is proved.

*Proof.* By Lemma 3, each step expands a frontier node, which is an interior node of the full tree that was not expanded before; expanded nodes stay expanded. So there are at most $N$ steps, and the loop of line L2 stops. When it stops, $\mathrm{pn}(\text{root}) = 0$ or $\mathrm{dn}(\text{root}) = 0$. By Lemmas 1 and 2, in the first case the root is proved, and line L15 returns true; in the second case the root is disproved and $\mathrm{pn}(\text{root}) = \infty \ne 0$, and line L15 returns false. $\square$

**Theorem 2 (most-proving node).** Let $m$ be the node selected in a step, with $0 < \mathrm{pn}(\text{root}), \mathrm{dn}(\text{root})$. Then $m$ lies in a smallest proof set and in a smallest disproof set of the root. If $m$ became a proved terminal node, $\mathrm{pn}(\text{root})$ would drop by exactly 1; if it became a disproved terminal node, $\mathrm{dn}(\text{root})$ would drop by exactly 1.

*Proof.* Let $m = n_k, n_{k-1}, \ldots, n_0 = \text{root}$ be the path from $m$ up to the root. We show by induction on $j = k, k-1, \ldots, 0$ that $n_j$ has a smallest proof set and a smallest disproof set that both contain $m$. For $j = k$, $\{m\}$ is both. Let $n = n_j$ with $j < k$ and $c = n_{j+1}$, and let $P_c$ and $D_c$ be a smallest proof set and a smallest disproof set of $c$ that contain $m$. If $n$ is an OR node, then $c$ was chosen with $\mathrm{pn}(c) = \mathrm{pn}(n)$. $P_c$ is a proof set of $n$ of size $p^*(c) = p^*(n)$, so it is a smallest one. A smallest disproof set of $n$ is the union of smallest disproof sets of the children (proof of Lemma 1), and we may use $D_c$ for the child $c$. If $n$ is an AND node, the argument is the same with proof and disproof exchanged, using the choice $\mathrm{dn}(c) = \mathrm{dn}(n)$.

Now let $P$ be a smallest proof set of the root with $m \in P$, and let $T'$ be the tree in which $m$ is a proved terminal node. Then $P \setminus \{m\}$ is a proof set in $T'$, because the evaluation in $T'$ with $P \setminus \{m\}$ equals the evaluation in $T$ with $P$. So the new proof number is at most $\mathrm{pn}(\text{root}) - 1$. Conversely, if $P'$ is a proof set in $T'$, then $P' \cup \{m\}$ is a proof set in $T$ for the same reason, so the new proof number is at least $\mathrm{pn}(\text{root}) - 1$. The case of a disproof is the dual. $\square$

**Theorem 3 (cost).** Each step of PNS costs $O(b d)$ time besides the move generator, where $b$ is the largest number of children and $d$ the depth of the tree. The total time is $O(N b d)$, and the space is $O(N b)$ nodes.

*Proof.* The walk of lines L4 to L6 visits at most $d + 1$ nodes and scans at most $b$ children at each, so it costs $O(b d)$. Lines L7 and L8 cost $O(b)$. The loop of lines L9 to L14 visits at most $d$ ancestors, with an $O(b)$ recomputation at each. By Theorem 1 there are at most $N$ steps, which gives $O(N b d)$. Each step adds at most $b$ nodes to $T$, so $T$ has at most $1 + N b$ nodes. $\blacksquare$
