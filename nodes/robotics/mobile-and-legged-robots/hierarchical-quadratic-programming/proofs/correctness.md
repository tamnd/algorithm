Line numbers refer to the pseudocode on the [hierarchical quadratic programming](/hierarchical-quadratic-programming/) page. The proof is in exact arithmetic, with $\varepsilon = 0$, a threshold of 0 for violated rows and an exact solver for each QP; the last two paragraphs treat $\varepsilon > 0$ and the active-set solver.

For level $k$, let $f_k(x) = \tfrac12\|A_kx - b_k\|^2 + \tfrac12\|\max(0, C_kx - d_k)\|^2$. Let $S_0 = \mathbb{R}^n$ and $S_k = \operatorname{argmin}\{f_k(x) : x \in S_{k-1}\}$. A lexicographic optimum is a point of $S_p$. We show by induction that every $S_k$ is nonempty and that the set described by $E$ and $G$ after level $k$ is exactly $S_k$.

**Lemma 1 (the slack form).** Let $P$ be a nonempty polyhedron. Then $\min\{f_k(x) : x \in P\}$ exists, and it equals the minimum of $\tfrac12\|A_kx - b_k\|^2 + \tfrac12\|v\|^2$ over the pairs $(x, v)$ with $x \in P$ and $C_kx - d_k \le v$. At an optimal pair, $v = \max(0, C_kx - d_k)$.

*Proof.* For a fixed $x$, the least $\|v\|^2$ subject to $v \ge C_kx - d_k$ is reached at $v_i = \max(0, (C_kx - d_k)_i)$ in each component, because $v_i$ can be 0 when the bound is negative and must be at least the bound otherwise. So the two problems have the same values for each $x$. The slack problem is a convex QP whose objective is bounded below by 0 on a nonempty polyhedron, so it attains its minimum (the Frank-Wolfe theorem for quadratic programs). $\square$

**Lemma 2 (the optimal residuals are unique).** Let $P$ be a nonempty polyhedron and $S = \operatorname{argmin}\{f_k(x) : x \in P\}$. Then there are vectors $w^*$ and $v^* \ge 0$ such that every $x \in S$ has $A_kx - b_k = w^*$ and $\max(0, C_kx - d_k) = v^*$. Moreover,
$$S = \{x \in P : A_kx = b_k + w^*,\ C_{k,i}x = d_{k,i} + v^*_i \text{ for } v^*_i > 0,\ C_{k,i}x \le d_{k,i} \text{ for } v^*_i = 0\}.$$

*Proof.* Let $x_1, x_2 \in S$ and $x(t) = (1 - t)x_1 + tx_2$ for $t \in [0, 1]$. $S$ is convex, so $x(t) \in S$ and $f_k(x(t))$ is the constant $f^*$. $f_k$ is a sum of convex functions of $t$: the terms $\tfrac12(a_i\cdot x(t) - b_i)^2$ and $\tfrac12\max(0, c_i\cdot x(t) - d_i)^2$. A sum of convex functions that is affine on an interval has every term affine there, since each term is at most its chord and the chords add up to the sum. The term $\tfrac12(a_i\cdot x(t) - b_i)^2$ is a quadratic in $t$ with leading coefficient $\tfrac12(a_i\cdot(x_2 - x_1))^2$, so it is affine only if $a_i\cdot x_1 = a_i\cdot x_2$. For an inequality row, let $s(t) = c_i\cdot x(t) - d_i$, an affine function. If $s(0) > 0$ and $s$ is not constant, then $\tfrac12\max(0, s)^2$ equals $\tfrac12 s^2$ near $t = 0$, which is strictly convex there, so it is not affine. Hence if $c_i\cdot x_1 > d_i$, then $s$ is constant and $c_i\cdot x_2 = c_i\cdot x_1$. Exchanging $x_1$ and $x_2$: if $c_i\cdot x_1 \le d_i$, then $c_i\cdot x_2 \le d_i$. This proves the first claim.

For the set equality: the inclusion $\subseteq$ is the first claim. Conversely, a point $x \in P$ of the right side has $A_kx - b_k = w^*$, the violated rows at $v^*_i$ and the other rows not violated, so $f_k(x) = \tfrac12\|w^*\|^2 + \tfrac12\|v^*\|^2 = f^*$, and $x \in S$. $\square$

**Lemma 3 (the null-space step).** Let $E$ be a matrix, $e$ a vector and $x_0$ a point with $Ex_0 = e$. Let the columns of $Z$ be a basis of the null space of $E$. Then $\{x : Ex = e\} = \{x_0 + Zy : y \in \mathbb{R}^{r}\}$, where $r$ is the number of columns of $Z$.

*Proof.* $E(x_0 + Zy) = e$. Conversely, if $Ex = e$, then $E(x - x_0) = 0$, so $x - x_0$ is in the null space and equals $Zy$ for some $y$. Rows of $E$ that are linear combinations of other rows do not change the null space, so line L7 may drop them. $\square$

**Theorem (the cascade is correct).** For each $k$, after line L7 of iteration $k$, $S_k = \{x : Ex = e,\ Gx \le g\}$ and the current $x$ is in $S_k$. At line L8, $x \in S_p$, and $(w_k, v_k)$ are the optimal residuals of level $k$.

*Proof.* By induction on $k$. Before the loop, $E$ and $G$ are empty, $S_0 = \mathbb{R}^n$, and $x = 0 \in S_0$. Assume the claim for $k - 1$. By Lemma 3 with $x_0 = x$, the feasible set of line L3 in the variable $x + Zy$ is $\{x' : Ex' = e, Gx' \le g\} = S_{k-1}$, a nonempty polyhedron. By Lemma 1, line L3 minimizes $f_k$ over $S_{k-1}$, so the new $x$ of line L4 is in $S_k$, and by Lemma 2 its $w_k$ and $v_k$ are the vectors $w^*$ and $v^*$ of that lemma. Lines L5 and L6 add exactly the equalities and inequalities of Lemma 2 to $E$ and $G$, so the new set is $S_k$, and the new $x$ satisfies it. $\square$

**The damping.** With $\varepsilon > 0$, line L3 minimizes $f_k(x + Zy) + \tfrac12\varepsilon\|y\|^2$. Let $y^*$ minimize the undamped level problem and $y_\varepsilon$ the damped one. Then $f_k(x + Zy_\varepsilon) \le f_k(x + Zy_\varepsilon) + \tfrac12\varepsilon\|y_\varepsilon\|^2 \le f_k(x + Zy^*) + \tfrac12\varepsilon\|y^*\|^2$, so the level loses at most $\tfrac12\varepsilon\|y^*\|^2$. Such a loss can make a row look violated by a tiny amount, which is why the code uses a tolerance in line L5 and keeps such a row as an inequality with its bound moved by the tiny violation; the current $x$ still satisfies every hard row, so the next level starts feasible. The damped QP is strictly convex: its objective is $\tfrac12\|Fu - f\|^2$ with $F$ of full column rank, because $F$ contains $\sqrt\varepsilon I$ for $y$ and $I$ for $v$.

**The active-set solver.** The method of `active_set_lsq` starts from the feasible point $y = 0$, $v = \max(0, C_kx - d_k)$, and keeps a working set of linearly independent active rows: a row enters only when it blocks a step $p$ in the null space of the working set, and then its normal has a positive product with $p$, so it is not a combination of the working rows. Each step solves the equality-constrained problem on the working set exactly. When the step is zero or full, the multipliers come from $A_W^T\lambda = -\nabla$; if all are nonnegative, the point satisfies the [KKT conditions](/kkt-conditions/) of a convex QP and is optimal; otherwise the row with the most negative multiplier leaves. For a strictly convex QP, this method terminates in a finite number of iterations when no step of length zero repeats a working set (Nocedal and Wright, Chapter 16). The code also stops after $50(n + m) + 50$ iterations with an error; the tests never reach that limit.

The tests check the theorem on random data: `test_inequality_stacks_match_brute_force` enumerates, at each level, every choice of active, violated and free rows, takes the best feasible candidate, and compares the residuals and the point with the cascade to $10^{-6}$ and $10^{-5}$, on 40 random stacks of three levels in three variables. `test_equality_stacks_match_the_null_space_cascade` compares stacks of equalities with an independent level-by-level solution in the null space of the higher levels.
