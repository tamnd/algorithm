title: Correctness of the Difference-of-Gaussians detector
proves: [correctness]

We prove four facts: the extremum search of line L5 returns exactly the strict extrema among the 26 neighbours; the fit of line L6 returns the exact vertex of a quadratic; the edge test keeps exactly the points with a ratio of curvatures below $r$; and for a Gaussian blob the DoG peaks at $\sigma^2 = t_0 / k$.

**Lemma 1 (the extremum search).** Line L5 returns exactly the samples $(u, v, i)$ with $1 \le i \le s$, $1 \le u \le W' - 2$ and $1 \le v \le H' - 2$, for an octave of size $W' \times H'$, such that $D_i(u, v) > D_{i'}(u', v')$ for all 26 neighbours $(u', v', i') \ne (u, v, i)$ with $|u' - u|, |v' - v|, |i' - i| \le 1$, or $D_i(u, v) < D_{i'}(u', v')$ for all of them.

*Proof.* The bounds on $i$, $u$ and $v$ are the ranges of the loops, and they make every neighbour a valid sample. The implementation keeps two flags, "larger than all" and "smaller than all", both true at the start. A neighbour with a value $\ge$ the sample clears the first, and a neighbour with a value $\le$ the sample clears the second. So after all 26 neighbours the first flag is true exactly when every neighbour is strictly smaller, and the second exactly when every neighbour is strictly larger. The early exit happens only when both flags are false, and then neither can become true again, so it does not change the result. $\square$

**Lemma 2 (central differences are exact on quadratics).** Let $q(\mathbf x) = a + \mathbf b^{\mathsf T} \mathbf x + \tfrac12 \mathbf x^{\mathsf T} Q \mathbf x$ on $\mathbb Z^3$ with $Q$ symmetric. At each point $\mathbf p$, the central differences of line L6 give $\nabla q(\mathbf p) = \mathbf b + Q \mathbf p$ and the Hessian $Q$ exactly.

*Proof.* Write $e_j$ for the unit vectors. Then $q(\mathbf p + e_j) - q(\mathbf p - e_j) = 2 e_j^{\mathsf T}(\mathbf b + Q\mathbf p)$, because the terms of even order cancel; dividing by $2$ gives the $j$-th component of the gradient. Also $q(\mathbf p + e_j) + q(\mathbf p - e_j) - 2q(\mathbf p) = e_j^{\mathsf T} Q e_j = Q_{jj}$. For $j \ne l$, $q(\mathbf p + e_j + e_l) - q(\mathbf p - e_j + e_l) - q(\mathbf p + e_j - e_l) + q(\mathbf p - e_j - e_l)$ expands to $4 e_j^{\mathsf T} Q e_l = 4 Q_{jl}$, since all other terms cancel in pairs; dividing by $4$ gives $Q_{jl}$. $\square$

**Lemma 3 (the fit).** If $D$ equals a quadratic $q$ with an invertible $Q$ on all the samples read by the fit, then each step of line L6 computes the vertex $\mathbf x^\ast = -Q^{-1}\mathbf b$, and when the step does not move, it returns $\mathbf x^\ast$ and the value $q(\mathbf x^\ast)$.

*Proof.* At the sample $\mathbf p$, Lemma 2 gives $g = \mathbf b + Q\mathbf p$ and $\mathcal H = Q$. The offset is $\hat{\mathbf x} = -Q^{-1}(\mathbf b + Q\mathbf p) = \mathbf x^\ast - \mathbf p$, so $\mathbf p + \hat{\mathbf x} = \mathbf x^\ast$ at every step. The step returns when each component of $\hat{\mathbf x}$ is at most $0.5$ in absolute value; otherwise it moves to $\mathbf p + \operatorname{round}(\hat{\mathbf x})$, which is the nearest sample to $\mathbf x^\ast$ in each coordinate, and the next step returns, unless $\mathbf x^\ast$ is at a distance of exactly $0.5$ from two samples. The value is $q(\mathbf p) + \tfrac12 g^{\mathsf T}\hat{\mathbf x}$. Since $q(\mathbf p + \mathbf y) = q(\mathbf p) + g^{\mathsf T}\mathbf y + \tfrac12 \mathbf y^{\mathsf T} Q \mathbf y$ and $Q\hat{\mathbf x} = -g$, we get $q(\mathbf x^\ast) = q(\mathbf p) + g^{\mathsf T}\hat{\mathbf x} - \tfrac12 g^{\mathsf T}\hat{\mathbf x} = q(\mathbf p) + \tfrac12 g^{\mathsf T}\hat{\mathbf x}$. $\square$

**Lemma 4 (the edge test).** Let $H$ be a symmetric $2 \times 2$ matrix with eigenvalues $\alpha$ and $\beta$, and let $r \ge 1$. The test "$\det H > 0$ and $r \operatorname{tr}(H)^2 < (r + 1)^2 \det H$" holds exactly when $\alpha$ and $\beta$ have the same sign and $\max(|\alpha|, |\beta|) / \min(|\alpha|, |\beta|) < r$.

*Proof.* $\det H = \alpha\beta$ and $\operatorname{tr} H = \alpha + \beta$. $\det H > 0$ means that $\alpha$ and $\beta$ are nonzero with the same sign. Then let $\rho = |\alpha| / |\beta| \ge 1$, swapping the names if needed. The quotient $\operatorname{tr}(H)^2 / \det H = (\alpha + \beta)^2 / (\alpha\beta) = (\rho + 1)^2 / \rho$. The function $f(\rho) = (\rho + 1)^2 / \rho = \rho + 2 + 1/\rho$ is strictly increasing for $\rho \ge 1$, since $f'(\rho) = 1 - 1/\rho^2 > 0$ for $\rho > 1$. So $f(\rho) < f(r)$, which after multiplication by $\det H > 0$ is the test, holds exactly when $\rho < r$. $\square$

**Proposition 5 (the scale of a Gaussian blob).** Let the image be a Gaussian $G_{t_0}$ of variance $t_0 > 0$, and let $k > 1$. The value at the center of $D = G_{k^2 t} \ast G_{t_0} - G_t \ast G_{t_0}$, as a function of $t = \sigma^2 > 0$, has its single extremum at $t = t_0 / k$.

*Proof.* Gaussians add their variances under convolution, and a 2D Gaussian of variance $\tau$ has the value $1/(2\pi\tau)$ at its center. So the central value is $\phi(t) = \frac{1}{2\pi}\big(\frac{1}{t_0 + k^2 t} - \frac{1}{t_0 + t}\big)$, which is negative for $t > 0$ and tends to $0$ at both ends. Its derivative is $\frac{1}{2\pi}\big(\frac{1}{(t_0 + t)^2} - \frac{k^2}{(t_0 + k^2 t)^2}\big)$. It is zero when $t_0 + k^2 t = k(t_0 + t)$, that is $t(k^2 - k) = t_0(k - 1)$, so $t = t_0 / k$, and this is the only zero for $t > 0$. $\square$

**Theorem.** DOG-DETECTOR returns, for each octave, the samples of Lemma 1 whose fit converges within the move limit, whose fitted value has absolute value at least $c$, and whose spatial Hessian passes the test of Lemma 4, each mapped to the input pixel units by the factor $2^o$ and to the scale $\sigma_0 2^{o + \hat\imath / s}$.

*Proof.* By Lemma 1, line L5 visits exactly the strict extrema. Line L6 discards a candidate when the fit does not converge or leaves the valid range; Lemma 3 shows what the fit returns when $D$ is locally quadratic. Line L7 applies the contrast test and, by Lemma 4, the edge test. Line L8 maps the point: pixel $u$ of octave $o$ is pixel $2^o u$ of the input, since line L9 keeps every second pixel starting at $0$, and level $\hat\imath$ of octave $o$ has blur $\sigma_0 k^{\hat\imath}$ in octave pixels, which is $\sigma_0 2^{o + \hat\imath/s}$ in input pixels. Line L9 is a valid start of the next octave because $G_s$ has blur $\sigma_0 k^s = 2\sigma_0$, which is $\sigma_0$ in units of the new pixels. $\blacksquare$
