---
title: On exact data the DLT matrix has rank 3 and its null vector is the point, unless the point lies on the line through two centers
proves: [correctness]
status: full
---

We use the notation of the page. Each view $i = 1, \ldots, m$ has a camera matrix $P_i$ of rank 3 with rows $\mathbf{p}_i^{1\mathsf T}$, $\mathbf{p}_i^{2\mathsf T}$, $\mathbf{p}_i^{3\mathsf T}$ and center $\mathbf{C}_i \in \mathbb{R}^4$, the nonzero vector with $P_i\mathbf{C}_i = \mathbf{0}$. The image point is $(u_i, v_i)$, and $\tilde{\mathbf{x}}_i = (u_i, v_i, 1)^{\mathsf T}$. The matrix $A$ has the rows $u_i\mathbf{p}_i^{3\mathsf T} - \mathbf{p}_i^{1\mathsf T}$ and $v_i\mathbf{p}_i^{3\mathsf T} - \mathbf{p}_i^{2\mathsf T}$ for all $i$. The arithmetic is exact (real RAM).

**Claim.** Let $\mathbf{X} \in \mathbb{R}^4$ be a homogeneous point with $X_4 \ne 0$ and $P_i\mathbf{X} \sim \tilde{\mathbf{x}}_i$ for every $i$ (exact data, point in front of or behind the cameras, but not at a center). Assume that two of the cameras, say 1 and 2, have different centers, and that $\mathbf{X}$ is not on the line through them, that is, $\mathbf{C}_1$, $\mathbf{C}_2$ and $\mathbf{X}$ are linearly independent. Then (a) the null space of $A$ is spanned by $\mathbf{X}$, so $A$ has rank 3; (b) the homogeneous method returns the point $(X_1, X_2, X_3)/X_4$; (c) the inhomogeneous method returns the same point.

**Lemma 1 (the two rows of one view).** For one view, a vector $\mathbf{Y}$ satisfies both of its rows, $(u\mathbf{p}^3 - \mathbf{p}^1)^{\mathsf T}\mathbf{Y} = 0$ and $(v\mathbf{p}^3 - \mathbf{p}^2)^{\mathsf T}\mathbf{Y} = 0$, if and only if $P\mathbf{Y}$ is a multiple of $\tilde{\mathbf{x}}$, possibly the zero multiple.

*Proof.* Put $\lambda = \mathbf{p}^{3\mathsf T}\mathbf{Y}$, the third entry of $P\mathbf{Y}$. The two equations say $\mathbf{p}^{1\mathsf T}\mathbf{Y} = \lambda u$ and $\mathbf{p}^{2\mathsf T}\mathbf{Y} = \lambda v$, so together they say $P\mathbf{Y} = \lambda\tilde{\mathbf{x}}$. Conversely, if $P\mathbf{Y} = \mu\tilde{\mathbf{x}}$, the third entry gives $\mu = \lambda$, and the first two entries are the two equations. $\square$

**Lemma 2 (the ray as a plane through the origin of $\mathbb{R}^4$).** If $P\mathbf{X} \sim \tilde{\mathbf{x}}$ with $P\mathbf{X} \ne \mathbf{0}$, then the vectors that satisfy the two rows of the view form the 2-dimensional subspace $\operatorname{span}(\mathbf{C}, \mathbf{X})$.

*Proof.* By Lemma 1 the set is $P^{-1}(\operatorname{span}\tilde{\mathbf{x}})$, the preimage of a line through the origin of $\mathbb{R}^3$. The map $P: \mathbb{R}^4 \to \mathbb{R}^3$ has rank 3, so it is onto and its kernel is $\operatorname{span}(\mathbf{C})$. The preimage of a 1-dimensional subspace under an onto map with a 1-dimensional kernel has dimension 2. It contains $\mathbf{C}$ and $\mathbf{X}$, which are independent because $P\mathbf{X} \ne \mathbf{0}$, so it equals $\operatorname{span}(\mathbf{C}, \mathbf{X})$. $\square$

**Proof of part (a).** $\mathbf{X}$ is not a center, so $P_i\mathbf{X} \ne \mathbf{0}$ for every $i$. By Lemma 2 the null space of $A$ is the intersection of the subspaces $\operatorname{span}(\mathbf{C}_i, \mathbf{X})$. It contains $\mathbf{X}$. Let $\mathbf{Y}$ be in the intersection of the first two: $\mathbf{Y} = a\mathbf{C}_1 + b\mathbf{X} = c\mathbf{C}_2 + d\mathbf{X}$. Then $a\mathbf{C}_1 - c\mathbf{C}_2 + (b - d)\mathbf{X} = \mathbf{0}$, and the independence of $\mathbf{C}_1$, $\mathbf{C}_2$, $\mathbf{X}$ gives $a = c = 0$, so $\mathbf{Y} = b\mathbf{X}$. Further views can only make the intersection smaller, and it always contains $\mathbf{X}$. So the null space is $\operatorname{span}(\mathbf{X})$, and $A$, with 4 columns, has rank 3. $\square$

**Proof of part (b).** Line L4 returns a unit vector $\mathbf{Y}$ that minimizes $\|A\mathbf{Y}\|$, the right singular vector of the smallest singular value. By part (a) the smallest singular value is 0 and it is simple, so the minimizers are exactly $\pm\mathbf{X}/\|\mathbf{X}\|$. Both have a nonzero fourth entry, so line L5 does not stop, and line L6 returns $(Y_1, Y_2, Y_3)/Y_4 = (X_1, X_2, X_3)/X_4$. $\square$

**Proof of part (c).** Write $A = [M \mid \mathbf{a}_4]$ with $M$ the first three columns. The inhomogeneous method minimizes $\|M\mathbf{z} + \mathbf{a}_4\|$ over $\mathbf{z} \in \mathbb{R}^3$. If $M\mathbf{z} = \mathbf{0}$ for some $\mathbf{z} \ne \mathbf{0}$, then $(\mathbf{z}, 0)$ is in the null space of $A$, which is impossible by part (a), because every nonzero vector of $\operatorname{span}(\mathbf{X})$ has a nonzero fourth entry. So $M$ has full column rank, $M^{\mathsf T}M$ is invertible, and the minimizer is unique. The vector $\mathbf{z} = (X_1, X_2, X_3)/X_4$ gives $M\mathbf{z} + \mathbf{a}_4 = A\mathbf{X}/X_4 = \mathbf{0}$, so it is the minimizer. $\blacksquare$

**Remark (invariance under a change of the world frame).** Replace the world frame by $\mathbf{X}' = H\mathbf{X}$ with an invertible $4 \times 4$ matrix $H$; the cameras become $P_i' = P_iH^{-1}$ and the matrix becomes $A' = AH^{-1}$. For the inhomogeneous method let $H$ be affine, with last row $(0, 0, 0, 1)$. Then $\mathbf{Y} \mapsto H\mathbf{Y}$ maps the vectors with last entry 1 onto themselves, and $\|A'H(\mathbf{z}, 1)\| = \|A(\mathbf{z}, 1)\|$, so the minimizer moves with the frame: the method is affine invariant, also on noisy data. For the homogeneous method let $H = sQ$ with $Q$ orthogonal and $s \ne 0$. For $\mathbf{Y} = H\mathbf{Z}$ we have $A'\mathbf{Y} = A\mathbf{Z}$ and $\|\mathbf{Y}\| = |s|\,\|\mathbf{Z}\|$, so $\|A'\mathbf{Y}\|/\|\mathbf{Y}\| = \|A\mathbf{Z}\|/(|s|\,\|\mathbf{Z}\|)$, the minimizers correspond, and the method is invariant under such $H$, for example a rotation of the world about its origin. A translation is not of this form, and on noisy data the homogeneous result changes when the world origin moves; the example of the page shows this. On exact data both methods return the true point in every frame, by parts (b) and (c).
