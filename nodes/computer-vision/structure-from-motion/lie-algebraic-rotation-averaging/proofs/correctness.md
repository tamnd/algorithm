---
title: The Lie-algebraic update is a well defined descent step that stops exactly at stationary points, and the tree start is exact on consistent data
proves: [correctness]
status: full
---

We use the notation of the page. The graph is connected, with cameras $1, \dots, N$. For an edge $(i, j)$ the residual is $r_{ij} = \log(R_j^{\mathsf T} R_{ij} R_i)$, and the cost with the squared loss is $F(R) = \sum_{(i,j)} \|r_{ij}\|^2$. The update is $R_k \leftarrow R_k \exp([\omega_k]_\times)$ with $\omega_1 = 0$. Line L5 solves $L \omega = b$, where $L$ is the weighted graph Laplacian with row and column 1 removed, applied to each coordinate of $\omega$, and $b_k = \sum_{(i,k)} w_{ik} r_{ik} - \sum_{(k,j)} w_{kj} r_{kj}$. All angles of the residuals are below $\pi$, so the logarithm is smooth at every residual.

**Claim.** (a) The grounded Laplacian $L$ is positive definite when all weights are positive, so line L5 has exactly one solution. (b) With unit weights, the gradient of $F$ with respect to $\omega_k$ at $\omega = 0$ is $-2 b_k$, and line L5 is the Gauss-Newton step of $F$. (c) If $b \ne 0$, the step $\omega$ of line L5 is a descent direction of $F$, and $\omega = 0$ if and only if $b = 0$, which holds if and only if $R$ is a stationary point of $F$. The same holds for the reweighted cost $\sum w_{ij} \|r_{ij}\|^2$ with the weights fixed. (d) If the edges are exact, $R_{ij} = R_j^{\mathrm{true}} (R_i^{\mathrm{true}})^{\mathsf T}$, then the tree start of line L1 has all residuals equal to 0, and the algorithm returns $R_k = R_k^{\mathrm{true}} (R_1^{\mathrm{true}})^{\mathsf T}$, the true rotations up to the gauge.

**Proof of (a).** For a vector $x \in \mathbb{R}^N$, the weighted Laplacian $\bar L$ satisfies $x^{\mathsf T} \bar L x = \sum_{(i,j)} w_{ij} (x_j - x_i)^2 \ge 0$. The grounded matrix $L$ is $\bar L$ restricted to the vectors with $x_1 = 0$. Let $x_1 = 0$ and $x^{\mathsf T} \bar L x = 0$. Every weight is positive, so $x_i = x_j$ on every edge. The graph is connected, so $x$ is constant, and $x_1 = 0$ gives $x = 0$. So $L$ is positive definite and invertible. $\square$

**Proof of (b).** Fix an edge $(i, j)$ and put $Q = R_j^{\mathsf T} R_{ij} R_i$, so $r_{ij} = \log Q$. After the update, the residual is $\log(\exp(-[\omega_j]_\times) \, Q \, \exp([\omega_i]_\times))$. We use one fact about $SO(3)$: for a rotation $Q$ with angle below $\pi$ and a small rotation vector $u$, $\|\log(Q \exp([u]_\times))\|^2 = \|\log Q\|^2 + 2 \langle \log Q, u \rangle + O(\|u\|^2)$, and $\|\log(\exp([u]_\times) Q)\|^2 = \|\log Q\|^2 + 2 \langle \log Q, u \rangle + O(\|u\|^2)$. To see it, write $\phi = \log Q$. The squared geodesic distance $d(Q, I)^2 = \|\phi\|^2$ has the Riemannian gradient $-2\log(Q^{\mathsf T}) = 2\phi$ at $Q$, in the body frame of the right action and also in the space frame of the left action, because $\phi$ is fixed by $Q$: $Q \phi = \phi$, as $\phi$ is the axis of $Q$. So both directional derivatives along $u$ are $2 \langle \phi, u \rangle$.

Apply this with $u = \omega_i$ on the right and $u = -\omega_j$ on the left. To first order, the residual norm squared is $\|r_{ij}\|^2 + 2 \langle r_{ij}, \omega_i - \omega_j \rangle$. Summing over the edges, the coefficient of $\omega_k$ is $2 \sum_{(k,j)} r_{kj} - 2 \sum_{(i,k)} r_{ik} = -2 b_k$ with unit weights. So $\nabla_{\omega_k} F = -2 b_k$.

The same first order expansion of the residual vector itself is $r_{ij} + J_{ij} (\omega_i - \omega_j)$ with $J_{ij} = I + O(\|r_{ij}\|)$. Gauss-Newton replaces each residual by its linear model. The page uses the model with $J_{ij} = I$, the form of Govindu (2004): $\min_\omega \sum \|r_{ij} + \omega_i - \omega_j\|^2$ with $\omega_1 = 0$. Setting the derivative with respect to $\omega_k$, $k \ne 1$, to zero gives $\sum_{(i,k)} (\omega_k - \omega_i - r_{ik}) + \sum_{(k,j)} (\omega_k - \omega_j + r_{kj}) = 0$, which is row $k$ of $L \omega = b$. So line L5 solves the linear least squares problem of the model, and its right side is exactly $-\frac{1}{2}$ times the true gradient. $\square$

**Proof of (c).** By (a), $\omega = L^{-1} b$. The directional derivative of $F$ along $\omega$ is $\sum_k \langle \nabla_{\omega_k} F, \omega_k \rangle = -2 \, b^{\mathsf T} \omega = -2 \, b^{\mathsf T} L^{-1} b$, where the sum and the products run over the cameras $k \ne 1$ and the three coordinates. The matrix $L^{-1}$ is positive definite, so this value is negative when $b \ne 0$. So $\omega$ is a descent direction. Since $L$ is invertible, $\omega = 0$ exactly when $b = 0$. The gauge fixes $\omega_1 = 0$, and $F$ does not change when all rotations are multiplied on the right by one rotation, so the gradient with respect to $\omega_1$ is minus the sum of the other gradients; hence the full gradient is zero if and only if $b_k = 0$ for all $k \ne 1$. So $b = 0$ is the stationarity condition. With fixed positive weights $w_{ij}$, every step above holds with $w_{ij}$ as a factor in each sum, and $L$ is the weighted Laplacian. $\square$

**Proof of (d).** Line L1 chains the rotations along a spanning tree from $R_1 = I$, setting $R_j = R_{ij} R_i$ for each tree edge from the parent $i$ to the child $j$. By induction on the depth, $R_k = R_k^{\mathrm{true}} (R_1^{\mathrm{true}})^{\mathsf T}$: this holds for the root, and if it holds for $i$, then $R_j = R_j^{\mathrm{true}} (R_i^{\mathrm{true}})^{\mathsf T} R_i^{\mathrm{true}} (R_1^{\mathrm{true}})^{\mathsf T} = R_j^{\mathrm{true}} (R_1^{\mathrm{true}})^{\mathsf T}$. Then for every edge $(i, j)$, tree edge or not, $R_j^{\mathsf T} R_{ij} R_i = R_1^{\mathrm{true}} (R_j^{\mathrm{true}})^{\mathsf T} R_j^{\mathrm{true}} (R_i^{\mathrm{true}})^{\mathsf T} R_i^{\mathrm{true}} (R_1^{\mathrm{true}})^{\mathsf T} = I$, so $r_{ij} = 0$. Then $b = 0$, line L5 gives $\omega = 0$ by (a), and line L7 stops in the first iteration with the start unchanged. Every loss gives a finite positive weight at $r = 0$, with the floor $\delta$ for the $L_1$ weight, so this holds for all three losses. $\blacksquare$
