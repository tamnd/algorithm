---
title: The view graph operations keep both edge directions consistent, find a maximum spanning forest and chain the rotations exactly
proves: [correctness]
status: full
---

We use the notation of the page. The label $(R, t)$ of the direction $i \to j$ means $X_j = R X_i + t$ for the coordinates $X_i$ and $X_j$ of one point in the frames of cameras $i$ and $j$. The edge is exact if $R_{ij} = R_j R_i^{\mathsf T}$ for the true absolute rotations.

**Claim.** (a) The label stored by line L2 is the inverse motion of the label stored by line L1. (b) Lines L3 to L7 return a spanning forest of largest total weight. (c) Lines L8 to L13 return rotations with $R_j R_i^{\mathsf T} = R_{ij}$ for every tree edge $(i, j)$ in the component of the root, and if all tree edges are exact, $R_j = R_j^{\mathrm{true}} (R_{\mathrm{root}}^{\mathrm{true}})^{\mathsf T}$. (d) Line L14 returns $0$ for a triangle of exact edges.

**Proof of (a).** From $X_j = R X_i + t$ and $R^{\mathsf T} R = I$ we get $X_i = R^{\mathsf T} X_j - R^{\mathsf T} t$. So the motion from frame $j$ to frame $i$ is $(R^{\mathsf T}, -R^{\mathsf T} t)$, which is the label of line L2. The rotation $R^{\mathsf T}$ is in $SO(3)$ and the weight is the same, so both directions describe the same pair. $\square$

**Proof of (b).** Lines L3 to L7 are Kruskal's method run on the edges in the order of decreasing weight. By the invariant of union-find, $\mathrm{FIND}(i) = \mathrm{FIND}(j)$ holds exactly when $i$ and $j$ are joined by edges already in $T$, so an edge is added if and only if it closes no cycle with $T$. Hence $T$ stays a forest, and at the end every edge of $G$ either is in $T$ or closes a cycle with $T$, so $T$ spans each component of $G$.

For optimality, we show by induction that after each step $T$ is contained in some maximum weight spanning forest $T^*$. This holds at the start with $T$ empty. Let line L6 add the edge $e = (i, j)$, and let $T \subseteq T^*$ before the step. If $e \in T^*$, we are done. Otherwise $T^* \cup \{e\}$ holds a cycle through $e$, since $i$ and $j$ are in one component of $G$ and so of $T^*$. Let $S$ be the vertex set of the tree of $T$ that holds $i$. The cycle leaves $S$ through $e$, so it leaves $S$ through a second edge $f \in T^*$ with exactly one end in $S$. The edge $f$ is not in $T$, because no edge of $T$ leaves $S$, and $f$ closes no cycle with $T$, because its ends are in different trees of $T$. So $f$ was not yet processed, and the order gives $w(f) \le w(e)$. Then $T^{**} = T^* - f + e$ is again a spanning forest, since removing $f$ breaks the cycle, and $w(T^{**}) \ge w(T^*)$, so $T^{**}$ is a maximum weight spanning forest that contains $T \cup \{e\}$. At the end, $T$ is a spanning forest contained in a maximum one with the same number of edges, so it is that forest. $\square$

**Proof of (c).** Breadth-first search from the root reaches every vertex of the component of the root in the tree, and line L12 sets $R_j$ once, when $j$ is first reached from its parent $i$, as $R_j = R_{ij} R_i$. Then $R_j R_i^{\mathsf T} = R_{ij} R_i R_i^{\mathsf T} = R_{ij}$. Each tree edge joins a vertex and its parent in the search, so this holds for every tree edge, in the direction from the parent; for the other direction it holds by (a), since $R_{ji} = R_{ij}^{\mathsf T}$. Now let all tree edges be exact. We show $R_j = R_j^{\mathrm{true}} (R_{\mathrm{root}}^{\mathrm{true}})^{\mathsf T}$ by induction on the depth of $j$ in the tree. For the root both sides are $I$. For a vertex $j$ with parent $i$, $R_j = R_{ij} R_i = R_j^{\mathrm{true}} (R_i^{\mathrm{true}})^{\mathsf T} R_i^{\mathrm{true}} (R_{\mathrm{root}}^{\mathrm{true}})^{\mathsf T} = R_j^{\mathrm{true}} (R_{\mathrm{root}}^{\mathrm{true}})^{\mathsf T}$. The factor $(R_{\mathrm{root}}^{\mathrm{true}})^{\mathsf T}$ is the gauge: right multiplication of all rotations by one fixed rotation changes no $R_j R_i^{\mathsf T}$. $\square$

**Proof of (d).** For exact edges, $R_{ki} R_{jk} R_{ij} = R_i R_k^{\mathsf T} R_k R_j^{\mathsf T} R_j R_i^{\mathsf T} = I$. The trace of $I$ is 3, and $\arccos((3 - 1)/2) = \arccos 1 = 0$. The rotation angle $\theta$ of any rotation satisfies $\operatorname{trace} R = 1 + 2 \cos \theta$, so line L14 returns the angle of the loop rotation in $[0, \pi]$, and it is $0$ only for the identity. The converse of (d) is false: a wrong edge in the triangle can be cancelled by an equal and opposite error in another edge of the same triangle. $\blacksquare$
