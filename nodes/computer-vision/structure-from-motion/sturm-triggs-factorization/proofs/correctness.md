---
title: The chained depths are the true projective depths up to row and column scales, so the factorization gives a projective reconstruction of exact data
proves: [correctness]
status: full
---

We use the notation of the page and exact arithmetic. The true cameras are $P_i$, $3 \times 4$ of rank 3 with centers $C_i$ ($P_i C_i = 0$, $C_i \ne 0$), and the true points are $X_p$. In the normalized coordinates of line L1, camera $i$ is $\tilde P_i = T_i P_i$ and the image points are $x_{ip} = T_i u_{ip}$ with last entry 1. The last row of $T_i$ is $(0, 0, 1)$, so the true depths $\lambda_{ip}^* \ne 0$ with $\lambda_{ip}^* x_{ip} = \tilde P_i X_p$ are the same in both coordinate systems. We assume:

- (G1) For each $i \ge 1$, the centers $C_{i-1}$ and $C_i$ differ, and the conditioned eight-point system of the pair has a null space of dimension 1.
- (G2) No image point $x_{ip}$, $i \ge 1$, is the epipole $e_i$ of line L3, so $e_i \times x_{ip} \ne 0$.
- (G3) The stacked cameras $P$ ($3N \times 4$) and the points $X$ ($4 \times n$) both have rank 4.

**Claim.** (a) For each $i \ge 1$ there is a fundamental matrix $F_i^*$ and an epipole $e_i^*$ with $e_i^* \times (\lambda_{ip}^* x_{ip}) = F_i^* (\lambda_{i-1,p}^* x_{i-1,p})$ for all $p$. (b) Line L4 gives $\lambda_{ip} = \alpha_i \beta_p \lambda_{ip}^*$ with $\alpha_i \ne 0$ and $\beta_p = 1 / \lambda_{0p}^*$. (c) The balanced matrix of line L6 has rank 4, and lines L7 and L8 return $P_i^{\mathrm{out}} = c_i P_i H$ and $X_p^{\mathrm{out}} = d_p H^{-1} X_p$ for one invertible $4 \times 4$ matrix $H$ and nonzero scalars $c_i$, $d_p$. (d) The output reproduces every image point exactly.

**Proof of (a).** Fix $i \ge 1$ and write $A = \tilde P_{i-1}$, $B = \tilde P_i$, $C = C_{i-1}$. Since $A$ has rank 3, $A^+ = A^{\mathsf T} (A A^{\mathsf T})^{-1}$ satisfies $A A^+ = I$. For any point, $A (X_p - A^+ A X_p) = 0$, so $X_p - A^+ A X_p = \mu_p C$ for some scalar $\mu_p$, because the null space of $A$ is spanned by $C$. Hence $X_p = A^+ (\lambda_{i-1,p}^* x_{i-1,p}) + \mu_p C$. Apply $B$ and put $e_i^* = B C$, which is nonzero because $C$ is not the center of $B$ by (G1):
$$\lambda_{ip}^* x_{ip} = B X_p = B A^+ (\lambda_{i-1,p}^* x_{i-1,p}) + \mu_p e_i^*.$$
The cross product with $e_i^*$ removes the last term, so $e_i^* \times (\lambda_{ip}^* x_{ip}) = F_i^* (\lambda_{i-1,p}^* x_{i-1,p})$ with $F_i^* = [e_i^*]_\times B A^+$. This $F_i^*$ is the fundamental matrix of the pair in the convention $x_i^{\mathsf T} F_i^* x_{i-1} = 0$ (Hartley and Zisserman, Chapter 9): indeed, $x_{ip}^{\mathsf T} (e_i^* \times x_{ip}) = 0$ gives $x_{ip}^{\mathsf T} F_i^* x_{i-1,p} = 0$ for every point. It has rank 2 for distinct centers, and $(F_i^*)^{\mathsf T} e_i^* = (B A^+)^{\mathsf T} [e_i^*]_\times^{\mathsf T} e_i^* = -(B A^+)^{\mathsf T} (e_i^* \times e_i^*) = 0$. $\square$

**Proof of (b).** By (G1), every exact fundamental matrix of the pair is in the null space of the eight-point system, which has dimension 1, so line L3 finds $F_i = \kappa_i F_i^*$ with $\kappa_i \ne 0$. The projection to rank 2 does not change it, since $F_i^*$ already has rank 2. The left null space of a rank 2 matrix has dimension 1, so $e_i = \nu_i e_i^*$ with $\nu_i \ne 0$. By (a), $F_i^* x_{i-1,p} = (\lambda_{ip}^* / \lambda_{i-1,p}^*) \, e_i^* \times x_{ip}$. So
$$\frac{(e_i \times x_{ip}) \cdot (F_i x_{i-1,p})}{\|e_i \times x_{ip}\|^2} = \frac{\nu_i \kappa_i}{\nu_i^2} \cdot \frac{\lambda_{ip}^*}{\lambda_{i-1,p}^*} \cdot \frac{(e_i^* \times x_{ip}) \cdot (e_i^* \times x_{ip})}{\|e_i^* \times x_{ip}\|^2} = \frac{\kappa_i}{\nu_i} \cdot \frac{\lambda_{ip}^*}{\lambda_{i-1,p}^*},$$
where the denominator is nonzero by (G2). Line L4 multiplies this by $\lambda_{i-1,p}$. With $\lambda_{0p} = 1 = \beta_p \lambda_{0p}^*$ and $\alpha_0 = 1$, induction on $i$ gives $\lambda_{ip} = \alpha_i \beta_p \lambda_{ip}^*$ with $\alpha_i = \alpha_{i-1} \kappa_i / \nu_i \ne 0$. $\square$

**Proof of (c).** By (b), the block $(i, p)$ of $W$ is $\alpha_i \beta_p \lambda_{ip}^* x_{ip} = \alpha_i \beta_p \tilde P_i X_p$. So $W = D_\alpha \tilde P X D_\beta$, where $\tilde P$ stacks the $\tilde P_i$, $D_\alpha$ repeats each $\alpha_i$ three times on its diagonal and $D_\beta = \operatorname{diag}(\beta_p)$. Each balancing step divides a column or a triplet of rows by its norm, which is positive because the column or the triplet is nonzero; so the balanced matrix is $W' = E_1 W E_2$ with positive diagonal $E_1$, constant on each triplet, and $E_2$. Then $W' = \hat P_0 \hat X_0$ with $\hat P_0 = E_1 D_\alpha \tilde P$ and $\hat X_0 = X D_\beta E_2$. The matrix $\tilde P$ has rank 4 because $T_i$ is invertible and (G3) holds, and the diagonal factors are invertible, so both factors have rank 4 and $W'$ has rank exactly 4. As in the proof of the [Tomasi-Kanade factorization](/tomasi-kanade-factorization/), the SVD gives $W' = \hat P \hat X$ exactly with $\hat P = U_4 \Sigma_4$, the column spaces of $\hat P$ and $\hat P_0$ agree, so $\hat P_0 = \hat P G$ for an invertible $4 \times 4$ matrix $G$, and then $\hat X = G \hat X_0$. Put $H = G^{-1}$. The block of camera $i$ in $\hat P = \hat P_0 H$ is $\epsilon_i \alpha_i T_i P_i H$, where $\epsilon_i$ is the entry of $E_1$ for the triplet $i$, and line L8 gives $P_i^{\mathrm{out}} = T_i^{-1} \epsilon_i \alpha_i T_i P_i H = c_i P_i H$ with $c_i = \epsilon_i \alpha_i \ne 0$. Column $p$ of $\hat X = H^{-1} \hat X_0$ is $d_p H^{-1} X_p$ with $d_p = \beta_p \cdot (E_2)_{pp} \ne 0$. $\square$

**Proof of (d).** By (c), $P_i^{\mathrm{out}} X_p^{\mathrm{out}} = c_i d_p P_i H H^{-1} X_p = c_i d_p \lambda_{ip}^* u_{ip}$, where $u_{ip} = (u, v, 1)$ is the pixel in homogeneous form and $\lambda_{ip}^* u_{ip} = P_i X_p$. The factor $c_i d_p \lambda_{ip}^*$ is nonzero, so the dehomogenized projection is exactly the observed pixel. $\blacksquare$
