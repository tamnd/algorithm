---
title: On exact images the true state is a global minimizer and a fixed point of every step, the Schur steps are exact, and the window energy never goes up
proves: [correctness]
status: full
---

**Setting.** A state is the list of keyframe poses $T_i$, affine terms $(a_i, b_i)$ and inverse depths $d_p$. The residual of a pattern pixel $q$ of a point $p$ hosted in keyframe $i$ and seen in target $j$ is $r_q = (I_j[q'] - b_j) - e^{a_j - a_i}(I_i[q] - b_i)$ with $q' = \Pi(R_{ji} \Pi^{-1}(q, d_p) + t_{ji})$. The tracking energy (line L3) and the window energy (lines L8 and L9) are sums of $w_q \rho_k(r_q)$, with $w_q = c^2/(c^2 + |\nabla I_i(q)|^2) > 0$ and the Huber function $\rho_k \ge 0$, $\rho_k(r) = 0$ only for $r = 0$. After a marginalization (line L11), a prior $P(x) = -\hat b^{\mathsf T} x + \frac{1}{2} x^{\mathsf T} \hat H x$ is added, where $x$ is the change of the remaining keyframes from their values at that time.

**Assumptions.** (B1) Exact images: there is a true state such that every image is $I_j[u] = e^{a_j} L(X(u)) + b_j$, where $X(u)$ is the scene point seen at pixel $u$ in frame $j$ and $L$ is its radiance. (B2) Each point's pattern lies on a plane parallel to the image plane of its host, so the true inverse depth of all 8 pattern pixels is $d_p$. (B3) Every sample used is inside its image. (B4) At line L11 the state is the true state. The first keyframe and one inverse depth are held at their true values, as the algorithm does.

**Lemma 1 (zero residuals).** At the true state every residual is zero. By (B2), $\Pi^{-1}(q, d_p)$ is the true host camera point of $q$, and $q'$ is the pixel where the target sees the same scene point $X$. By (B1), $I_j[q'] - b_j = e^{a_j} L(X)$ and $I_i[q] - b_i = e^{a_i} L(X)$, so $r_q = e^{a_j} L(X) - e^{a_j - a_i} e^{a_i} L(X) = 0$.

**Lemma 2 (global minimizer without a prior).** Every term $w_q \rho_k(r_q)$ is $\ge 0$, and by Lemma 1 every term is 0 at the true state. So the true state attains the smallest possible value 0 of the tracking energy and of the window energy. This is a statement about the energy, not about uniqueness: a state with the same images (for example the same scene under another similarity, if the gauge were not fixed) has the same value.

**Lemma 3 (exact Schur step).** Let $H$ be symmetric with an invertible block $H_{\beta\beta}$, and split $H x = b$ into $(x_\alpha, x_\beta)$. If $x_\alpha$ solves $(H_{\alpha\alpha} - H_{\alpha\beta} H_{\beta\beta}^{-1} H_{\beta\alpha}) x_\alpha = b_\alpha - H_{\alpha\beta} H_{\beta\beta}^{-1} b_\beta$ and $x_\beta = H_{\beta\beta}^{-1}(b_\beta - H_{\beta\alpha} x_\alpha)$, then $H x = b$. The second block row holds by the definition of $x_\beta$. The first block row is $H_{\alpha\alpha} x_\alpha + H_{\alpha\beta} H_{\beta\beta}^{-1}(b_\beta - H_{\beta\alpha} x_\alpha) = b_\alpha$, which is the reduced equation after the terms are moved. So lines L9 and the back-substitution give the exact Gauss-Newton step. In the window every residual depends on one inverse depth, so $H_{\beta\beta}$ is diagonal and its inverse is the list of reciprocals, which is what the code uses.

**Lemma 4 (marginal of a quadratic).** Let $Q(x_\alpha, x_\beta) = -b^{\mathsf T} x + \frac{1}{2} x^{\mathsf T} H x$ with $H_{\beta\beta}$ positive definite. For fixed $x_\alpha$, $Q$ is a strictly convex quadratic in $x_\beta$, minimized at $x_\beta = H_{\beta\beta}^{-1}(b_\beta - H_{\beta\alpha} x_\alpha)$. Putting this in gives $\min_{x_\beta} Q = -\hat b^{\mathsf T} x_\alpha + \frac{1}{2} x_\alpha^{\mathsf T} \hat H x_\alpha + C$ with $\hat H = H_{\alpha\alpha} - H_{\alpha\beta} H_{\beta\beta}^{-1} H_{\beta\alpha}$, $\hat b = b_\alpha - H_{\alpha\beta} H_{\beta\beta}^{-1} b_\beta$ and a constant $C = -\frac{1}{2} b_\beta^{\mathsf T} H_{\beta\beta}^{-1} b_\beta$. So the prior of line L11 is, up to a constant, the Gauss-Newton model of the energy of the removed residuals minimized over the removed variables. If $H$ is positive semidefinite, so is $\hat H$, because $x_\alpha^{\mathsf T} \hat H x_\alpha = \min_{x_\beta} x^{\mathsf T} H x \ge 0$ (the case $b = 0$ of the same formula, times 2).

**Lemma 5 (the truth stays a minimizer after marginalization).** We use induction over the marginalizations. When line L11 builds its system, the state is the true state by (B4). The residual part of the right-hand side is $-J^{\mathsf T} W r = 0$, because $r = 0$ by Lemma 1. An older prior adds $\hat b_{old} - \hat H_{old} x$, where $x = 0$ because the older prior was also made at the true state, and $\hat b_{old} = 0$ by the induction hypothesis. So $b = 0$, and the new prior has $\hat b = b_\alpha - H_{\alpha\beta} H_{\beta\beta}^{-1} b_\beta = 0$. With $\hat b = 0$ and $\hat H \succeq 0$ (Lemma 4, since a Gauss-Newton matrix $J^{\mathsf T} W J$ with $W \ge 0$ and an older prior matrix are both positive semidefinite), the prior is $\ge 0$ and equals 0 at $x = 0$, the true state. The remaining residuals are zero at the true state by Lemma 1. So the true state is a global minimizer, with value 0, of the window energy plus the prior, after any number of marginalizations.

**Lemma 6 (fixed point).** At the true state, the right-hand side of every Gauss-Newton system is $b = -J^{\mathsf T} W r + (\hat b - \hat H x) = 0$, because $r = 0$ by Lemma 1, $\hat b = 0$ by Lemma 5 and $x = 0$. The step is therefore 0 (or the solve fails and the loop stops). A zero step gives the same energy, which is not smaller, so lines L3 and L9 stop and return the true state unchanged.

**Lemma 7 (monotone energy).** Lines L3 and L9 compute the energy after each candidate step and keep the step only if the energy is strictly smaller; otherwise they restore the previous state and stop. So the sequence of energies that the code keeps is strictly decreasing, and the returned energy is at most the starting energy. This holds for any data, not only under (B1) to (B4).

**Conclusion.** On exact data, the true state is a global minimizer of every energy the algorithm uses (Lemmas 2 and 5), it is a fixed point of every step (Lemma 6), each Gauss-Newton step is solved exactly by the Schur complement (Lemma 3), and the prior is the exact marginal of the Gauss-Newton model (Lemma 4). On any data, the kept energies never go up (Lemma 7). $\blacksquare$

**What is not proved.** Convergence to the true state from a start far from it. Gauss-Newton on the photometric error is a local method: the image is only close to linear within a pixel or two, and the energy has other minima. The pyramid, the constant motion guess and the frame rate are there to keep the start in the region where it works; none of them gives a guarantee. On real images (B1) and (B2) hold only approximately, the brightness model is an approximation, and the prior is a linearization made at a state that is not the truth, so the estimates are biased and drift. The keyframe and marginalization rules are heuristics and are not part of this proof.
