---
title: Without noise, and when the robust steps pick a hypothesis from correct matches, the monocular scheme returns the true poses up to one scale
proves: [correctness]
status: full
---

**Setting.** The true poses are $(R_k, t_k)$, with $(R_0, t_0) = (I, 0)$ and $t_2 \ne 0$. Every correct observation is exact: $x = \pi(R_k X + t_k)$ with $\pi(a, b, c) = (a/c, b/c)$ and $R_k X + t_k$ in front of the camera. Let $s = 1/|t_2|$. The scaled scene has poses $(R_k, s t_k)$ and points $s X$. It gives the same observations, because $\pi(R_k (sX) + s t_k) = \pi(s(R_k X + t_k)) = \pi(R_k X + t_k)$ for $s > 0$. We show that every pose and every map point that the algorithm stores is the one of the scaled scene.

**Assumptions.** (A1) At lines L2 and L6 the hypothesis that preemptive scoring returns is a solution of a minimal sample of correct observations that equals the true model. (A2) No wrong observation is within $\tau$ of the position that the true model gives, so the inlier sets and the checks of line L10 contain only correct observations. (A3) General position: the five and three points of the samples are not degenerate for their solvers, and no point lies on the line through two camera centers that are used to triangulate it. RANSAC does not guarantee (A1); it holds with a probability that grows with the number of samples, as described by [ransac-iteration-bound](/ransac-iteration-bound/).

**Lemma 1 (line L2).** The true essential matrix $E = [t_2]_\times R_2$ satisfies $x_2^{\mathsf T} E x_1 = 0$ on every correct pair of frames 0 and 2, written as homogeneous 3-vectors, because $x_2 \propto R_2 x_1 \lambda + t_2$ for the depth $\lambda$ of the point in frame 0, and $[t_2]_\times$ kills $t_2$ and makes $[t_2]_\times R_2 x_1$ orthogonal to $R_2 x_1$. The five-point method returns every real solution of the five linear equations and the ten cubic constraints that every essential matrix satisfies, and under (A3) the true $E$, scaled to norm 1, is among them. By (A1) line L2 returns it, up to a nonzero factor.

**Lemma 2 (line L3).** Let $E = U \operatorname{diag}(\sigma, \sigma, 0) V^{\mathsf T}$ with $\det U = \det V = 1$. The rotations $R$ with $[t]_\times R \propto E$ for a unit $t$ are exactly $U W V^{\mathsf T}$ and $U W^{\mathsf T} V^{\mathsf T}$, and $t = \pm u_3$, the third column of $U$ (Hartley and Zisserman, second edition, Results 9.18 and 9.19). So the four candidates contain $(R_2, t_2/|t_2|) = (R_2, s t_2)$. For a point $X$ in front of both true cameras, of the four candidates only the true one triangulates $X$ in front of both cameras: changing the sign of $t$ puts the point behind both cameras, and the other rotation (the "twisted pair") puts it behind exactly one of them (the same book, Section 9.6.3). By (A2), every inlier is a correct observation of a point in front of both cameras, so the true candidate gets every vote and each other candidate gets none, and line L3 selects $(R_2, s t_2)$.

**Lemma 3 (lines L4 and L10).** Let two poses $(R_a, s t_a)$ and $(R_b, s t_b)$ be correct for the scaled scene, and let $x_a$, $x_b$ be correct observations of $X$. Then $sX$ makes all four rows of the linear triangulation zero: $x P^3 - P^1$ applied to $(sX, 1)$ is $x \, c - a$, where $(a, b, c)$ are the camera coordinates of $sX$, and $x = a/c$. Under (A3) the four rows have rank 3, so the null vector is $(sX, 1)$ up to a factor, and the returned point is $sX$. Its error is 0 and it is in front, so it passes the check. A point from a wrong observation is rejected by (A2). So every stored point is the scaled true point.

**Lemma 4 (line L6, P3P).** Let $f_i$ be the unit bearings of three correct observations in frame $k$ and $X_i$ the stored points, which by Lemma 3 are scaled true points. The true distances $d_i = |R_k X_i + s t_k|$ satisfy the three law-of-cosines equations $d_j^2 + d_l^2 - 2 d_j d_l \cos\theta_{jl} = |X_j - X_l|^2$. Write $d_2 = u d_1$ and $d_3 = v d_1$, and $a^2, b^2, c^2$ for the squared distances of the pairs (2, 3), (1, 3) and (1, 2). Then $d_1^2 = b^2 / q(v)$ with $q(v) = 1 + v^2 - 2 v \cos\beta$, and the other two equations become

$$
b^2 u^2 - 2 b^2 \cos\gamma\, u + b^2 - c^2 q(v) = 0, \qquad b^2 u^2 - 2 b^2 \cos\alpha\, v u + b^2 v^2 - a^2 q(v) = 0 .
$$

Their difference is linear in $u$ and gives $u D(v) = N(v)$ with $D = 2 b^2 (\cos\gamma - v \cos\alpha)$ and $N = b^2 - b^2 v^2 + (a^2 - c^2) q(v)$. Multiplying the first equation by $D^2$ and putting $u D = N$ gives the quartic $b^2 N^2 - 2 b^2 \cos\gamma\, N D + (b^2 - c^2 q) D^2 = 0$. The true $v$ is a positive root of it, and under (A3) $D(v) \ne 0$, so the code recovers the true $u$, $d_1$, and the true camera points $d_i f_i$. The code then fits $(R, t)$ to three pairs $X_i \mapsto d_i f_i$ by the SVD method with the sign correction that forces $\det R = 1$. The three points are not collinear by (A3), so the rigid motion between them is unique and the SVD method returns it with zero residual. Hence the true $(R_k, s t_k)$ is among the hypotheses, and by (A1) line L6 returns it.

**Lemma 5 (line L7).** At the true pose every residual of the inliers is 0, by (A2). The Gauss-Newton right-hand side $-J^{\mathsf T} r$ is then 0, and the step is 0 (or the solve fails). The candidate cost equals the current cost 0, which is not smaller, so the loop stops and returns the true pose unchanged.

**Induction.** Before the loop, Lemmas 1 to 3 give pose 0, pose 2 and the map for the scaled scene. Assume that all poses and map points stored before frame $k$ are those of the scaled scene. Lemma 4 and Lemma 5 give pose $k$, and Lemma 3 keeps the map correct after lines L8 to L10. Line L11 changes only which frames line L9 may use; every allowed frame already has a correct pose. So after the loop every pose is $(R_k, s t_k)$. This is the true trajectory up to the single scale $s = 1/|t_2|$, which cannot be recovered from one camera because the scaled scene gives the same images. $\blacksquare$

**Stereo.** For the rectified rig, the right camera of frame $k - 1$ has the known pose $(I, (-b, 0, 0))$ relative to the left one. Lemma 3 with these two poses gives the true points in the left camera of frame $k - 1$ with their metric size. Lemmas 4 and 5 give the true motion between frames $k - 1$ and $k$, and composing the motions gives the true metric poses.

**What is not proved.** With noise, the outputs are estimates; the errors add up along the path and the monocular scale drifts. Assumptions (A1) and (A2) are about luck and data, not about the algorithm; a test with a fixed seed shows that they hold for that seed.
