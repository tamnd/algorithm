---
title: Sparse bundle adjustment computes the exact Levenberg-Marquardt step, so it keeps all the properties of Levenberg-Marquardt
proves: [correctness]
status: full
---

We use the notation of the page. There are $N$ cameras, of which the free ones carry 6 parameters each, and $n$ points with 3 parameters each. The observation $(i, j)$ has the residual $r_{ij} = \pi(K X_c) - x_{ij}$ with $X_c = R_i X_j + t_i$, and the Jacobian blocks $A_{ij}$ ($2 \times 6$) and $B_{ij}$ ($2 \times 3$). The camera update is $R_i \leftarrow \exp([\omega_i]_\times) R_i$, $t_i \leftarrow t_i + \delta t_i$, and the point update is $X_j \leftarrow X_j + \delta X_j$. We write $x \oplus \delta$ for this update and $\phi_x(\delta) = r(x \oplus \delta)$.

**Claim.** (a) $A_{ij}$ and $B_{ij}$ of line L1 are the Jacobians of $\phi_x$ at $\delta = 0$. (b) For $\mu > 0$, $S$ of line L6 is symmetric positive definite, and lines L6 to L8 return the unique solution $\delta$ of $(J^{\mathsf T} J + \mu I) \delta = -J^{\mathsf T} r$, where $J$ is the full Jacobian of $\phi_x$ at $0$. (c) So each step is the Levenberg-Marquardt step for $\phi_x$, and all properties proved on the Levenberg-Marquardt page hold: the predicted reduction is positive, accepted steps lower $F$ strictly, and a non-stationary point is left after finitely many rejections.

**Proof of (a).** Write $X_c = (x, y, z)$. The projection is $u = (f_x x + s y)/z + c_x$, $v = f_y y / z + c_y$, so
$$\frac{\partial (u, v)}{\partial X_c} = \begin{pmatrix} f_x / z & s / z & -(f_x x + s y)/z^2 \\ 0 & f_y / z & -f_y y / z^2 \end{pmatrix} = D.$$
For the rotation, $\exp([\omega]_\times) = I + [\omega]_\times + O(\|\omega\|^2)$, so $X_c(\omega) = R X + t + [\omega]_\times R X + O(\|\omega\|^2) = X_c + \omega \times (R X) + \dots = X_c - [R X]_\times \omega + \dots$. Hence $\partial X_c / \partial \omega = -[R X]_\times$ at $\omega = 0$. Also $\partial X_c / \partial \delta t = I$ and $\partial X_c / \partial \delta X = R$. By the chain rule, $A_{ij} = D \, (-[R_i X_j]_\times \;\; I)$ and $B_{ij} = D R_i$, which is what the code computes. The residual $r_{ij}$ does not depend on the parameters of other cameras or points, so these are the only nonzero blocks of the row pair $(i, j)$ of $J$. A fixed camera has no columns. $\square$

**The structure of $J^{\mathsf T} J$.** Order the parameters as cameras first, then points. By (a),
$$J^{\mathsf T} J = \begin{pmatrix} U & W \\ W^{\mathsf T} & V \end{pmatrix}, \quad U = \operatorname{diag}(U_i),\; U_i = \sum_j A_{ij}^{\mathsf T} A_{ij}, \quad V = \operatorname{diag}(V_j),\; V_j = \sum_i B_{ij}^{\mathsf T} B_{ij},$$
and $W$ has the block $W_{ij} = A_{ij}^{\mathsf T} B_{ij}$ when camera $i$ sees point $j$ and zero otherwise. The gradient is $g = (g_a, g_b)$ with $g_{a,i} = \sum_j A_{ij}^{\mathsf T} r_{ij}$ and $g_{b,j} = \sum_i B_{ij}^{\mathsf T} r_{ij}$. $U$ is block diagonal because a residual involves only one camera, and $V$ because it involves only one point.

**Proof of (b).** Let $M = J^{\mathsf T} J + \mu I$. For $v \ne 0$, $v^{\mathsf T} M v = \|J v\|^2 + \mu \|v\|^2 > 0$, so $M$ is positive definite. Its diagonal block $V^* = V + \mu I$ is then positive definite, and so is each $3 \times 3$ block $V_j^*$, which line L6 inverts. The Schur complement $S = U^* - W V^{*-1} W^{\mathsf T}$, with $U^* = U + \mu I$, is symmetric. For $a \ne 0$, put $b = -V^{*-1} W^{\mathsf T} a$. Then
$$\begin{pmatrix} a \\ b \end{pmatrix}^{\mathsf T} M \begin{pmatrix} a \\ b \end{pmatrix} = a^{\mathsf T} U^* a + 2 a^{\mathsf T} W b + b^{\mathsf T} V^* b = a^{\mathsf T} U^* a - a^{\mathsf T} W V^{*-1} W^{\mathsf T} a = a^{\mathsf T} S a,$$
and the left side is positive, so $S$ is positive definite and its Cholesky factorization in line L7 exists.

Now the system $M \delta = -g$ reads $U^* \delta_a + W \delta_b = -g_a$ and $W^{\mathsf T} \delta_a + V^* \delta_b = -g_b$. The second equation gives $\delta_b = -V^{*-1}(g_b + W^{\mathsf T} \delta_a)$, which is line L8, block by block, since $V^*$ is block diagonal: $\delta X_j = -V_j^{*-1} (g_{b,j} + \sum_i W_{ij}^{\mathsf T} \delta a_i)$. Putting it into the first equation gives $(U^* - W V^{*-1} W^{\mathsf T}) \delta_a = -g_a + W V^{*-1} g_b$, which is the system of lines L6 and L7. Its block $(i, k)$ is $\delta_{ik} U_i^* - \sum_j W_{ij} V_j^{*-1} W_{kj}^{\mathsf T}$, with the sum over the points seen by both cameras, and its right side at camera $i$ is $-g_{a,i} + \sum_j W_{ij} V_j^{*-1} g_{b,j}$. These are the sums the code accumulates point by point. Conversely, any solution of the reduced system together with line L8 solves $M \delta = -g$, and that solution is unique because $M$ is nonsingular. $\square$

**Proof of (c).** By (a) and (b), at each step the code computes the exact Levenberg-Marquardt step with $D = I$ for the residual function $\phi_x$, whose value at $0$ is $r(x)$ and whose Jacobian at $0$ is $J$. Line L10 compares $F(x \oplus \delta) = \tfrac12 \|\phi_x(\delta)\|^2$ with the model $\tfrac12 \|r + J \delta\|^2$ and uses the predicted reduction $\tfrac12 \delta^{\mathsf T} (\mu \delta - g)$, which is the formula of the Levenberg-Marquardt page. The proofs there use only these facts at a single point, so they apply unchanged: the predicted reduction is positive when $g \ne 0$, an accepted step lowers $F$ strictly, and $\rho \to 1$ as $\mu \to \infty$ because $\phi_x$ is differentiable at $0$. $\square$

**The gauge.** With camera $0$ fixed, the cost is still unchanged by the scaling $X_j \to s X_j$, $t_i \to s t_i$, so $J$ has a null vector and $J^{\mathsf T} J$ is singular. This does not affect (b), which needs only $\mu > 0$. In floating point, a very small $\mu$ can make $S$ numerically indefinite; the code then treats the step as rejected and raises $\mu$, which is a safe choice by the argument of (c).
