---
title: The prediction filter is the unique least-squares predictor, Levinson recursion solves its Toeplitz equations, the spiking filter is minimum phase, and for an autoregressive wavelet under white reflectivity the output is the reflectivity convolved with the first alpha wavelet samples
proves: [correctness]
status: full
---

**Setting.** A trace $d_0, \ldots, d_{N-1}$ is real and not all zero; $d_t = 0$ outside this range. Its autocorrelation is $r_k = \sum_t d_t d_{t+k}$, so $r_{-k} = r_k$. The filter has $p$ taps $a_0, \ldots, a_{p-1}$ and the gap is $\alpha \ge 1$. The prediction of $d_{t+\alpha}$ is $\hat d_{t+\alpha} = \sum_{j=0}^{p-1} a_j d_{t-j}$, and the prediction error filter (PEF) is $f = (1, 0, \ldots, 0, -a_0, \ldots, -a_{p-1})$ with $\alpha - 1$ zeros, so that $e_{t+\alpha} = (f * d)_{t+\alpha} = d_{t+\alpha} - \hat d_{t+\alpha}$. $R$ is the $p \times p$ Toeplitz matrix $R_{ij} = r_{|i-j|}$ and $g_i = r_{\alpha+i}$. We write $z$ for the unit delay and $A(z) = \sum_j c_j z^j$ for the $z$-transform of a filter $c$.

**Claim 1 (normal equations).** The error energy $E(a) = \sum_{t} (d_{t+\alpha} - \hat d_{t+\alpha})^2$, summed over all $t$ with the zero extension, is minimized by exactly one $a$, the solution of $R a = g$. With prewhitening $\varepsilon \ge 0$, line L2 replaces $r_0$ by $(1 + \varepsilon) r_0$; the solution then minimizes $E(a) + \varepsilon r_0 \|a\|^2$.

*Proof.* Expand $E(a) = \sum_t d_{t+\alpha}^2 - 2\sum_j a_j \sum_t d_{t+\alpha} d_{t-j} + \sum_{i,j} a_i a_j \sum_t d_{t-i} d_{t-j}$. With the zero extension, $\sum_t d_{t-i} d_{t-j} = r_{|i-j|}$ and $\sum_t d_{t+\alpha} d_{t-j} = r_{\alpha+j}$, so $E(a) = r_0 - 2 a^T g + a^T R a$. $R$ is the Gram matrix of the shifted copies $(d_{t-j})_t$, $j = 0, \ldots, p - 1$. These copies are linearly independent: in $\sum_j c_j d_{t-j}$ with $c \ne 0$, let $j^\ast$ be the largest index with $c_{j^\ast} \ne 0$ and $t^\ast$ the last index with $d_{t^\ast} \ne 0$; the term at time $t^\ast + j^\ast$ is $c_{j^\ast} d_{t^\ast} \ne 0$. So $R$ is positive definite, $E$ is strictly convex, and its gradient $2(R a - g)$ is zero at exactly one point. With prewhitening the matrix is $R + \varepsilon r_0 I$, the Hessian of $E(a) + \varepsilon r_0\|a\|^2$, which is also positive definite. $\square$

**Claim 2 (Levinson recursion).** For a symmetric positive definite Toeplitz matrix, the function levinson (line L3) returns the solution of $R x = g$ in $O(p^2)$ operations.

*Proof.* For $m = 1, \ldots, p$ let $R_m$ be the leading $m \times m$ block. The loop keeps two vectors: $a^{(m)}$ with $a^{(m)}_0 = 1$ and $R_m a^{(m)} = (\epsilon_m, 0, \ldots, 0)^T$, and $x^{(m)}$ with $R_m x^{(m)} = (g_0, \ldots, g_{m-1})^T$. For $m = 1$ these are $a = (1)$, $\epsilon_1 = r_0$ and $x = (g_0/r_0)$, as in the code. Because $R_m$ is symmetric and Toeplitz, it commutes with the reversal $J$, so $R_m (J a^{(m)}) = (0, \ldots, 0, \epsilon_m)^T$. For the step to $m + 1$, let $\Delta = \sum_{j<m} a^{(m)}_j r_{m-j}$. Then
$$R_{m+1}\begin{pmatrix} a^{(m)} \\ 0 \end{pmatrix} = \begin{pmatrix} \epsilon_m \\ 0 \\ \Delta \end{pmatrix}, \qquad R_{m+1}\begin{pmatrix} 0 \\ J a^{(m)} \end{pmatrix} = \begin{pmatrix} \Delta \\ 0 \\ \epsilon_m \end{pmatrix},$$
where the middle blocks have $m - 1$ zeros. With $k = -\Delta/\epsilon_m$, the vector $a^{(m+1)} = (a^{(m)}, 0) + k (0, J a^{(m)})$ has first entry $1$ and gives $R_{m+1} a^{(m+1)} = (\epsilon_m + k\Delta, 0, \ldots, 0)^T$, with $\epsilon_{m+1} = \epsilon_m + k\Delta = \epsilon_m (1 - k^2)$. Since $\epsilon_{m+1} = a^{(m+1)T} R_{m+1} a^{(m+1)} > 0$ for a positive definite matrix, the check in the code never fails, and $|k| < 1$. For $x$, let $\eta = \sum_{j<m} x^{(m)}_j r_{m-j}$; then $R_{m+1}(x^{(m)}, 0) = (g_0, \ldots, g_{m-1}, \eta)$, and adding $\mu J a^{(m+1)}$ with $\mu = (g_m - \eta)/\epsilon_{m+1}$ changes only the last entry, to $g_m$. These are the lines of the loop. Each step costs $O(m)$, so the total is $O(p^2)$, and the memory is $O(p)$. $\square$

**Claim 3 (the spiking filter is minimum phase).** For $\alpha = 1$, the PEF $f$ has $F(z) = \sum_j f_j z^j$ with all zeros outside the closed unit disk. So $1/F(z)$ is a causal, stable filter.

*Proof.* For $\alpha = 1$, the equations $R a = g$ say that $(R_{p+1} f)_i = 0$ for $i = 1, \ldots, p$, with $(R_{p+1} f)_0 > 0$. By uniqueness (Claim 1 for $R_{p+1}$) $f$ is the vector $a^{(p+1)}$ of the Levinson recursion run on $r_0, \ldots, r_p$. Let $A_m(z)$ be the polynomial of $a^{(m)}$ (degree at most $m - 1$) and $\tilde A_m(z) = z^{m} A_m(1/z)$, the polynomial of the reversed vector shifted by one, so that $A_{m+1}(z) = A_m(z) + k\,\tilde A_m(z)$. On $|z| = 1$ the coefficients are real, so $|\tilde A_m(z)| = |A_m(\bar z)| = |A_m(z)|$. $A_1 = 1$ has no zeros. If $A_m$ has no zeros in $|z| \le 1$, then on $|z| = 1$ we have $|k \tilde A_m(z)| = |k|\,|A_m(z)| < |A_m(z)|$ because $|k| < 1$ (Claim 2). By Rouché's theorem $A_{m+1}$ has as many zeros in $|z| < 1$ as $A_m$, that is none, and the strict inequality excludes zeros on $|z| = 1$. By induction $F = A_{p+1}$ has all zeros in $|z| > 1$. A polynomial with no zeros in the closed unit disk has a reciprocal that is analytic on a disk of radius above 1, so its power series is causal with geometrically decaying coefficients. Prewhitening keeps the matrix positive definite, so the claim holds with it too. $\square$

**Claim 4 (the ideal case).** Assume the statistical model: $d = w * \rho$, where $\rho$ is white with $\mathbb{E}\rho_t \rho_s = \sigma^2 [t = s]$, and the wavelet is autoregressive of order at most $p$, that is $W(z) = 1/A(z)$ with $A(z) = 1 + \sum_{j=1}^{p} A_j z^j$ having all zeros outside the closed unit disk. Replace $r_k$ by the expected autocorrelation $\mathbb{E} d_t d_{t+k}$. Then the PEF with gap $\alpha$ and $p$ taps gives $e_t = \sum_{k=0}^{\alpha-1} w_k \rho_{t-k}$: the output is the reflectivity convolved with the first $\alpha$ samples of the wavelet. For $\alpha = 1$ the output is $w_0 \rho_t = \rho_t$.

*Proof.* Since $1/A$ is causal and stable, $d_t = \sum_{k \ge 0} w_k \rho_{t-k}$, and $\rho_t = (A * d)_t$ is a function of $d_t, \ldots, d_{t-p}$. So the past $d_t, d_{t-1}, \ldots$ and the past $\rho_t, \rho_{t-1}, \ldots$ span the same space. Split $d_{t+\alpha} = \sum_{k<\alpha} w_k \rho_{t+\alpha-k} + \sum_{k \ge \alpha} w_k \rho_{t+\alpha-k}$. The first sum is uncorrelated with every $d_{t-j}$, $j \ge 0$, because it holds only $\rho$ at times after $t$. The second sum is a function of the past, and it is a linear function of $d_t, \ldots, d_{t-p+1}$ only: apply the recursion $d_s = \rho_s - \sum_{j=1}^{p} A_j d_{s-j}$ for $s = t + \alpha, \ldots, t + 1$ and drop the future $\rho$ terms; what remains is a combination of $d_t, \ldots, d_{t-p+1}$. Call its coefficients $a^\ast$. Then the error $d_{t+\alpha} - \sum_j a^\ast_j d_{t-j}$ equals the first sum, which is orthogonal to $d_t, \ldots, d_{t-p+1}$. Orthogonality of the error to the data is exactly the normal equations $R a^\ast = g$ with the expected autocorrelation, so by Claim 1 the filter of lines L2 and L3 is $a^\ast$, and the output is the first sum. $\square$

For the test cases: the wavelet $w_k = (1/2)^k$ has $A(z) = 1 - z/2$, so the spiking taps are $(1/2, 0, \ldots, 0)$, the gapped taps are $((1/2)^\alpha, 0, \ldots)$, and the output keeps the first $\alpha$ samples. A water-layer reverberation $W(z) = 1/(1 + c z^\tau)$ has $w_k = 0$ for $0 < k < \tau$, so with gap $\tau$ and $p \ge 1$ the output is $\rho$ itself.

**Claim 5 (cost).** For a trace of $N$ samples, line L1 costs $O(N (p + \alpha))$, Levinson costs $O(p^2)$ and line L5 costs $O(N (p + \alpha))$. $\square$

*Proof.* The autocorrelation computes $p + \alpha$ lags, each a sum of at most $N$ products. The convolution of line L5 has at most $p + \alpha$ products per output sample. Claim 2 gives the cost of the solve. $\square$
