We use the language and the pseudocode of the page, with the two levels $L \le H$. A faceted value is a plain value, which both views see, or a pair $\langle a : b \rangle$ with $a \ne b$, whose $H$ view is $a$ and whose $L$ view is $b$. We write $\langle a : b \rangle$ also when $a = b$, and then mean the plain value $a$. For a faceted store $\sigma$ and a view $X \in \{H, L\}$, $\pi_X(\sigma)$ is the plain store of the $X$ views. The faceted value of an expression $e$ is $\langle [\![e]\!]\pi_H(\sigma) : [\![e]\!]\pi_L(\sigma) \rangle$, so its $X$ view is the plain value of $e$ in $\pi_X(\sigma)$.

**The plain machine.** The plain run of $c$ from a store $s$ is this machine. Its state is a stack of commands and a store, and it starts with the stack $[c]$. A step pops the top command $d$. For skip it does nothing. For $x := e$ it sets $s(x)$ to the value of $e$. For $d_1; d_2$ it pushes $d_2$ and then $d_1$. For "if $e$ then $d_1$ else $d_2$" it pushes $d_1$ if $e$ is true and $d_2$ otherwise. For "while $e$ do $d_1$" it pushes the loop and then $d_1$ if $e$ is true, and nothing otherwise. The run ends when the stack is empty; $[\![c]\!](s)$ is the final store, or $\bot$ if the run does not end. This machine gives the usual semantics of the language.

**Projection of a configuration.** A configuration of the faceted run is a stack $S$ of pairs $(d, p)$ with $p \in \{\mathit{none}, H, L\}$, and a faceted store $\sigma$. For a view $X$, let $\pi_X(S)$ be the stack of the commands $d$ of the pairs $(d, p)$ of $S$ with $p = \mathit{none}$ or $p = X$, in the same order. A pair with $p = H$ belongs only to the $H$ view, a pair with $p = L$ only to the $L$ view, and a pair with $p = \mathit{none}$ to both.

**Lemma (one step).** Let a step of the faceted run go from $(S, \sigma)$ to $(S', \sigma')$, and let $(d, p)$ be the popped pair. For each view $X$: if $p = \mathit{none}$ or $p = X$, the plain machine goes in one step from $(\pi_X(S), \pi_X(\sigma))$ to $(\pi_X(S'), \pi_X(\sigma'))$; otherwise $\pi_X(S') = \pi_X(S)$ and $\pi_X(\sigma') = \pi_X(\sigma)$.

*Proof.* If $p = \mathit{none}$ or $p = X$, then $d$ is in $\pi_X(S)$, and it is the top of $\pi_X(S)$ because it is the top of $S$ and $\pi_X$ keeps the order. So the plain machine also pops $d$. We go through the cases.

- *skip.* Nothing changes.
- *$x := e$ (lines L4 to L7).* Let $v$ be the faceted value of $e$. If $p = \mathit{none}$, line L5 sets $\sigma'(x) = v$, whose $X$ view is the plain value of $e$ in $\pi_X(\sigma)$, as in the plain machine. If $p = H$, line L6 sets the $H$ view of $x$ to the $H$ view of $v$ and keeps its $L$ view. So $\pi_H$ follows the plain step, and $\pi_L(\sigma') = \pi_L(\sigma)$; the pair is not in $\pi_L(S)$, so $\pi_L(S') = \pi_L(S)$. Line L7 is the same with $H$ and $L$ exchanged.
- *$d_1; d_2$ (line L8).* Both new pairs get the label $p$. So they are in $\pi_X(S')$ exactly when the popped pair was in $\pi_X(S)$, and then $\pi_X$ follows the plain step.
- *if or while on $e$ (lines L9 to L14).* Let $b_H$ and $b_L$ be the truth of $e$ in the two views. If $p = \mathit{none}$ and $b_H \ne b_L$, line L11 pushes the arm for $b_L$ with the label $L$ and then the arm for $b_H$ with the label $H$. For an if, this is the branch chosen by $b_L$ and the branch chosen by $b_H$. For a while, it is the loop and its body, for each view whose condition is true. The pairs with the label $X$ are the ones the plain step of the $X$ view pushes, with the condition $b_X$, and the other pairs are not in $\pi_X(S')$. Otherwise, line L12 makes one arm with the label $p$ and the truth value $b$, where $b = b_L$ if $p = L$ and $b = b_H$ if $p = H$. If $p = \mathit{none}$, then $b_H = b_L = b$. In each case, for each view $X$ with $p = \mathit{none}$ or $p = X$, $b = b_X$, so the pushed pairs are the ones the plain step pushes, and they are in $\pi_X(S')$. For the other view, nothing changes.

**Theorem 1 (projection).** Let $\sigma_0$ be a faceted store. The faceted run of $c$ from $\sigma_0$ ends if and only if the plain runs from $\pi_H(\sigma_0)$ and from $\pi_L(\sigma_0)$ both end. If it ends in $\sigma$, then $\pi_H(\sigma) = [\![c]\!](\pi_H(\sigma_0))$ and $\pi_L(\sigma) = [\![c]\!](\pi_L(\sigma_0))$. The number of steps of the faceted run is at most the sum of the numbers of steps of the two plain runs.

*Proof.* The start configuration $([(c, \mathit{none})], \sigma_0)$ projects to the start configuration $([c], \pi_X(\sigma_0))$ of the plain run of each view. By the lemma and induction on the number of steps, after each step of the faceted run, the projection on each view $X$ is a configuration of the plain run of $X$, reached after as many plain steps as there were faceted steps whose pair belongs to $X$. Each pair belongs to at least one view, so after $m$ faceted steps the two plain runs together have made at least $m$ steps.

If the faceted run ends, its stack is empty, so both projected stacks are empty: both plain runs have ended, with the final stores $\pi_H(\sigma)$ and $\pi_L(\sigma)$. Their numbers of steps add up to at least the number of faceted steps. If both plain runs end, after $a$ and $b$ steps, the faceted run cannot make more than $a + b$ steps, since each of its steps is a step of one of the plain runs, and a plain run that has ended has no more steps; so the stack of the faceted run is empty after at most $a + b$ steps, and the run ends.

**Theorem 2 (TINI).** Let $s_1$ and $s_2$ be plain stores that agree on the public variables. Let $\sigma^i$ be the initial faceted store, as in the function initial_store of the code: each secret variable $x$ gets $\langle s_i(x) : d \rangle$ for a fixed default value $d$, and each public variable gets $s_i(x)$. If both faceted runs end, in $\sigma^1$ and $\sigma^2$, then $\pi_L$ of the two final stores are equal. So the observer at $L$, who sees the $L$ view, sees the same final store in both runs.

*Proof.* $\pi_L(\sigma^1)$ and $\pi_L(\sigma^2)$ both map each secret variable to $d$ and each public variable to its common value, so they are equal; call this store $s_L$. By Theorem 1, the $L$ views of both final stores are $[\![c]\!](s_L)$.

**Transparency.** By Theorem 1, the $H$ view of the final store is the result of the plain run on the true inputs, $[\![c]\!](s_i)$, because $\pi_H(\sigma^i) = s_i$. If $c$ is termination-insensitive noninterferent and the faceted run ends, the plain runs from $s_i$ and from $s_L$ both end. Since $s_i$ and $s_L$ agree on the public variables, the $L$ view gives the same public values as the plain run on the true inputs.

**Only termination-insensitive.** The faceted run does not end when the $H$ view does not end. For "while $h = 1$ do skip; $l := 1$", the run with $h = 1$ does not end and the run with $h = 0$ ends with $l = 1$, so the observer at $L$ learns whether $h = 1$ from termination. The theorems compare only runs that end, and the code, with its bound on the steps, returns no result in the same cases or more. $\blacksquare$
