---
title: The Gaussian smoothed classifier is constant on the certified l2 ball, and CERTIFY is correct with probability at least 1 - alpha
proves: [correctness]
status: full
---

Let $f : \mathbb{R}^d \to \{1, \dots, k\}$ be any measurable base classifier, let $\sigma > 0$, and let $\eta \sim N(0, \sigma^2 I)$. For a label $c$ write $p_c(x) = P(f(x + \eta) = c)$, and let $g(x) = \arg\max_c p_c(x)$. We write $\Phi$ for the distribution function of the standard normal distribution and $\Phi^{-1}$ for its inverse. The proof has three parts: the radius for known probabilities (Lemma 1 to the Theorem), the Clopper-Pearson bound (Lemma 3), and the procedure (the Corollary).

**Lemma 1 (Neyman-Pearson).** Let $P$ and $Q$ be two distributions on $\mathbb{R}^d$ with densities $\mu_P$ and $\mu_Q$, and let $S = \{z : \mu_Q(z) / \mu_P(z) \le t\}$ for some $t > 0$. If a measurable function $h : \mathbb{R}^d \to [0, 1]$ has $E_P[h] \ge P(S)$, then $E_Q[h] \ge Q(S)$.

*Proof.* Let $u = h - 1_S$. On $S$ we have $u \le 0$ and $\mu_Q \le t \mu_P$, so $u \mu_Q \ge t u \mu_P$. Outside $S$ we have $u \ge 0$ and $\mu_Q > t \mu_P$, so again $u \mu_Q \ge t u \mu_P$. Integration gives $E_Q[h] - Q(S) \ge t (E_P[h] - P(S)) \ge 0$. $\square$

**Lemma 2 (the Gaussian half-space).** Let $P = N(x, \sigma^2 I)$ and $Q = N(x + \delta, \sigma^2 I)$ with $\delta \ne 0$, and let $0 < p < 1$. The set $S = \{z : \delta^\top (z - x) \le \sigma \lVert \delta \rVert_2 \Phi^{-1}(p)\}$ has $P(S) = p$ and $Q(S) = \Phi(\Phi^{-1}(p) - \lVert \delta \rVert_2 / \sigma)$, and it has the form of Lemma 1.

*Proof.* The density ratio is $\mu_Q(z) / \mu_P(z) = \exp((2 \delta^\top (z - x) - \lVert \delta \rVert_2^2) / (2 \sigma^2))$, an increasing function of $\delta^\top (z - x)$, so $S$ is a set $\{\mu_Q / \mu_P \le t\}$ for a $t > 0$. Under $P$, the variable $\delta^\top (z - x)$ is normal with mean $0$ and standard deviation $\sigma \lVert \delta \rVert_2$, so $P(S) = \Phi(\Phi^{-1}(p)) = p$. Under $Q$, it is normal with mean $\lVert \delta \rVert_2^2$ and the same standard deviation, so $Q(S) = \Phi(\Phi^{-1}(p) - \lVert \delta \rVert_2 / \sigma)$. The set $S^c$ has the form $\{\mu_Q / \mu_P > t\}$, and the same argument with the opposite inequality gives: if $E_P[h] \le P(S^c) = 1 - p$, then $E_Q[h] \le Q(S^c) = 1 - \Phi(\Phi^{-1}(p) - \lVert \delta \rVert_2 / \sigma)$. $\square$

**Theorem (Cohen, Rosenfeld and Kolter 2019).** Let $c_A$ be a label, and let $0 < p_B \le p_A < 1$ with $p_{c_A}(x) \ge p_A$ and $p_c(x) \le p_B$ for every $c \ne c_A$. If $\lVert \delta \rVert_2 < R = \frac{\sigma}{2}(\Phi^{-1}(p_A) - \Phi^{-1}(p_B))$, then $g(x + \delta) = c_A$.

*Proof.* The case $\delta = 0$ is clear. Otherwise let $P = N(x, \sigma^2 I)$ and $Q = N(x + \delta, \sigma^2 I)$, so $p_c(x) = E_P[1\{f = c\}]$ and $p_c(x + \delta) = E_Q[1\{f = c\}]$. Apply Lemma 1 with $h = 1\{f = c_A\}$ and the set $S_A$ of Lemma 2 for $p = p_A$: since $E_P[h] \ge p_A = P(S_A)$, we get $p_{c_A}(x + \delta) \ge \Phi(\Phi^{-1}(p_A) - \lVert \delta \rVert_2 / \sigma)$. For $c \ne c_A$, apply the second statement of Lemma 2 with $h = 1\{f = c\}$ and $p = 1 - p_B$: since $E_P[h] \le p_B$, we get $p_c(x + \delta) \le 1 - \Phi(\Phi^{-1}(1 - p_B) - \lVert \delta \rVert_2 / \sigma) = \Phi(\Phi^{-1}(p_B) + \lVert \delta \rVert_2 / \sigma)$, by the symmetry $\Phi^{-1}(1 - q) = -\Phi^{-1}(q)$. Because $\Phi$ is strictly increasing, $p_{c_A}(x + \delta) > p_c(x + \delta)$ holds when $\Phi^{-1}(p_A) - \lVert \delta \rVert_2 / \sigma > \Phi^{-1}(p_B) + \lVert \delta \rVert_2 / \sigma$, that is, when $\lVert \delta \rVert_2 < R$. Then $c_A$ has the strictly largest probability at $x + \delta$, so $g(x + \delta) = c_A$. $\square$

With $p_B = 1 - p_A$ and $p_A > 1/2$ the radius is $\frac{\sigma}{2}(\Phi^{-1}(p_A) + \Phi^{-1}(p_A)) = \sigma \Phi^{-1}(p_A)$, which is the radius of line L6. The choice is allowed, because $p_c(x) \le 1 - p_{c_A}(x) \le 1 - p_A$ for every $c \ne c_A$, and $p_A > 1/2$ gives $p_B < p_A$.

**Lemma 3 (Clopper-Pearson coverage).** Let $K \sim \mathrm{Bin}(n, p)$ and $0 < \alpha < 1$. Define $L(0) = 0$ and, for $k \ge 1$, let $L(k)$ be the unique $q$ with $T_k(q) = \alpha$, where $T_k(q) = P(\mathrm{Bin}(n, q) \ge k)$. Then $P(L(K) > p) \le \alpha$.

*Proof.* For $k \ge 1$, $T_k$ is continuous and strictly increasing on $[0, 1]$ with $T_k(0) = 0$ and $T_k(1) = 1$; it is increasing because a $\mathrm{Bin}(n, q')$ variable with $q' > q$ can be built as a $\mathrm{Bin}(n, q)$ variable plus extra successes, by a coupling of each trial, and strict because the extra mass is positive for $0 < q < 1$. So $L(k)$ exists and is unique, and $L(k) > p$ holds if and only if $T_k(p) < \alpha$. Also $T_k$ decreases in $k$, so $L$ is non-decreasing in $k$. Let $k^* = \min\{k \ge 1 : L(k) > p\}$; if it does not exist, the probability is $0$. By monotonicity, $L(K) > p$ holds exactly when $K \ge k^*$, and $P(K \ge k^*) = T_{k^*}(p) < \alpha$. $\square$

**Corollary (CERTIFY).** Run CERTIFY with $n_0 \ge 1$, $n \ge 1$ and $0 < \alpha < 1$. With probability at least $1 - \alpha$ over the noise draws, the following holds: if CERTIFY returns $(c_A, R)$, then $g(x + \delta) = c_A$ for every $\lVert \delta \rVert_2 < R$.

*Proof.* The draws of line L1 and of line L3 are independent. Condition on the result of lines L1 and L2, so the label $c_A$ is fixed. Under this condition the samples of line L3 are still independent draws of $N(0, \sigma^2 I)$, so the count $n_A$ of $c_A$ at line L3 is $\mathrm{Bin}(n, p_{c_A}(x))$. Line L4 computes $\underline p_A = L(n_A)$ for the level $\alpha$. By Lemma 3, the event $E = \{\underline p_A \le p_{c_A}(x)\}$ has conditional probability at least $1 - \alpha$, for every value of $c_A$; so it has probability at least $1 - \alpha$ without the condition. On $E$, suppose that CERTIFY returns at line L6. Then $\underline p_A > 1/2$, so with $p_A = \underline p_A$ and $p_B = 1 - \underline p_A$ the hypotheses of the Theorem hold: $p_{c_A}(x) \ge p_A$, and $p_c(x) \le 1 - p_{c_A}(x) \le p_B$ for $c \ne c_A$. The Theorem gives $g(x + \delta) = c_A$ for every $\lVert \delta \rVert_2 < \sigma \Phi^{-1}(\underline p_A) = R$. If CERTIFY abstains at line L7, there is nothing to prove. So the claim holds on $E$, and $P(E) \ge 1 - \alpha$. $\blacksquare$
