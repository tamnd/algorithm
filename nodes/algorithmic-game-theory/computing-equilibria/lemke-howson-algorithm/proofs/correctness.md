---
title: The Lemke-Howson path from the artificial pair ends at a Nash equilibrium
proves: [correctness, termination]
status: full
---

Let $(A, B)$ be an $m \times n$ bimatrix game, shifted so that all entries of $A'$ and $B'$ are at least 1. Let $P = \{x \ge 0 : B'^{\mathsf T} x \le \mathbf 1\}$ and $Q = \{y \ge 0 : A' y \le \mathbf 1\}$, with the labels of the page: $x$ has label $i$ if $x_i = 0$ and label $m + j$ if $(B'^{\mathsf T} x)_j = 1$; $y$ has label $i$ if $(A' y)_i = 1$ and label $m + j$ if $y_j = 0$. Write $L(x)$ and $L(y)$ for the sets of labels, and $N = \{0, \ldots, m + n - 1\}$.

**Lemma 1 (bounded polytopes).** $P$ and $Q$ are bounded, and they are full-dimensional with $0$ as a vertex.

*Proof.* For $x \in P$ and each $i$, $x_i \le \sum_r B'_{r0} x_r \le 1$, because $B'_{r0} \ge 1$ and $x \ge 0$. The same holds for $Q$. The point $0$ satisfies the $m$ independent constraints $x \ge 0$ with equality, and a small positive $x$ is inside $P$. $\square$

**Lemma 2 (completely labeled pairs).** $(x, y) \in P \times Q$ with $L(x) \cup L(y) = N$ and $(x, y) \ne (0, 0)$ gives a Nash equilibrium $(x / \sum_i x_i, y / \sum_j y_j)$, and every Nash equilibrium arises in this way.

*Proof.* Suppose $L(x) \cup L(y) = N$ and $x \ne 0$. If $y = 0$, then no label $i < m$ is at $y$, so all of them are at $x$ and $x = 0$, a contradiction; so $y \ne 0$, and in the same way $x \ne 0$ when $y \ne 0$. Let $\bar x = x / \sum x$, $\bar y = y / \sum y$. For each row $i$ with $x_i > 0$, the label $i$ is not at $x$, so it is at $y$: $(A'y)_i = 1 = \max_r (A'y)_r$, so row $i$ is a best response to $\bar y$ in $A'$, and so in $A$, since the shift adds the same constant to every row. By the same argument every column in the support of $\bar y$ is a best response to $\bar x$, and by the best response fact the pair is an equilibrium.

Conversely, let $(\bar x, \bar y)$ be an equilibrium, $u = \max_r (A' \bar y)_r > 0$ and $v = \max_c (B'^{\mathsf T} \bar x)_c > 0$. Then $y = \bar y / u \in Q$ and $x = \bar x / v \in P$, and each row with $\bar x_i > 0$ is a best response, so it has $(A'y)_i = 1$; hence label $i$ is at $x$ or at $y$. The same holds for the columns. $\square$

**Lemma 3 (the graph).** Assume the game is nondegenerate: every $x \in P$ has at most $m$ labels and every $y \in Q$ at most $n$. Fix $k \in N$. Let $G_k$ be the graph whose nodes are the pairs of vertices $(x, y)$ of $P \times Q$ with $L(x) \cup L(y) \supseteq N \setminus \{k\}$, and whose edges join $(x, y)$ to $(x', y)$ when $x x'$ is an edge of $P$, or to $(x, y')$ when $y y'$ is an edge of $Q$. Then every completely labeled node has degree 1 and every other node has degree 2.

*Proof.* By nondegeneracy, a vertex $x$ of $P$ has exactly $m$ labels, and for each $\ell \in L(x)$ there is exactly one edge of $P$ from $x$ on which the labels $L(x) \setminus \{\ell\}$ stay and $\ell$ is dropped; its other end $x'$ has the labels $L(x) \setminus \{\ell\}$ plus exactly one new label. The same holds for $Q$. Since $|L(x)| + |L(y)| = m + n = |N|$, a node with $L(x) \cup L(y) = N$ has no repeated label, and the only move that keeps all of $N \setminus \{k\}$ drops $k$ at the point that has it: one neighbor. A node that misses $k$ has $|L(x) \cup L(y)| = m + n - 1$, so exactly one label $\ell$ is at both points; the moves that keep $N \setminus \{k\}$ are to drop $\ell$ at $x$ or to drop $\ell$ at $y$: two neighbors. $\square$

**Theorem 1.** For a nondegenerate game and any $k$, lines L1 to L8 end, and they return a Nash equilibrium.

*Proof.* The tableaux $T_1$ and $T_2$ have the basic solutions $x$ and $y$; the nonbasic variables are zero, and they carry the labels of the vertex, because a zero slack $s_j$ means $(B'^{\mathsf T} x)_j = 1$ and a zero slack $r_i$ means $(A'y)_i = 1$. At line L2 the pair is $(0, 0)$, which is completely labeled. Line L4 enters the variable with label $\ell$: in the polytope of $T$ this moves along the edge that drops label $\ell$, and the ratio test picks the end of the edge; the edge is finite by Lemma 1, so a row with a positive pivot entry exists. The leaving variable becomes nonbasic, which is the new label $\ell'$. So each iteration is one step along $G_k$ from the current node to a neighbor. The first step leaves $(0, 0)$ by its only edge. After that, the next step drops the double label at the other point (line L7), which is the neighbor other than the one we came from.

So the algorithm walks along the component of $G_k$ that contains $(0, 0)$. By Lemma 3 that component is a path, since a cycle has no node of degree 1. A path visits no node twice, and $G_k$ is finite, so the walk ends, at the other end of the path. The walk stops when the leaving label is $k$ (line L6), which is when the pair becomes completely labeled, and that end is not $(0, 0)$. By Lemma 2, line L8 returns a Nash equilibrium. $\square$

**Corollary (odd number).** A nondegenerate game has an odd number of Nash equilibria.

*Proof.* The nodes of degree 1 in $G_k$ are the completely labeled pairs, and they are the ends of the paths of $G_k$, two per path. So their number is even. One of them is $(0, 0)$, and by Lemma 2 the others are in one-to-one correspondence with the equilibria. $\square$

**Degenerate games and the lexicographic rule.** Replace the right-hand side $\mathbf 1$ of both tableaux by $\mathbf 1 + (\varepsilon, \varepsilon^2, \ldots)$ for a small $\varepsilon > 0$. For all small enough $\varepsilon$ the perturbed polytopes are nondegenerate, because a point with an extra label would solve one more equation than its dimension allows, which happens for only finitely many $\varepsilon$. The ratio test on the perturbed tableau compares the values $(\text{rhs} + \sum_t \varepsilon^t \beta_t) / a$, where the $\beta_t$ are the entries in the columns of the first basis; for small $\varepsilon$ this is the lexicographic comparison of the vector (rhs, the first basis columns) divided by the pivot entry $a$, which is what the code does. The rows of the first basis columns are the rows of the inverse of the current basis, so they are linearly independent, and the lexicographic minimum is unique. So the code follows the path of the perturbed game, which ends by Theorem 1. At the end the pair is completely labeled for the perturbed game; the labels of the unperturbed pair include them, since letting $\varepsilon$ tend to 0 keeps every equation, so the result is completely labeled for the original game. It is not $(0, 0)$. Suppose $x = 0$. Then $s = \mathbf 1$, so all $n$ slacks are basic and $T_1$ has its first basis. The labels $m, \ldots, m + n - 1$ are not at $x = 0$, because $s > 0$, so they are at $y$, which gives $y = 0$, and in the same way $T_2$ has its first basis. Then the end pair of bases is the start pair, which is impossible, because the perturbed path ends at a node other than its start. By Lemma 2 it is an equilibrium of the original game.
