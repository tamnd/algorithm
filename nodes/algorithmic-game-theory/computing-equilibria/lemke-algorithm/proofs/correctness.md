---
title: Lemke's method ends, and when it does not end on a ray it returns a solution of the LCP
proves: [correctness, termination]
status: full
---

Let $M$ be an $n \times n$ matrix, $q \in \mathbb{R}^n$ with some $q_i < 0$, and $d > 0$. The augmented system is $w - Mz - d z_0 = q$ with $2n + 1$ variables $w_1, \ldots, w_n, z_1, \ldots, z_n, z_0$, all nonnegative. Its coefficient matrix $[I, -M, -d]$ has rank $n$, because of the identity block, so a basis is a set of $n$ columns whose submatrix $G$ is nonsingular, and its basic solution is $G^{-1} q$.

**Perturbation.** Let $q(\varepsilon) = q + (\varepsilon, \varepsilon^2, \ldots, \varepsilon^n)$. For a basis $G$, the basic solution is $G^{-1} q(\varepsilon) = G^{-1} q + \sum_t \varepsilon^t (G^{-1})_{\cdot t}$. Each entry is a polynomial in $\varepsilon$ whose coefficient vector is a row of $[G^{-1} q, G^{-1}]$, and it is not the zero polynomial, because $G^{-1}$ is nonsingular and has no zero row. So for all small enough $\varepsilon > 0$, no basic variable of any basis is 0, and comparing two entries for small $\varepsilon$ is the lexicographic comparison of their coefficient vectors. In the tableau of the code the columns of $w$ hold $G^{-1}$, because they started as the identity. So the lexicographic rule of lines L3 and L7 is the ordinary rule on the system with $q(\varepsilon)$, for all small $\varepsilon > 0$, and that system is nondegenerate: every feasible basis has all basic variables positive, and every ratio test has a unique minimum. From now on, argue with $q(\varepsilon)$.

**Lemma 1 (start).** After line L3 the basis is feasible and almost complementary, and the pair with both members nonbasic is $(z_r, w_r)$.

*Proof.* With $z = 0$, the system says $w_i = q_i + d_i z_0$. These are all nonnegative exactly when $z_0 \ge \max_i (-q_i / d_i)$, which is positive. At the smallest such value, $z_0 = -q_r / d_r$, only $w_r$ is 0 (the minimum is unique by the perturbation). Pivoting $z_0$ in for $w_r$ gives the basis $\{z_0\} \cup \{w_i : i \ne r\}$, which is feasible and almost complementary, with both $z_r$ and $w_r$ nonbasic. $\square$

**Lemma 2 (invariant).** Before each execution of line L6, the basis is feasible and almost complementary, $z_0$ is basic, and $e$ is a member of the unique pair with both members nonbasic.

*Proof.* True at the first time by Lemma 1 and line L4. Suppose it holds and line L7 pivots $e$ in and some variable $v \ne z_0$ out. The ratio test keeps feasibility. The pair of $e$ now has one basic member. The variable $v$ was basic and is now nonbasic. Since the old basis had exactly one basic member in each pair other than the pair of $e$, the pair of $v$ now has both members nonbasic, and it is the only such pair. Line L8 sets $e$ to the partner of $v$. $\square$

**Lemma 3 (exits).** If line L7 removes $z_0$, the returned $(z, w)$ solves the LCP. If line L6 returns "ray", the augmented system has an unbounded edge of feasible solutions on which all pairs except one are complementary.

*Proof.* When $z_0$ leaves, the new basis has $n$ members, none of them $z_0$, and by Lemma 2 the pair of $e$ became basic, so each pair has exactly one basic member: the basis is complementary, and $z^{\mathsf T} w = 0$ for its basic solution. It is feasible with $z_0 = 0$, so $w = Mz + q$, $z, w \ge 0$; letting $\varepsilon \to 0$ keeps all these conditions, which are closed, so the solution for $q$ itself also satisfies them. If no row has a positive entry in column $e$, raising $e$ from 0 keeps all basic variables nonnegative forever, and all nonbasic variables other than $e$ stay 0; this is the ray. $\square$

**Lemma 4 (no repetition).** Call two feasible almost complementary bases adjacent if one pivot changes one into the other. In the nondegenerate perturbed system, a feasible almost complementary basis has at most two adjacent ones, one for each member of its pair with both members nonbasic. The basis of Lemma 1 has at most one, because entering $w_r$ in it gives back the initial point $z = 0$ with $z_0$ on the ray that starts there.

*Proof.* Any pivot that keeps the basis almost complementary and $z_0$ basic must enter a member of the double nonbasic pair: entering a nonbasic member of another pair would give that pair two basic members, and then some pair would have to have none, but only one leaves. For each of the two choices of the entering variable, the ratio test has a unique minimum, so there is at most one adjacent basis. For the start, entering $w_r$ moves along the edge on which $z = 0$ and $z_0$ grows, which is unbounded and gives no adjacent basis. $\square$

**Theorem.** With the lexicographic rule, Lemke's method ends after finitely many pivots, either at line L6 with a ray or at line L7 with a solution of the LCP.

*Proof.* By Lemmas 2 and 4, the method walks in the graph of feasible almost complementary bases, in which each node has degree at most 2 and the start has degree at most 1. Each step goes to the neighbor that is not the previous node, because it enters the partner of the variable that just left, and entering that variable again would undo the last pivot. A walk of this kind from a node of degree at most 1 never repeats a node: the first repeated node would have three distinct neighbors on the walk, or would be the start with two. There are finitely many bases, so the walk ends. It can only end at line L6 or at line L7 with $z_0$ leaving, and Lemma 3 describes both. $\square$

**Classes of $M$.** The statements of the page about P-matrices, copositive-plus and strictly copositive matrices are the standard theorems on the matrix classes processed by Lemke's method, proved in the book of Cottle, Pang and Stone. For a strictly copositive $M$ the argument is short: on a ray, $z(t) = z + t a$, $w(t) = w + t b$, $z_0(t) = z_0 + t c$ with $a, b, c \ge 0$, not all 0, $b = M a + d c$, and complementarity $a^{\mathsf T} b = 0$ for all large $t$, because all but one pair stay complementary and the double nonbasic pair has both members 0. If $a \ne 0$, then $0 = a^{\mathsf T} b = a^{\mathsf T} M a + c\, a^{\mathsf T} d > 0$, a contradiction. If $a = 0$, then $c > 0$ (otherwise $b = 0$ too) and $b = d c > 0$. Then for large $t$ all $w_i(t)$ and $z_0(t)$ are positive, and the positive variables on the ray are the $n$ basic ones and the entering one, so the basis consists of $z_0$ and all $w_i$ but one, $w_e$, which is the entering variable. The basic solution of that basis has $z = 0$ and $w_e = 0$, so it is the basis of Lemma 1 (with $e = r$). But the walk never returns to the start (Theorem), and at the start it enters $z_r$, not $w_r$. This is a contradiction. So for strictly copositive $M$ the method returns a solution, which is the case used by the code for bimatrix games.
