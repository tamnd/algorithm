---
title: Top trading cycles gives the unique strict core allocation and is strategyproof
proves: [correctness, termination]
status: full
---

Agent $i$ owns house $h_i$, for $i = 1, \dots, n$, and has a strict ranking $\succ_i$ of the houses. A list that stops at $h_i$ stands for any ranking that puts the unlisted houses below $h_i$; we show below that the algorithm never reads past $h_i$, so the choice of these rankings does not matter. An allocation is a permutation $x$, with $x(i)$ the house of agent $i$. A coalition $S$ *weakly blocks* $x$ if there is a permutation $y$ of the houses $\{h_j : j \in S\}$ among the agents of $S$ with $y(i) \succeq_i x(i)$ for all $i \in S$ and $y(i) \succ_i x(i)$ for some $i \in S$. The *strict core* is the set of allocations that no coalition weakly blocks.

At any moment, call the agents and houses that have not left *remaining*; agent $i$ remains exactly when $h_i$ remains. The *pointer graph* has the remaining agents as nodes and an arc from $i$ to the owner of the best remaining house of $i$. Every node has exactly one outgoing arc, so the graph has at least one cycle.

**Claim 1 (pointers stay in range).** Whenever line L7 runs for a remaining agent $i$, it stops at an entry at or before $h_i$, and the entry is the best remaining house of $i$. *Proof.* Each list contains $h_i$, which remains while $i$ remains. Houses only leave, so every entry before $\text{ptr}[i]$ was already gone at an earlier time and is still gone. Line L7 skips gone houses and stops at the first remaining one, which is the best remaining house because the list is in order of preference. $\square$

**Claim 2 (path invariant).** At the start of each pass of line L5, the path consists of distinct remaining agents $p_1, \dots, p_r$, and for each $q < r$, $\text{ptr}[p_q]$ points to $h_{p_{q+1}}$, which is the best remaining house of $p_q$. *Proof.* It holds when line L4 sets the path to one remaining agent. Line L10 appends $j$ after the last agent $i$; by Claim 1 and line L8, $h_j$ is the best remaining house of $i$, and $j$ is not on the path. Line L9 removes a suffix $j, \dots, i$ and the houses of these agents only. The agents before $j$ on the path point to houses of agents on the path, and only the agent just before $j$ points into the removed part; it becomes the last agent, for which the invariant asks nothing. For the others, the house they point to remains, so it is still their best remaining house. $\square$

**Claim 3 (each trade is a cycle of the pointer graph).** When line L9 runs, the agents $j = p_t, p_{t+1}, \dots, p_r = i$ form a cycle of the pointer graph, and each gets the house of the next agent on the cycle. *Proof.* By Claim 2, each $p_q$ with $t \le q < r$ points to $h_{p_{q+1}}$, its best remaining house, and by Claim 1 and line L8, $i$ points to $h_j$, its best remaining house. $\square$

**Termination.** An agent is appended to the path only when it is not on it, and it stays on the path until line L9 removes it, at which point it leaves the market. A left agent is never appended again, because line L8 only finds owners of remaining houses. So each agent is appended at most once. Each pass of line L5 appends one agent or removes at least one, so over the whole run there are at most $2n$ passes. The loop of line L3 starts a walk only at a remaining agent, and the walk ends only when the path is empty, which happens only after the start agent leaves. So after the loop every agent has left, and by Claim 3 every agent got a house.

**Cycle removal.** Call a *cycle removal* any process that, starting with all agents, repeatedly picks a cycle of the current pointer graph, gives each agent on it the house of the next agent, and removes these agents and their houses. By Claim 3 and termination, the algorithm performs a cycle removal for every start order. Let $x$ be the result of a cycle removal with cycles $C_1, \dots, C_r$ in the order of removal, and let $H_k$ be the set of houses of the agents of $C_1 \cup \dots \cup C_k$. The houses given to $C_k$ are the houses of $C_k$, so $x$ maps the agents of $C_1 \cup \dots \cup C_k$ onto $H_k$. Each agent $i$ of $C_k$ gets its best house outside $H_{k-1}$.

**Claim 4 ($x$ is in the strict core).** *Proof.* Suppose a coalition $S$ and a permutation $y$ of its houses weakly block $x$. Since some agent is strictly better off, $y(i) \ne x(i)$ for some $i \in S$. Choose such an $i$ in the cycle $C_k$ with the smallest $k$. The preferences are strict, so $y(i) \succ_i x(i)$. The house $x(i)$ is the best house of $i$ outside $H_{k-1}$, so $y(i) \in H_{k-1}$. Let $E = S \cap (C_1 \cup \dots \cup C_{k-1})$. By the choice of $k$, $y(j) = x(j)$ for every $j \in E$, so $y(E) = x(E)$. These are $|E|$ houses in $H_{k-1}$, and they are houses of agents of $S$ because $y$ only uses houses of $S$. The houses of $H_{k-1}$ that belong to agents of $S$ are exactly the houses of $E$, and there are $|E|$ of them. So $y(E)$ is the set of all houses of $E$. But $y(i)$ is a house of an agent of $S$ in $H_{k-1}$, that is, a house of $E$, and $i \notin E$, so $y$ gives the same house to $i$ and to an agent of $E$. This contradicts that $y$ is a permutation. $\square$

**Claim 5 (the strict core has at most the one element $x$).** *Proof.* Let $z$ be in the strict core. We show by induction on $k$ that $z(i) = x(i)$ for all agents of $C_k$. Assume it for $C_1, \dots, C_{k-1}$. Then $z$ maps the agents of $C_1 \cup \dots \cup C_{k-1}$ onto $H_{k-1}$, so every agent of $C_k$ gets under $z$ a house outside $H_{k-1}$. Each agent $i$ of $C_k$ gets under $x$ its best house outside $H_{k-1}$, so $x(i) \succeq_i z(i)$. The allocation $x$ restricted to $C_k$ is a permutation of the houses of $C_k$. If $z(i) \ne x(i)$ for some $i \in C_k$, then $x(i) \succ_i z(i)$ by strictness, and the coalition $C_k$ with $x$ weakly blocks $z$, a contradiction. So $z = x$ on $C_k$. $\square$

By Claims 4 and 5, every cycle removal, and so every run of the algorithm with any start order, returns the same allocation, the unique element of the strict core. In particular it equals the result of the textbook rounds, which is also a cycle removal. Taking $S = \{i\}$ in Claim 4 shows that $x(i) \succeq_i h_i$ (individual rationality), and with Claim 1 this shows that no agent gets a house that it lists after $h_i$, so cutting a list after $h_i$ does not change the result. Taking $S$ as all agents shows that $x$ is Pareto optimal.

**Claim 6 (strategyproofness).** Fix agent $i$ and the lists of the others. Let $x$ be the result when $i$ reports its true list, and $\hat x$ the result when it reports any other list that contains $h_i$. Then $x(i) \succeq_i \hat x(i)$. *Proof.* Both results can be computed by any cycle removal. Use this one: while the pointer graph has a cycle without $i$, remove the cycle without $i$ that contains the smallest agent. The arcs of the agents other than $i$, and so the cycles without $i$, depend only on the remaining set and the lists of the others. By induction, the two runs remove the same cycles, in the same order, until they reach the same remaining set $R$ in which every cycle contains $i$. A functional graph has a cycle in each weakly connected part, so the pointer graph on $R$ is connected with one cycle, through $i$, and the path of arcs from any agent of $R$ leads to $i$. Now $i$ points to the owner $j \in R$ of its best house in $R$ according to its report, and the cycle is $i$, then $j$, then the path from $j$ back to $i$. So $i$ gets its reported best house in $R$. With the true list this is the truly best house in $R$, and with the false list it is some house in $R$. Hence $x(i) \succeq_i \hat x(i)$. $\blacksquare$

**Cost.** By termination there are at most $2n$ passes of line L5, each costing $O(1)$ besides line L7 and the removals of line L9. Line L9 costs $O(1)$ per removed agent, $O(n)$ in total. By Claim 1, each pointer only moves forward inside its list, so line L7 costs $O(L)$ in total, where $L$ is the total list length. The loop of line L3 costs $O(n)$. The total time is $O(n + L)$, and the extra space is $O(n)$.
