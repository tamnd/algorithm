We use the pseudocode of the page, lines L1 to L15, and the fragment of the page: $k$ ground fluents, a finite set of ground actions, no sensing. A state is a map $s$ from the fluents to $\{0, 1\}$, extended to formulas in the usual way; we write $s \models u$ when $u$ is true in $s$. For an action $a$, $\Phi_{F,a} = \gamma^+_{F,a} \vee (F \wedge \neg \gamma^-_{F,a})$ is the right side of the successor state axiom of $F$, and $\mathrm{succ}(s, a)$ is the state with $\mathrm{succ}(s, a)(F) = 1$ if and only if $s \models \Phi_{F,a}$. For a sequence, $\mathrm{succ}(s, []) = s$ and $\mathrm{succ}(s, [a_1, \ldots, a_n]) = \mathrm{succ}(\mathrm{succ}(s, [a_1, \ldots, a_{n-1}]), a_n)$.

**Semantics of the fragment.** A model of the theory assigns a state to every situation. The successor state axioms say that the state of $\mathit{do}(a, \sigma)$ is $\mathrm{succ}(\text{state of } \sigma, a)$, so by induction on the length of the action list the state of $\mathit{do}([a_1, \ldots, a_n], S_0)$ is $\mathrm{succ}(s_0, [a_1, \ldots, a_n])$, where $s_0$ is the state of $S_0$. The only other axioms on states are those of $\mathcal{D}_{S_0}$, so the possible values of $s_0$ are exactly the models of $\mathcal{D}_{S_0}$, and each of them extends to a model of the whole theory by this rule. $\mathit{Poss}(a, \sigma)$ is true if and only if $\Pi_a$ is true in the state of $\sigma$.

**Lemma 0 (MAKE).** MAKE$(\neg, v)$, MAKE$(\wedge, v, w)$ and MAKE$(\vee, v, w)$ return a node that is true in each state $s$ exactly when $\neg v$, $v \wedge w$ or $v \vee w$ is.

*Proof.* MAKE either returns a stored node built from the same operator and the same children, or applies one of the identities $\neg \mathit{true} = \mathit{false}$, $\neg \neg v = v$, $v \wedge \mathit{false} = \mathit{false}$, $v \wedge \mathit{true} = v$, $v \wedge v = v$ and their duals for $\vee$, each of which holds in every state. $\square$

**Lemma 1 (one step).** Fix an action $a$ and a memo table $M$ such that every entry $M[u] = r$ satisfies: for every state $s$, $s \models r \iff \mathrm{succ}(s, a) \models u$. Then STEP$(u, a, M)$ returns a node $r$ with the same property, and every entry it adds to $M$ has it.

*Proof.* By induction on the number of nodes below $u$. If $u$ is in $M$ (line L5), the claim is the assumption on $M$. If $u$ is a constant (line L6), $r = u$ and a constant has the same value in every state. If $u$ is a fluent $F$ (line L7), $r = \Phi_{F,a}$, and $s \models \Phi_{F,a}$ if and only if $\mathrm{succ}(s, a)(F) = 1$, by the definition of succ. If $u = \neg v$ (line L8), the call on $v$ returns $r_v$ with $s \models r_v \iff \mathrm{succ}(s, a) \models v$ by the induction hypothesis, since $v$ has fewer nodes below it than $u$; by Lemma 0, $s \models r \iff s \not\models r_v \iff \mathrm{succ}(s, a) \not\models v \iff \mathrm{succ}(s, a) \models u$. The case $u = v \circ w$ (line L9) is the same with two calls; the call on $w$ may use entries that the call on $v$ added, and these have the property by the induction hypothesis. Line L10 adds the entry $(u, r)$, which has the property by the case analysis. $\square$

**Lemma 2 (REGRESS).** For every formula $\varphi$, every action list $[a_1, \ldots, a_n]$ and every state $s$,

$$s \models \mathrm{REGRESS}(\varphi, [a_1, \ldots, a_n]) \iff \mathrm{succ}(s, [a_1, \ldots, a_n]) \models \varphi.$$

*Proof.* Let $\varphi_n = \varphi$ and let $\varphi_{i-1}$ be the value of $\varphi$ after the loop body for $i$ (lines L2 and L3). We show by induction on $j = n, n - 1, \ldots, 0$ that for every state $s$, $s \models \varphi_j \iff \mathrm{succ}(s, [a_{j+1}, \ldots, a_n]) \models \varphi$. For $j = n$ the list is empty and both sides are $s \models \varphi$. For the step from $j$ to $j - 1$, line L2 makes an empty table, which satisfies the assumption of Lemma 1 for $a = a_j$. By Lemma 1, $s \models \varphi_{j-1} \iff \mathrm{succ}(s, a_j) \models \varphi_j$, and by the induction hypothesis applied to the state $\mathrm{succ}(s, a_j)$ this holds if and only if $\mathrm{succ}(\mathrm{succ}(s, a_j), [a_{j+1}, \ldots, a_n]) \models \varphi$, which is $\mathrm{succ}(s, [a_j, \ldots, a_n]) \models \varphi$. For $j = 0$ this is the claim. $\square$

**Theorem 1 (projection).** PROJECT returns true if and only if $\varphi$ holds in $\mathit{do}([a_1, \ldots, a_n], S_0)$ in every model of the theory.

*Proof.* By the semantics of the fragment, $\varphi$ holds in $\mathit{do}([a_1, \ldots, a_n], S_0)$ in every model if and only if $\mathrm{succ}(s_0, [a_1, \ldots, a_n]) \models \varphi$ for every model $s_0$ of $\mathcal{D}_{S_0}$. By Lemma 2 this holds if and only if every model of $\mathcal{D}_{S_0}$ satisfies REGRESS$(\varphi, [a_1, \ldots, a_n])$, that is, if and only if $\mathcal{D}_{S_0}$ entails it, which is what line L15 tests. $\square$

**Theorem 2 (executability).** EXECUTABLE-FORMULA$([a_1, \ldots, a_n])$ returns a formula $\chi_0$ such that, for every state $s$, $s \models \chi_0$ if and only if for each $i$ from 1 to $n$, $\mathrm{succ}(s, [a_1, \ldots, a_{i-1}]) \models \Pi_{a_i}$. So $\mathcal{D}_{S_0} \models \chi_0$ if and only if the sequence is executable in every model.

*Proof.* Let $\chi_n = \mathit{true}$ and let $\chi_{i-1}$ be the value after line L13 for $i$. We show by induction on $j = n, \ldots, 0$: for every state $s$, $s \models \chi_j$ if and only if $\mathrm{succ}(s, [a_{j+1}, \ldots, a_{i-1}]) \models \Pi_{a_i}$ for each $i$ with $j < i \le n$. For $j = n$ there is no such $i$ and $\chi_n = \mathit{true}$. For the step, $\chi_{j-1} = \Pi_{a_j} \wedge \mathrm{STEP}(\chi_j, a_j, \emptyset)$, so by Lemmas 0 and 1, $s \models \chi_{j-1}$ if and only if $s \models \Pi_{a_j}$ and $\mathrm{succ}(s, a_j) \models \chi_j$. By the induction hypothesis at the state $\mathrm{succ}(s, a_j)$, the second part says that $\mathrm{succ}(s, [a_j, a_{j+1}, \ldots, a_{i-1}]) \models \Pi_{a_i}$ for each $i$ with $j < i \le n$, and the first part is the case $i = j$. For $j = 0$ this is the claim. The second sentence follows from the semantics of $\mathit{Poss}$ and of $S_0$, as in Theorem 1. $\square$

**Termination and size.** The loop of line L1 runs $n$ times. Each call of STEP on a node not in $M$ adds that node to $M$ before it returns, and it calls STEP only on the children of the node, so each node of the current DAG is expanded at most once per step. The nodes that step $i$ creates are the nodes of the formulas $\Phi_{F,a_i}$ (these exist before the step) and at most one node from line L8 or L9 for each node of $\varphi_i$. So $|\varphi_{i-1}| \le |\varphi_i| + \sum_F |\Phi_{F,a_i}|$, and by induction $|\varphi_0| \le |\varphi| + \sum_{i=1}^{n} \sum_F |\Phi_{F,a_i}| \le q + n m$. $\square$
