We use the pseudocode of the page, lines L1 to L23, and a fixed vtree. For an SDD node $u$, $f_u$ is its function. For a vtree node $v$, $\mathrm{sub}(v)$ is the set of vtree nodes in the subtree of $v$. We say $u$ is **normal** if it is a constant, or a literal, or a decomposition at some $v$ that is compressed and trimmed and whose primes and subs are normal. Every node in the manager is made by `literal` or by line L18, so it suffices to show that the operations return normal nodes with the right functions.

**Lemma 0 (dependence).** Let $u$ be a normal decomposition at $v$. Then $f_u$ depends on some variable of $\mathrm{vars}(v^l)$ and on some variable of $\mathrm{vars}(v^r)$, and on no variable outside $\mathrm{vars}(v)$.

*Proof.* The last part holds because the primes and subs use only variables below $v$. Let $X = \mathrm{vars}(v^l)$. For an assignment $x$ to $X$, exactly one prime $p_i$ holds, and $f_u|x = s_i$. If $f_u$ did not depend on $X$, all $f_u|x$ would be equal, so all subs would be equal, and by compression there would be one element $(\mathit{true}, s_1)$, which trimming excludes. If $f_u$ did not depend on $\mathrm{vars}(v^r)$, each $f_u|x$ would be a constant, so each sub would be $\mathit{true}$ or $\mathit{false}$. By compression and since a partition has at least one element, the elements would be $\{(p, \mathit{true})\}$, $\{(p, \mathit{false})\}$ (both with $p = \mathit{true}$) or $\{(p, \mathit{true}), (\neg p, \mathit{false})\}$, and trimming excludes all three. $\square$

**Theorem 1 (canonicity; Darwiche 2011, Theorem 10).** If $u$ and $u'$ are normal and $f_u = f_{u'}$, then $u = u'$.

*Proof.* By induction on the size of the vtree subtree involved. Let $f = f_u = f_{u'}$ and let $D$ be the set of variables that $f$ depends on. If $D = \emptyset$, $f$ is a constant, and neither a literal nor (by Lemma 0) a decomposition has a constant function, so $u = u'$ is that constant. If $D = \{x\}$, $f$ is $x$ or $\neg x$, a decomposition depends on at least two variables by Lemma 0, so $u$ and $u'$ are the same literal. Otherwise $u$ and $u'$ are decompositions at $v$ and $v'$. By Lemma 0, $D \subseteq \mathrm{vars}(v)$ and $D$ meets both $\mathrm{vars}(v^l)$ and $\mathrm{vars}(v^r)$, so $v$ is the lowest common ancestor of the leaves of $D$. The same holds for $v'$, so $v = v'$. Let $X = \mathrm{vars}(v^l)$. In a compressed partition, the sub of the element whose prime holds at $x$ is $f|x$, so the subs are exactly the distinct functions $f|x$ and the prime of a sub $s$ is the set of $x$ with $f|x = s$. So $u$ and $u'$ have the same set of (prime function, sub function) pairs. The primes and subs are normal and respect smaller subtrees, so by induction equal functions give equal ids. The keys of $u$ and $u'$ are equal, and the unique table gives one id for one key. $\square$

**Lemma 2 (ELEMENTS).** If $u$ is normal, not a constant, and $\mathrm{vt}(u) \in \mathrm{sub}(v)$ for an inner node $v$, then ELEMENTS$(u, v)$ is a $\mathrm{vars}(v^l)$-partition of $f_u$ whose primes are normal and respect nodes in $\mathrm{sub}(v^l)$ or are $\mathit{true}$, and whose subs are normal and respect nodes in $\mathrm{sub}(v^r)$ or are constants.

*Proof.* Line L12 returns the elements of $u$, which have these properties by definition. At line L13, $f_u$ uses only variables of $v^l$, so $f_u = (f_u \wedge \mathit{true}) \vee (\neg f_u \wedge \mathit{false})$, and $f_u$ and $\neg f_u$ are both satisfiable because $f_u$ is not constant. NEGATE$(u)$ is normal and respects $\mathrm{vt}(u)$ by Lemma 4 below. At line L14, $f_u$ uses only variables of $v^r$, and $\{(\mathit{true}, u)\}$ is a partition. $\square$

**Lemma 3 (UNIQUE).** If $E$ is a $\mathrm{vars}(v^l)$-partition of a function $g$ with normal primes in $\mathrm{sub}(v^l)$ and normal subs in $\mathrm{sub}(v^r)$, then UNIQUE$(v, E)$ returns a normal node $r$ with $f_r = g$ and $\mathrm{vt}(r) \in \mathrm{sub}(v)$.

*Proof.* Line L15 replaces two elements $(p, s)$ and $(p', s)$ by $(p \vee p', s)$. Since $(p \wedge s) \vee (p' \wedge s) = (p \vee p') \wedge s$, the function is kept. The new prime is satisfiable and inconsistent with the other primes, and the primes still cover all assignments, so $E$ stays a partition. After the merges the subs are distinct. The primes $p \vee p'$ come from APPLY, which is normal and stays in $\mathrm{sub}(v^l)$ by Theorem 5 applied to smaller calls. At line L16, one element left means its prime is $\mathit{true}$ and $g = s$, a normal node in $\mathrm{sub}(v^r)$. At line L17, the primes $a$ and $b$ partition, so $b = \neg a$ and $g = (a \wedge \mathit{true}) \vee (\neg a \wedge \mathit{false}) = a$, a normal node in $\mathrm{sub}(v^l)$. Otherwise the node of line L18 is compressed and not of either trimmed form, so it is normal, and its function is $g$. $\square$

**Lemma 4 (NEGATE).** If $u$ is normal, NEGATE$(u)$ is normal, has the function $\neg f_u$, and respects $\mathrm{vt}(u)$ when $u$ is not constant.

*Proof.* By induction on $u$. Constants swap and line L19 is clear. At line L20, $\neg f_u = \bigvee_i (p_i \wedge \neg s_i)$, because exactly one prime holds at each assignment. The primes are unchanged, so $\{(p_i, \mathrm{NEGATE}(s_i))\}$ is a partition. The negated subs are distinct because negation is a bijection, so line L15 merges nothing. The set of subs equals $\{\mathit{true}, \mathit{false}\}$ only if the original set did, and a single element would need a single original element, which trimming excludes. So line L18 returns a decomposition at $\mathrm{vt}(u)$. $\square$

**Theorem 5 (APPLY).** If $\alpha$ and $\beta$ are normal, APPLY$(\alpha, \beta, \circ)$ returns a normal node $r$ with $f_r = f_\alpha \circ f_\beta$, and $r$ is a constant or $\mathrm{vt}(r)$ is in the subtree of the lowest common ancestor of $\mathrm{vt}(\alpha)$ and $\mathrm{vt}(\beta)$.

*Proof.* By induction on the calls, which terminate because each recursive call at lines L8, L9 and L15 is on nodes that respect proper subtrees of $v$ or on constants. Line L1: $\mathit{false} \wedge g = \mathit{false}$, $\mathit{true} \wedge g = g$, $g \wedge g = g$, and the duals for $\vee$; the returned node is one of the inputs or a constant. Line L2 returns a result computed earlier for the same input. Line L3: if $\mathrm{vt}(\alpha) = \mathrm{vt}(\beta)$ is a leaf and $\alpha \ne \beta$, the two nodes are $x$ and $\neg x$, and $x \wedge \neg x = \mathit{false}$, $x \vee \neg x = \mathit{true}$. Otherwise $v$ at line L4 is an inner node, because two nodes that respect one leaf are literals of one variable. By Lemma 2, ELEMENTS gives partitions $\{(p_i, s_i)\}$ of $f_\alpha$ and $\{(q_j, t_j)\}$ of $f_\beta$ over $X = \mathrm{vars}(v^l)$. For an assignment $x$ to $X$, exactly one $p_i$ and one $q_j$ hold, so exactly one product $p_i \wedge q_j$ holds, and there $(f_\alpha \circ f_\beta)|x = s_i \circ t_j$. Hence the products that are not $\mathit{false}$ (line L9) are satisfiable, pairwise inconsistent, cover all of $X$, and
$$f_\alpha \circ f_\beta = \bigvee_{i,j} (p_i \wedge q_j) \wedge (s_i \circ t_j).$$
By induction, $p_i \wedge q_j$ is normal in $\mathrm{sub}(v^l)$ or a constant, and $s_i \circ t_j$ is normal in $\mathrm{sub}(v^r)$ or a constant; a prime of $\mathit{true}$ arises only when both $p_i$ and $q_j$ are $\mathit{true}$, which is a partition of one element. So $E$ satisfies the condition of Lemma 3, and line L10 gives the claim. $\square$

**Lemma 6 (COUNT).** For a normal node $u$ and a vtree node $w$ with $u$ constant or $\mathrm{vt}(u) \in \mathrm{sub}(w)$, COUNT$(u, w)$ is the number of assignments to $\mathrm{vars}(w)$ that satisfy $f_u$.

*Proof.* Line L21 is clear. Let $c$ be the value of line L22; we show it is the number of models of $f_u$ over $\mathrm{vars}(\mathrm{vt}(u))$. A literal has one model over its variable. For a decomposition at $v$ with elements $(p_i, s_i)$, an assignment to $\mathrm{vars}(v)$ is a pair $(x, y)$ of assignments to $\mathrm{vars}(v^l)$ and $\mathrm{vars}(v^r)$. It satisfies $f_u$ if and only if it satisfies $p_i \wedge s_i$ for the unique $i$ with $x \models p_i$, that is, $x \models p_i$ and $y \models s_i$. The sets of such pairs for different $i$ are disjoint, so the count is $\sum_i \#p_i \cdot \#s_i$ with each count over the variables of $v^l$ and $v^r$, which is what line L22 computes by induction (the primes respect nodes in $\mathrm{sub}(v^l)$ and the subs nodes in $\mathrm{sub}(v^r)$). Finally $f_u$ does not use the variables of $\mathrm{vars}(w) \setminus \mathrm{vars}(\mathrm{vt}(u))$, so each model over $\mathrm{vars}(\mathrm{vt}(u))$ extends in $2^{|\mathrm{vars}(w)| - |\mathrm{vars}(\mathrm{vt}(u))|}$ ways, which is line L23. $\square$

**Corollary 7 (equivalence).** Two nodes of one manager have equal functions if and only if their ids are equal: every node is normal by Theorem 5 and Lemmas 3 and 4, and Theorem 1 applies. $\square$
