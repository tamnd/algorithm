This theorem is the complete answer to the question "which kinds of interval constraints can be solved fast?". For every set $S$ of relations of [Allen's interval algebra](/allens-interval-algebra/), consistency of networks with labels in $S$ is either in P or NP-complete, and it is in P exactly when $S$ is inside one of 18 explicit classes. Krokhin, Jeavons and Jonsson proved it in 2003. The [Nebel-Bürckert theorem](/nebel-burckert-theorem/) gives one of the 18, the [ORD-Horn subclass](/ord-horn-subclass/), with its proof; this page states the whole classification, which is an instance, for one infinite structure, of the [dichotomy](/csp-dichotomy-theorem/) pattern known for finite domains.

## Statement

For a set $S$ of interval relations, $\mathrm{CSP}(S)$ is the consistency problem of [qualitative constraint networks](/qualitative-constraint-network/) in which each pair has a label in $S$ or no constraint (the universal relation). A *subalgebra* is a set of relations closed under converse, intersection and composition. $\mathrm{CSP}(S)$ and $\mathrm{CSP}(\langle S \rangle)$, where $\langle S \rangle$ is the subalgebra generated by $S$, are equivalent under polynomial reductions: intersection is two constraints on one pair, converse is the same constraint read backwards, and $x \mathrel{(R \diamond T)} z$ is $x \mathrel{R} y$, $y \mathrel{T} z$ with a new interval $y$, since the interval table is strong.

> **Theorem (Krokhin, Jeavons and Jonsson 2003).** There are exactly 18 maximal tractable subalgebras of the interval algebra: the ORD-Horn class $\mathcal{H}$, the class $\mathcal{A}_{\equiv}$, the classes $\mathcal{S}_p$, $\mathcal{S}_d$, $\mathcal{S}_o$, $\mathcal{S}^{*}$, $\mathcal{E}_p$, $\mathcal{E}_d$, $\mathcal{E}_o$, $\mathcal{E}^{*}$, and the classes $\mathcal{A}_1, \ldots, \mathcal{A}_4$ and $\mathcal{B}_1, \ldots, \mathcal{B}_4$. For every set $S$ of relations: if $S$ is contained in one of the 18, $\mathrm{CSP}(S)$ is in P; otherwise $\mathrm{CSP}(S)$ is NP-complete.

Two of the classes are easy to describe. $\mathcal{H}$ has 868 relations, counting the empty one. $\mathcal{A}_{\equiv}$ consists of the $2^{12} = 4096$ relations that contain $eq$, plus the empty relation, 4097 in all. The $\mathcal{S}$ classes are defined through what a relation says about the starting points of the two intervals, and the $\mathcal{E}$ classes are their mirror images for the end points; the exact definitions of all 18 are in the paper.

## In plain words

Constraints between intervals can be easy or hard to solve, depending on which kinds you allow. This result lists every way to stay easy. There are eighteen largest easy families. If all your constraints belong to one family, a fast method decides whether they can be met. If they do not fit in any single family, the problem is as hard as any puzzle whose answers are easy to check. There is no middle ground. One family is the one of Nebel and Bürckert, the only one that allows every exact relation. Another is trivial: if every constraint allows the two intervals to be the same, make all intervals the same.

## Proof

*Proof sketch.* The theorem has two halves.

**Tractability.** Each of the 18 classes needs its own algorithm.

- $\mathcal{A}_{\equiv}$: if some label is empty, answer no; otherwise every label contains $eq$, and setting all intervals to $(0, 1)$ is a solution.
- $\mathcal{H}$: algebraic closure decides consistency, by the [Nebel-Bürckert theorem](/nebel-burckert-theorem/), with a full proof on that page.
- The $\mathcal{S}$ and $\mathcal{E}$ classes, found by Drakengren and Jonsson (1997): the algorithms first deal with what the labels say about the starting points (or end points), a [point algebra](/point-algebra/) problem, and then with the remaining constraints.
- The $\mathcal{A}_i$ and $\mathcal{B}_i$ classes: polynomial algorithms of the same kind, given in the 2003 paper.

**Hardness and completeness of the list.** Membership in NP holds for every $S$ ([NP-completeness of the interval algebra](/interval-algebra-np-completeness/)). For the rest, by the equivalence above it suffices to show that every subalgebra not contained in one of the 18 contains a relation set already known to be NP-complete. Krokhin, Jeavons and Jonsson do this by a long case analysis over the relations that generate such a subalgebra, using algebraic facts about the 18 classes to prune the cases. Each case ends in a set of relations that is NP-complete by a reduction in the style of the 3-SAT reduction for the full algebra. Finally, each of the 18 is maximal: adding any relation to it gives one of the hard sets. $\square$

## Consequences

- **Dichotomy.** No set of interval relations has a complexity strictly between P and NP-complete, unless P = NP.
- **A decision procedure for the question itself.** To know whether a given set $S$ is tractable, test whether $S$ lies inside one of 18 finite lists. A program can do this for any $S$ in time that depends only on the 8192 relations.
- **ORD-Horn is special.** It is the only one of the 18 that contains all 13 base relations, which is why it is the one used to split labels in complete search: a search that reaches base relations must stay inside a class that has them.
- **Outside the 18.** Any set of relations not inside one class gives an NP-complete problem, so for such labels a complete solver must search.

## Tightness

- **Maximal means maximal.** For each of the 18 classes $\mathcal{C}$ and each relation $R \notin \mathcal{C}$, $\mathrm{CSP}(\mathcal{C} \cup \{R\})$ is NP-complete.
- **Containment in one class.** A set that is covered by two classes together, but not contained in either, is NP-complete by the theorem. Being a union of tractable pieces is not enough.
- **Small hard sets.** The six labels $\{d\}$, $\{di\}$, $\{m, mi\}$, $\{b, bi\}$, $\{m, s, bi\}$ and $\{b, bi, m, mi\}$ of the 3-SAT reduction already give an NP-complete problem, so, unless P = NP, no one of the 18 contains them all.

## History

Vilain and Kautz (1986) proved the full algebra NP-hard. Van Beek and others showed the pointisable relations tractable, and Nebel and Bürckert (1995) found the maximal ORD-Horn class. Drakengren and Jonsson (1997) found several more maximal tractable classes that do not contain all base relations. Krokhin, Jeavons and Jonsson published the complete classification in the Journal of the ACM in 2003, using the algebraic methods developed for finite-domain constraint problems.
