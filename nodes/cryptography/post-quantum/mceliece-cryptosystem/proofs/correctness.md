title: McEliece decryption recovers the message, because Patterson's algorithm corrects t errors of a binary Goppa code
proves: [correctness]
status: full

We use the notation of the page. $g \in \mathbb{F}_{2^m}[x]$ is irreducible of degree $t \ge 2$, so it has no root in $\mathbb{F}_{2^m}$ and no repeated factor. $L = (\alpha_1, \ldots, \alpha_n)$ are distinct elements of $\mathbb{F}_{2^m}$. For $y \in \mathbb{F}_2^n$ let $S_y(x) = \sum_i y_i (x - \alpha_i)^{-1} \bmod g$, where each inverse exists because $g(\alpha_i) \ne 0$. The Goppa code is $\Gamma = \{c : S_c = 0\}$. The ring $K = \mathbb{F}_{2^m}[x]/(g)$ is a field with $2^{mt}$ elements.

**Lemma 1 (the error locator).** Let $e \ne 0$ with support $E$, and $\sigma(x) = \prod_{i \in E}(x - \alpha_i)$. Then $S_e \sigma \equiv \sigma' \pmod g$, and $\gcd(\sigma, g) = 1$.

*Proof.* In $\mathbb{F}_{2^m}[x]$, $\sigma' = \sum_{i \in E} \prod_{j \in E, j \ne i}(x - \alpha_j)$ by the product rule. Modulo $g$, $(x - \alpha_i)^{-1}\sigma \equiv \prod_{j \ne i}(x - \alpha_j)$ because both sides times $(x - \alpha_i)$ are $\sigma$, and $x - \alpha_i$ is invertible modulo $g$. Summing over $i \in E$ gives $S_e \sigma \equiv \sigma'$. The roots of $\sigma$ are the $\alpha_i$, which are not roots of $g$, and $g$ is irreducible of degree at least 2, so $\gcd(\sigma, g) = 1$. $\square$

**Lemma 2 (minimum distance).** Every nonzero $c \in \Gamma$ has weight at least $2t + 1$. So for each $y$ there is at most one $e$ with $\mathrm{wt}(e) \le t$ and $y + e \in \Gamma$.

*Proof.* Let $c \in \Gamma$ be nonzero with support $E$ and locator $\sigma$. By Lemma 1, $\sigma' \equiv S_c\sigma \equiv 0 \pmod g$. In characteristic 2, $\sigma'$ has only even powers of $x$, so $\sigma' = \rho^2$ for some polynomial $\rho$ (take the square root of each coefficient, which exists in $\mathbb{F}_{2^m}$). Then $g \mid \rho^2$, and since $g$ is irreducible, $g \mid \rho$, so $g^2 \mid \sigma'$. Also $\sigma' \ne 0$: $\sigma$ has distinct roots, so it is coprime to its derivative, and $\sigma' = 0$ would make $\sigma$ a square. So $2t \le \deg \sigma' \le |E| - 1$, and $|E| \ge 2t + 1$. If $y + e_1$ and $y + e_2$ are both in $\Gamma$ with weights at most $t$, then $e_1 + e_2 \in \Gamma$ has weight at most $2t$, so $e_1 = e_2$. $\square$

**Lemma 3 (Patterson's key equation).** Let $e \ne 0$ with $\mathrm{wt}(e) \le t$, and write $\sigma = a_0^2 + x b_0^2$, where $a_0^2$ collects the even powers of $\sigma$ and $x b_0^2$ the odd ones. Let $T = S_e^{-1} \bmod g$. Then $\sigma' = b_0^2$, $\deg a_0 \le \lfloor t/2 \rfloor$, $\deg b_0 \le \lfloor (t-1)/2 \rfloor$, and $(T + x) b_0^2 \equiv a_0^2 \pmod g$. If $\tau \in K$ is the square root of $T + x$, then $a_0 \equiv \tau b_0 \pmod g$.

*Proof.* The split into even and odd powers, with square roots of the coefficients, gives $a_0$ and $b_0$, and $\deg \sigma = \mathrm{wt}(e) \le t$ gives the degree bounds. The derivative of $a_0^2$ is 0 and the derivative of $x b_0^2$ is $b_0^2$ in characteristic 2, so $\sigma' = b_0^2$. $S_e \ne 0$ in $K$: otherwise Lemma 1 gives $g \mid \sigma'$, and the argument of Lemma 2 gives $\mathrm{wt}(e) \ge 2t + 1$. So $T$ exists. By Lemma 1, $S_e(a_0^2 + x b_0^2) \equiv b_0^2$; multiplying by $T$ gives $a_0^2 + x b_0^2 \equiv T b_0^2$, so $a_0^2 \equiv (T + x) b_0^2 = \tau^2 b_0^2$. Squaring is injective on the field $K$, so $a_0 \equiv \tau b_0$. $\square$

**Lemma 4 (the Euclidean step).** Run the extended Euclidean algorithm on $r_{-1} = g$, $r_0 = \tau$ with $v_{-1} = 0$, $v_0 = 1$, so that $r_i = u_i g + v_i \tau$ for polynomials $u_i$, and $\deg v_i = t - \deg r_{i-1}$, at each step. Stop at the first $i$ with $\deg r_i \le \lfloor t/2 \rfloor$. Then $(r_i, v_i) = \mu (a_0, b_0)$ for a nonzero constant $\mu$. If $T = x$, then $\tau = 0$ and $\sigma = x$.

*Proof.* The identity $r_i = u_i g + v_i \tau$, the degree formula $\deg v_i = t - \deg r_{i-1}$, and $\gcd(u_i, v_i) = 1$ are the standard invariants of the extended Euclidean algorithm. At the stopping index, $\deg r_{i-1} > \lfloor t/2 \rfloor$, so $\deg v_i = t - \deg r_{i-1} \le t - \lfloor t/2 \rfloor - 1 = \lceil t/2 \rceil - 1 = \lfloor (t-1)/2 \rfloor$. Now $r_i \equiv v_i \tau$ and $a_0 \equiv b_0 \tau$ give $r_i b_0 \equiv v_i a_0 \pmod g$. Both sides have degree at most $\lfloor t/2 \rfloor + \lfloor (t-1)/2 \rfloor = t - 1 < t$, so $r_i b_0 = v_i a_0$ as polynomials. The pair $(a_0, b_0)$ is coprime: a common factor would divide $\sigma = a_0^2 + x b_0^2$ twice, but $\sigma$ has distinct roots, and a common constant does not matter. The pair $(r_i, v_i)$ is also coprime: a common factor $d$ divides $u_i g = r_i - v_i \tau$, and it is coprime to $u_i$ because it divides $v_i$, so $d \mid g$; since $g$ is irreducible of degree $t > \deg v_i$, $d$ is a constant. So $(r_i, v_i) = \mu(a_0, b_0)$ for a constant $\mu \ne 0$. If $T = x$, then $(T + x) b_0^2 \equiv 0$, so $a_0^2 \equiv 0$, and with $\deg a_0 < t$ this gives $a_0 = 0$, so $\sigma = x b_0^2$ with distinct roots, which forces $\sigma = x$ up to a constant. $\square$

**Theorem (correctness of decryption).** For every message $m \in \mathbb{F}_2^k$ and every error $e$ of weight $t$, DECRYPT(sk, ENCRYPT(pk, m)) returns $m$.

*Proof.* Let $c = mG' + e = mSGP + e$. Line L7 computes $y = cP^{-1} = (mS)G + eP^{-1}$, where $(mS)G \in \Gamma$ and $e_1 = eP^{-1}$ has weight $t$, because $P$ only permutes the positions. Since $S_y = S_{e_1}$, Lemmas 3 and 4 show that lines P2 to P6 compute $\sigma = \mu^2 (a_0^2 + x b_0^2) = \mu^2 \sigma_{e_1}$, which has the same roots as the locator of $e_1$. Line P7 marks exactly the positions $i$ with $\sigma(\alpha_i) = 0$, which are the support of $e_1$ because the $\alpha_i$ are distinct. So line L8 returns $e' = e_1$. Then $y + e' = (mS)G$. The rows of $G$ are a basis of $\Gamma$, so $u = mS$ is the unique solution of $uG = y + e'$ in line L9, and line L10 returns $uS^{-1} = m$. $\blacksquare$
