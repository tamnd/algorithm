---
title: Correctness of GDH.2
proves: [correctness]
status: full
---

We prove that in an honest run of GDH.2 every member outputs $K = g^{x_1 x_2 \cdots x_n}$, that no membership check fails, and that the exp counts are those of the page. Notation is that of the page: $G$ is the subgroup of order $q$ generated by $g$, $\pi(S) = \prod_{j \in S} x_j \bmod q$, $[i] = \{1, \ldots, i\}$, and all exponents are taken modulo $q$.

**Lemma 1 (values stay in G and are not 1).** Every value that a member raises in an honest run is $g^{e}$ with $e \not\equiv 0 \pmod q$, so it lies in $G \setminus \{1\}$ and the membership check passes.

*Proof.* Every value is $g^{\pi(S)}$ for some set $S$, including $S = \emptyset$, which gives $g$. Each $x_j \in [1, q)$ and $q$ is prime, so $\pi(S) \not\equiv 0$, and $g^{\pi(S)} \ne 1$ because $g$ has order $q$. A power of $g$ lies in $G$. $\square$

**Lemma 2 (upflow invariant).** For $1 \le i \le n - 1$, the flow that $M_i$ sends in line L4 is
$$\Bigl(\bigl(g^{\pi([i] \setminus \{1\})}, g^{\pi([i] \setminus \{2\})}, \ldots, g^{\pi([i] \setminus \{i\})}\bigr),\ g^{\pi([i])}\Bigr).$$

*Proof.* By induction on $i$. For $i = 1$, $M_1$ receives $((), g)$ from line L1; line L2 gives $P = (g)$ and line L3 gives $c = g^{x_1}$. Since $\pi(\emptyset) = 1$, $g = g^{\pi([1] \setminus \{1\})}$, and $g^{x_1} = g^{\pi([1])}$.

Assume the claim for $i - 1 \ge 1$. $M_i$ receives partial values $g^{\pi([i-1] \setminus \{k\})}$ for $k \in [i-1]$ and the cardinal value $g^{\pi([i-1])}$. For $k < i$, line L2 raises $g^{\pi([i-1] \setminus \{k\})}$ to $x_i$ and gets $g^{\pi([i-1] \setminus \{k\}) x_i} = g^{\pi([i] \setminus \{k\})}$, since $i \notin [i-1] \setminus \{k\}$. It then appends the received cardinal value $g^{\pi([i-1])} = g^{\pi([i] \setminus \{i\})}$ at position $i$. Line L3 gives $g^{\pi([i-1]) x_i} = g^{\pi([i])}$. $\square$

**Lemma 3 (the broadcast).** The list $B$ of line L6 satisfies $B[k] = g^{\pi([n] \setminus \{k\})}$ for $1 \le k \le n - 1$, and line L5 gives $K = g^{\pi([n])}$.

*Proof.* By Lemma 2 with $i = n - 1$, $M_n$ receives the partial values $g^{\pi([n-1] \setminus \{k\})}$ and the cardinal value $g^{\pi([n-1])}$. Raising to $x_n$ adds $n$ to each index set. $\square$

**Lemma 4 (exp counts).** $M_i$ with $i < n$ does $i + 1$ exps, $M_n$ does $n$, and the total is $(n^2 + 3n)/2 - 1$.

*Proof.* By Lemma 2, $M_i$ receives $i - 1$ partial values, so line L2 does $i - 1$ exps and line L3 one; line L7 adds one, for $i + 1$. $M_n$ does one exp in line L5 and $n - 1$ in line L6. The total is $\sum_{i=1}^{n-1} (i + 1) + n = \frac{(n-1)n}{2} + (n - 1) + n = \frac{n^2 + 3n}{2} - 1$. $\square$

**Theorem.** In an honest run of GDH.2 with $n \ge 2$ members, every member outputs $K = g^{x_1 x_2 \cdots x_n}$, after $n$ rounds and $n$ messages, with the exp counts of Lemma 4.

*Proof.* Lemma 1 shows that no check fails. Lemma 3 gives the key of $M_n$. For $i < n$, line L7 computes $B[i]^{x_i} = g^{\pi([n] \setminus \{i\}) x_i} = g^{\pi([n])}$ by Lemma 3. The upflow uses $n - 1$ rounds with one message each, and the broadcast one more round and message. $\blacksquare$
