---
title: Correctness of the Ingemarsson-Tang-Wong protocol
proves: [correctness]
status: full
---

We prove that in an honest run every member outputs $K = g^{x_1 x_2 \cdots x_n}$, that no membership check fails, and that the costs are those of the page. Notation is that of the page: indices are taken modulo $n$, $G$ is the subgroup of prime order $q$ generated by $g$, all exponents are taken modulo $q$, and for $r \ge 0$ we write $\pi(i - r, i) = x_{i-r} x_{i-r+1} \cdots x_i \bmod q$, a product of $r + 1$ factors.

**Lemma 1 (round invariant).** For $0 \le r \le n - 1$, after $r$ rounds (with round 0 meaning after line L2), $h_i = g^{\pi(i - r, i)}$ for every $i$.

*Proof.* By induction on $r$. For $r = 0$, line L2 gives $h_i = g^{x_i} = g^{\pi(i, i)}$. Assume the claim after $r$ rounds, with $r < n - 1$. In round $r + 1$, line L4 delivers to $M_i$ the value that $M_{i-1}$ held after round $r$, which is $g^{\pi(i - 1 - r, i - 1)}$, and line L5 raises it to $x_i$. The result is $g^{\pi(i - 1 - r, i - 1) x_i} = g^{\pi(i - (r + 1), i)}$. All members update at the same time from the values of round $r$, so the claim holds after round $r + 1$. $\square$

**Lemma 2 (each secret once).** For every $i$, $\pi(i - n + 1, i) = x_1 x_2 \cdots x_n \bmod q$.

*Proof.* The indices $i - n + 1, \ldots, i$ are $n$ consecutive integers, so modulo $n$ they are $n$ distinct residues, that is, all of $1, \ldots, n$, each once. Multiplication modulo $q$ is commutative, so the product is $x_1 \cdots x_n$. $\square$

**Lemma 3 (checks pass).** In an honest run, every value received in line L4 lies in $G$.

*Proof.* By Lemma 1, each received value is a power of $g$, so it lies in $G$. It is not 1: its exponent is a product of elements of $[1, q)$ with $q$ prime, so it is not $0 \bmod q$, and $g$ has order $q$. The code checks $1 < v < p$ and $v^q \equiv 1$, which every element of $G \setminus \{1\}$ satisfies. $\square$

**Theorem.** In an honest run with $n \ge 2$ members, every member outputs $K = g^{x_1 \cdots x_n}$ after $n - 1$ rounds, $n(n - 1)$ messages and $n$ exps per member.

*Proof.* By Lemma 3 no member aborts. By Lemma 1 with $r = n - 1$ and Lemma 2, $h_i = g^{x_1 \cdots x_n}$ for all $i$. Line L3 runs $n - 1$ rounds, and in each round each of the $n$ members sends one message and does one exp; line L2 adds one exp per member, for $n$ in total. $\blacksquare$
