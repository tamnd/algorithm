---
title: Correctness of the Burmester-Desmedt protocol
proves: [correctness]
status: full
---

We prove that in an honest run every member outputs $K = g^{x_1 x_2 + x_2 x_3 + \cdots + x_n x_1}$, that the membership checks pass, and that the product of all round-2 values is 1. Notation is that of the page: indices are taken modulo $n$, $G$ is the subgroup of prime order $q$ generated by $g$, exponents are taken modulo $q$, and $k_j = g^{x_j x_{j+1}}$.

**Lemma 1 (round-2 values).** For every $i$, $X_i = k_i / k_{i-1} = g^{x_i x_{i+1} - x_{i-1} x_i}$.

*Proof.* Line L2 computes $(z_{i+1} z_{i-1}^{-1})^{x_i} = (g^{x_{i+1} - x_{i-1}})^{x_i} = g^{x_i x_{i+1} - x_{i-1} x_i}$, which is $k_i k_{i-1}^{-1}$. This holds for every $n \ge 2$; for $n = 2$, $i + 1 \equiv i - 1$, so $k_i = k_{i-1}$ and $X_i = 1$. $\square$

**Lemma 2 (checks pass).** In an honest run, every $z_j$ lies in $G \setminus \{1\}$, and every $X_j$ lies in $G$; if $n \ge 3$, $X_j \ne 1$ except with probability at most $n/(q-1)$ over the choice of secrets.

*Proof.* $z_j = g^{x_j}$ with $x_j \in [1, q)$, so $z_j \in G \setminus \{1\}$. $X_j$ is a power of $g$, so $X_j \in G$. $X_j = 1$ if and only if $x_j (x_{j+1} - x_{j-1}) \equiv 0$, that is, $x_{j+1} = x_{j-1}$, since $x_j \ne 0$ and $q$ is prime. For $n \ge 3$ these are different members, so for fixed $x_{j-1}$ this holds with probability $1/(q-1)$ over $x_{j+1}$; a union bound over $j$ gives $n/(q-1)$. For $n = 2$, the check accepts $X_j = 1$. For $n \ge 3$, the check of the code requires $X_j \ne 1$, so an honest run aborts with probability at most $n/(q-1)$, which is negligible. $\square$

**Lemma 3 (the walk).** In the computation of member $M_i$, after $j$ passes of line L5 ($0 \le j \le n - 1$), $y = k_{i+j-1}$ and $K = \prod_{t=0}^{j} k_{i+t-1}$.

*Proof.* By induction on $j$. For $j = 0$, line L3 gives $y = z_{i-1}^{x_i} = g^{x_{i-1} x_i} = k_{i-1}$ and $K = k_{i-1}$. If the claim holds for $j - 1$, then line L5 gives $y = k_{i+j-2} \cdot X_{i+j-1} = k_{i+j-2} \cdot k_{i+j-1} / k_{i+j-2} = k_{i+j-1}$ by Lemma 1, and line L6 multiplies $K$ by it. $\square$

**Lemma 4 (product of round-2 values).** $\prod_{j=1}^{n} X_j = 1$.

*Proof.* By Lemma 1 the product is $\prod_j k_j / \prod_j k_{j-1}$, and both products run over all $n$ residues modulo $n$, so they are equal. $\square$

**Theorem.** In an honest run with $n \ge 2$ members, except with probability at most $n/(q-1)$ when $n \ge 3$, every member outputs $K = g^{\sum_{j=1}^{n} x_j x_{j+1}}$, after 2 rounds, $2n$ broadcast messages and 3 exps per member.

*Proof.* Lemma 2 shows that no honest member aborts, except with the stated probability. By Lemma 3 with $j = n - 1$, member $M_i$ outputs $\prod_{t=0}^{n-1} k_{i+t-1}$. The indices $i - 1, i, \ldots, i + n - 2$ are $n$ consecutive integers, so modulo $n$ they cover each residue once, and the product is $\prod_{j=1}^{n} k_j = g^{\sum_j x_j x_{j+1}}$, the same for every $i$. Each member sends one message in each of the 2 rounds and does exps only in lines L1, L2 and L3. $\blacksquare$
