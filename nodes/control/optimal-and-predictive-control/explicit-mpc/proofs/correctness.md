---
title: The critical regions of the independent active sets cover the feasible states, and on each region the MPC input is the stored affine law
proves: [correctness]
status: full
---

The MPC problem at the state $x \in \mathbb{R}^{n}$ is the multiparametric quadratic program

$$\min_z \ \tfrac12 z^T H z + x^T F^T z \quad \text{subject to} \quad G z \le w + E x,$$

with $H = H^T > 0$, $z \in \mathbb{R}^{s}$ and $q$ rows $g_i^T$ in $G$. For a fixed $x$ the problem is strictly convex, so if it is feasible it has exactly one minimizer $z^*(x)$, and $z$ is that minimizer if and only if there is $\lambda \in \mathbb{R}^q$ with

$$H z + F x + G^T \lambda = 0, \quad G z \le w + E x, \quad \lambda \ge 0, \quad \lambda_i (w_i + E_i x - g_i^T z) = 0. \tag{KKT}$$

Let $X$ be the box of states given to the algorithm and $S = \{x \in X : \text{the QP is feasible at } x\}$. The set $S$ is the projection of the polyhedron $\{(z, x) : G z \le w + E x, x \in X\}$, so it is a convex polyhedron.

## Lemma 1: the affine law of one active set

Let $A \subseteq \{1, \dots, q\}$ be a set whose rows $G_A$ are linearly independent. Then the system

$$H z + F x + G_A^T \lambda_A = 0, \qquad G_A z = w_A + E_A x$$

has, for every $x$, exactly one solution, given by

$$\lambda_A(x) = -M^{-1} \big(w_A + (E_A + G_A H^{-1} F) x\big), \qquad z_A(x) = -H^{-1} \big(F x + G_A^T \lambda_A(x)\big), \qquad M = G_A H^{-1} G_A^T.$$

*Proof.* $M$ is positive definite: for $v \ne 0$, $G_A^T v \ne 0$ by independence, so $v^T M v = (G_A^T v)^T H^{-1} (G_A^T v) > 0$. The first equation gives $z = -H^{-1}(F x + G_A^T \lambda_A)$. Substituting it into the second gives $-G_A H^{-1} F x - M \lambda_A = w_A + E_A x$, which has the single solution stated. $\square$

These are lines L3 to L5. Both maps are affine in $x$, so line L6 defines a polyhedron

$$CR_A = \{x \in X : G z_A(x) \le w + E x, \ \lambda_A(x) \ge 0\}.$$

## Lemma 2: inside a region the law is optimal

If $x \in CR_A$, then $z_A(x) = z^*(x)$, and $\lambda$ equal to $\lambda_A(x)$ on $A$ and 0 elsewhere is a KKT multiplier.

*Proof.* Stationarity holds by Lemma 1. Feasibility and $\lambda_A \ge 0$ are the inequalities of $CR_A$. Complementarity holds because $\lambda_i = 0$ off $A$ and the rows in $A$ hold with equality. So (KKT) holds, and $z_A(x)$ is the unique minimizer. $\square$

## Lemma 3: every feasible state is in some region

If $x \in S$, there is a set $A$ with independent rows and $x \in CR_A$.

*Proof.* Let $z^* = z^*(x)$ and let $I$ be the set of active rows at $z^*$. By (KKT), $-(H z^* + F x)$ lies in the cone generated by $\{g_i : i \in I\}$. By Carathéodory's theorem for cones, it is a nonnegative combination $\sum_{i \in A} \mu_i g_i$ of a subset $A \subseteq I$ whose vectors are linearly independent. Then $z^*$ and $\mu$ solve the system of Lemma 1 for this $A$, because the rows in $A$ are active, and by uniqueness $z_A(x) = z^*$ and $\lambda_A(x) = \mu \ge 0$. Since $z^*$ is feasible, $x \in CR_A$. $\square$

Lemma 3 is why the enumeration of line L2 only needs sets of at most $s$ rows: an independent set in $\mathbb{R}^s$ has at most $s$ elements.

## Theorem 1: the kept regions cover the feasible box

Assume $S$ has an interior point. Let $D$ be the union of the regions $CR_A$ that have an interior point (the ones kept by line L7 in exact arithmetic, where the test is radius $> 0$). Then $D = S$.

*Proof.* Each $CR_A \subseteq S$ by Lemma 2, so $D \subseteq S$. By Lemma 3, $S$ is the union of all the regions, of which there are finitely many. Suppose $x \in S \setminus D$. $D$ is a finite union of closed sets, so it is closed, and some open ball $U$ around $x$ misses $D$. Because $S$ is convex with an interior point and $x \in S$, the set $U \cap \operatorname{int} S$ is open and not empty (the segment from $x$ to an interior point of $S$ enters $\operatorname{int} S$ at once). This open set lies in the union of the regions without interior points. Each of them lies in a proper affine subspace, which has Lebesgue measure 0, and a finite union of null sets cannot contain a nonempty open set. This is a contradiction. $\square$

The Chebyshev radius computed in line L7 is positive if and only if the polyhedron has an interior point, because a polyhedron with an interior point contains a ball and a ball is an interior neighborhood of its center. In floating point the code keeps a region only when the radius exceeds a small $\varepsilon$, so a region thinner than $\varepsilon$ can be lost, and the search then finds no region for the states inside it. With $\varepsilon = 0$ in exact arithmetic nothing is lost.

## Theorem 2: the online evaluation is correct

For $x \in S$, lines L9 to L11 return $z^*(x)$. For $x \in X \setminus S$ they report that no region contains $x$.

*Proof.* If $x \in S$, Theorem 1 gives a kept region that contains $x$, so the search finds a first region $CR_A \ni x$ and returns $z_A(x)$, which is $z^*(x)$ by Lemma 2. Different regions may share boundary points, but every region that contains $x$ gives the same value, since the minimizer is unique. If $x \notin S$, no region contains $x$, because every region lies in $S$. $\square$

## Consequences: continuity and convexity

**The law is continuous on $S$.** On each kept region $z^*$ is affine, so continuous. The regions are finitely many closed sets that cover $S$, and on any intersection the affine laws agree (both equal $z^*$). By the pasting lemma for finitely many closed sets, $z^*$ is continuous on $S$.

**The value function is convex and piecewise quadratic.** For the MPC cost, the horizon cost is $J(x, z) = z^T H z + 2 x^T F^T z + x^T Y x$ with the block matrix $\begin{bmatrix} H & F \\ F^T & Y \end{bmatrix} \ge 0$, because $J$ is a sum of nonnegative quadratic terms in $(z, x)$. The set $\{(z, x) : G z \le w + E x\}$ is convex. The minimum of a jointly convex function over the $z$ section of a convex set is a convex function of $x$, so $V(x) = \min_z J(x, z)$ is convex on $S$. On each region $V(x) = J(x, z_A(x))$ is quadratic in $x$.

## Limits of the enumeration

The algorithm needs neither strict complementarity nor a nondegenerate problem: Lemma 3 picks an independent subset of the active rows even when more than $s$ rows are active at the solution. The price is the enumeration of $\sum_{k \le s} \binom{q}{k}$ sets, each with an $s \times s$ solve and a linear program. When $S$ has no interior point (for example when equality constraints are written as two inequalities), Theorem 1 does not apply and the radius test drops every region; such problems must first be reduced to a lower dimension.
