---
title: The chain method with fractional cascading answers every query correctly
proves: [correctness, termination]
status: full
---

**Setting.** $G$ is a regular planar straight-line graph with $n$ edges, vertices $v_1 <_{\mathrm{lex}} \cdots <_{\mathrm{lex}} v_N$ and $f$ bounded faces. All statements are in the sheared plane of the page, where the order of $x$-coordinates is $<_{\mathrm{lex}}$, so no edge is vertical. Each edge $(a, b)$ has $a <_{\mathrm{lex}} b$, its upper side is its left side, and it *spans* $q$ if $a <_{\mathrm{lex}} q <_{\mathrm{lex}} b$. The faces are numbered as in line L2, the outer face counts as $0$ below an edge and as $f + 1$ above it, and $C_j$ is the upper boundary of the union $U_j$ of the outer part below the graph and the faces $1, \ldots, j$. The query point $q$ is not a vertex and $v_1 <_{\mathrm{lex}} q <_{\mathrm{lex}} v_N$; the other cases end before line L6 and are correct by inspection.

**Claim.** MLOC-QUERY stops after one pass down the tree and returns the edge that contains $q$ in its relative interior if there is one, and otherwise the face answer (high, low): the lowest edge that spans $q$ and lies above $q$, and the highest edge that spans $q$ and lies below $q$, or nil.

**Step 1 (the chains).** By the [monotone subdivision](/monotone-subdivision/) page (Theorem 2 and its construction), the relation "directly below" is acyclic, so line L2 succeeds, and $C_0, \ldots, C_f$ are $x$-monotone chains from $v_1$ to $v_N$ along edges of $G$ with: (i) every edge is in some chain; (ii) $C_{j}$ is nowhere above $C_{j+1}$. An edge $e$ is on the upper boundary of $U_j$ exactly when the region on its lower side is in $U_j$ and the region on its upper side is not, that is, when $\mathrm{lo}(e) \le j$ and $j + 1 \le \mathrm{hi}(e) + 1$. So the chains through $e$ are $C_{\mathrm{lo}(e)}, \ldots, C_{\mathrm{hi}(e)}$, as line L3 records. Since $C_j$ is $x$-monotone and $q$ is strictly between $v_1$ and $v_N$ and not a vertex, $q$ is strictly between two consecutive vertices of $C_j$, so exactly one edge $s_j$ of $C_j$ spans $q$. Say that $q$ is *above* $C_j$ if $\mathrm{orient}(s_j) > 0$, *on* it if $= 0$, and *below* it if $< 0$, where $\mathrm{orient}(s) = \mathrm{orient}(a, b, q)$ for $s = (a, b)$. By (ii), the heights of $s_0, \ldots, s_f$ at the sheared $x$ of $q$ are non-decreasing, so the set of $j$ with $q$ above $C_j$ is an initial segment $0, \ldots, t$ (with $t = -1$ if it is empty), and the set with $q$ below $C_j$ is a final segment. Extend this to the keys $j + 1 > f + 1$ by declaring $q$ below the missing chains, which keeps both properties.

**Step 2 (the storage rule).** In the implicit tree, a key $m$ with exactly $z$ trailing zeros has the subtree with the keys $m - 2^z + 1, \ldots, m + 2^z - 1$, and its children are $m \pm 2^{z-1}$. Let $I = [x, y]$ be an interval of keys and $m$ a key of $I$ with the most trailing zeros, $z$ of them. Then $m - 2^z$ and $m + 2^z$ are multiples of $2^{z+1}$, so they are not in $I$, and $I$ lies inside the subtree of $m$. Two keys with $z$ trailing zeros differ by at least $2^{z+1}$ and have a multiple of $2^{z+1}$ between them, so $m$ is unique; this is the value computed by `top_node`. Line L4 stores $e$ at the key $m(e)$ of $[\mathrm{lo}(e) + 1, \mathrm{hi}(e) + 1]$ with this property, so every key $j + 1$ with $C_j \ni e$ lies in the subtree of $m(e)$. In particular, the spanning edge $s_j$ is stored at node $j + 1$ or at an ancestor of it. All edges of $L(m)$ are in the chain $C_{m-1}$, so their $x$-ranges are disjoint, and sorted by left end point they are also sorted by right end point.

**Step 3 (the cascading invariant).** Claim: at every node $m$ visited by the query, $\mathrm{pos}$ equals the number of keys of $A(m)$ smaller than $q$. At the root this is line L6. Suppose it holds at $m$ and the search goes to the child $c$. The pointer $\mathrm{down}(\mathrm{pos})$ is the number of keys of $A(c)$ at most the $\mathrm{pos}$-th key of $A(m)$, which is smaller than $q$, or $0$ if $\mathrm{pos} = 0$. So all these keys of $A(c)$ are smaller than $q$, and the loop of line L9, which walks over the sorted list $A(c)$ while the keys are smaller than $q$, ends at the number of keys of $A(c)$ smaller than $q$. No key equals $q$, since keys are vertices. Now let $e$ be the edge of $L(m)$ that spans $q$, if there is one. Its key is smaller than $q$. Any own key after it and smaller than $q$ would belong to an edge of $L(m)$ that starts after $e$ starts and before $q$, so before $e$ ends, which contradicts Step 2. So $e$ is $\mathrm{nat}(m, \mathrm{pos})$, the last own edge among the keys smaller than $q$. Conversely, the code accepts $\mathrm{nat}(m, \mathrm{pos})$ only if $q$ is before its right end, that is, only if it spans $q$. So at node $m$ with $j = m - 1 \le f$, the code finds an edge exactly when $s_j \in L(m)$, and the edge it finds is $s_j$. With `cascade=False` the same holds by a binary search in the sorted keys of $L(m)$.

**Step 4 (the decisions).** Claim: at every visited node with chain index $j$, the variable $\mathrm{above}$ is true exactly when $q$ is above $C_j$ (with $q$ never on $C_j$, or the query has returned), and after the node, $\mathrm{low}$ is $s_i$ for the largest index $i$ visited so far with a true decision, and $\mathrm{high}$ is $s_i$ for the smallest index $i$ visited so far with a false decision at which $s_i$ was tested (nil if there is none).

Proof by induction along the path. Nodes with $j > f$ decide false, which is correct by the convention of Step 1. If line L8 runs, the edge is $s_j$ by Step 3: $\mathrm{orient}(s_j) = 0$ means that $q$ is on the line of $s_j$ and strictly inside its $x$-range, so in its relative interior, and the return is correct; otherwise the decision is the definition of above.

Let line L7 run at node $m = j + 1$. By Step 3, $s_j \notin L(m)$, so by Step 2 it is stored at a proper ancestor $a$ of $m$, which the search visited, and at $a$ the code found $s_j$ itself (Step 3) and tested it. Every visited node with a true decision lies to the left of $m$ in the in-order, and every node with a false decision lies to the right, by the search tree property. If $q$ is above $s_j$, then the decision at $a$ was true and $\mathrm{low}$ became $s_j$ there. The indices $i$ visited between $a$ and $m$ with a true decision satisfy $a - 1 < i < j$, so $s_j \in C_i$ by the contiguous range of Step 1, hence $s_i = s_j$; so $\mathrm{low} = s_j$ now, and $\mathrm{hi}(\mathrm{low}) \ge j$, a true decision. If $q$ is below $s_j$, then either $\mathrm{low}$ is nil and the decision is false, or $\mathrm{low} = s_i$ for a visited index $i < j$ with $q$ above $s_i$. If $\mathrm{hi}(s_i) \ge j$, then $s_i \in C_j$ by the contiguous range, and $s_i = s_j$, with $q$ both above and below it, which is impossible. So $\mathrm{hi}(\mathrm{low}) < j$, a false decision. In both cases the decision is correct, and line L7 changes neither variable; the variables keep their meaning because the new decision at $j$ is about the same edge $s_j$ that is already recorded.

**Step 5 (termination and the answer).** Each iteration moves to a child, so the loop ends at a leaf after $k$ iterations, unless it returns an edge. By Step 4 every decision is correct, so the search is a binary search in a search tree whose in-order is $C_0, \ldots, C_{2^k - 2}$, with the monotone predicate of Step 1. Such a search visits the node of the last chain $C_t$ above which $q$ lies and the node of the first chain $C_{t+1}$ below $q$, whenever these exist. By Step 4, after the leaf, $\mathrm{low} = s_t$ if $t \ge 0$ and nil otherwise. For $\mathrm{high}$: if $t + 1 \le f$, then node $t + 2$ was visited with a false decision; if it tested $s_{t+1}$, $\mathrm{high} = s_{t+1}$; if it inherited, the edge $s_{t+1}$ was tested at an ancestor with a false decision, and the indices between them with false decisions also have the spanning edge $s_{t+1}$ by the argument of Step 4, so again $\mathrm{high} = s_{t+1}$. If $t = f$, every chain is below $q$, no false decision tested an edge, and $\mathrm{high}$ is nil.

It remains to see that $s_t$ is the highest edge below $q$ that spans it. Let $e$ be an edge that spans $q$ with $q$ above it. By (i), $e \in C_i$ for some $i$, and $e = s_i$, so $q$ is above $C_i$ and $i \le t$. By (ii), $s_t$ is at least as high as $s_i = e$ at the sheared $x$ of $q$. Two different edges that span $q$ cannot have the same height there, since they would share a point that is not an end point of both. So $e$ is $s_t$ or lower than it, and $s_t$ itself is below $q$. If $t = -1$, no edge below $q$ spans it. The same argument with the order reversed shows that $s_{t+1}$ is the lowest edge above $q$, or that there is none when $t = f$. This proves the claim. $\blacksquare$
