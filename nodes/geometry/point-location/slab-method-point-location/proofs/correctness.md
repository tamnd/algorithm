---
title: The slab method answers vertical ray shooting and point location queries
proves: [correctness, termination]
status: full
---

**Setting.** $S$ is a finite set of segments in the plane, each stored as $(a, b)$ with $a <_{\mathrm{lex}} b$, such that two segments meet at most in a common end point. $P$ is the set of end points. For $\varepsilon > 0$ let $\sigma_\varepsilon(x, y) = (x + \varepsilon y, y)$, and write $p' = \sigma_\varepsilon(p)$.

**Claim.** For every query point $q$, SLAB-QUERY returns: the vertex $q$ if $q \in P$; otherwise the segment of $S$ that contains $q$, if there is one; otherwise the face answer (above, below), where *above* is the segment $s \in S$ whose image $s'$ is the first one hit by the upward vertical ray from $q'$, and *below* the first one hit by the downward ray, for every small enough $\varepsilon > 0$ (each is "none" if the ray hits nothing). The build terminates, and so does each query.

**Step 1 (the shear).** $\sigma_\varepsilon$ is linear with determinant $1$, so for all points $\mathrm{orient}(p', q', r') = \mathrm{orient}(p, q, r)$, and $\sigma_\varepsilon$ maps segments to segments and preserves incidences. For two points $p \ne q$ of a finite set $F$, $p'_x - q'_x = (p_x - q_x) + \varepsilon (p_y - q_y)$. If $p_x \ne q_x$ the sign is that of $p_x - q_x$ for $\varepsilon < |p_x - q_x| / |p_y - q_y|$ (or any $\varepsilon$ if $p_y = q_y$); if $p_x = q_x$ the sign is that of $p_y - q_y \ne 0$. With $F = P \cup \{q\}$ finite, there is $\varepsilon_0 > 0$ such that for all $0 < \varepsilon < \varepsilon_0$: $p'_x < q'_x$ if and only if $p <_{\mathrm{lex}} q$. Fix such an $\varepsilon$. Then no two points of $F$ have the same sheared $x$, and no segment $s'$ is vertical, since its end points have distinct sheared $x$. Also, $q'$ lies strictly between the sheared vertical lines through $a'$ and $b'$ if and only if $a <_{\mathrm{lex}} q <_{\mathrm{lex}} b$; we then say that $s$ spans $q$.

**Step 2 (above and below in the sheared plane).** Let $s = (a, b)$ span $q$. Since $a'_x < b'_x$, the point $q'$ lies above the line of $s'$ if and only if $\mathrm{orient}(a', b', q') > 0$, that is $\mathrm{orient}(a, b, q) > 0$; below if and only if it is negative; and on $s'$ (hence $q$ on $s$) if and only if it is zero, because $q'$ is strictly inside the $x$-range of $s'$.

**Step 3 (the order in a slab).** Let $u <_{\mathrm{lex}} v$ be consecutive points of $X$, and let $T$ be the set of segments that span $(u, v)$. Every segment of $T$ meets every sheared vertical line $\ell$ strictly between $u'$ and $v'$, in one point since it is not vertical. No point of $P$ has its sheared $x$ in that open range, so no two segments of $T$ meet on such a line (they meet only at end points), and the vertical order of two segments of $T$ on $\ell$ is the same for all such $\ell$, by continuity and the intermediate value theorem. Call it the slab order. It is a strict total order on $T$.

It is computed by line L3 as follows. Take $s = (a, b)$ and $t = (c, d)$ in $T$ with $a \le_{\mathrm{lex}} c$. Then $c \le_{\mathrm{lex}} u <_{\mathrm{lex}} b$, so $c'$ lies in the closed $x$-range of $s'$. If $\mathrm{orient}(a, b, c) \ne 0$, its sign says whether $c'$ is above or below $s'$ on the vertical line through $c'$; the segment $t'$ starts there and meets $s'$ nowhere strictly between $c'$ and $v'$, so its sign is the slab order. If $\mathrm{orient}(a, b, c) = 0$, then $c$ lies on $s$, so $c$ is a common point of $s$ and $t$, hence a common end point; as $c \le_{\mathrm{lex}} u <_{\mathrm{lex}} b$, $c = a$. The segments do not overlap, so $d$ is not on the line of $s$, and $\mathrm{orient}(a, b, d) \ne 0$. Both segments leave $a'$ to the right, and $t'$ lies above $s'$ just right of $a'$ if and only if $d$ lies to the left of the directed line $ab$. So the sign of $\mathrm{orient}(a, b, d)$ is the slab order. The case $c <_{\mathrm{lex}} a$ is symmetric.

**Step 4 (the sweep invariant).** Invariant: after the iteration for $X[i]$, the active list is the set $T_i$ of segments that span $(X[i], X[i+1])$, in slab order, and $L[i]$ is a copy of it.

*Initialization.* Before the first iteration the active list is empty. At $X[0]$ no segment ends, and the segments that start at $X[0]$ are inserted. A segment spans $(X[0], X[1])$ if and only if it starts at $X[0]$, because its start is a point of $P$ that is $\le_{\mathrm{lex}} X[0]$. Each insertion uses binary search with the comparator of Step 3, which is a total order on $T_0$, so the result is $T_0$ in slab order.

*Maintenance.* Suppose the active list is $T_{i-1}$ in slab order. A segment of $T_{i-1}$ spans $(X[i], X[i+1])$ unless its end point $b$ equals $X[i]$: indeed $b \ge_{\mathrm{lex}} X[i]$, and $b$ is a point of $P$, so $b >_{\mathrm{lex}} X[i]$ implies $b \ge_{\mathrm{lex}} X[i+1]$. The deletion removes exactly those. A segment that is not in $T_{i-1}$ is in $T_i$ if and only if it starts at $X[i]$, by the argument of the initialization. The remaining segments keep their relative order: both orders are the vertical order on lines just right of $X[i]'$ and just left of it, and two segments of $T_{i-1} \cap T_i$ do not meet on the vertical line through $X[i]'$ (they would meet at the point of $P$ at $X[i]$, which is an end point of neither, as they span both slabs). Each inserted segment goes to the place given by the total order of Step 3 on $T_i$. So the active list is $T_i$ in slab order.

*Termination of the build.* The loop runs $m - 1$ times, each iteration finite.

**Step 5 (the query).** If $q \in P$, line L4 finds it by binary search in the sorted array $X$ and returns it. Otherwise $q \notin X$. If $q <_{\mathrm{lex}} X[0]$ or $q >_{\mathrm{lex}} X[m-1]$, no segment spans $q$, and $q$ lies on no segment, since a point of a segment lies in its closed lexicographic range. So both rays miss everything and line L5 is right.

Otherwise there is a unique $i$ with $X[i] <_{\mathrm{lex}} q <_{\mathrm{lex}} X[i+1]$. A segment spans $q$ if and only if it is in $T_i$, by the argument of Step 4. A segment that contains $q$ spans $q$, since $q$ is not an end point. Let $\ell$ be the sheared vertical line through $q'$; it lies strictly inside slab $i$, so by Step 3 the segments of $L[i]$ meet $\ell$ in the slab order from bottom to top. Hence the predicate "$q'$ lies above $s'$" holds for a prefix $L[i][0 .. k-1]$, and "$q'$ lies below $s'$" for the rest, unless $q'$ lies on some $s'$, which happens for at most one segment because segments meet only at end points.

Binary search with the invariant "every index below lo is a segment below $q'$, every index at least hi is a segment above $q'$" keeps it at each step by Step 2, and halves $hi - lo$, so it terminates. If a probe gives $\mathrm{orient} = 0$, then $q$ lies on that segment by Step 2, and line L7 returns it. If $q$ lies on $L[i][j]$, then every probe at an index below $j$ sets $lo \le j$ and every probe above $j$ sets $hi > j$, so $j$ stays in $[lo, hi)$ until it is probed, and the loop cannot end before that. So if no probe gives zero, no segment of $L[i]$ contains $q$: the final $lo = hi = k$ splits $L[i]$ into $k$ segments strictly below $q'$ and the rest strictly above. Then no segment contains $q$, the first segment hit upward on $\ell$ is $L[i][k]$, the first hit downward is $L[i][k-1]$, and segments not in $T_i$ do not meet $\ell$ at all. So line L8 returns the correct pair. $\blacksquare$
