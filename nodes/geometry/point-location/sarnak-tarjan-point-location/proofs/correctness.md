---
title: The persistent sweep stores every slab list and answers point location queries
proves: [correctness, termination]
status: full
---

**Setting.** $S$ is a finite set of segments, each stored as $(a, b)$ with $a <_{\mathrm{lex}} b$, any two meeting at most in a common end point. $X[0 .. m-1]$ is the sorted list of end points. For $0 \le i \le m - 2$, let $T_i$ be the set of segments that span the slab $(X[i], X[i+1])$, that is $a \le_{\mathrm{lex}} X[i]$ and $X[i+1] \le_{\mathrm{lex}} b$, and let $\prec_i$ be the bottom-to-top order of $T_i$ in the sheared plane. We use the facts proved for the [slab method](/slab-method-point-location/proofs/correctness/): (F1) after the symbolic shear, the sheared $x$-order of points is the lexicographic order and $\mathrm{orient}$ is unchanged; (F2) $\prec_i$ is a strict total order on $T_i$, and the comparator seg_cmp computes it for any two segments of $T_i$; (F3) a segment of $T_{i-1}$ is in $T_i$ unless it ends at $X[i]$, a segment not in $T_{i-1}$ is in $T_i$ if and only if it starts at $X[i]$, and two segments of $T_{i-1} \cap T_i$ are in the same order in $\prec_{i-1}$ and $\prec_i$.

**Claim.** (1) For every $i$, the in-order sequence of the tree $R[i]$ is $T_i$ sorted by $\prec_i$, also after the build ends. (2) ST-QUERY returns the vertex $q$ if $q \in X$; else the segment that contains $q$ if there is one; else the lowest segment above $q$ and the highest segment below $q$ in the sheared plane. (3) The build and each query terminate.

**Step 1 (persistent updates are functional).** INSERT$(T, s)$ and DELETE$(T, s)$ create new nodes for the changed part and reuse the other subtrees by pointer, and they never write to a node that existed before the call. (In the AVL code every node is built by a constructor and its fields are never assigned again; with node copying, a write to an old node only fills an empty extra field stamped with the new version, which a search of an older version ignores.) So the tree reachable from an old root, read as that version, never changes. By induction on the number of calls, every root stored in line L6 keeps its in-order sequence forever.

**Step 2 (each update is a correct sorted-set update).** Let $T$ be a search tree whose in-order is a sequence $\sigma$ sorted by a strict total order $\prec$ on a set $U \supseteq \operatorname{set}(\sigma)$, and let the comparator agree with $\prec$ on $U$. If $s \in U \setminus \sigma$, INSERT returns a tree whose in-order is $\sigma$ with $s$ inserted at its place: the search descends left exactly when $s \prec$ the node key, so it reaches the empty subtree between the predecessor and the successor of $s$; and the rotations of the AVL balance step (or the red-black fix-up) preserve in-order sequences. If $s \in \sigma$, DELETE returns a tree with in-order $\sigma$ minus $s$: the search finds the node of $s$, and replacing it by its in-order successor taken from the right subtree, followed by rotations, keeps the in-order sequence of the other keys.

**Step 3 (the sweep invariant).** Let $W_i$ be the tree after line L6 for index $i$. We show by induction on $i$ that the in-order of $W_i$ is $T_i$ sorted by $\prec_i$.

*Base, $i = 0$.* The tree starts empty. No segment ends at $X[0]$, since its start would be lexicographically smaller. The segments that start at $X[0]$ are exactly $T_0$ (F3 with $T_{-1} = \emptyset$). Each insertion compares segments of $T_0$, on which the comparator is $\prec_0$ (F2), so by Step 2 the in-order after line L5 is $T_0$ sorted by $\prec_0$.

*Step, $i \ge 1$.* By the hypothesis the tree before line L4 has in-order $T_{i-1}$ sorted by $\prec_{i-1}$. Line L4 deletes the segments of $T_{i-1}$ that end at $X[i]$; each deletion compares the target with segments of $T_{i-1}$ only, on which the comparator is $\prec_{i-1}$, so by Step 2 the in-order becomes $T_{i-1} \cap T_i$ in order $\prec_{i-1}$, which is also order $\prec_i$ by F3. Line L5 inserts the segments that start at $X[i]$, which are $T_i \setminus T_{i-1}$ by F3. Each insertion compares segments of $T_i$, on which the comparator is $\prec_i$, so by Step 2 the in-order becomes $T_i$ sorted by $\prec_i$.

With Step 1, $R[i] = W_i$ keeps this in-order sequence after the build. This proves (1). The loop of line L3 runs $m - 1$ times and each update is a finite descent, so the build terminates.

**Step 4 (the query).** Lines L7 and L8 are the same as lines L4 and L5 of the slab method, so the vertex case and the outside case are correct. Otherwise $X[i] <_{\mathrm{lex}} q <_{\mathrm{lex}} X[i+1]$, and by the slab method proof, the segments of $T_i$ cross the sheared vertical line through $q$ in the order $\prec_i$, the predicate "$q$ is above $s$" ($\mathrm{orient}(a, b, q) > 0$) holds on a prefix of this order and "$q$ is below $s$" on the rest, except for at most one segment that contains $q$ (orient zero), and no segment outside $T_i$ meets that line.

Line L9 walks down $R[i]$. Invariant: all keys in the current subtree lie strictly between the recorded below and above segments in $\prec_i$, every key $\preceq$ below is below $q$, and every key $\succeq$ above is above $q$. It holds at the root with both records empty. At a node $s$ with $\mathrm{orient} > 0$, $s$ and all keys of its left subtree are below $q$ (prefix property), so recording $s$ as below and going right keeps it; the case $\mathrm{orient} < 0$ is symmetric. If $q$ lies on a segment $t$ of $T_i$, then $t$ is never in an abandoned subtree, because the abandoned keys are all strictly below or strictly above $q$; so the walk meets $t$ before it reaches an empty subtree and returns it. Otherwise the walk ends at an empty subtree, every key is $\preceq$ below or $\succeq$ above, so below and above are consecutive in $\prec_i$ with $q$ between them: they are the highest segment below and the lowest segment above $q$. Each step goes one level down, so the walk terminates after at most the height of the tree. This proves (2) and (3). $\blacksquare$
