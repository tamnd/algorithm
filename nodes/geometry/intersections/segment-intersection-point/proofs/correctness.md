---
title: SEGMENT-INTERSECTION returns the exact common part of two closed segments
proves: [correctness, termination]
status: full
---

**Claim.** For points $a, b, c, d$ with rational coordinates, SEGMENT-INTERSECTION$(a, b, c, d)$ returns the empty result when $[a, b] \cap [c, d] = \emptyset$, the point $p$ when $[a, b] \cap [c, d] = \{p\}$, and the pair $(p, q)$ with $p < q$ in lexicographic order when $[a, b] \cap [c, d]$ is the segment $[p, q]$ with $p \ne q$. Here $[a, b]$ is the closed segment $\{a + t(b - a) : 0 \le t \le 1\}$, which is the single point $a$ when $a = b$.

**Notation.** For vectors $u, w$ let $u \times w = u_x w_y - u_y w_x$. Then $\mathrm{orient}(p, q, r)$ is the sign of $(q - p) \times (r - p)$. Write $d_1 = \mathrm{orient}(c, d, a)$, $d_2 = \mathrm{orient}(c, d, b)$, $d_3 = \mathrm{orient}(a, b, c)$ and $d_4 = \mathrm{orient}(a, b, d)$, as in line L1.

**Fact 1 (sides).** Let $c \ne d$ and let $\ell$ be the line through $c$ and $d$. The function $f(x) = (d - c) \times (x - c)$ is affine, it is zero exactly on $\ell$, and it is positive on one open side of $\ell$ and negative on the other. For $x = a + t(b - a)$ it is $f(a) + t(f(b) - f(a))$, an affine function of $t$.

**Fact 2 (collinear points).** If the points $x, y, z$ are on one line $\ell$, then $z \in [x, y]$ if and only if $z$ lies in the bounding box of $x$ and $y$, and if and only if $\min(x, y) \le z \le \max(x, y)$ in lexicographic order. *Proof.* Choose the coordinate $i$ on which $\ell$ is not constant (the $x$-coordinate unless $\ell$ is vertical). On $\ell$ the map $z \mapsto z_i$ is an affine bijection onto $\mathbb{R}$ that preserves the lexicographic order, and the other coordinate is an affine function of $z_i$. So $z \in [x, y]$ if and only if $z_i$ is between $x_i$ and $y_i$, and then the other coordinate is also between, which gives the box; and the box test implies the condition on $z_i$. $\square$

**Case 1: line L2 holds,** $d_1 d_2 < 0$ and $d_3 d_4 < 0$. Then $c \ne d$ (else $d_1 = d_2 = 0$) and $a \ne b$. By Fact 1, $f(a)$ and $f(b)$ have opposite signs, so the affine function $t \mapsto f(a + t(b - a))$ has exactly one zero $t_0$, and $t_0 \in (0, 1)$. So $[a, b]$ meets $\ell$ in exactly one point $x_0 = a + t_0(b - a)$, interior to $[a, b]$. In the same way $[c, d]$ meets the line through $a, b$ in one point $y_0$ interior to $[c, d]$. The two lines are not parallel (else $f$ would be constant on $[a, b]$), so they meet in one point, and $x_0 = y_0$ is that point. The intersection is $\{x_0\}$. Line L3 solves $(d - c) \times (a + t(b - a) - c) = 0$, that is $t \cdot (b - a) \times (d - c) = (c - a) \times (d - c)$, and the coefficient $(b - a) \times (d - c)$ is not zero because the lines are not parallel. So line L4 returns $x_0$.

**Case 2: line L5 holds,** all four signs are zero. If $a \ne b$, then $d_3 = d_4 = 0$ puts $c$ and $d$ on the line through $a$ and $b$. If $a = b$ and $c \ne d$, then $d_1 = 0$ puts $a$ on the line through $c$ and $d$. If $a = b$ and $c = d$, the points are on any line through both. So all four points are on one line $\ell$. On $\ell$, by Fact 2, the closed segment $[a, b]$ is the lexicographic interval $[\min(a, b), \max(a, b)]$, and the same holds for $[c, d]$. The intersection of two intervals of a totally ordered line is $[\mathrm{lo}, \mathrm{hi}]$ with lo the larger left end and hi the smaller right end, empty when $\mathrm{lo} > \mathrm{hi}$. Lines L6 to L9 compute exactly this and return it in the three forms of the claim.

**Case 3: neither L2 nor L5 holds.** We show first that the intersection has at most one point. If it had two points, $[a, b]$ and $[c, d]$ would share a segment of positive length, so $a \ne b$, $c \ne d$, and the two segments would lie on one line, which makes all four signs zero. So the intersection is empty or a single point.

Next, a common point $p$ of the two segments is one of $a, b, c, d$. Suppose not. Then $a \ne b$ (else $p = a$) and $c \ne d$. The point $p$ is interior to $[a, b]$, and $f(p) = 0$ with $f$ as in Fact 1. If $f(a) = f(b) = 0$, the segment $[a, b]$ lies on $\ell$; then $c, d$ are on the line through $a, b$, so $d_3 = d_4 = 0$ and, with $d_1 = d_2 = 0$, line L5 holds, a contradiction. Otherwise the affine function $t \mapsto f(a + t(b - a))$ vanishes at an interior $t$ and is not identically zero, so $f(a)$ and $f(b)$ are both nonzero with opposite signs: $d_1 d_2 < 0$. In the same way $d_3 d_4 < 0$, and line L2 holds, a contradiction.

So in Case 3 the result is either empty or one of the four end points. Lines L10 to L13 test each end point in turn. The point $a$ lies on $[c, d]$ if and only if $d_1 = 0$ and $a$ is in the box of $c$ and $d$: when $c \ne d$ this is Fact 2 for the collinear points $c, d, a$, and when $c = d$ the box is the point $c$ itself. The other three tests are the same with the roles exchanged. The first test that succeeds gives a common point, which is then the only common point. If all four fail, no end point is common, so the intersection is empty and line L14 is right.

**Termination.** The procedure has no loops. It does a fixed number of exact operations on rational numbers. $\blacksquare$
