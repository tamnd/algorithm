---
title: Welzl's algorithm returns the smallest enclosing disk, terminates, and makes at most 10n expected containment tests
proves: [correctness, termination, time.expected]
status: full
---

**Setting.** Points are in $\mathbb{R}^2$. A disk is a pair $(z, r)$ with center $z$ and radius $r \ge 0$; it is the closed set $\{x : |x - z| \le r\}$, and its circle is $\{x : |x - z| = r\}$. For finite sets $P$ and $R$ (we treat $P$ as a list, so duplicates are allowed), a disk is *feasible for* $(P, R)$ if it contains every point of $P$ and has every point of $R$ on its circle. If a feasible disk exists, $\mathrm{md}(P, R)$ denotes a feasible disk of smallest radius; Lemma 1 shows that it is unique. For $P = R = \emptyset$ we set $\mathrm{md}(\emptyset, \emptyset) = \emptyset$, the empty set, which contains no point.

**The combination of two disks.** For a disk $D_k = (z_k, r_k)$ let $f_k(x) = |x - z_k|^2 - r_k^2$, so $D_k = \{f_k \le 0\}$ and its circle is $\{f_k = 0\}$. For $\lambda \in [0, 1]$ let $f_\lambda = (1 - \lambda) f_0 + \lambda f_1$. Expanding the squares,

$$f_\lambda(x) = |x - z_\lambda|^2 - s_\lambda, \qquad z_\lambda = (1 - \lambda) z_0 + \lambda z_1, \qquad s_\lambda = (1 - \lambda) r_0^2 + \lambda r_1^2 - \lambda (1 - \lambda) |z_0 - z_1|^2,$$

because $(1 - \lambda)|z_0|^2 + \lambda |z_1|^2 - |z_\lambda|^2 = \lambda (1 - \lambda)|z_0 - z_1|^2$. If some point $x$ has $f_\lambda(x) \le 0$, then $s_\lambda \ge |x - z_\lambda|^2 \ge 0$, and $D_\lambda = (z_\lambda, \sqrt{s_\lambda})$ is a disk with $D_\lambda = \{f_\lambda \le 0\}$. A point in $D_0 \cap D_1$ has $f_0, f_1 \le 0$, so it is in $D_\lambda$. A point on both circles has $f_0 = f_1 = 0$, so it is on the circle of $D_\lambda$. The map $\lambda \mapsto f_\lambda(x)$ is continuous for each $x$.

**Lemma 1 (existence and uniqueness).** If a disk is feasible for $(P, R)$ and $P \cup R \ne \emptyset$, then $\mathrm{md}(P, R)$ exists and is unique.

*Proof.* Let $(z', r')$ be feasible and fix $x_0 \in P \cup R$. Every feasible disk $(z, r)$ with $r \le r'$ has $|z - x_0| \le r'$. The set of such pairs $(z, r)$ is defined by finitely many non-strict inequalities and equations in continuous functions, so it is closed, and it is bounded. It is not empty, so the continuous function $r$ has a minimum on it. For uniqueness, let $D_0 \ne D_1$ both be feasible with the smallest radius $r$. If $z_0 = z_1$ then the radii are equal and the disks are equal, so $z_0 \ne z_1$. Take $\lambda = 1/2$. Every point of $P \cup R$ satisfies $f_{1/2} \le 0$, so $D_{1/2}$ is a disk, and it is feasible by the remarks above. Its squared radius is $r^2 - |z_0 - z_1|^2/4 < r^2$, a contradiction. $\square$

**Lemma 2 (a violator is on the boundary).** Let $p$ be an entry of $P$ and $P' = P \setminus \{p\}$ (one copy removed). Assume a disk is feasible for $(P, R)$. If $p \notin \mathrm{md}(P', R)$, then $p$ lies on the circle of $\mathrm{md}(P, R)$, and $\mathrm{md}(P, R) = \mathrm{md}(P', R \cup \{p\})$.

*Proof.* If $P' = R = \emptyset$, then $\mathrm{md}(P, R)$ is the disk of radius 0 at $p$, and so is $\mathrm{md}(\emptyset, \{p\})$. Otherwise both $D_0 = \mathrm{md}(P', R)$ and $D_1 = \mathrm{md}(P, R)$ exist by Lemma 1, since a disk feasible for $(P, R)$ is feasible for $(P', R)$. $D_1$ is feasible for $(P', R)$, so $r_0 \le r_1$. Suppose that $p$ is not on the circle of $D_1$, so $f_1(p) < 0$, while $f_0(p) > 0$ because $p \notin D_0$. By continuity there is $\lambda \in (0, 1)$ with $f_\lambda(p) = 0$. Then $D_\lambda$ is a disk; it contains $P'$ and has $R$ on its circle because $D_0$ and $D_1$ do, and it contains $p$. So it is feasible for $(P, R)$. Its squared radius is $s_\lambda \le (1 - \lambda) r_0^2 + \lambda r_1^2 - \lambda(1 - \lambda)|z_0 - z_1|^2$. If $r_0 < r_1$ this is less than $r_1^2$. If $r_0 = r_1$, then $z_0 \ne z_1$ (else $D_0 = D_1$, but $p \in D_1 \setminus D_0$), and again $s_\lambda < r_1^2$. Both cases contradict the choice of $D_1$. So $p$ is on the circle of $D_1$. Then $D_1$ is feasible for $(P', R \cup \{p\})$, and every disk feasible for $(P', R \cup \{p\})$ is feasible for $(P, R)$, so the two problems have the same smallest disk. $\square$

**Lemma 3 (at most $3 - |R|$ points fix the disk).** Let $|R| \le 3$ and let $Q$ be a list with a disk feasible for $(Q, R)$ and $Q \cup R \ne \emptyset$. Then there is a sublist $S$ of $Q$ with $|S| \le 3 - |R|$ and $\mathrm{md}(S, R) = \mathrm{md}(Q, R)$. Moreover, every entry $p$ of $Q$ outside $S$ satisfies $p \in \mathrm{md}(Q \setminus \{p\}, R)$.

*Proof.* Let $D = (z, r) = \mathrm{md}(Q, R)$. First the "moreover" part. If $S \subseteq Q \setminus \{p\} \subseteq Q$, the smallest radii satisfy $r(S, R) \le r(Q \setminus \{p\}, R) \le r(Q, R) = r(S, R)$, since a disk feasible for a list is feasible for each sublist. So $D$, which is feasible for $(Q \setminus \{p\}, R)$, has the smallest radius there, and by Lemma 1 it is $\mathrm{md}(Q \setminus \{p\}, R)$, which contains $p$.

Now the existence of $S$, by the size of $R$.

- $|R| = 3$. The three points of $R$ are distinct points of one circle, and a line meets a circle in at most two points, so they are not collinear. Exactly one circle passes through three non-collinear points. So $\mathrm{md}(\emptyset, R) = D$, and $S = \emptyset$.
- $|R| = 2$, $R = \{a, b\}$ with $a \ne b$. A disk with $a$ and $b$ on its circle has its center $z(t) = m + t u$ on the bisector of $ab$, where $m = (a + b)/2$, $u$ is a unit normal of $b - a$ and $t \in \mathbb{R}$, and its squared radius is $|a - m|^2 + t^2$. A point $x$ is in it iff $|x - m|^2 - 2t \langle x - m, u \rangle \le |a - m|^2$. This is a linear inequality in $t$, so the feasible values of $t$ for $Q$ form a closed interval $I$, the intersection of the intervals $I_x$, $x \in Q$, each of which is a closed half-line, the whole line, or empty. $D$ corresponds to the point $t^*$ of $I$ nearest to 0. If $t^* = 0$, take $S = \emptyset$. Otherwise $t^*$ is an end point of $I$, so it is the end point of some $I_x$ that is a half-line away from 0, and $0 \notin I_x$. Then $t^*$ is also the point of $I_x$ nearest to 0, and $S = (x)$ works.
- $|R| = 1$, $R = \{a\}$. A disk with $a$ on its circle and center $w$ has radius $|w - a|$, and it contains $x$ iff $|x - w|^2 \le |a - w|^2$, that is iff $\langle n_x, w \rangle \le \beta_x$ with $n_x = a - x$ and $\beta_x = (|a|^2 - |x|^2)/2$. So the feasible centers form a polyhedron $K = \{w : \langle n_x, w \rangle \le \beta_x, x \in Q\}$, and $z$ is the point of $K$ nearest to $a$. If $z = a$, take $S = \emptyset$. Otherwise, the projection property of a closed convex set gives $\langle a - z, w - z \rangle \le 0$ for all $w \in K$. By Farkas' lemma, $a - z$ is then a nonnegative combination of the normals $n_x$ of the constraints that are tight at $z$, and by Carathéodory's theorem for cones in $\mathbb{R}^2$ we can use at most 2 of them: $a - z = \mu_1 n_{x_1} + \mu_2 n_{x_2}$ with $\mu_k \ge 0$ and tight constraints. Let $S = (x_1, x_2)$ and $K_S \supseteq K$ the polyhedron of these two constraints. For $w \in K_S$, $\langle a - z, w - z \rangle = \sum_k \mu_k (\langle n_{x_k}, w \rangle - \beta_{x_k}) \le 0$, so $|w - a|^2 = |w - z|^2 + |z - a|^2 - 2\langle w - z, a - z \rangle \ge |z - a|^2$. So $z$ is also the point of $K_S$ nearest to $a$, and $\mathrm{md}(S, R) = D$.
- $|R| = 0$. Let $B$ be the points of $Q$ on the circle of $D$; $B \ne \emptyset$, since otherwise a slightly smaller disk with center $z$ is feasible. Suppose $z \notin \operatorname{conv} B$. By the separation theorem there is a unit vector $u$ with $\langle b - z, u \rangle > 0$ for all $b \in B$. For small $\tau > 0$, $|b - (z + \tau u)|^2 = r^2 - 2\tau \langle b - z, u \rangle + \tau^2 < r^2$ for every $b \in B$, and the points of $Q \setminus B$, which are at distance less than $r$ from $z$, stay at distance less than $r$ from $z + \tau u$. So a disk centered at $z + \tau u$ with radius less than $r$ is feasible, a contradiction. So $z \in \operatorname{conv} B$, and by Carathéodory's theorem $z = \sum_{s \in S} \lambda_s s$ for some $S \subseteq B$ with $|S| \le 3$, $\lambda_s \ge 0$ and $\sum \lambda_s = 1$. For any center $w$, $\sum_s \lambda_s \langle s - z, w - z \rangle = 0$, so some $s \in S$ has $\langle s - z, w - z \rangle \le 0$ and $|s - w|^2 = r^2 + |w - z|^2 - 2\langle s - z, w - z\rangle \ge r^2$. So every disk that contains $S$ has radius at least $r$, and $D$ contains $S$; by Lemma 1, $\mathrm{md}(S, \emptyset) = D$. $\square$

**Claim A (correctness).** Let $0 \le |R| \le 3$, and suppose a disk is feasible for $(P[0..m-1], R)$. Then B-MTF$(P, m, R)$ returns $\mathrm{md}(P[0..m-1], R)$, with or without line L8. In particular MINIDISK$(P)$ returns $\mathrm{md}(P, \emptyset)$, since every finite set lies in some disk.

*Proof.* By induction on $3 - |R|$.

*Line L3.* If $R$ is feasible, line L3 computes $\mathrm{md}(\emptyset, R)$. For $|R| = 0$ it is $\emptyset$. For $|R| = 1$ it is the point. For $|R| = 2$, $R = \{a, b\}$, every disk with $a$ and $b$ on its circle has diameter at least $|a - b|$, and the disk with center $(a + b)/2$ attains it. For $|R| = 3$ the three points are distinct points on the circle of a feasible disk, so they are not collinear (as in Lemma 3), the determinant in the circumcenter formula is not zero, and the circumcircle is the only disk with $R$ on its circle. This settles $|R| = 3$, where line L4 returns.

*Line L5, for $|R| < 3$.* Invariant: before iteration $i$, $D = \mathrm{md}(P[0..i-1], R)$, where $P[0..i-1]$ is read as a list of points (line L8 permutes only positions $0..i$, so it does not change this list as a multiset, nor any position after $i$). At $i = 0$ this is line L3. Let $p = P[i]$, $Q = P[0..i]$; a disk is feasible for $(Q, R)$ because one is feasible for the longer list.

- If $p \in D$, then $D$ is feasible for $(Q, R)$. Its radius is the smallest for the shorter list, so also for $Q$. By Lemma 1, $D = \mathrm{md}(Q, R)$.
- If $p \notin D$, then $p \notin R$ (points of $R$ are on the circle of $D$), so $|R \cup \{p\}| = |R| + 1$. By Lemma 2, $\mathrm{md}(Q, R) = \mathrm{md}(P[0..i-1], R \cup \{p\})$, and the latter problem has a feasible disk, namely $\mathrm{md}(Q, R)$. By the induction hypothesis, line L7 returns it.

After the last iteration, $D = \mathrm{md}(P[0..m-1], R)$. $\square$

**Claim B (termination).** A call with $|R| = 3$ makes no call and stops after line L4. A call with $|R| = k < 3$ runs the loop $m$ times, and each iteration makes at most one call, with $|R| = k + 1$, which terminates by induction on $3 - k$. So every call terminates, and at most four frames (with $|R| = 0, 1, 2, 3$) are active at a time.

**Claim C (expected tests).** Consider the version without line L8. Let $t_j(m)$ be the maximum, over all lists of $m$ points and all sets $R$ with $|R| = 3 - j$ that admit a feasible disk, of the expected number of executions of line L6 by B-MTF$(P, m, R)$ when $P[0..m-1]$ is in uniformly random order. Then $t_j(m) \le c_j m$ with $c_0 = 0$ and $c_j = 1 + j\, c_{j-1}$, so MINIDISK makes at most $c_3 n = 10 n$ tests in expectation.

*Proof.* For $j = 0$ there are no tests. Let $j \ge 1$. Iteration $i$ makes one test. Condition on the multiset $Q$ of the first $i + 1$ entries. The order of $P[0..i]$ is uniform, so $p = P[i]$ is each entry of $Q$ with probability $1/(i + 1)$. A call happens iff $p \notin \mathrm{md}(Q \setminus \{p\}, R)$. By Lemma 3 (and the case $Q \cup R = \emptyset$ does not arise for $i \ge 0$), this requires $p$ to be in a fixed sublist $S$ of at most $j$ entries, so the probability is at most $j / (i + 1)$. Given $Q$ and $p$, the order of $P[0..i-1]$ is still uniform, so the expected number of tests in the call is at most $t_{j-1}(i)$. Hence

$$t_j(m) \le \sum_{i=0}^{m-1} \Big(1 + \frac{j}{i + 1}\, c_{j-1}\, i\Big) \le m + j\, c_{j-1}\, m = c_j m.$$

With $c_0 = 0$ this gives $c_1 = 1$, $c_2 = 3$ and $c_3 = 10$. Each test and each execution of line L3 costs $O(1)$ arithmetic operations, and the number of executions of line L3 is at most one more than the number of failed tests, so the expected time is $O(n)$. $\blacksquare$
