---
title: The power diagram built by clipping a box is correct
proves: [correctness]
status: full
---

**Claim.** Let $P$ be a set of $n \ge 1$ distinct sites $p_i$ with real weights $w_i$, and let $B$ be the box of line L1. Then POWER-BUILD stores a cell for $p_i$ exactly when $C_i$ has nonempty interior, the stored polygon is $C_i \cap B$ with its corners in counterclockwise order, and the stored flag says correctly whether $C_i$ is bounded. $\mathrm{vertices}()$ returns exactly the corners of the cells with nonempty interior, and $\mathrm{locate}(q)$ returns exactly the sites of smallest power distance at $q$.

No general position is assumed. Write $\pi_i(x) = |x - p_i|^2 - w_i$ and $C_i = \{x : \pi_i(x) \le \pi_j(x) \text{ for all } j\}$.

**Lemma 1 (bisectors).** For $i \ne j$, $\pi_i(x) - \pi_j(x) = 2 (p_j - p_i) \cdot x - (|p_j|^2 - w_j - |p_i|^2 + w_i)$. So $\{x : \pi_i(x) \le \pi_j(x)\}$ is the closed half-plane $a x + b y \le c$ with $(a, b) = 2 (p_j - p_i) \ne (0, 0)$ and $c = |p_j|^2 - w_j - |p_i|^2 + w_i$, the triple the code computes. Its boundary line $\ell_{ij}$ is the power bisector.

*Proof.* Expand $|x - p|^2 = |x|^2 - 2 p \cdot x + |p|^2$; the terms $|x|^2$ cancel. The sites are distinct, so $(a, b) \ne (0, 0)$. $\square$

So $C_i$ is an intersection of $n - 1$ closed half-planes, a closed convex set whose boundary lies in the union of the lines $\ell_{ij}$. The cells cover the plane, since each point has a site of smallest power distance, and two cells $C_i$, $C_j$ with $i \ne j$ meet only on $\ell_{ij}$, which has no interior points.

**Lemma 2 (vertices are radical centers).** Every corner $v$ of a cell $C_i$ with nonempty interior is the crossing point of two lines $\ell_{ij}$ and $\ell_{ik}$ that are not parallel, and it is strictly inside $B$.

*Proof.* A corner of an intersection of half-planes lies on the boundary lines of at least two of them whose lines are not parallel, since near a point on only one boundary line, or on several parallel ones, which are then the same line, the set looks like a half-plane or the plane. So $v \in \ell_{ij} \cap \ell_{ik}$ with $\ell_{ij}$ not parallel to $\ell_{ik}$, and $v$ is the unique crossing point. Line L1 computes the crossing point of $\ell_{ij}$ and $\ell_{ik}$ for every triple $i < j < k$ whose lines are not parallel, by Cramer's rule, and puts it among the candidates; the box extends $1$ beyond all candidates on each side. The triple with $i$ not the smallest index gives the same point, because $\ell_{ij} \cap \ell_{ik}$ is the point with $\pi_i = \pi_j = \pi_k$, which is symmetric in $i, j, k$. $\square$

**Lemma 3 (every cell with interior meets the inside of B).** If $C_i$ has nonempty interior, then $C_i \cap B$ has nonempty interior.

*Proof.* If $C_i$ has a corner $v$, then $v$ is strictly inside $B$ by Lemma 2, so a small disc $D$ around $v$ is inside $B$. A convex set with nonempty interior has interior points in every disc around each of its points, so $C_i \cap D$ has nonempty interior. If $C_i$ is the whole plane, the claim is clear. Otherwise $C_i$ is a closed convex set with nonempty interior, not the plane, and with no corner. Its boundary lies in finitely many lines and has no corner, so each connected piece of the boundary is a whole line; such a line lies in some $\ell_{ij}$, and so it equals $\ell_{ij}$. Line L1 puts the point $(a c, b c)/(a^2 + b^2)$ of $\ell_{ij}$ among the candidates, so a point $y$ of the boundary of $C_i$ is strictly inside $B$, and as before $C_i$ has interior points in a small disc around $y$ inside $B$. $\square$

**The cells.** Line L5 cuts the box by the half-plane of Lemma 1 for each $j \ne i$, with the exact cutting routine, which returns the corners of the intersection of a convex polygon with a closed half-plane in counterclockwise order, without repeated corners and without corners inside sides, when it has positive area, and nothing otherwise. Once the polygon has zero area, later cuts keep it at zero area, and the code stops cutting. So after the loop, the code holds $C_i \cap B$ if this set has positive area, and nothing otherwise. For a convex set, positive area means nonempty interior. If $C_i$ has nonempty interior, so does $C_i \cap B$, by Lemma 3; if $C_i$ has empty interior, so does $C_i \cap B$. So the code stores a cell exactly for the sites whose cell has nonempty interior, and $\mathrm{isRedundant}$ is right.

**Bounded flag.** Let $C_i$ have nonempty interior. If $C_i$ is bounded, it is a convex polygon and equals the convex hull of its corners, which are strictly inside $B$ by Lemma 2; so $C_i \subseteq B$, $C_i \cap B = C_i$, and all stored corners are strictly inside $B$. If $C_i$ is unbounded, it has points outside $B$ and, by Lemma 3, points inside $B$; being convex, it contains a segment between them, which crosses the boundary of $B$. So $C_i \cap B$ contains a point of the boundary of $B$. If all corners of the convex polygon $C_i \cap B$ were strictly inside $B$, the polygon, their convex hull, would be strictly inside $B$ too. So some corner is on the boundary of $B$, and the flag is false.

**Vertices.** Let $v$ be a corner of a stored polygon $C_i \cap B$ strictly inside $B$. In a small disc around $v$ inside $B$, $C_i \cap B$ equals $C_i$, so $v$ is a corner of $C_i$, a cell with nonempty interior. Conversely, a corner $v$ of a cell $C_i$ with nonempty interior is strictly inside $B$ by Lemma 2, and the same disc argument shows that it is a corner of $C_i \cap B$. So $\mathrm{vertices}$ returns exactly the vertices, each once, since it collects them in a set.

**locate.** It computes all $n$ power distances exactly and returns the sites with the smallest one.

**Lifting.** Let $\ell_i(x) = 2 p_i \cdot x - |p_i|^2 + w_i$, so $\pi_i(x) = |x|^2 - \ell_i(x)$, and $x \in C_i$ exactly when $\ell_i(x) = \max_j \ell_j(x)$: the diagram is the projection of the upper envelope of the planes $z = \ell_j(x)$. Let $\hat{p}_i = (p_i, |p_i|^2 - w_i)$. For a point $x$, the plane $z = 2 x \cdot y + c_i$ through $\hat{p}_i$ has $c_i = |p_i|^2 - w_i - 2 x \cdot p_i = -\ell_i(x)$, and $\hat{p}_j$ is strictly above it exactly when $|p_j|^2 - w_j > 2 x \cdot p_j + c_i$, that is, when $\ell_i(x) > \ell_j(x)$. So some $x$ has $\ell_i(x) > \ell_j(x)$ for all $j \ne i$ exactly when some non-vertical plane through $\hat{p}_i$ has all other lifted sites strictly above it, that is, when $\hat{p}_i$ is a corner of the lower convex hull of the lifted sites. The set of points $x$ with $\ell_i(x) > \ell_j(x)$ for all $j \ne i$ is open and is the interior of $C_i$: it is open and inside $C_i$, and an interior point of $C_i$ with $\ell_i(x) = \ell_j(x)$ for some $j$ would have a neighbourhood inside $C_i$ on both sides of the line $\ell_{ij}$, where $\ell_j > \ell_i$ on one side. So $p_i$ is not redundant exactly when $\hat{p}_i$ is a corner of the lower hull. $\square$

**Other properties.** Adding a constant $c$ to every weight subtracts $c$ from every $\pi_i$, which keeps all comparisons, so with equal weights the cells are those of zero weights, the Voronoi cells. By Lemma 1, with the unit vector $u = (p_j - p_i)/|p_j - p_i|$, the line $\ell_{ij}$ is $u \cdot x = (|p_j|^2 - |p_i|^2)/(2 |p_j - p_i|) + (w_i - w_j)/(2 |p_j - p_i|)$, while the ordinary bisector has only the first term; so $\ell_{ij}$ is the ordinary bisector moved by $(w_i - w_j)/(2 |p_j - p_i|)$ in the direction $u$, toward $p_j$ when $w_i > w_j$. If the circles of radius $\sqrt{w_i}$ and $\sqrt{w_j}$ around $p_i$ and $p_j$ cross, each crossing point has $\pi_i = \pi_j = 0$, so both lie on $\ell_{ij}$, which is the line through them. Finally, for sites $(p, z_p)$ in space and a point $(x, 0)$, $|(x, 0) - (p, z_p)|^2 = |x - p|^2 + z_p^2 = \pi(x)$ for the weight $-z_p^2$, so the Voronoi diagram cut by the plane $z = 0$ is the power diagram of the points $p$ with these weights. $\blacksquare$
