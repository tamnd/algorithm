---
title: The crossing number algorithm decides the boundary exactly and computes the even-odd parity
proves: [correctness, termination]
status: full
---

We use the pseudocode of the page. The polygon is a cyclic list $v_0, \ldots, v_{n-1}$ with edges $e_i = v_i v_{i+1}$ (indices modulo $n$), and $C$ is the union of the closed edges. The query point is $q$. An edge $ab$ *straddles* height $y$ when exactly one of $a_y > y$ and $b_y > y$ holds; this is the test of line L5 for $y = q_y$. For $p \notin C$ let $N(p)$ be the number of edges that straddle $p_y$ and meet the line $y = p_y$ at a point with $x > p_x$, and let $\pi(p) = N(p) \bmod 2$.

**Claim.** The algorithm stops after at most $n$ iterations. It returns BOUNDARY if and only if $q \in C$. Otherwise it returns INSIDE if and only if $\pi(q) = 1$, and when $C$ is a simple polygon, $\pi(q) = 1$ if and only if $q$ is in the bounded component of $\mathbb{R}^2 \setminus C$.

**Step 1 (line L7 counts exactly the crossings right of $q$).** Let $ab$ straddle $q_y$, so $a_y \ne b_y$ and the edge meets the line $y = q_y$ at exactly one point, with $x$-coordinate $x^* = a_x + (b_x - a_x)(q_y - a_y)/(b_y - a_y)$. Expanding line L6,

$$s = (b_x - a_x)(q_y - a_y) - (b_y - a_y)(q_x - a_x) = (b_y - a_y)(x^* - q_x).$$

If $s = 0$ then $x^* = q_x$, so $q$ is the point of $ab$ at height $q_y$, and line L4 would have returned in this iteration. So $s \ne 0$, and $s > 0$ holds exactly when $x^* - q_x$ has the sign of $b_y - a_y$. Hence the test of line L7 is true if and only if $x^* > q_x$.

**Step 2 (loop invariant and termination).** Before the iteration for $i$, $q$ is on none of $e_0, \ldots, e_{i-1}$, and $c$ is the parity of the number of edges among them that straddle $q_y$ and cross the line right of $q$. It holds for $i = 0$ by line L1. Line L4 returns BOUNDARY exactly when $q \in e_i$; otherwise lines L5 to L7 flip $c$ exactly when $e_i$ is such an edge, by Step 1. The loop runs at most $n$ times, each in constant time. If it ends without a return, $q \notin C$ and $c = \pi(q)$, so line L8 returns INSIDE exactly when $\pi(q) = 1$. This proves the claim up to the last sentence.

**Step 3 (the half-open rule is a ray just above $q$).** Let $p \notin C$, let $\delta > 0$ be the least positive value of $|v_y - p_y|$ over the vertices, and let $0 < \varepsilon < \delta$. A vertex with $v_y > p_y$ has $v_y > p_y + \varepsilon$, and a vertex with $v_y \le p_y$ has $v_y < p_y + \varepsilon$. So an edge meets the line $y = p_y + \varepsilon$, at a single interior point of the edge, if and only if it straddles $p_y$, and no vertex lies on that line. The crossing abscissa of a straddling edge is continuous in $\varepsilon$ and tends to $x^* \ne p_x$ (as $p \notin C$). So for all small $\varepsilon$, $N(p)$ is the number of points in which the horizontal ray from $(p_x, p_y + \varepsilon)$ to the right meets $C$, and each of these points is an interior point of a non-horizontal edge.

**Step 4 ($\pi$ is constant on each component of $\mathbb{R}^2 \setminus C$).** Two points in one component of the open set $\mathbb{R}^2 \setminus C$ are joined by a path of horizontal and vertical segments in that set, so it suffices to show that $\pi$ does not change along such a segment.

- *Horizontal segment.* The set of straddling edges depends only on the height. A crossing point of a straddling edge passes from the right of $p$ to the left only if $p$ meets it, but it lies on $C$.
- *Vertical segment* at abscissa $x$. $N$ can change only at a height $t$ where the straddle status of some edge changes, that is, at the height of a vertex. Fix such a height $t$. The vertices at height $t$ form maximal horizontal runs: a run is a chain $u_1, \ldots, u_k$ of consecutive vertices at height $t$ with an edge $e$ entering $u_1$ and an edge $e'$ leaving $u_k$, both non-horizontal (if all vertices are at height $t$, no edge ever straddles and $N = 0$ throughout). The run is a segment of $C$ at height $t$ that does not contain $(x, t)$, so it is entirely left or entirely right of $x$. A run on the left adds nothing for heights near $t$. For a run on the right, the edges $e$ and $e'$ cross right of $x$ at heights near $t$; at heights just above $t$ the run contributes the number of edges among $e, e'$ whose other endpoint is above $t$, and at heights just below $t$ the number whose other endpoint is below; these two numbers sum to 2, so they have the same parity. By Step 3 the value at height exactly $t$ equals the value just above. So $\pi$ is the same just below, at and just above $t$.

**Step 5 ($\pi$ changes across an edge).** Let $m$ be an interior point of a non-horizontal edge $e$ at a height that no vertex has, and let $p^-$ and $p^+$ be points at the height of $m$ just left and just right of $m$, so close that the segment $p^- p^+$ meets $C$ only in $m$. The same edges straddle at this height for both points, and only the crossing of $e$, at $m$, is right of $p^-$ and not right of $p^+$. So $N(p^-) = N(p^+) + 1$.

**Step 6 (simple polygons).** Let $C$ be simple. By the [Jordan curve theorem](/jordan-curve-theorem/) for polygons, $\mathbb{R}^2 \setminus C$ has exactly two components, one bounded and one unbounded. Points above all vertices have $N = 0$, and they lie in the unbounded component, so $\pi = 0$ there by Step 4. By Steps 4 and 5, $p^-$ and $p^+$ are in different components, and one of them has $\pi = 1$; that component is not the unbounded one, so it is the bounded one, and $\pi = 1$ on all of it by Step 4. Hence for $q \notin C$, $\pi(q) = 1$ if and only if $q$ is in the bounded component. $\blacksquare$

**Non-simple polygons.** Steps 1 to 5 do not use simplicity. So for any closed polygon the algorithm returns the parity $\pi(q)$, which is constant on each face of the arrangement of the edges and flips across each edge. This is the even-odd fill rule. Step 3 shows that it equals the parity of the number of crossings of a ray that meets $C$ only at interior points of edges. The winding number of $C$ around the start point is the signed count of the same crossings, $+1$ for an edge that goes up and $-1$ for one that goes down (Hormann and Agathos 2001, the paper cited on the page), and a sum of terms $\pm 1$ has the parity of the number of terms. So $\pi(q)$ is the winding number of $C$ around $q$ modulo 2.
