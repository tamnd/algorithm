---
title: In a fixed bridged LAN, the protocol elects the least bridge id as root within one round and reaches the shortest-path tree with the 802.1D tie-breaks within D + 2 rounds, and the forwarding ports form a spanning tree
proves: [correctness, termination, time.worst]
status: full
---

**Setting.** A bridged LAN is a bipartite graph: bridges on one side, LANs on the other, and a port for each edge. Each bridge $b$ has a distinct id; each port $p$ has an id, distinct on its bridge, and a cost $c(p) > 0$. Vectors are compared lexicographically, smaller is better. The bridges run the main pseudocode in synchronous rounds: in each round every bridge decides (lines L1 to L6), then sends (lines L7, L8), and all BPDUs are received at the end of the round (lines L9, L10). No bridge, port or LAN changes during the run, and messages are not lost. Fix one connected component; the claims hold in each component on its own.

Let $r$ be the least bridge id in the component. For a bridge $x$ let $d(x)$ be the least cost of a path from $r$ to $x$, where a path enters a bridge $y$ from a LAN $\ell$ at cost $c(p)$ of $y$'s port $p$ on $\ell$. Then $d(r) = 0$ and, for $x \ne r$,

$$d(x) = \min_{\text{ports } p \text{ of } x} \Bigl( \min_{y \text{ on the LAN of } p} d(y) + c(p) \Bigr). \qquad (1)$$

For each LAN $\ell$ let its *designated port* be the port $(y, q)$ on $\ell$ with the least triple $(d(y), y, q)$, and its *designated vector* $V_\ell = (r, d(y), y, q)$. For each bridge $x \ne r$ let its *root port* be the port $p$ of $x$, on a LAN $\ell$ whose designated port is not on $x$, with the least $(d(D_\ell) + c(p), D_\ell, q_\ell, p)$, where $(D_\ell, q_\ell)$ is the designated port of $\ell$. This is the tree that the centralized function of the implementation computes, and Claims 4 and 5 show that it is the one the protocol reaches. Let the *depth* of $x$ be the number of bridges on the path from $x$ up to $r$ through root ports and designated ports, with $r$ at depth 0, and let $D$ be the largest depth. Assume $D < \mathrm{MAXAGE}$.

**Claim 1 (no information is better than the truth).** At all times, every vector $(R, C, S, P)$ stored on a port or sent in a BPDU satisfies $R \ge r$, and $C \ge d(S)$ if $R = r$. Every bridge state $(\mathrm{root}[x], \mathrm{cost}[x])$ satisfies $(\mathrm{root}[x], \mathrm{cost}[x]) \ge (r, d(x))$.

*Proof.* By induction on time. At the start no port has information, and each bridge has state $(x, 0) \ge (r, d(x))$ because $x \ge r$, with equality only at $x = r$. A bridge's state is set in line L5 either to $(x, 0)$ or to $(R, C + c(p))$ for a stored vector $(R, C, S, P)$ on a port $p$ of $x$. In the second case, by induction $R \ge r$, and if $R = r$ then $C + c(p) \ge d(S) + c(p) \ge d(x)$ by (1), since $S$ is on the LAN of $p$. A BPDU sent by $x$ is $(\mathrm{root}[x], \mathrm{cost}[x], x, q)$, so it satisfies the claim because the state of $x$ does. Stored vectors are copies of sent ones. Ids are only copied, so every root id in the system is the id of a bridge in the component, hence $\ge r$. $\square$

**Claim 2 (the root).** From round 1 on, bridge $r$ has state $(r, 0)$, has no root port, and sends a BPDU with age 0 on each of its designated ports in every round.

*Proof.* Line L2 starts from $(r, 0, r, 0, 0)$, and by Claim 1 no stored vector gives a candidate $(R, C + c(p), \dots)$ below it: $R > r$, or $R = r$ and $C + c(p) > C \ge 0$. So line L4 never fires and $\mathrm{rootport}[r] = \mathrm{nil}$; line L7 sends in every round. $\square$

**Claim 3 (the designated vector wins its LAN).** Suppose that from round $t$ on, the bridge $D_\ell$ of the designated port $(D_\ell, q_\ell)$ of $\ell$ has state $(r, d(D_\ell))$ and sends on $q_\ell$ in every round. Then from the end of round $t$ on, every other port on $\ell$ stores $V_\ell$, and the port $q_\ell$ stays designated.

*Proof.* Port $q_\ell$ is not the root port of $D_\ell$: by Claim 1, any vector stored on it is $(R, C, S, P)$ with $(R, C, S, P) \ge (r, d(S), S, P)$, and $(r, d(S), S, P) > V_\ell$ because $(d(S), S, P) > (d(D_\ell), D_\ell, q_\ell)$ by the choice of the designated port. So it gives the candidate $(R, C + c(q_\ell), \dots) > (r, d(D_\ell), \dots)$, which cannot be the best when the state is $(r, d(D_\ell))$. For the same reason, $V_\ell$ is less than the stored vector, so line L6 marks $q_\ell$ designated and line L8 sends exactly $V_\ell$. At any other port on $\ell$, the stored vector is either missing, or it is $\ge V_\ell$ by the same argument, with equality only if it is $V_\ell$ itself. So line L9 accepts $V_\ell$ in every round, and nothing can replace it later, since no vector is smaller and the only other way in, a vector from the same sender, again comes from $D_\ell$ and is $V_\ell$. Its age is refreshed each round. $\square$

**Claim 4 (convergence of the states).** A bridge at depth $k$ has state $(r, d(x))$ from round $k + 1$ on, and sends in every round from round $k + 1$ on.

*Proof.* By induction on $k$. Depth 0 is Claim 2. Let $x$ have depth $k + 1$, with root port $p$ on LAN $\ell$, and with $D_\ell$ at depth $k$. By induction, $D_\ell$ has the right state and sends from round $k + 1$ on, so by Claim 3 every port of $x$ on a LAN whose designated bridge is at depth at most $k$ stores the designated vector from the end of round $k + 1$. In round $k + 2$, the candidate of $p$ is $(r, d(D_\ell) + c(p), D_\ell, q_\ell, p) = (r, d(x), \dots)$ by (1). By Claim 1 no candidate is below $(r, d(x))$. So $x$ takes state $(r, d(x))$ in round $k + 2$ and keeps it, because the vector on $p$ cannot be replaced (Claim 3). The BPDU on $p$ arrives in every round, so line L7 lets $x$ send in every round. A BPDU sent by a bridge at depth $j$ has age $j$, so every stored designated vector has age at most $D < \mathrm{MAXAGE}$ when line L1 checks it, and line L1 never drops it. $\square$

**Claim 5 (the roles).** From round $D + 2$ on, the root port of each bridge $x \ne r$ is the root port defined above, the designated ports are exactly the designated ports defined above, and all other ports are blocked.

*Proof.* By Claim 4, from round $D + 1$ on every bridge has its final state and every designated bridge sends, so by Claim 3 every port $p$ of $x$ on a LAN $\ell$ whose designated port is not $p$ stores $V_\ell$. If the designated port of $\ell$ is on another bridge, the candidate of $p$ in line L4 is $(r, d(D_\ell) + c(p), D_\ell, q_\ell, p)$, the key of the root port definition. If it is another port $q$ of $x$ itself, the candidate is $(r, d(x) + c(p), \dots)$, worse than the state. A port $q_\ell$ that is designated for its LAN gives no better candidate (Claim 3). So line L4 picks the defined root port. For a port $p \ne$ root port on $\ell$: if $p$ is the designated port of $\ell$, Claim 3 shows it is designated; otherwise it stores $V_\ell$, and $(r, d(x), x, p) > V_\ell$ by the choice of the designated port, so line L6 blocks it. $\square$

**Theorem.** From round $D + 2$ on, the forwarding ports (root ports and designated ports) form a spanning tree of the component, viewed as a bipartite graph of bridges and LANs, and it is the shortest-path tree from $r$ with the tie-breaks above.

*Proof.* By Claim 5, each LAN has exactly one designated port, and each bridge other than $r$ has exactly one root port. Orient each root port from the bridge to its LAN, and each designated port from the LAN to its bridge. Then every node except $r$ has exactly one outgoing edge, toward its parent. Following parents strictly lowers the key $(d, \cdot)$: from a bridge $x$ to its root LAN $\ell$, and then to the designated bridge $D_\ell$ with $d(D_\ell) = d(x) - c(p) < d(x)$. So the walk ends at $r$ with no cycle. A graph on $N$ nodes in which every node but one has one parent and the parent walks end at the same node is a spanning tree with $N - 1$ edges. Each bridge's path to $r$ has cost $d(x)$, so it is a shortest-path tree. $\blacksquare$

**Time.** By Claim 5, the protocol converges in $D + 2 = O(D)$ rounds. In each round each bridge sends one BPDU per designated port, so at most $m$ BPDUs per round when there are $m$ ports, and $O(D m)$ until convergence. A bridge stores one vector per port, so the space is $O(m)$ in total.

**Failures.** When a bridge fails, the vectors that it or its subtree sent are no longer refreshed. A bridge sends only when a BPDU reached its root port in the last round (line L7), and it adds one to the message age at each hop, so information that no longer comes from a live root keeps getting older and line L1 drops it within MAXAGE rounds. After that the claims above apply again to the remaining bridges, as if from a new start with some stale but worse vectors, which Claim 3 overrides. This is the reason for the age: without it, stale vectors could circulate as in [count-to-infinity](/count-to-infinity/).
