---
title: Fast recovery repairs one loss without a timeout and leaves one half of the window in flight
proves: [correctness]
status: full
---

**The model.** Segments are numbered $0, 1, \ldots, n-1$, and the windows count segments. Each transmission either is lost or reaches the receiver exactly $R/2$ after it is sent, so the network keeps the order of the segments. The receiver keeps the segments that it gets, and after each arrival it sends a cumulative ACK $a$, the smallest segment number that it does not have. Every ACK reaches the sender $R/2$ later. The sender runs lines L1 to L18 for each ACK. One retransmission timer runs while data is outstanding. It restarts on each ACK of new data, it fires $\text{RTO} > 2R$ after its last start, and on a timeout the sender sets ssthresh, sets $\text{cwnd} = 1$, sets $\text{snd\_nxt} = \text{snd\_una}$ and sends again. The caller says which transmissions are lost.

**Lemma 1 (invariants).** After each event: $0 \le \text{snd\_una} \le \text{snd\_nxt} \le n$, $\text{cwnd} \ge 1$, $\text{ssthresh} \ge 2$, and if $\text{snd\_una} < n$ then $\text{snd\_nxt} > \text{snd\_una}$.

*Proof.* The receiver never acknowledges a segment that was not sent, so $a \le \text{snd\_nxt}$, and line L11 keeps $\text{snd\_una} \le \text{snd\_nxt}$. Line L18 raises snd_nxt only while it is below $n$. Line L6 and the timeout set $\text{ssthresh} \ge 2$. Line L9 gives $\text{cwnd} \ge 5$, lines L2 and L17 only add, line L14 takes a maximum with 1, line L16 sets $\text{cwnd} = \text{ssthresh} \ge 2$, and the timeout sets 1. Every event ends with line L18 (or the same fill after a timeout). Since $\text{cwnd} \ge 1$, the fill sends at least one segment when nothing is outstanding and $\text{snd\_una} < n$. $\square$

**Lemma 2 (in order).** The receiver hands the segments to the application in the order $0, 1, 2, \ldots$, each one once.

*Proof.* The receiver hands over segment $a$ only when it has all of $0, \ldots, a$, and then it raises $a$. Copies of a segment below $a$ are ignored. $\square$

**Theorem 1 (one loss).** Let the ACK $a = s$ arrive at time $T_0$, outside fast recovery, and let $W = \text{snd\_nxt} - \text{snd\_una} = \text{cwnd} \ge 4$ just after line L18 of this ACK. Let exactly one of the $W$ segments in flight, segment $s = \text{snd\_una}$, be lost, while its retransmission and all later transmissions arrive. Assume that the sender has more data to send. Then the sender repairs the loss without a timeout. During fast recovery it sends $\lfloor W/2 \rfloor - 1$ new segments, the retransmission is acknowledged one round trip after it is sent, and just after line L18 of that ACK, $\text{cwnd} = \lfloor W/2 \rfloor$ and $\lfloor W/2 \rfloor$ segments are in flight. This holds for Reno and for NewReno.

*Proof.* The $W - 1$ segments after $s$ arrive and each one makes a duplicate ACK $a = s$. The first two of them run line L4 only, so cwnd stays $W$ and line L18 sends nothing, because the flight is already $W$. The third one runs lines L6 to L9. The flight is $W$, so $\text{ssthresh} = \max(\lfloor W/2 \rfloor, 2) = \lfloor W/2 \rfloor$, since $W \ge 4$. Line L8 resends $s$ and line L9 sets $\text{cwnd} = \lfloor W/2 \rfloor + 3$. Each of the other $W - 4$ duplicate ACKs runs line L2, so after the last one $\text{cwnd} = \lfloor W/2 \rfloor + 3 + W - 4 = \lfloor W/2 \rfloor + W - 1$. snd_una does not move, and line L18 keeps the flight at most cwnd. So the sender has sent $(\lfloor W/2 \rfloor + W - 1) - W = \lfloor W/2 \rfloor - 1$ new segments in fast recovery.

The retransmission of $s$ leaves before all of these new segments, so it arrives first. Then the receiver has $0, \ldots, s + W - 1$, and it sends the ACK $a = s + W$. This ACK reaches the sender one round trip after line L8. The new segments arrive later, and each one makes a new ACK, not a duplicate, so no other duplicate ACK exists. For the timer: it restarted at $T_0$. All $W$ segments in flight were sent at or before $T_0$, so the third duplicate ACK, made by segment $s + 3$, arrives at a time $T_1 \le T_0 + R$, and the ACK of the retransmission arrives at $T_1 + R \le T_0 + 2R < T_0 + \text{RTO}$. Duplicate ACKs do not restart the timer, so it does not fire before. The ACK $a = s + W$ is above recover $= s + W - 1$, so line L15 is taken (NewReno also takes it, because line L12 needs $a \le \text{recover}$). Line L16 sets $\text{cwnd} = \lfloor W/2 \rfloor$. The flight is the $\lfloor W/2 \rfloor - 1$ new segments, so line L18 sends one more, and the flight becomes $\lfloor W/2 \rfloor$. $\blacksquare$

So the sender keeps about one half of the window in flight during the whole repair: the flight is $W$ until the new data starts at the $(\lceil W/2 \rceil + 1)$-th duplicate ACK, and after it the sender sends one new segment per duplicate ACK. This is Jacobson's conservation of packets: one new segment enters the network for each segment that leaves.

**Theorem 2 (NewReno, several losses).** Take the window of Theorem 1, with $\text{recover} < s$ before it, and let it lose $k \ge 1$ of its segments $s_1 < \cdots < s_k$, with $s_1 = s$, while the retransmissions and all other segments arrive. Assume that the losses leave at least three segments after $s_1$ that arrive before any retransmission. Then NewReno repairs all $k$ losses without a timeout, in one fast recovery that lasts $k$ round trips.

*Proof.* The segments after $s_1$ that arrive make duplicate ACKs, and the third one starts fast recovery as in Theorem 1, with $\text{recover} = s_1 + W - 1 \ge s_k$. The retransmission of $s_1$ arrives one round trip later. Then the receiver has all segments below $s_2$, so the ACK is $a = s_2 \le \text{recover}$. This is a partial ACK, and lines L13 and L14 resend $s_2$ at once. By induction on $j$, the ACK of the retransmission of $s_j$ arrives one round trip after it is sent, it names $s_{j+1}$ for $j < k$, and line L13 resends $s_{j+1}$. For $j = k$, the ACK is above recover, and line L16 ends fast recovery. The first of these ACKs comes at most $2R$ after $T_0$, as in Theorem 1. Each of them acknowledges new data, so the timer restarts, and the next one comes $R < \text{RTO}$ later. So the timer does not fire. Line L14 keeps $\text{cwnd} \ge 1$, so line L18 never blocks a retransmission. $\blacksquare$

Reno, without lines L12 to L14, takes the first partial ACK as the end of fast recovery at line L16. It then needs three new duplicate ACKs for $s_2$ to start again, and it halves ssthresh a second time. If too few segments are in flight to make three duplicate ACKs, Reno waits for a timeout. The examples on the page show both cases.

**Theorem 3 (termination).** If only finitely many transmissions are lost, the sender gets all $n$ segments acknowledged.

*Proof.* Let $t^*$ be a time after the last lost transmission. By Lemma 1, while $\text{snd\_una} < n$ some segment is outstanding, so the timer runs. Take any time $t \ge t^*$ with $\text{snd\_una} = u < n$. If a copy of segment $u$ sent after $t^*$ is in flight, it arrives, and its ACK is above $u$. Otherwise, either a new ACK comes in, or the timer fires within $\text{RTO} \cdot 2^m$, where $m$ is the number of timeouts since the last new ACK. A timeout resends $u$ after $t^*$, so that copy arrives, and the ACK above $u$ comes one round trip later. In each case snd_una grows by at least 1 within a bounded time. Since snd_una never falls and is at most $n$, it reaches $n$. $\blacksquare$
