---
title: Path vector never holds a looping path, its quiet states are exactly the stable path assignments, and with shortest-path ranking it converges after the last change
proves: [correctness, termination]
status: full
---

**Setting.** A graph $G = (V, E)$ with a destination $d$. Each node $u \ne d$ has a ranking: a strict order on a set $\mathcal{P}^u$ of simple paths from $u$ to $d$, its permitted paths. The protocol is the main pseudocode: $u$ stores the last path $\mathrm{rib}[u][v]$ received from each neighbour $v$; on each change of $\mathrm{rib}[u]$ or of its links it sets $\mathrm{best}[u]$ to the best permitted path among $u \cdot \mathrm{rib}[u][v]$ that do not contain $u$ (lines L6, L7), or $\varepsilon$ if there is none; and after every change of $\mathrm{best}[u]$ it sends, within a bounded time, its current best to every neighbour (lines L8, L9). When a link comes up, both ends send their best over it (line L10). Channels are reliable and FIFO.

**Part 1 (no loops, at every time).** Each $\mathrm{best}[u]$ is $\varepsilon$, the path $(d)$, or $u \cdot P$ where $P$ is a path that does not contain $u$ (line L6). By induction over the order of events, every path that a node sends is a best path and so is simple: if $P$ is simple and $u \notin P$, then $u \cdot P$ is simple. So no node ever holds or forwards a path with a repeated node.

**Part 2 (quiet states are stable).** Call a state quiet if no message is in flight and no send is pending. In a quiet state, for every link $(u, v)$, $\mathrm{rib}[u][v] = \mathrm{best}[v]$, because $v$ sent its latest best after its last change (or when the link came up) and FIFO delivered it last. Write $\pi(u) = \mathrm{best}[u]$. Line L7 then says that $\pi(u)$ is the best permitted path among $u \cdot \pi(v)$ over the neighbours $v$, which is the definition of a stable path assignment in the stable paths problem (SPP) of Griffin, Shepherd and Wilfong. It is also consistent: if $\pi(u) = u \cdot P$ with first hop $v$, then $P = \mathrm{rib}[u][v] = \pi(v)$, so following first hops from $u$ walks along $\pi(u)$ to $d$. Conversely, a stable assignment, once held by all nodes with all channels empty, is quiet, since no recomputation changes a best. So the protocol can stop only in a stable assignment, and an SPP instance with no stable assignment (BAD GADGET) makes it run for ever.

**Part 3 (shortest-path ranking converges).** Now let every simple path be permitted and rank paths by the number of links, with ties broken by a fixed total order on node sequences, the same at every node. Fix a time $T_0$ after which the graph does not change. A path is *valid* if all its links exist after $T_0$.

*Step 3a (invalid paths die out).* By induction on the number of nodes $\ell$, we show that there is a time $T_\ell$ after which no node holds an invalid path of at most $\ell$ nodes, as $\mathrm{best}$, in $\mathrm{rib}$, or in a message. For $\ell = 1$ the only path is $(d)$, which is valid. Let $\ell \ge 2$ and let $P = u \cdot Q$ be invalid with $\ell$ nodes, where $Q$ starts at $v$. Node $u$ can hold $P$ as its best only while $\mathrm{rib}[u][v] = Q$. If the link $(u, v)$ is gone, $u$ deleted $\mathrm{rib}[u][v]$ when the link went down (line L4) and never hears from $v$ again. Otherwise $Q$ is invalid with $\ell - 1$ nodes, and after $T_{\ell - 1}$ no message carries $Q$, so $\mathrm{rib}[u][v] \ne Q$. In both cases, from some time on $\mathrm{rib}[u][v] \ne Q$; the change of $\mathrm{rib}[u]$ makes $u$ recompute at once, and the new best is not $P$. Node $u$ then sends its new best to all neighbours, and once these messages arrive, no $\mathrm{rib}$ entry holds $P$. Only finitely many paths and nodes exist, so $T_\ell$ exists. Simple paths have at most $n$ nodes, so after $T_n$ every held path is valid.

*Step 3b (the target).* For each node $u$ that can reach $d$ after $T_0$, let $P^*(u)$ be its best valid path under the ranking. It is suffix-consistent: if $P^*(u) = u \cdot S$ with $S$ starting at $v$, then $S = P^*(v)$. Indeed $S$ is a shortest path from $v$; if $P^*(v)$ were a different, better-ranked path, it cannot contain $u$ (a shortest path from $v$ through $u$ has length at least $1 + \mathrm{dist}(u) > \mathrm{dist}(v)$), so $u \cdot P^*(v)$ is a valid simple path from $u$ of the same length as $P^*(u)$, which ranks before $P^*(u)$, which is a contradiction. So the paths $P^*$ form a tree toward $d$.

*Step 3c (induction on the tree).* We show that each node $u$ that can reach $d$ eventually has $\mathrm{best}[u] = P^*(u)$ for ever, by induction on its depth in the tree. For $u = d$ this holds from the start. Let $v$ be the parent of $u$, and suppose $\mathrm{best}[v] = P^*(v)$ from some time on, after $T_n$. Then $v$ never changes again, and the last best that $v$ sent to $u$ (after its last change, or when the link came up) is $P^*(v)$, so eventually $\mathrm{rib}[u][v] = P^*(v)$ for ever. From then on $u \cdot P^*(v) = P^*(u)$ is a candidate at every recomputation of $u$, and every other candidate is a valid simple path from $u$ (Step 3a), so it ranks after $P^*(u)$. Hence $u$ selects $P^*(u)$ at its next recomputation, which happens when $\mathrm{rib}[u][v]$ is set, and it keeps it. A node that cannot reach $d$ has no valid candidate after $T_n$, so its best is $\varepsilon$.

*Step 3d (termination).* After all bests are final, no node changes, so no node sends, and the finitely many messages in flight are delivered. The state is quiet, and by Part 2 the next hops follow the shortest-path tree $P^*$. $\blacksquare$

**Remark.** Step 3b is the only place where the ranking matters. The same argument works for any ranking in which extending a path always makes it worse and ties are broken in the same way at every node, for example by additive link costs. Under general policies it can fail, and the gadgets show what then happens: DISAGREE has two stable assignments and the outcome depends on timing; BAD GADGET has none.
