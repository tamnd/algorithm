---
title: Two-finger compaction moves the live cells into one block and rewrites every pointer
proves: [correctness, termination]
status: full
---

**Setting.** The heap has the cells $0, \ldots, n-1$, each with $k$ fields. Let $M$ be the set of marked cells when TWO-FINGER starts, and $L = |M|$. We assume that $M$ is closed under the fields (every non-nil field of a cell of $M$ is in $M$) and that every non-nil root is in $M$; the mark phase gives both, with $M$ the set of reachable cells. Write $f_j(x)$ for the original field $j$ of a cell $x$.

**Claim.** TWO-FINGER terminates with $\mathit{top} = L$, and there is a bijection $\varphi : M \to \{0, \ldots, L - 1\}$ with $\varphi(x) = x$ for every $x \in M$ with $x < L$, such that at the end, for each $x \in M$ and each $j$, field $j$ of cell $\varphi(x)$ holds $\varphi(f_j(x))$ (nil stays nil), and each root that held $x$ holds $\varphi(x)$. No mark is set at the end.

**Pass 1.** Call a run of lines L6 to L8 a *move* from the source $s = \mathit{live}$ to the destination $d = \mathit{free}$. Define $\varphi(x) = d$ if $x$ was the source of a move to $d$, and $\varphi(x) = x$ otherwise. We show that the following hold at the test of line L5, after the two inner loops:

- (J1) exactly $L$ cells are marked;
- (J2) the cells $0, \ldots, \mathit{free} - 1$ are marked, and the cells $\mathit{live} + 1, \ldots, n - 1$ are unmarked; if $\mathit{free} < n$ the cell $\mathit{free}$ is unmarked, and if $\mathit{live} \ge 0$ the cell $\mathit{live}$ is marked;
- (J3) every move so far had $s > \mathit{live}$ and $d < \mathit{free}$ for the current values, and $d < s$;
- (J4) the marked cells are exactly $\varphi(M)$; for each $x \in M$, cell $\varphi(x)$ holds the original fields of $x$; for each source $s$, field 0 of cell $s$ holds $\varphi(s)$.

*Initialization.* Before any move, $\varphi$ is the identity, so (J1), (J3) and (J4) hold. At the start $\mathit{free} = 0$ and $\mathit{live} = n - 1$, so the two ranges of (J2) are empty. Line L3 advances $\mathit{free}$ only over marked cells and stops at an unmarked cell or at $n$; line L4 moves $\mathit{live}$ down only over unmarked cells and stops at a marked cell or at $-1$. So (J2) holds at line L5. The same argument shows that the inner loops keep (J2) in every later iteration.

*Maintenance.* Suppose line L5 does not exit, so $\mathit{free} \le \mathit{live}$. Then $\mathit{free} < n$ and $\mathit{live} \ge 0$, so by (J2) the cell $d = \mathit{free}$ is unmarked and the cell $s = \mathit{live}$ is marked, and $d \ne s$, so $d < s$. By (J4), $s = \varphi(x)$ for one $x \in M$. The cell $s$ is not a destination of an earlier move, because by (J3) earlier destinations are below $\mathit{free} \le s$. So $s = x$ is a cell of $M$ that has not moved. The cell $d$ is unmarked, so by (J4) it is not $\varphi$ of any cell. Line L6 copies the fields of $s$ (the original fields of $s$, by (J4)) into $d$ and marks $d$; line L7 unmarks $s$ and writes $d$ into field 0 of $s$. Now $\varphi(s) = d$, the marked set changes from $\varphi_{\mathrm{old}}(M)$ to $\varphi_{\mathrm{old}}(M) \setminus \{s\} \cup \{d\} = \varphi(M)$, and the count of marked cells stays $L$. Lines L6 and L7 write only to $d$, to field 0 of $s$ and to two mark bits. The cell $d$ held no field that (J4) speaks of, and field 0 of $s$ belongs to a cell that is no longer $\varphi$ of anything. So (J1) and (J4) hold. Line L8 sets $\mathit{free} \leftarrow d + 1$ and $\mathit{live} \leftarrow s - 1$, and the inner loops only increase $\mathit{free}$ and decrease $\mathit{live}$, so (J3) holds for all moves.

*Termination.* Each iteration that does not exit increases $\mathit{free}$ by at least 1 and decreases $\mathit{live}$ by at least 1, so $\mathit{live} - \mathit{free}$ falls by at least 2. The inner loops stop because $\mathit{free} \le n$ and $\mathit{live} \ge -1$. So pass 1 ends after at most $n/2 + 1$ iterations of line L2.

*At the exit.* Line L5 exits with $\mathit{free} > \mathit{live}$. If $\mathit{free} > \mathit{live} + 1$, the cell $\mathit{live} + 1$ is below $\mathit{free}$, so marked, and above $\mathit{live}$, so unmarked, by (J2). This is impossible, so $\mathit{free} = \mathit{live} + 1$. Then (J2) says that the marked cells are exactly $0, \ldots, \mathit{free} - 1$, and by (J1) $\mathit{free} = L$. Line L9 sets $\mathit{top} = L$.

**Facts about $\varphi$.** Every source is greater than the final $\mathit{live} = L - 1$ by (J3), so every source is at least $L$, and every destination is less than the final $\mathit{free} = L$. So no cell is both a source and a destination, and each cell is moved at most once. A cell of $M$ that is not a source keeps its mark (only line L7 clears a mark, and only of a source). At the end the cells from $L$ up are unmarked, so every cell of $M$ that is at least $L$ is a source, and no cell of $M$ below $L$ is a source. Hence $\varphi(x) = x$ for $x \in M$ with $x < L$, and for $x \in M$ with $x \ge L$, field 0 of cell $x$ holds $\varphi(x) < L$. The destinations are distinct, since $\mathit{free}$ grows, and none of them is a cell of $M$ below $L$, since each destination was unmarked. So $\varphi$ is injective, and its image is the marked set $\{0, \ldots, L - 1\}$ by (J4) and the exit argument.

**Pass 2.** Every value $v$ that lines L10 and L11 rewrite is a root or a field of a cell $\varphi(x)$ with $x \in M$, and by (J4) the latter is an original field of $x$. By the assumptions, a non-nil $v$ is in $M$. If $v < L$, then $\varphi(v) = v$ and line L11 keeps it. If $v \ge L$, then line L11 replaces it with field 0 of cell $v$, which is $\varphi(v)$. Pass 2 writes only to roots and to the cells below $L$, and reads field 0 only of cells from $L$ up, so no forwarding address changes before it is read. So at the end field $j$ of cell $\varphi(x)$ holds $\varphi(f_j(x))$, and each root holds $\varphi$ of its old value. Line L12 clears the marks of $0, \ldots, L - 1$, which are the only marked cells. $\blacksquare$
