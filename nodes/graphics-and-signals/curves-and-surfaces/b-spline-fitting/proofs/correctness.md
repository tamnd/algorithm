---
title: BSPLINE-FIT returns the unique least-squares control points exactly when the Schoenberg-Whitney condition holds for some sites, and reports a zero pivot otherwise
proves: [correctness, uniqueness, termination]
status: full
---

We use the notation of the page. The data are $Q_0, \dots, Q_m \in \mathbb{R}^d$ at parameters $t_0 \le \dots \le t_m$, the degree is $p$, the knot vector $U$ has $n + p + 2$ knots, and $N_{i,p}$, $i = 0, \dots, n$, are the B-splines on $U$. The collocation matrix is $N \in \mathbb{R}^{(m+1) \times (n+1)}$ with $N_{ki} = N_{i,p}(t_k)$. We work in exact arithmetic (the real RAM, or rationals).

We use three standard facts about B-splines (see the pages [B-spline](/b-spline/) and [Cox-de Boor recursion](/cox-de-boor-recursion/)): (B1) $N_{i,p}$ is zero outside $[u_i, u_{i+p+1})$, closed at the right end of the domain; (B2) if $u_s \le t < u_{s+1}$, the only B-splines that can be nonzero at $t$ are $N_{s-p,p}, \dots, N_{s,p}$; (B3) the Schoenberg-Whitney theorem: for sites $\tau_0 < \dots < \tau_n$ in the domain, the square matrix $[N_{j,p}(\tau_i)]$ is nonsingular if and only if $N_{i,p}(\tau_i) \ne 0$ for all $i$.

**Lemma 1 (normal equations).** $\mathbf{P}$ minimizes $F(\mathbf{P}) = \lVert \mathbf{Q} - N\mathbf{P} \rVert_F^2$ if and only if $N^T N \mathbf{P} = N^T \mathbf{Q}$.

*Proof.* $F$ is the sum over the $d$ coordinates $c$ of $f(x) = \lVert q - Nx \rVert^2$ with $x$ and $q$ the columns $c$ of $\mathbf{P}$ and $\mathbf{Q}$, and the coordinates do not interact, so it suffices to treat one $f$. For any $x$ and $y$,
$$f(x + y) = f(x) - 2 y^T N^T (q - Nx) + \lVert N y \rVert^2 .$$
If $N^T N x = N^T q$, the middle term is zero and $f(x + y) = f(x) + \lVert Ny \rVert^2 \ge f(x)$, so $x$ is a minimizer. Conversely, if $g = N^T(q - Nx) \ne 0$, take $y = \varepsilon g$ with a small $\varepsilon > 0$: $f(x + y) = f(x) - 2\varepsilon \lVert g \rVert^2 + \varepsilon^2 \lVert Ng \rVert^2 < f(x)$, so $x$ is not a minimizer. $\square$

**Lemma 2 (the assembly).** After line L5, $A = N^T N$ and $R = N^T \mathbf{Q}$. Both have the band property $A_{ij} = 0$ for $|i - j| > p$.

*Proof.* By definition $(N^T N)_{ij} = \sum_{k=0}^m N_{ki} N_{kj}$ and $(N^T \mathbf{Q})_i = \sum_k N_{ki} Q_k$. Fix $k$ and let $s$ be the span of $t_k$. By (B2), $N_{ki} = 0$ unless $s - p \le i \le s$, and in that range $N_{ki} = B_{i - s + p}$, the value that L3 computes. So the term $k$ of $(N^T N)_{ij}$ is $B_a B_b$ with $a = i - s + p$, $b = j - s + p$ when both are in $0, \dots, p$, and zero otherwise. Line L4 adds exactly these products, and L5 adds exactly the terms $B_a Q_k$. Summing over $k$ (the loop L2) gives the claim. If $|i - j| > p$, no $k$ has both indices in a window of width $p + 1$, so $A_{ij} = 0$. $\square$

**Lemma 3 (rank).** $N$ has full column rank $n + 1$ if and only if there are indices $k_0 < k_1 < \dots < k_n$ with $t_{k_0} < t_{k_1} < \dots < t_{k_n}$ and $N_{i,p}(t_{k_i}) \ne 0$ for $i = 0, \dots, n$.

*Proof.* If such indices exist, the rows $k_0, \dots, k_n$ of $N$ form the square matrix $[N_{j,p}(t_{k_i})]$, which is nonsingular by (B3). So $N$ has $n + 1$ independent rows and rank $n + 1$. Conversely, if $N$ has rank $n + 1$, it has $n + 1$ independent rows $k_0 < \dots < k_n$. Two rows with equal parameters are equal, so the parameters $t_{k_i}$ are distinct, and since the $t_k$ are sorted they increase. The square matrix of these rows is nonsingular, so by (B3) $N_{i,p}(t_{k_i}) \ne 0$ for all $i$. $\square$

**Lemma 4 (band $LDL^T$).** Let $A$ be symmetric with band $p$. If $A$ is positive definite, the recurrences of line L6 run to the end with every $D_i > 0$, and give $A = LDL^T$ with $L$ unit lower triangular and $L_{ij} = 0$ for $i - j > p$. If $A$ is positive semidefinite and singular, some $D_i$ is zero.

*Proof.* Let $A_r$ be the leading $r \times r$ block. We show by induction on $r$ that after the rows $0, \dots, r - 1$ have been processed, $A_r = L_r D_r L_r^T$, with $L_r$ and $D_r$ the leading blocks, and that $L$ has band $p$ in these rows. For $r = 1$, $D_0 = A_{00}$. For the step, write the row $r$ of $A_r$ as $a^T$ and its diagonal entry as $\alpha$. We need a row $\ell^T$ of $L$ and a pivot $\delta$ with $L_r D_r \ell = a$ and $\delta = \alpha - \ell^T D_r \ell$. The first is a forward substitution with the unit lower triangular $L_r$ and the diagonal $D_r$, which is the formula for $L_{rj}$ in L6, taken for increasing $j$. If $a_j = 0$ for $j < r - p$, the forward substitution gives $\ell_j = 0$ for those $j$, because each such $\ell_j$ is a combination of $a_0, \dots, a_j$ and of earlier $\ell$ values, all zero. So the band is kept, and the sums in L6 may start at $\max(0, r - p)$. The second is the formula for $D_r$. Then $A_{r+1} = L_{r+1} D_{r+1} L_{r+1}^T$ by block multiplication. The determinant gives $\det A_{r+1} = D_0 D_1 \cdots D_r$. If $A$ is positive definite, every leading block has a positive determinant, so every $D_i > 0$ and no division by zero occurs. If $A$ is positive semidefinite, every leading block has a nonnegative determinant. If no pivot were zero, all leading determinants would be positive and $A$ would be positive definite. So a singular $A$ has a zero pivot, which line L6 detects. $\square$

**Theorem.** Suppose the sites satisfy the condition of Lemma 3. Then BSPLINE-FIT terminates and returns the unique minimizer of $F$. If the condition fails, line L6 finds a zero pivot and the algorithm stops with that report.

*Proof.* Termination: every loop in L1 to L7 has a fixed number of steps. By Lemma 2, L1 to L5 build $A = N^T N$ and $R = N^T \mathbf{Q}$. The matrix $N^T N$ is positive semidefinite, since $x^T N^T N x = \lVert Nx \rVert^2 \ge 0$, and it is positive definite exactly when $Nx = 0$ only for $x = 0$, that is, when $N$ has full column rank. If the condition holds, $N$ has full rank by Lemma 3, so $A$ is positive definite, and by Lemma 4 L6 succeeds. Line L7 solves $Ly = R$, $Dz = y$ and $L^T \mathbf{P} = z$, so $A\mathbf{P} = LDL^T \mathbf{P} = R$: $\mathbf{P}$ solves the normal equations, and by Lemma 1 it is a minimizer. A positive definite $A$ is nonsingular, so the normal equations have one solution, and by Lemma 1 the minimizer is unique. If the condition fails, $N$ does not have full rank by Lemma 3, $A$ is positive semidefinite and singular, and by Lemma 4 some pivot is zero. $\blacksquare$
