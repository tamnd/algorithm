---
title: Quadric simplification collapses a cheapest valid edge at each step and keeps the topology of a 2-manifold
proves: [correctness]
status: full
---

We use the names of the pseudocode. For a quadric $Q$ and a point $v$, write $E_Q(v) = \bar v^{\mathsf T} Q \bar v$ with $\bar v = (v, 1)$. An edge is valid when it passes the test of line L6.

**Claim.** (1) At all times, for each vertex $i$ there is a multiset $S_i$ of input triangles with $E_{Q_i}(v) = \sum_{t \in S_i} \operatorname{dist}(v, H_t)^2$, where $H_t$ is the plane of $t$. (2) If $A$ is invertible, line L11 returns the unique minimizer of $E_Q$. (3) Each collapse made in line L7 is of an edge that is valid and, among the valid edges of the current mesh, has the least key $(c, i, j)$. (4) If the input is a 2-manifold, closed or with a border, every collapse gives a 2-manifold that is homeomorphic to the one before it, and no surviving triangle has its normal turned by $90°$ or more. (5) The algorithm stops.

**Step 1: the quadrics.** For a unit normal $u$ and a point $p_0$ of $H_t$, $\pi = (u, -u \cdot p_0)$ and $\bar v^{\mathsf T} \pi \pi^{\mathsf T} \bar v = (\pi \cdot \bar v)^2 = (u \cdot (v - p_0))^2 = \operatorname{dist}(v, H_t)^2$. The code uses $N N^{\mathsf T} / |N|^2$ for an unnormalized normal $N$, which is the same matrix. Line L2 sets $S_i$ to the triangles at $i$. Line L7 sets $Q_i \leftarrow Q_i + Q_j$, and $E$ is linear in $Q$, so $S_i \leftarrow S_i + S_j$ keeps (1). No other line changes a quadric.

**Step 2: the position.** Write $Q = \begin{pmatrix} A & b \\ b^{\mathsf T} & c \end{pmatrix}$. Then $E_Q(v) = v^{\mathsf T} A v + 2 b^{\mathsf T} v + c$. $A$ is a sum of matrices $u u^{\mathsf T}$, so it is positive semidefinite; if it is invertible, it is positive definite, $E_Q$ is strictly convex, and its only critical point $A v + b = 0$ is its unique minimizer $v = -A^{-1} b$. Otherwise line L11 returns one of three named points; the claim says nothing about that case.

**Step 3: the heap.** Call an entry fresh when its two versions are the current versions of its end points. We show this invariant at the start of each pass of line L4: every edge $(i, j)$ of the current mesh has exactly one fresh entry, with the cost and position computed from the current $Q_i$, $Q_j$, $p_i$, $p_j$; this entry is in the heap, or it is set aside and the edge is not valid.

Line L3 makes the invariant true at the start. Suppose it is true, and a pass pops a fresh entry. If line L6 sets it aside, then the edge is not valid, and the invariant holds. If the edge $(i, j)$ is collapsed, the versions of $i$ and $j$ change, so all entries at $i$ or $j$ become stale. The edges at $i$ after the collapse are $(i, k)$ for the neighbors $k$ of $i$, and line L9 pushes one new fresh entry for each. Every other edge $(a, b)$ has $a, b \notin \{i, j\}$; its quadrics and positions do not change, so its entry is still fresh and correct. If it was set aside, its validity may change only if the triangles at $a$ or at $b$ change, or the position of a vertex of such a triangle changes. The triangles that change are those at $i$ or $j$, and a triangle at $a$ contains $i$ only if $a$ is a neighbor of $i$. So only edges with an end point in $\{i\} \cup \operatorname{nbr}(i)$ can become valid, and line L9 puts those back into the heap. The others are still not valid. Thus the invariant holds again.

Now take the entry that is collapsed in some pass. Every entry that was popped before it in the same pass was stale and skipped, or set aside as not valid. By the invariant, every valid edge of the mesh has its fresh entry in the heap, with key $(c, i, j)$. The heap returns entries in the order of the key, and the collapsed entry is the first fresh valid one, so its key is the least among the valid edges. This proves (3).

**Step 4: the topology.** Let the mesh be a 2-manifold $M$. If it has a border, add one new vertex $\omega$ and the triangles $(u, w, \omega)$ for each border edge $(u, w)$; this gives a closed 2-manifold $M^*$, and $M$ is $M^*$ with the open star of $\omega$ removed. In $M^*$, the link $\operatorname{Lk}(i)$ of a vertex is a cycle of vertices and edges, and the link of an edge $(i, j)$ is the two vertices opposite to it. Dey, Edelsbrunner, Guha and Nekhayev proved that contracting $(i, j)$ in a closed 2-manifold gives a homeomorphic 2-manifold if and only if $\operatorname{Lk}(i) \cap \operatorname{Lk}(j) = \operatorname{Lk}(i, j)$. The three parts of the test of line L6 are this condition in $M^*$:

- The vertex part, without $\omega$: the common neighbors of $i$ and $j$ are the opposite vertices of the triangles on the edge.
- The edge part, without $\omega$: no edge $(u, w)$ is in both links, that is, there are no two triangles $(i, u, w)$ and $(j, u, w)$.
- The parts with $\omega$: $\omega$ is in $\operatorname{Lk}(i) \cap \operatorname{Lk}(j)$ exactly when $i$ and $j$ are both border vertices, and in $\operatorname{Lk}(i, j)$ exactly when $(i, j)$ is a border edge, so the first border test of the code is the vertex part for $\omega$. An edge $(u, \omega)$ is in $\operatorname{Lk}(i)$ exactly when $(i, u)$ is a border edge, so the second border test is the edge part for the edges at $\omega$.

The contraction in $M^*$ never involves $\omega$, because $\omega$ is not a vertex of the mesh; it keeps the star of $\omega$ as a disk with the same border cycle, minus $j$ if $(i, j)$ is a border edge. So the contraction of $M$ is homeomorphic to $M$. The Euler characteristic and the number of border loops are invariants of the homeomorphism type, so they stay. Line L6 also requires $N_{\text{old}} \cdot N_{\text{new}} > 0$ for each triangle at $i$ or $j$ that survives, and the other triangles do not move. This proves (4).

**Step 5: the stop.** Each collapse removes the vertex $j$ for good, so there are at most $V$ collapses. Between two collapses, each pass pops one entry. A pass pushes nothing unless it collapses, so after the last collapse the heap only shrinks, and before it, the number of pushes is finite. So line L4 ends, when $|T| \le m$ or the heap is empty. $\blacksquare$
