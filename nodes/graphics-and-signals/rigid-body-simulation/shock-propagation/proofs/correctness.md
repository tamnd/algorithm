---
title: The levels respect the contact graph, and after the shock sweep no contact of a stack approaches
proves: [correctness, termination]
status: full
---

The setting is the code of the page: 2D axis-aligned boxes that only translate, $y$ up, and contacts $(A, B)$ where $A$ rests on $B$, with the normal $(0, 1)$ from $B$ to $A$. RESOLVE on a contact computes $v_{rel} = v_A - v_B$ (vertical components); if $v_{rel} < 0$ and $k = w_A + w_B > 0$, where $w$ is the inverse mass used in the current sweep, it applies $j = -v_{rel}/k \ge 0$: $v_A$ gains $w_A j$ and $v_B$ loses $w_B j$. Afterwards $v_{rel} = 0$. Line numbers refer to the pseudocode of the page.

**Termination.** Building the graph (line L1) visits each ordered pair of bodies once. The two depth-first searches (line L2) visit each node and edge a constant number of times. Line L3 visits each component and each edge between components once. The sweeps (lines L4 to L9) run $S$ contact sweeps and one shock sweep, each over the levels with $I$ passes over the contacts of the level, and each RESOLVE is a constant amount of work. So the step ends after $O(n^2 + e + (S + 1) I c)$ operations for $n$ bodies, $e$ edges and $c$ contacts.

**Lemma 1 (components and levels).** Line L2 returns the strongly connected components in a topological order of the condensation (an edge between two components goes from an earlier to a later one). Line L3 then assigns levels with $\text{level}(u) = \text{level}(v)$ if $u$ and $v$ are in the same component, and $\text{level}(u) < \text{level}(v)$ for every edge $u \to v$ between different components.

*Proof.* The first part is the correctness of the two-pass depth-first search algorithm for [strongly connected components](/strongly-connected-components/): the second search, run on the reversed graph in decreasing order of finishing times of the first search, collects exactly one component per tree, and the component that contains the node with the largest finishing time has no edge entering it from an unvisited component. So the components come out in a topological order. In that order, every predecessor component of $c$ comes before $c$, so line L3 reads only levels that are already set. A node gets the level of its component. For an edge $u \to v$ between components, the component of $u$ is a predecessor of the component of $v$, so $\text{level}(v) \ge \text{level}(u) + 1$. $\square$

**Lemma 2 (stacks give an acyclic graph).** Let the boxes have disjoint interiors, and let the graph have the edge $j \to i$ when box $i$, moved down by $\delta > 0$, overlaps box $j$. Then every edge $j \to i$ has $\text{top}(j) \le \text{bottom}(i)$. In particular $\text{bottom}(j) < \text{bottom}(i)$, the graph is acyclic, every component is a single box, and every edge goes to a strictly higher level.

*Proof.* The moved box overlaps $j$, so the horizontal intervals overlap. Before the move the interiors were disjoint, so the vertical intervals were disjoint: either $\text{top}(j) \le \text{bottom}(i)$ or $\text{top}(i) \le \text{bottom}(j)$. In the second case, moving $i$ down keeps $\text{top}(i) - \delta < \text{bottom}(j)$, so there is no overlap. Hence the first case holds, and $\text{bottom}(j) < \text{top}(j) \le \text{bottom}(i)$. The bottoms strictly increase along every edge, so there is no cycle, each component is one box, and Lemma 1 gives strictly increasing levels. $\square$

When a box $A$ rests on $B$ with a gap of at most zero and $\delta$ is smaller than the heights of the boxes, the moved $A$ overlaps $B$, so the edge $B \to A$ exists. The theorem below assumes this for every contact of the solve.

**Theorem 1 (after the shock sweep, no contact approaches).** Assume that every contact $(A, B)$ of the solve has $\text{level}(A) > \text{level}(B)$, and that static bodies have inverse mass zero. Then after lines L7 to L9, every contact has $v_A - v_B \ge 0$. This holds for any number $S \ge 0$ of contact sweeps before and any $I \ge 1$.

*Proof.* A contact $(A, B)$ belongs to the level $\max(\text{level}(A), \text{level}(B)) = \text{level}(A)$. The shock sweep handles the levels $0, 1, 2, \ldots$ in increasing order, and line L9 sets $w_u = 0$ for every body $u$ of a level after that level is handled. RESOLVE changes the velocity of a body only if its $w$ is nonzero.

Consider the pass over level $\ell$. Every body of a lower level has $w = 0$ by then. Each contact of level $\ell$ has its lower body $B$ at a level below $\ell$, so RESOLVE on it changes only $v_A$, and only upward ($w_A j \ge 0$). Bodies of level $\ell$ are never the lower body of a contact of level $\ell$, because such a contact would belong to a higher level. So during the pass over level $\ell$, velocities change only for bodies of level $\ell$, and they only increase. Take a contact $(A, B)$ of level $\ell$. Since $I \ge 1$, RESOLVE runs on it at least once; after that, $v_A - v_B \ge 0$. Later in the same pass, $v_A$ can only increase and $v_B$ is fixed, so $v_A - v_B \ge 0$ at the end of the pass. After the pass, $A$ and $B$ both have $w = 0$, so no later RESOLVE changes $v_A$ or $v_B$. $\square$

**Corollary (a resting stack stops in one sweep).** In a single column of boxes on static ground in which every box moves down with the same speed $u > 0$ and there are no other contacts, the shock sweep leaves every box at rest, whatever $S$.

*Proof.* Let box $k$ sit on box $k - 1$, with the ground as box 0, so box $k$ has level $k$. Before the shock sweep, the contact sweeps only apply nonnegative impulses that push the upper box up and the lower box down, so every box still moves down or is at rest: by induction over the sweeps, each RESOLVE moves $v_A$ and $v_B$ toward each other and never above the larger of the two old values, which is at most zero. In the shock sweep, the pass over level $k$ sets $v_k$ to $\max(v_k, v_{k-1}) = \max(v_k, 0) = 0$, by induction from the ground, which has $v_0 = 0$. $\square$

**Proposition (no effect when nothing approaches).** If no contact has $v_A - v_B < 0$ before the shock sweep, the shock sweep changes no velocity. *Proof.* Each RESOLVE then does nothing, and so nothing changes for the next one. $\square$

**Momentum is not kept.** A RESOLVE with $w_B = 0$ for a body $B$ of finite mass changes the momentum of $A$ and not that of $B$. So the shock sweep changes the total momentum whenever it acts on such a contact. The page gives an example with momentum $-2$ before and $4$ after. This is the sense in which shock propagation changes the physics: it is a heuristic, not a solution method for the contact problem.

**What is not proved.** For bodies that rotate, a contact of level $\ell$ can receive an impulse from another contact of the same body with a different normal that lowers its relative velocity, so Theorem 1 does not apply as stated. Contacts inside one strongly connected component (bodies of the same level) are only iterated $I$ times, and no bound on their remaining error is proved. Nothing is proved about the contact sweeps before the shock sweep, and the plausibility of the result is judged by eye in the source.
