---
title: The cubic CCD tests find every root in order and never return a time after the first contact
proves: [correctness, termination]
status: full
---

Each of the four points $x_i(t) = x_i^0 + t\,(x_i^1 - x_i^0)$ moves on a line for $t \in [0, 1]$, with the velocity $w_i = x_i^1 - x_i^0$. For the vertex-face test the points are $p, a, b, c$, and a contact at time $t$ means that $p(t)$ is in the closed triangle $a(t) b(t) c(t)$. For the edge-edge test the points are $a, b, c, d$, and a contact means that the closed segments $a(t) b(t)$ and $c(t) d(t)$ meet. Let $D(t)$ be the distance of the vertex to the triangle, or of the two segments, so a contact is $D(t) = 0$. Let $t^*$ be the first contact time in $[0, 1]$, if there is one. We work in the real RAM, so the arithmetic, the square root of the critical points, and the bisection are exact. Let $\delta > 0$ be the distance tolerance and $k$ the number of bisection steps.

**Lemma 1 (contact implies a root).** Let $f(t) = u(t) \cdot (v(t) \times w(t))$ with $u = p - a$, $v = b - a$, $w = c - a$ for a vertex and a face, and $u = c - a$, $v = b - a$, $w = d - c$ for two edges. Then $f$ is a polynomial of degree at most 3, and $f(t) = 0$ at each contact time.

*Proof.* Each of $u$, $v$, $w$ is affine in $t$, and the triple product is linear in each factor, so $f$ has degree at most 3. The triple product is the signed volume of the box spanned by $u$, $v$, $w$, and it is 0 exactly when the three vectors are linearly dependent. At a vertex-face contact, $p - a$ is a combination of $b - a$ and $c - a$. At an edge-edge contact there are $s, r \in [0, 1]$ with $a + s(b - a) = c + r(d - c)$, so $c - a = s(b - a) - r(d - c)$. In both cases the vectors are dependent. $\square$

**Lemma 2 (all roots, in order).** Suppose $f$ is not the zero polynomial. Let $0 = z_0 < z_1 < \dots < z_m = 1$ be 0, the roots of $f'$ in $(0, 1)$, and 1, with $m \le 3$. Then each piece $[z_j, z_{j+1}]$ has at most one root of $f$, and it has one exactly when $f(z_j)\, f(z_{j+1}) \le 0$. The loop of the code reports, for each root $r$ of $f$ in $[0, 1]$ and in increasing order, a value $\tilde r$ with $r - 2^{-k} \le \tilde r \le r$, and it reports nothing else.

*Proof.* $f'$ has no root inside a piece, so it has one sign there, and $f$ is strictly monotone on the piece, or constant if $f' \equiv 0$. A constant $f$ is not 0 here, so it has no root. A strictly monotone function has at most one root, and by the intermediate value theorem it has one exactly when the end values do not have the same strict sign. The code checks the pieces from left to right. If $f(z_j) = 0$, it reports $z_j$. If the end values have strictly opposite signs, the bisection keeps a bracket $[l, h]$ with $f(l)$ of the sign of $f(z_j)$ and the root in $(l, h]$, and halves it $k$ times, so it reports $l$ with $r - 2^{-k} \le l \le r$, or the root itself if a midpoint hits it. If $f(z_{j+1}) = 0$, the root is the left end of the next piece, or $z_m = 1$, which the last check reports. The duplicate removal drops a value that is not larger than the last one, which happens only for a root at a shared end $z_j$. So each root is reported once, in order. $\square$

**Lemma 3 (the distance is Lipschitz).** $|D(s) - D(t)| \le L\,|s - t|$ with $L = |w_p| + \max(|w_a|, |w_b|, |w_c|)$ for a vertex and a face, and $L = \max(|w_a|, |w_b|) + \max(|w_c|, |w_d|)$ for two edges.

*Proof.* For a vertex and a face, $D(t) = \min_\lambda |p(t) - \sum_i \lambda_i x_i(t)|$ over the barycentric weights $\lambda \ge 0$ with $\sum_i \lambda_i = 1$. For a fixed $\lambda$, the point $\sum_i \lambda_i x_i(t)$ moves with the velocity $\sum_i \lambda_i w_i$, which has a length of at most $\max_i |w_i|$. So each function in the minimum is $L$-Lipschitz, and so is their minimum. The edge-edge case is the same with two weights. $\square$

**Theorem.** Suppose $f$ is not the zero polynomial and $L\,2^{-k} \le \delta$. If the vertex and the face (or the two edges) touch in $[0, 1]$, the test returns a time $t$ with $t \le t^*$ and $D(t) \le \delta$. If the test returns a time $t$, then $D(t) \le \delta$, and $t$ is within $2^{-k}$ before a root of $f$. If $D(t) > \delta$ at every time within $2^{-k}$ before each root of $f$, the test returns no time. The test always terminates.

*Proof.* By Lemma 1, $t^*$ is a root of $f$, and by Lemma 2 the loop meets a value $\tilde r$ with $t^* - 2^{-k} \le \tilde r \le t^*$. By Lemma 3, $D(\tilde r) \le D(t^*) + L\,2^{-k} \le \delta$, so the check passes at $\tilde r$. The test returns the first value that passes, so it returns a time $t \le \tilde r \le t^*$ with $D(t) \le \delta$. The other two claims are the check itself and Lemma 2. The loop runs over at most three roots, and each bisection has $k$ steps, so the test terminates. $\blacksquare$

**The exact count.** For Fraction input, the coefficients of $f$ are exact, and so is the Sturm sequence $p_0 = f$, $p_1 = f'$, $p_{i+1} = -(p_{i-1} \bmod p_i)$. By Sturm's theorem, for $l < h$ that are not roots of $f$, the number of sign changes of the sequence at $l$ minus that at $h$ is the number of distinct real roots of $f$ in $(l, h)$. The tests compare this exact count with the number of float roots that the loop finds.

**Remarks.** The theorem says nothing about floating point. There, the coefficients of $f$, the critical points and the contact check have rounding errors. A root at which $f$ only touches 0 (a grazing contact) can become two close roots or none. A contact on an edge or at a vertex of a triangle can fail the check on both triangles that share it if $\delta = 0$. A positive $\delta$ catches these cases, but it also reports near misses as contacts. Exact methods, such as that of Brochu, Edwards and Bridson (2012), evaluate the needed signs exactly and do not need the tolerance for correctness.
