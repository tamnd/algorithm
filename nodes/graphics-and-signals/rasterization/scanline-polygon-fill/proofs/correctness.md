---
title: Scanline fill marks exactly the pixels whose shifted centers are inside
proves: [correctness]
status: full
---

We use the pseudocode of the page and exact arithmetic. Row $j$ has its center line at $y_j = j + 1/2$, and $y$ grows downward. For a pixel center $c = (i + 1/2, y_j)$, the shifted center is $c_\varepsilon = c + (\varepsilon, \varepsilon^2)$. Pixel $(i, j)$ must be filled exactly when $c_\varepsilon$ is inside under the rule for all small enough $\varepsilon > 0$. For a non-horizontal edge $e$ with end points $t_e$ (top) and $b_e$ (bottom), with $y(t_e) < y(b_e)$, let $x_e(y)$ be the $x$ of the edge line at height $y$, and let $\Delta_e = (x(b_e) - x(t_e)) / (y(b_e) - y(t_e))$.

**Lemma 1 (the active edges).** At the start of line L11 for row $j$, the AET holds exactly the non-horizontal edges $e$ with $y(t_e) \le y_j < y(b_e)$, each once, each with the value $x = x_e(y_j)$, sorted by $x$.

*Proof.* Line L4 sets $j_0 = \lceil y(t_e) - 1/2 \rceil$ and $j_1 = \lceil y(b_e) - 1/2 \rceil$. For an integer $j$, the condition $y(t_e) \le j + 1/2$ is $j \ge y(t_e) - 1/2$, which is $j \ge j_0$. In the same way $j + 1/2 < y(b_e)$ is $j < j_1$. So the rows of the lemma for $e$ are $j_0 \le j < j_1$. Line L5 puts $e$ in the bucket of row $\max(j_0, 0)$, when this row is before $\min(j_1, H)$, with $x = x_e(y_{\max(j_0, 0)})$. Line L10 adds the bucket of row $j$ to the AET, line L8 removes $e$ at the first row $j \ge j_1$, and line L12 adds $\Delta_e$ once per row. Since $x_e(y_{j+1}) = x_e(y_j) + \Delta_e$, the value is $x_e(y_j)$ at each row where $e$ is active. Horizontal edges are never added. Line L9 sorts the edges that stayed, and line L10 merges in the sorted bucket, so the AET is sorted by $x$. $\square$

**Lemma 2 (which edges the shifted row meets).** Let $\varepsilon > 0$ be small enough. The horizontal line $y = y_j + \varepsilon^2$ crosses a non-horizontal edge $e$ if and only if $y(t_e) \le y_j < y(b_e)$, and then it crosses $e$ at one inner point. It passes through no vertex.

*Proof.* The line crosses $e$ at an inner point when $y(t_e) < y_j + \varepsilon^2 < y(b_e)$. If $y(t_e) \le y_j < y(b_e)$, this holds for each $\varepsilon$ with $\varepsilon^2 < y(b_e) - y_j$. If $y_j < y(t_e)$, it fails for $\varepsilon^2 < y(t_e) - y_j$. If $y_j \ge y(b_e)$, it fails for every $\varepsilon$. There are finitely many vertices and edges, so one $\varepsilon_0$ works for all of them, and a vertex at height $y_j + \varepsilon^2$ exists for at most finitely many $\varepsilon$. $\square$

**Lemma 3 (left of the shifted center).** For an active edge $e$ of row $j$ with value $x = x_e(y_j)$, and $\varepsilon$ small enough, the edge crosses the line $y = y_j + \varepsilon^2$ to the left of $c_\varepsilon$ if and only if $x \le i + 1/2$.

*Proof.* The crossing is at $x + \Delta_e \varepsilon^2$, and $c_\varepsilon$ has $x$ coordinate $i + 1/2 + \varepsilon$. If $x < i + 1/2$, the crossing is to the left for small $\varepsilon$. If $x > i + 1/2$, it is to the right for small $\varepsilon$. If $x = i + 1/2$, the difference is $\varepsilon - \Delta_e \varepsilon^2 > 0$ for $\varepsilon < 1 / |\Delta_e|$, so the crossing is to the left. $\square$

**Theorem.** SCANLINE-FILL fills pixel $(i, j)$ if and only if $c_\varepsilon$ is inside $P$ under the rule, for all small enough $\varepsilon > 0$.

*Proof.* Fix row $j$, let the sorted AET be $e_1, \dots, e_m$ with values $x_1 \le \dots \le x_m$ and directions $d_1, \dots, d_m$, and fix a column $i$. Take $\varepsilon$ small enough for Lemmas 2 and 3. The point $c_\varepsilon$ lies on no edge, because by Lemma 2 the only edges that meet its row are the active ones, at inner points whose $x$ differs from that of $c_\varepsilon$ by Lemma 3 (the difference is nonzero in each case of the proof). So its winding number $w(c_\varepsilon)$ is defined.

Cast the ray from $c_\varepsilon$ to the left. By Lemma 2 it passes through no vertex, and by Lemmas 2 and 3 the edges it crosses are the $e_k$ with $x_k \le i + 1/2$. Since the $x_k$ are sorted, these are $e_1, \dots, e_r$ for the largest $r$ with $x_r \le i + 1/2$ (or $r = 0$). An edge that goes down crosses the leftward ray in one direction, and an edge that goes up crosses it in the other, so $w(c_\varepsilon) = \sigma \sum_{k \le r} d_k$ for a fixed sign $\sigma \in \{+1, -1\}$. The crossing count is $r$. So under the even-odd rule $c_\varepsilon$ is inside when $r$ is odd, and under the nonzero rule when $\sum_{k \le r} d_k \ne 0$. The sign $\sigma$ changes neither test.

Line L11 computes, for each $k$ from 1 to $m - 1$, the value $w$ after $e_1, \dots, e_k$: the count $k$ for the even-odd rule, or $\sum_{l \le k} d_l$ for the nonzero rule. If the rule holds for this value, it fills the columns $i$ with $\lceil x_k - 1/2 \rceil \le i < \lceil x_{k+1} - 1/2 \rceil$, clamped to the image. For an integer $i$, this condition is $x_k \le i + 1/2 < x_{k+1}$, which says exactly that $r = k$. So pixel $(i, j)$ is filled for $1 \le r \le m - 1$ exactly when the rule holds for $r$. For $r = 0$, the value is 0, and the pixel is outside under both rules. For $r = m$, the leftward ray crosses all active edges, and the rightward ray crosses none, so $w(c_\varepsilon) = 0$ and the crossing count has the parity of 0; the pixel is outside, and line L11 does not fill it. The spans for different $k$ are disjoint, so no pixel is filled twice. $\blacksquare$

**Shared edges.** Let $P_1$ and $P_2$ be two simple polygons with disjoint insides that share an edge, and let $Q$ be their union. The shifted center $c_\varepsilon$ is on no edge of $P_1$, $P_2$ or $Q$. Because the insides are disjoint, $c_\varepsilon$ is inside at most one of $P_1$ and $P_2$, and it is inside one of them exactly when it is inside $Q$. So by the theorem, each pixel of $Q$ is filled by exactly one of the two fills, also when its center lies on the shared edge.

**The cost of the sort.** Between two rows, the values of two active edges $a$ and $b$ change linearly in $y$, so $x_a - x_b$ changes sign at most once while both are active. Insertion sort on line L9 makes one move for each pair that is out of order, so each move belongs to a pair of edges that cross between the two center lines or meet on one. Each such pair causes at most one move in the whole run. So the total number of moves is at most $K$, the number of pairs of edges that intersect.
