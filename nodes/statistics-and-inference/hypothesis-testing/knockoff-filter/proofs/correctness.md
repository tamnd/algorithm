We prove what the lines compute and the exchangeability facts on which the FDR guarantee rests: the threshold at lines L6 and L7 is the one of the definition (Lemma 1); the construction at lines L1 to L5 gives the knockoff Gram matrix, and it exists exactly when $s \le 2\lambda_{\min}(\Sigma)$ (Proposition 2); swapping null features with their knockoffs changes neither the Gram matrix nor the law of the inner products with $y$ (Lemmas 3 and 4); and so the signs of the null statistics are independent fair coins (Lemma 5). The step from Lemma 5 to $\text{FDR} \le q$ for knockoff+, and to the modified FDR bound for the plain filter, is Theorems 1 and 2 of Barber and Candès (2015). We cite them and do not prove them. The tests check them in the coin model by exact enumeration, and measure them in one simulation.

**Setting.** $X \in \mathbb R^{n \times p}$ has full column rank, $n \ge 2p$, and unit column norms after line L1; $\Sigma = X^\top X$, so $\Sigma_{jj} = 1$, and $\lambda_{\min} > 0$ is its smallest eigenvalue. $y = X\beta + z$ with $z \sim N(0, \sigma^2I_n)$. A feature is null when $\beta_j = 0$. Write $A = [X\ \tilde X] \in \mathbb R^{n \times 2p}$, and for $S \subseteq \{1, \dots, p\}$ let $A_{\text{swap}(S)}$ be $A$ with columns $j$ and $j + p$ exchanged for each $j \in S$. A statistic $W = w(A, y) \in \mathbb R^p$ has the sufficiency property if $w(A, y) = f(A^\top A, A^\top y)$ for some function $f$, and the antisymmetry property if $w(A_{\text{swap}(S)}, y)_j = -w(A, y)_j$ for $j \in S$ and $= w(A, y)_j$ for $j \notin S$.

**Lemma 1 (the threshold).** For $q > 0$ and $c \in \{0, 1\}$, let $\mathcal W = \{|W_j| : W_j \ne 0\}$ and $T = \min\{t \in \mathcal W : c + \#\{j : W_j \le -t\} \le q\max(\#\{j : W_j \ge t\}, 1)\}$, or $T = \infty$ if no $t$ qualifies. Lines L6 and L7 return $T$, and $\{j : W_j \ge T\} = \{j : W_j \ge t^*\}$ for the smallest $t^* > 0$ in the closure of the set of all positive $t$ that satisfy the inequality, when that set is not empty.

*Proof.* Line L6 lists $\mathcal W$ in increasing order, and line L7 returns the first element that satisfies the inequality, which is the minimum. The counts $\#\{W_j \ge t\}$ and $\#\{W_j \le -t\}$ are constant for $t$ in each interval $(a, b]$ between consecutive elements of $\{0\} \cup \mathcal W$, and both are 0 for $t > \max\mathcal W$, where the inequality reads $c \le q$. So a positive $t$ satisfies the inequality exactly when the right end $b$ of its interval does, with the same selected set, or when $t > \max\mathcal W$, where nothing is selected. Hence restricting to $t \in \mathcal W$ changes neither the selected set nor whether some $t$ qualifies, except that a $t$ beyond $\max\mathcal W$ selects nothing, as $T = \infty$ does. The tests compare the lines with this definition on random integer statistics. $\square$

For knockoff+ ($c = 1$) with $q < 1$ and $T < \infty$, $1 \le q\#\{W_j \ge T\}$, so the filter selects at least $1/q$ features or none.

**Proposition 2 (the construction).** Let $0 < s$, $D = sI$, and suppose $2sI - s^2\Sigma^{-1} \succeq 0$, with $C$ any matrix with $C^\top C = 2sI - s^2\Sigma^{-1}$, and $\tilde U$ with orthonormal columns and $\tilde U^\top X = 0$. Then $\tilde X = X(I - s\Sigma^{-1}) + \tilde UC$ satisfies
$$A^\top A = G = \begin{pmatrix}\Sigma & \Sigma - D\\ \Sigma - D & \Sigma\end{pmatrix}.$$
Moreover, $2sI - s^2\Sigma^{-1} \succeq 0$ if and only if $s \le 2\lambda_{\min}$, and a matrix $\tilde X$ with $A^\top A = G$ exists only if $s \le 2\lambda_{\min}$. Such $\tilde U$ exists because $n \ge 2p$.

*Proof.* Using $\tilde U^\top X = 0$, $\tilde U^\top\tilde U = I$ and the symmetry of $\Sigma^{-1}$:
$$X^\top\tilde X = \Sigma(I - s\Sigma^{-1}) = \Sigma - sI,$$
$$\tilde X^\top\tilde X = (I - s\Sigma^{-1})\Sigma(I - s\Sigma^{-1}) + C^\top C = \Sigma - 2sI + s^2\Sigma^{-1} + 2sI - s^2\Sigma^{-1} = \Sigma.$$
The eigenvalues of $2sI - s^2\Sigma^{-1}$ are $2s - s^2/\lambda$ over the eigenvalues $\lambda$ of $\Sigma$; all are $\ge 0$ exactly when $s \le 2\lambda$ for all $\lambda$, that is, $s \le 2\lambda_{\min}$. For the necessity, the orthogonal change of basis $(u, v) \mapsto ((u + v)/\sqrt2, (u - v)/\sqrt2)$ turns $G$ into the block diagonal matrix with blocks $2\Sigma - D$ and $D$. A Gram matrix is positive semidefinite, so $2\Sigma - sI \succeq 0$, that is, $s \le 2\lambda_{\min}$. Finally, the orthogonal complement of the column space of $X$ has dimension $n - p \ge p$, so $p$ orthonormal vectors in it exist; line L4 finds them by [Gram-Schmidt](/gram-schmidt-process/) on the columns of $X$ followed by random vectors, which are independent of the columns with probability 1. $\square$

The code computes $C = \operatorname{diag}(\sqrt{\mu})V^\top$ from the eigendecomposition $V\operatorname{diag}(\mu)V^\top$ of $2sI - s^2\Sigma^{-1}$, so $C^\top C = V\operatorname{diag}(\mu)V^\top$ as required; it clips eigenvalues that are negative only by rounding. The equicorrelated choice $s = \min(2\lambda_{\min}, 1)$ is allowed by Proposition 2, and $\langle X_j, \tilde X_j\rangle = 1 - s$. The tests check the two Gram identities numerically.

**Lemma 3 (swapping keeps the Gram matrix).** For every $S$, $A_{\text{swap}(S)}^\top A_{\text{swap}(S)} = A^\top A$.

*Proof.* By Proposition 2, for $j \ne k$ all four inner products $X_j^\top X_k$, $X_j^\top\tilde X_k$, $\tilde X_j^\top X_k$ and $\tilde X_j^\top\tilde X_k$ equal $\Sigma_{jk}$, since $\Sigma - D$ and $\Sigma$ agree off the diagonal. And $X_j^\top X_j = \tilde X_j^\top\tilde X_j = 1$, $X_j^\top\tilde X_j = 1 - s$. So the inner product of two columns depends only on their feature indices $j, k$ and, when $j = k$, on whether they are the same column. Exchanging $X_j$ and $\tilde X_j$ preserves both. $\square$

**Lemma 4 (swapping nulls keeps the law of $A^\top y$).** If every $j \in S$ is null, then $A_{\text{swap}(S)}^\top y$ has the same law as $A^\top y$.

*Proof.* For any fixed $n \times 2p$ matrix $B$, $B^\top y \sim N(B^\top X\beta, \sigma^2B^\top B)$. The covariances for $B = A$ and $B = A_{\text{swap}(S)}$ agree by Lemma 3. For the means, the entries of $A^\top X\beta$ are $X_j^\top X\beta$ and $\tilde X_j^\top X\beta = \sum_k\tilde X_j^\top X_k\beta_k$. By Proposition 2, $\tilde X_j^\top X_k = X_j^\top X_k$ for $k \ne j$ and $\tilde X_j^\top X_j = X_j^\top X_j - s$, so $\tilde X_j^\top X\beta = X_j^\top X\beta - s\beta_j$. For $j \in S$, $\beta_j = 0$, so the two entries that the swap exchanges are equal, and the means agree. Two Gaussian vectors with equal means and covariances have the same law. $\square$

**Lemma 5 (i.i.d. signs for the nulls; Barber and Candès, Lemma 1).** Let $W$ satisfy sufficiency and antisymmetry. Let $\varepsilon \in \{\pm1\}^p$ be independent of $W$, with $\varepsilon_j = 1$ for non-null $j$ and $\varepsilon_j$ independent uniform signs for null $j$. Then $(\varepsilon_1W_1, \dots, \varepsilon_pW_p)$ has the same law as $W$.

*Proof.* Fix a set $S$ of nulls and let $\varepsilon^S$ be $-1$ on $S$ and $+1$ elsewhere. By antisymmetry, $\varepsilon^S \cdot W = w(A_{\text{swap}(S)}, y)$. By sufficiency this is $f(A_{\text{swap}(S)}^\top A_{\text{swap}(S)}, A_{\text{swap}(S)}^\top y) = f(A^\top A, A_{\text{swap}(S)}^\top y)$, using Lemma 3, and by Lemma 4 it has the same law as $f(A^\top A, A^\top y) = W$. So $\varepsilon^S \cdot W$ has the law of $W$ for every fixed $S$, and a random $\varepsilon$ independent of $W$ is a mixture of such fixed patterns. $\square$

**Corollary 6 (the coin model).** Given $(|W_1|, \dots, |W_p|)$ and the signs of the non-null $W_j$, the signs of the null $W_j$ with $W_j \ne 0$ are independent and uniform on $\{\pm1\}$.

*Proof.* For any fixed null sign pattern $\varepsilon^S$, Lemma 5 says that $W$ and $\varepsilon^S \cdot W$ have the same law. The map $W \mapsto \varepsilon^S \cdot W$ keeps the magnitudes and the non-null signs, and on the nonzero null coordinates it changes a sign pattern $a$ into $\varepsilon^Sa$. So, given the magnitudes and the non-null signs, the patterns $a$ and $\varepsilon^Sa$ have the same conditional probability, for every $S$. The group of sign changes acts transitively on patterns, so the conditional law is uniform, which is independence with fair signs. $\square$

**The two statistics in the code have the properties.** The marginal $W_j = |X_j^\top y| - |\tilde X_j^\top y|$ is a function of $A^\top y$, and a swap exchanges $X_j^\top y$ and $\tilde X_j^\top y$, which flips its sign. For the least-squares statistic, $A$ has full rank $2p$ when $s < 2\lambda_{\min}$ (by the block form in Proposition 2, $G \succ 0$ then), and $\hat b = (A^\top A)^{-1}A^\top y$ is a function of $A^\top A$ and $A^\top y$. A swap is $A \mapsto AP$ for a permutation matrix $P$, which gives $\hat b \mapsto P^\top\hat b$, so $\hat b_j$ and $\hat b_{j+p}$ exchange and $W_j = |\hat b_j| - |\hat b_{j+p}|$ changes sign. The tests check both flips numerically.

**What is cited.** Barber and Candès (2015, Theorem 2) prove that knockoff+ has $E[V/\max(R, 1)] \le q$, and (Theorem 1) that the plain filter has $E[V/(R + q^{-1})] \le q$, for statistics with sufficiency and antisymmetry, in the setting above. Their proof starts from Corollary 6 and uses a supermartingale argument with optional stopping. Candès, Fan, Janson and Lv (2018) prove the model-X version. These are not proved here.

**What is checked and measured.** In the coin model of Corollary 6, the tests draw 150 random sets of magnitudes, non-null signs and null sets, enumerate all $2^{m_0}$ null sign patterns, and compute, in exact rational arithmetic, the FDR of knockoff+ and the modified FDR of the plain filter at $q = 1/5$. Both are at most $q$ in every case, as the cited theorems predict, while the FDR of the plain filter exceeds $q$ in some cases. A Monte Carlo run on one fixed design measures FDR 0.120 for knockoff+ and 0.227 for the plain filter at $q = 0.2$.
