---
title: Reduced ZDDs are canonical, the family operations are correct, and the ZDD and BDD sizes are within a factor of n of each other
proves: [correctness]
status: full
---

The ground set is $\{1, \ldots, n\}$. The sinks are $\bot$ with $\mathcal{F}(\bot) = \emptyset$ and $\top$ with $\mathcal{F}(\top) = \{\emptyset\}$, and both have $\mathrm{var} = n + 1$. An inner node $(v, L, H)$ has $v < \mathrm{var}(L)$, $v < \mathrm{var}(H)$ and $\mathcal{F}(v, L, H) = \mathcal{F}(L) \cup \{S \cup \{v\} : S \in \mathcal{F}(H)\}$. A store is *reduced* if no node has $H = \bot$ and no two nodes have the same triple. For a family $\mathcal{G}$ and an element $v$, let $\mathcal{G}_{\bar v} = \{S \in \mathcal{G} : v \notin S\}$ and $\mathcal{G}_v = \{S \setminus \{v\} : v \in S \in \mathcal{G}\}$.

**Lemma 1 (the elements of a node).** Every set of $\mathcal{F}(P)$ is a subset of $\{\mathrm{var}(P), \ldots, n\}$. If $P$ is an inner node of a reduced store, some set of $\mathcal{F}(P)$ contains $\mathrm{var}(P)$; in particular $\mathcal{F}(P) \ne \emptyset$ and $\mathcal{F}(P) \ne \{\emptyset\}$.

*Proof.* By induction on the node, from the sinks up. The sets of $\mathcal{F}(L)$ and $\mathcal{F}(H)$ use elements at least $\mathrm{var}(L), \mathrm{var}(H) > v$, so the sets of $\mathcal{F}(v, L, H)$ use elements at least $v$. If the node is reduced, $H \ne \bot$, and by induction $\mathcal{F}(H) \ne \emptyset$ (a sink $\top$ or an inner node), so some set $S \cup \{v\}$ contains $v$. $\square$

**Lemma 2 (split).** Let $v \le \mathrm{var}(P)$ and $\mathrm{split}(P, v) = (P_0, P_1)$. Then $\mathcal{F}(P_0) = \mathcal{F}(P)_{\bar v}$ and $\mathcal{F}(P_1) = \mathcal{F}(P)_v$, and both $P_0$ and $P_1$ have $\mathrm{var} > v$.

*Proof.* If $P = (v, L, H)$, the sets of $\mathcal{F}(L)$ and $\mathcal{F}(H)$ do not contain $v$ by Lemma 1, so the sets without $v$ are those of $\mathcal{F}(L)$, and the sets with $v$ are $S \cup \{v\}$ for $S \in \mathcal{F}(H)$. If $\mathrm{var}(P) > v$, no set contains $v$ by Lemma 1, so the two families are $\mathcal{F}(P)$ and $\emptyset = \mathcal{F}(\bot)$. $\square$

**Lemma 3 (GETNODE).** If $v < \mathrm{var}(L)$ and $v < \mathrm{var}(H)$, GETNODE$(v, L, H)$ returns a node $u$ with $\mathcal{F}(u) = \mathcal{F}(L) \cup \{S \cup \{v\} : S \in \mathcal{F}(H)\}$ and $\mathrm{var}(u) \ge v$, and the store stays reduced.

*Proof.* At lines L1 and L2, $H = \bot$ and the family is $\mathcal{F}(L) \cup \emptyset$, and $\mathrm{var}(L) > v$. Otherwise lines L3 to L5 return the node with this triple, which is stored at most once, and the new node has $H \ne \bot$. $\square$

**Theorem 1 (canonicity).** In a reduced store, two nodes $P$ and $Q$ with $\mathcal{F}(P) = \mathcal{F}(Q)$ are the same node.

*Proof.* By induction on $\mathrm{var}(P) + \mathrm{var}(Q)$, from the top. By Lemma 1, a node is $\bot$ exactly when its family is $\emptyset$, and $\top$ exactly when its family is $\{\emptyset\}$, so the claim holds if either node is a sink. Let both be inner nodes. By Lemma 1, $\mathrm{var}(P)$ is the smallest element in a set of $\mathcal{F}(P)$, and the same for $Q$, so $\mathrm{var}(P) = \mathrm{var}(Q) = v$. By Lemma 2 with $P = (v, L, H)$ and $Q = (v, L', H')$, $\mathcal{F}(L) = \mathcal{F}(P)_{\bar v} = \mathcal{F}(L')$ and $\mathcal{F}(H) = \mathcal{F}(P)_v = \mathcal{F}(H')$. The children have larger $\mathrm{var}$, so by induction $L = L'$ and $H = H'$. The merging rule gives $P = Q$. $\square$

**Theorem 2 (the operations).** For nodes $P, Q$ of a reduced store, UNION, INTERSECT, DIFF and JOIN return nodes for $\mathcal{F}(P) \cup \mathcal{F}(Q)$, $\mathcal{F}(P) \cap \mathcal{F}(Q)$, $\mathcal{F}(P) \setminus \mathcal{F}(Q)$ and $\{S \cup T : S \in \mathcal{F}(P), T \in \mathcal{F}(Q)\}$; SUBSET0, SUBSET1 and CHANGE return nodes for $\mathcal{F}(P)_{\bar v}$, $\mathcal{F}(P)_v$ and $\{S \mathbin{\triangle} \{v\} : S \in \mathcal{F}(P)\}$; and COUNT returns $\lvert \mathcal{F}(P) \rvert$. Every result $R$ of a binary operation has $\mathrm{var}(R) \ge \min(\mathrm{var}(P), \mathrm{var}(Q))$.

*Proof.* All recursions are on nodes with larger $\mathrm{var}$, so they end, and the computed table only returns earlier results for the same arguments. We use induction on $2(n + 1) - \mathrm{var}(P) - \mathrm{var}(Q)$.

*UNION.* Line L6 handles $\emptyset \cup \mathcal{G} = \mathcal{G}$ and $\mathcal{G} \cup \mathcal{G} = \mathcal{G}$. At line L7, $v \le \mathrm{var}(P), \mathrm{var}(Q)$, so Lemma 2 applies. The sets without $v$ of the union are $\mathcal{F}(P_0) \cup \mathcal{F}(Q_0)$, and the sets with $v$, with $v$ removed, are $\mathcal{F}(P_1) \cup \mathcal{F}(Q_1)$. By induction the two calls of line L8 return nodes for these families with $\mathrm{var} > v$, and Lemma 3 puts them together. If both arguments were $\top$, line L6 has returned already, since then $P = Q$; so $v \le n$ at line L7.

*INTERSECT and DIFF.* The same argument: a set without $v$ is in both families if and only if it is in both $\mathcal{F}(P_0)$ and $\mathcal{F}(Q_0)$, and a set with $v$ if and only if its remainder is in both $\mathcal{F}(P_1)$ and $\mathcal{F}(Q_1)$; the same holds for the difference. The base cases are $\emptyset \cap \mathcal{G} = \emptyset$, $\mathcal{G} \cap \mathcal{G} = \mathcal{G}$, $\mathcal{G} \setminus \mathcal{G} = \emptyset$, $\emptyset \setminus \mathcal{G} = \emptyset$ and $\mathcal{G} \setminus \emptyset = \mathcal{G}$. When $v = n + 1$ in INTERSECT, both nodes are sinks that are not $\bot$, so both are $\top$, and the result is $\top$.

*JOIN.* The base cases are $\emptyset \sqcup \mathcal{G} = \emptyset$ and $\{\emptyset\} \sqcup \mathcal{G} = \mathcal{G}$. Otherwise write $\mathcal{F}(P) = \mathcal{P}_0 \cup (\mathcal{P}_1 + v)$ and $\mathcal{F}(Q) = \mathcal{Q}_0 \cup (\mathcal{Q}_1 + v)$, where $\mathcal{G} + v$ adds $v$ to each set and no set of $\mathcal{P}_b, \mathcal{Q}_b$ contains $v$. A union $S \cup T$ lacks $v$ exactly when $S \in \mathcal{P}_0$ and $T \in \mathcal{Q}_0$. It contains $v$ in the other three cases, and its remainder is then in $\mathcal{P}_1 \sqcup \mathcal{Q}_1$, $\mathcal{P}_1 \sqcup \mathcal{Q}_0$ or $\mathcal{P}_0 \sqcup \mathcal{Q}_1$. These families use elements larger than $v$, so the induction hypothesis and the correctness of UNION give the high child, and Lemma 3 gives the node.

*SUBSET0, SUBSET1 and CHANGE.* If $\mathrm{var}(P) > v$, no set contains $v$: the results are $\mathcal{F}(P)$, $\emptyset$, and $\{S \cup \{v\} : S \in \mathcal{F}(P)\}$, which is GETNODE$(v, \bot, P)$. If $P = (v, L, H)$, the results are $\mathcal{F}(L)$ and $\mathcal{F}(H)$ by Lemma 2, and toggling $v$ exchanges the sets with and without $v$, which is GETNODE$(v, H, L)$. If $P = (w, L, H)$ with $w < v$, all three operations act on each set without changing the element $w$, so they commute with the decomposition at $w$, and GETNODE$(w, \cdot, \cdot)$ of the results for $L$ and $H$ is correct by induction; the results have $\mathrm{var} > w$ since $L$ and $H$ do and CHANGE adds only $v > w$.

*COUNT.* The two parts of $\mathcal{F}(v, L, H)$ are disjoint, since the sets of the first part lack $v$ and those of the second contain it, so $\lvert \mathcal{F}(v, L, H) \rvert = \lvert \mathcal{F}(L) \rvert + \lvert \mathcal{F}(H) \rvert$. $\square$

**The BDD of a family.** Let $\chi$ be the characteristic function of $\mathcal{F}$, and let $\mathcal{B}$ be its reduced OBDD for the order $x_1, \ldots, x_n$, with $B$ nodes counting the sinks. For $1 \le k \le n + 1$ and $a \in \{0, 1\}^{k-1}$, the restriction $\chi|_a$ is a function of $x_k, \ldots, x_n$. In $\mathcal{B}$, following the bits of $a$ from the root until the first node $w$ with level at least $k$ gives a node with $f_w = \chi|_a$.

**Theorem 3 (size relation).** Let $Z$ be the number of nodes of the reduced ZDD of $\mathcal{F}$, with the sinks that it reaches. Then $Z \le n B + 2$ and $B \le n Z + 2$.

*Proof.* *First bound.* Let $u$ be an inner node of the ZDD with $k = \mathrm{var}(u)$, and follow a path from the root to $u$. It fixes the elements $1, \ldots, k - 1$: an element tested on the path is in the set or not according to the edge, and a skipped element is absent. Let $a \in \{0, 1\}^{k-1}$ be this assignment, with the set $A$. Then $\mathcal{F}(u) = \{S \subseteq \{k, \ldots, n\} : A \cup S \in \mathcal{F}\}$, by Lemma 2 applied along the path, and so $\mathcal{F}(u)$ is the family of sets on which $\chi|_a$ is 1. With the node $w$ of $\mathcal{B}$ for $a$, $\mathcal{F}(u)$ is fixed by the pair $(k, w)$, where $k \le$ the level of $w$. By Theorem 1, distinct inner nodes have distinct families, so they have distinct pairs. There are at most $n$ values of $k$ and $B$ nodes $w$, so the ZDD has at most $n B$ inner nodes, and $Z \le n B + 2$.

*Second bound.* Let $w$ be an inner node of $\mathcal{B}$ on level $j$. Then $f_w = \chi|_a$ for some $a \in \{0, 1\}^{j-1}$, and $f_w$ depends on $x_j$, so it is not the constant 0. Follow the path of $a$ in the ZDD, with the set $A$ of $a$: at a node of element $i < j$ take the edge $a_i$, and stop at the first node $z$ with $\mathrm{var}(z) \ge j$. If an element $i < j$ with $a_i = 1$ were skipped, no set of $\mathcal{F}$ with the prefix $A$ would exist, and $\chi|_a$ would be 0. So no such element is skipped, and by Lemma 2 the family $\{S \subseteq \{j, \ldots, n\} : A \cup S \in \mathcal{F}\}$ consists of the sets of $\mathcal{F}(z)$, which avoid the elements $j, \ldots, \mathrm{var}(z) - 1$. So $f_w$ is fixed by the pair $(j, z)$ with $j \le \mathrm{var}(z)$. Distinct inner nodes of $\mathcal{B}$ have distinct functions, so $\mathcal{B}$ has at most $n Z$ inner nodes and at most 2 sinks. $\square$

**Tightness of the factor.** For the $n$ singletons, $Z = n + 2$: the node of $\{\{i\}, \ldots, \{n\}\}$ is $(i, \text{node of } \{\{i+1\}, \ldots\}, \top)$. The BDD of "exactly one $x_i$ is 1" has two nodes on each level but the first, which is $2n - 1$ inner nodes and $B = 2n + 1$. For the family of all subsets, the BDD is the sink 1 and $B = 1$, while the ZDD needs the chain $(1, P_2, P_2), \ldots, (n, \top, \top)$ with $Z = n + 1$. For $\{\emptyset\}$, the ZDD is $\top$ with $Z = 1$, while the BDD of $\neg x_1 \wedge \cdots \wedge \neg x_n$ has $B = n + 2$. So the ratio $Z/B$ can be $n + 1$, and the ratio $B/Z$ can be $n + 2$: up to the constant terms, the factor $n$ of Theorem 3 is reached in both directions. $\blacksquare$
