We use the notation of the page. $T$ is a finite set of ground terms closed under subterms, $E$ is a set of equations between terms of $T$, $D$ is a set of disequations between terms of $T$, and $\mathrm{CC}(E)$ is the least congruence on $T$ that contains $E$. A model $M$ is a nonempty domain with a value $a^M$ for each constant and a function $f^M$ for each function symbol, and $M(t)$ is the value of a term.

## Part 1. The closure decides the conjunction

**Lemma 1 (models respect the closure).** If $M \models E$, then $M(s) = M(t)$ for each $(s, t) \in \mathrm{CC}(E)$.

*Proof.* Let $\approx_M = \{(s, t) \in T \times T : M(s) = M(t)\}$. It is an equivalence relation, and it contains $E$ because $M \models E$. It is a congruence on $T$: if $f(s_1, \ldots, s_k)$ and $f(t_1, \ldots, t_k)$ are in $T$ and $M(s_i) = M(t_i)$ for all $i$, then $M(f(s_1, \ldots, s_k)) = f^M(M(s_1), \ldots, M(s_k)) = f^M(M(t_1), \ldots, M(t_k)) = M(f(t_1, \ldots, t_k))$. $\mathrm{CC}(E)$ is the least congruence on $T$ that contains $E$, so $\mathrm{CC}(E) \subseteq {\approx_M}$. $\square$

**Lemma 2 (the term model).** There is a model $M_E$ with $M_E(s) = M_E(t)$ if and only if $(s, t) \in \mathrm{CC}(E)$, for all $s, t \in T$.

*Proof.* Write $[t]$ for the class of $t$ in $\mathrm{CC}(E)$. The domain is the set of classes together with one more element $\bot$. A constant $a \in T$ has the value $[a]$, and other constants have the value $\bot$. For a symbol $f$ of arity $k$ and domain elements $x_1, \ldots, x_k$: if some $f(t_1, \ldots, t_k) \in T$ has $[t_i] = x_i$ for all $i$, let $f^{M_E}(x_1, \ldots, x_k) = [f(t_1, \ldots, t_k)]$; otherwise let it be $\bot$. This is well defined: two such terms have arguments in the same classes, so they are in one class because $\mathrm{CC}(E)$ is a congruence.

We show $M_E(t) = [t]$ for each $t \in T$, by induction on the size of $t$. For a constant this is the definition. For $t = f(t_1, \ldots, t_k) \in T$, each $t_i$ is in $T$ because $T$ is closed under subterms, so $M_E(t_i) = [t_i]$ by the induction hypothesis, and then $M_E(t) = f^{M_E}([t_1], \ldots, [t_k]) = [t]$ by the definition, with $t$ itself as the witness. So $M_E(s) = M_E(t)$ if and only if $[s] = [t]$. $\square$

**Theorem 1.** For $s, t \in T$, $E \models s = t$ (in every model) if and only if $(s, t) \in \mathrm{CC}(E)$. The conjunction $E \wedge D$ is satisfiable if and only if no $s \ne t$ in $D$ has $(s, t) \in \mathrm{CC}(E)$.

*Proof.* If $(s, t) \in \mathrm{CC}(E)$, Lemma 1 gives $M(s) = M(t)$ in each model of $E$. If $(s, t) \notin \mathrm{CC}(E)$, the model $M_E$ of Lemma 2 satisfies $E$ (each equation of $E$ is in $\mathrm{CC}(E)$) and has $M_E(s) \ne M_E(t)$. This proves the first claim. For the second: if no disequation of $D$ joins two terms of one class, $M_E$ satisfies $E$ and each disequation, by Lemma 2. If some $s \ne t$ in $D$ has $(s, t) \in \mathrm{CC}(E)$, each model of $E$ has $M(s) = M(t)$ by Lemma 1, so no model satisfies $E \wedge D$. $\blacksquare$

## Part 2. The algorithm computes the closure

Write $x \equiv y$ when $\mathit{rep}[x] = \mathit{rep}[y]$, and let $\equiv^*$ be the equivalence relation generated by $\equiv$ and the pairs on pending. We show that these statements hold after line L6 and after each pass of the loop of line L7.

- **(I1)** The lists $\mathit{members}[r]$ of the representatives $r$ partition $T$, and $\mathit{rep}[x] = r$ for each $x \in \mathit{members}[r]$.
- **(I2)** ${\equiv} \subseteq \mathrm{CC}(E)$, and each pair on pending is in $\mathrm{CC}(E)$.
- **(I3)** For each application $p = f(c_1, \ldots, c_k)$ and each $i$, $p$ is in $\mathit{uses}[\mathit{rep}[c_i]]$.
- **(I4)** For each application $p$, $\mathrm{SIG}(p)$ is a key of the table, and $\mathit{table}[\mathrm{SIG}(p)] \equiv^* p$.
- **(I5)** $E \subseteq {\equiv^*}$.

**Initialization.** Line L1 makes each node its own class, so (I1) holds and $\equiv$ is the identity, which is in $\mathrm{CC}(E)$. Line L2 puts $E$ on pending, so (I5) holds and the pairs on pending are in $\mathrm{CC}(E)$. In lines L3 to L6 no representative changes. Line L4 gives (I3) for $p$. If $\mathrm{SIG}(p)$ is already a key, its node $q$ has the same symbol and the same argument classes as $p$; the arguments are pairwise $\equiv$, so pairwise in $\mathrm{CC}(E)$ by (I2), so $(p, q) \in \mathrm{CC}(E)$ by congruence, and line L5 puts it on pending, which keeps (I2) and gives $q \equiv^* p$. Otherwise line L6 stores $p$ itself. Later steps of lines L3 to L6 never remove or overwrite a key and only add pairs to pending, so (I4) holds for all $p$ after line L6.

**Maintenance.** Take one pass, which removes the pair $(a, b)$. The pair was in $\equiv^*$, and either $a \equiv b$ already (line L9) or the merge makes $a \equiv b$, so removing it does not shrink $\equiv^*$. In the case of line L9 nothing else changes. Otherwise:

- Lines L12 and L13 move all members of $ra$ to $rb$ and relabel them, so (I1) holds. The new $\equiv$ is generated by the old $\equiv$ and the pair $(a, b)$, which is in $\mathrm{CC}(E)$ by (I2), so ${\equiv} \subseteq \mathrm{CC}(E)$ still holds.
- Only the representatives of the old class $ra$ change, so only an application $p$ with an argument in that class can change its signature. By (I3) before the pass, each such $p$ is in $\mathit{uses}[ra]$, and line L14 visits it after the relabelling. If the new $\mathrm{SIG}(p)$ is not a key, line L15 stores $p$. If it is a key with node $q$, then $q$ has the same symbol and argument classes, so as in the initialization $(p, q) \in \mathrm{CC}(E)$, and either $q \equiv p$ already or line L16 puts $(p, q)$ on pending. In each case (I2) holds and $\mathit{table}[\mathrm{SIG}(p)] \equiv^* p$. For an application whose signature did not change, its key and entry are unchanged, and $\equiv^*$ only grew, so (I4) still holds for it.
- Line L17 appends the old $\mathit{uses}[ra]$ to $\mathit{uses}[rb]$. Each argument that was in class $ra$ is now in class $rb$, so (I3) holds.
- $\equiv^*$ never shrinks, so (I5) holds.

**Termination.** A pass that does not stop at line L9 lowers the number of classes by one, so there are at most $|T| - 1$ such passes. Each of them adds at most $|\mathit{uses}[ra]|$ pairs, a finite number. Each other pass removes one pair and adds none. So pending is empty after a finite number of passes, and the loop stops.

**The result.** When the loop stops, pending is empty, so ${\equiv^*} = {\equiv}$. By (I5), $E \subseteq {\equiv}$. Let $p = f(s_1, \ldots, s_k)$ and $q = f(t_1, \ldots, t_k)$ be applications with $s_i \equiv t_i$ for all $i$. Then $\mathrm{SIG}(p) = \mathrm{SIG}(q)$, and by (I4) the one table entry $r$ for this key has $r \equiv p$ and $r \equiv q$, so $p \equiv q$. So $\equiv$ is a congruence on $T$ that contains $E$, and therefore ${\mathrm{CC}(E)} \subseteq {\equiv}$. With (I2) this gives ${\equiv} = \mathrm{CC}(E)$. By Theorem 1, the test of line L18 decides the conjunction $E \wedge D$. $\blacksquare$

## Part 3. Explanations are correct

Each merge of $a$ into $b$ first reverses the path from $a$ to its proof tree root, then adds the edge $a \to b$. The edge carries the label of the input equation $a = b$, or "congruence of $p$ and $q$" when $\{a, b\} = \{p, q\}$ came from line L5 or L16.

**Lemma 3.** At each time, the proof trees have the same node sets as the classes. A path reversal keeps the set of undirected edges and their labels.

*Proof.* At the start each node is a tree and a class. A merge joins the classes of $a$ and $b$, and the new edge joins their two trees, because the reversal makes $a$ a root and so the edge creates no cycle. The reversal changes only the direction of the edges on one path, and it moves each label with its edge. $\square$

**Theorem 2.** If $s \equiv t$, EXPLAIN$(s, t)$ stops and returns a set $L$ of input labels such that the equations with labels in $L$ entail $s = t$.

*Proof.* For an edge $e$ between $x$ and $y$, define the set of labels $L(e)$: the label itself for an input edge, and the union of $L(e')$ over the edges $e'$ on the tree paths between $p_i$ and $q_i$ for all $i$, for a congruence edge of $p = f(p_1, \ldots, p_k)$ and $q = f(q_1, \ldots, q_k)$. We show by induction on the creation time of $e$ that $L(e)$ is well defined and entails $x = y$. For an input edge this is clear. For a congruence edge created at time $\tau$, each pair $p_i, q_i$ was in one class at time $\tau$, so by Lemma 3 in one tree, joined by a unique tree path whose edges were all created before $\tau$. Later merges add edges only between different trees, and reversals keep the undirected edges, so this path stays the unique path between $p_i$ and $q_i$. By the induction hypothesis the edges on it give $p_i = q_i$, and congruence gives $p = q$.

EXPLAIN marks each edge when it expands it, and it puts on its work list the pairs that $L(e)$ uses. It expands each edge at most once, so it stops. Each skipped edge was expanded earlier in the same call, so at the end the output is the union of $L(e)$ over the edges on the tree path between $s$ and $t$ (found by the nearest common ancestor). These edges chain $s$ to $t$, so the output entails $s = t$. $\blacksquare$

The output need not be minimal. The page gives an input where one of the returned labels is redundant.
