*Probabilistic computation tree logic* (PCTL) is a temporal logic for systems that make random choices. It keeps the state formulas of [CTL](/computation-tree-logic/). It replaces the path quantifiers "for all paths" and "for some path" with one operator $\mathcal{P}_{\bowtie p}(\varphi)$. This operator says that the probability of the paths that satisfy $\varphi$ is in the range $\bowtie p$, for example at least $0.99$. It also adds a step-bounded until, $\Phi \,\mathcal{U}^{\le k}\, \Psi$, so that properties such as "with probability at least $0.99$ a reply comes within 5 steps" can be written. Hansson and Jonsson introduced PCTL in 1994 for discrete-time [Markov chains](/markov-chain/). Model checking it is polynomial in the size of the chain and linear in the size of the formula. That algorithm, which is graph search followed by linear equations, is on the page [PCTL model checking](/pctl-model-checking/). Estimating the same probabilities by simulation is [statistical model checking](/statistical-model-checking/).

## Definition

### Markov chains and the path measure

A (labelled, discrete-time) *Markov chain* is $M = (S, \mathbf{P}, L)$:

- $S$ is a finite set of states;
- $\mathbf{P} : S \times S \to [0, 1]$ is the transition matrix, with $\sum_{t} \mathbf{P}(s, t) = 1$ for each $s$;
- $L : S \to 2^{AP}$ labels each state with atomic propositions.

A *path* is an infinite sequence $s_0 s_1 s_2 \ldots$ with $\mathbf{P}(s_i, s_{i+1}) > 0$ for all $i$. For a start state $s$, the *cylinder set* of a finite prefix $s_0 \ldots s_k$ with $s_0 = s$ is the set of paths that begin with it. Its probability is $\prod_{i < k} \mathbf{P}(s_i, s_{i+1})$. This extends uniquely to a probability measure $\Pr_s$ on the $\sigma$-algebra generated by the cylinder sets. Every path formula below defines a measurable set of paths, so its probability is well defined.

### Syntax

Fix atomic propositions $AP$, comparisons $\bowtie \, \in \{<, \le, \ge, >\}$, rational $p \in [0, 1]$ and $k \in \mathbb{N}$. *State formulas* $\Phi$ and *path formulas* $\varphi$ are given by

$$\Phi ::= \mathrm{true} \mid a \mid \Phi \wedge \Phi \mid \neg \Phi \mid \mathcal{P}_{\bowtie p}(\varphi), \qquad \varphi ::= \mathcal{X}\, \Phi \mid \Phi \,\mathcal{U}\, \Phi \mid \Phi \,\mathcal{U}^{\le k}\, \Phi,$$

with $a \in AP$. As in CTL, every temporal operator is directly under a probability operator. A path formula cannot be negated, and two path formulas cannot be combined with $\wedge$.

### Semantics

For a state $s$ of $M$:

- $s \models \mathrm{true}$ always, and $s \models a$ when $a \in L(s)$;
- $\wedge$ and $\neg$ have their usual meaning;
- $s \models \mathcal{P}_{\bowtie p}(\varphi)$ when $\Pr_s\{\pi : \pi \models \varphi\} \bowtie p$.

For a path $\pi = s_0 s_1 \ldots$:

- $\pi \models \mathcal{X}\, \Phi$ when $s_1 \models \Phi$;
- $\pi \models \Phi \,\mathcal{U}\, \Psi$ when some $j \ge 0$ has $s_j \models \Psi$ and $s_i \models \Phi$ for all $i < j$;
- $\pi \models \Phi \,\mathcal{U}^{\le k}\, \Psi$ when the same holds with $j \le k$.

### Derived operators

- *Eventually:* $\mathcal{F}\, \Phi = \mathrm{true} \,\mathcal{U}\, \Phi$, and $\mathcal{F}^{\le k} \Phi = \mathrm{true} \,\mathcal{U}^{\le k}\, \Phi$.
- *Always:* $\mathcal{G}$ is not in the syntax, but $\mathcal{P}_{\ge p}(\mathcal{G}\, \Phi)$ means $\mathcal{P}_{\le 1-p}(\mathcal{F}\, \neg\Phi)$, and similarly for the other comparisons. This uses the fact that $\Pr(\mathcal{G}\,\Phi) = 1 - \Pr(\mathcal{F}\,\neg\Phi)$.
- *Qualitative* formulas use only $\mathcal{P}_{=1}$ ("almost surely") and $\mathcal{P}_{>0}$ ("possibly"). Here $\mathcal{P}_{=1}$ stands for $\mathcal{P}_{\ge 1}$ and $\mathcal{P}_{=0}$ for $\mathcal{P}_{\le 0}$. An exact value $\mathcal{P}_{=p}$ is $\mathcal{P}_{\ge p} \wedge \mathcal{P}_{\le p}$.

## Examples and non-examples

**The Knuth-Yao die.** Each flip of a fair coin moves a walk down a small binary tree of states, so that the walk ends in one of six faces $d_1, \ldots, d_6$ with equal probability. Two coin states lead back to earlier coin states. The formula $\mathcal{P}_{\ge 1/6}(\mathcal{F}\, d_6) \wedge \mathcal{P}_{\le 1/6}(\mathcal{F}\, d_6)$ holds in the initial state. So does $\mathcal{P}_{=1}(\mathcal{F}\, \mathit{done})$, although an infinite path that flips forever exists. The bounded formula $\mathcal{P}_{\ge 3/4}(\mathcal{F}^{\le 3}\, \mathit{done})$ also holds, because three flips end the walk with probability $3/4$. The page [PCTL model checking](/pctl-model-checking/) computes these numbers.

**Nested probabilities.** The formula

$$\mathcal{P}_{=1}\big(\mathcal{G}\, (\neg \mathit{req} \vee \mathcal{P}_{\ge 0.99}(\mathcal{F}^{\le 5}\, \mathit{ack}))\big)$$

says: almost surely, every state with a request has probability at least $0.99$ of an acknowledgement within 5 steps. The inner formula is a state formula, so it is checked first, as in CTL.

**Almost sure is not "on all paths".** Take a state $s$ with a self loop of probability $1/2$ and an edge of probability $1/2$ to a state $t$ labelled $a$. Then $s \models \mathcal{P}_{=1}(\mathcal{F}\, a)$, because the probability of staying in $s$ for $k$ steps is $2^{-k}$. But the CTL formula $\mathsf{AF}\, a$ fails at $s$, because the path $s s s \ldots$ never reaches $a$. So PCTL with $\mathcal{P}_{=1}$ is not CTL with $\mathsf{A}$, and $\mathsf{AF}\, a$ cannot be expressed in PCTL. CTL cannot express $\mathcal{P}_{\ge 1/2}$. The two logics are incomparable. With [fairness](/fairness/) assumptions, $\mathsf{A}$ and $\mathcal{P}_{=1}$ agree on many formulas.

**Not PCTL.**

- $\mathcal{P}_{\ge 0.9}(\mathcal{F}\, a \wedge \mathcal{G}\, b)$ combines two path formulas, so it is not in the syntax. It is a formula of PCTL*, which allows any [LTL](/linear-temporal-logic/) formula under $\mathcal{P}$.
- "The long-run fraction of time in state $a$ is at least $0.2$" is a steady-state property. The logic CSL for continuous-time chains has an operator for it, but PCTL does not.
- "The expected number of steps until $\mathit{done}$ is at most 4" is a reward property. It needs a reward extension of PCTL.
- $\mathcal{P}_{\ge 0.5}(\neg\, \mathcal{X}\, a)$ negates a path formula. It must be written $\mathcal{P}_{\ge 0.5}(\mathcal{X}\, \neg a)$.

## Related definitions

- **[CTL](/computation-tree-logic/).** The same state and path structure, with $\mathsf{A}$ and $\mathsf{E}$ in place of $\mathcal{P}_{\bowtie p}$. Its model checking by fixed points, on the page [CTL model checking](/ctl-model-checking/), is the template for PCTL model checking.
- **PCTL\*.** Allows any LTL formula under $\mathcal{P}$, as [CTL*](/ctl-star/) does for CTL. Its model checking uses automata for the LTL part.
- **PCTL over [Markov decision processes](/markov-decision-process/).** When the model also has nondeterministic choices, $\mathcal{P}_{\bowtie p}$ quantifies over all schedulers. A lower bound must hold for the minimal probability, and an upper bound for the maximal one (Bianco and de Alfaro 1995).
- **CSL.** Continuous stochastic logic, for continuous-time Markov chains. It has time intervals on until, and a steady-state operator.
- **Probabilistic [bisimulation](/bisimulation/).** Larsen and Skou's equivalence lumps states with the same labels and the same probability of moving into each class. On finite Markov chains, two states satisfy the same PCTL formulas exactly when they are probabilistically bisimilar.
- **Reward operators.** $\mathcal{R}_{\bowtie r}(\mathcal{F}\, \Phi)$ bounds the expected reward accumulated until $\Phi$ holds. Tools such as PRISM and Storm support it.
