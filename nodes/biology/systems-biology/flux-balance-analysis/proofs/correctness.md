---
title: FBA by the exact two-phase simplex method returns the status and an optimum of the flux LP
proves: [correctness]
status: full
---

Fix the data of the page: an $n \times m$ matrix $S$, bounds $lb_j \in \mathbb{Q} \cup \{-\infty\}$ and $ub_j \in \mathbb{Q} \cup \{+\infty\}$, and $c \in \mathbb{Q}^m$. Write $P = \{v \in \mathbb{R}^m : S v = 0, \; lb \le v \le ub\}$ for the flux polyhedron and (FBA) for the problem $\max \{c^{\mathsf T} v : v \in P\}$. We show that the code returns "infeasible" if $P$ is empty, "unbounded" if $c^{\mathsf T} v$ has no upper bound on $P$, and otherwise a vector $v^* \in P$ with $c^{\mathsf T} v^* = \max_P c^{\mathsf T} v$. All arithmetic is exact in $\mathbb{Q}$, so no rounding enters the argument.

**Lemma 1 (the change of variables).** Let lines L1 to L4 build $A$, $b$, $d$ and the affine map $y \mapsto v(y)$ of line L7, and let $Q = \{y \ge 0 : A y = b\}$. If some $lb_j > ub_j$, then $P$ is empty. Otherwise $v(Q) = P$, and $d^{\mathsf T} y = -c^{\mathsf T} v(y) + \kappa$ for all $y$, with a constant $\kappa$ that the code does not need.

*Proof.* If $lb_j > ub_j$, no $v_j$ satisfies $lb_j \le v_j \le ub_j$, and the code returns "infeasible" before line L2. Otherwise, line L1 writes $v_j$ as $lb_j + y_k$ when $lb_j$ is finite, as $ub_j - y_k$ when only $ub_j$ is finite, and as $y_k - y_{k+1}$ when both bounds are infinite. In the first case $y_k \ge 0$ is the same as $v_j \ge lb_j$, and line L3 adds the row $y_k + s = ub_j - lb_j$ with $s \ge 0$ when $ub_j$ is finite, which is the same as $v_j \le ub_j$. In the second case $y_k \ge 0$ is the same as $v_j \le ub_j$. In the third case every real $v_j$ is $y_k - y_{k+1}$ for some $y_k, y_{k+1} \ge 0$, for example $y_k = \max(v_j, 0)$ and $y_{k+1} = \max(-v_j, 0)$. So for every $y \ge 0$ with the bound rows satisfied, $v(y)$ obeys the bounds, and every $v$ that obeys the bounds is $v(y)$ for such a $y$. Line L2 writes the row $\sum_j S_{ij} v_j = 0$ as $\sum_j S_{ij} (off_j + \sum_k \sigma_{jk} y_k) = 0$, that is, $\sum_k (\sum_j S_{ij} \sigma_{jk}) y_k = -\sum_j S_{ij} off_j$, which is row $i$ of $A y = b$. So $y \in Q$ if and only if $v(y) \in P$, and $v(Q) = P$. Line L4 sets $d_k = -\sum_j c_j \sigma_{jk}$, so $d^{\mathsf T} y = -c^{\mathsf T} (v(y) - off)$, and $\kappa = c^{\mathsf T} off$. $\square$

By Lemma 1, $Q$ is empty if and only if $P$ is empty, $d^{\mathsf T} y$ has no lower bound on $Q$ if and only if $c^{\mathsf T} v$ has no upper bound on $P$, and $y^*$ minimizes $d^{\mathsf T} y$ on $Q$ if and only if $v(y^*)$ maximizes $c^{\mathsf T} v$ on $P$: for any $v \in P$ pick $y \in Q$ with $v(y) = v$, then $c^{\mathsf T} v = \kappa - d^{\mathsf T} y \le \kappa - d^{\mathsf T} y^* = c^{\mathsf T} v(y^*)$. It remains to show that line L5 solves $\min \{d^{\mathsf T} y : A y = b, \; y \ge 0\}$.

**Lemma 2 (Bland's rule terminates).** Let a simplex tableau be in canonical form for a feasible basis, and let each pivot choose the entering column as the smallest index with a negative reduced cost and the leaving row by the minimum ratio test, ties broken by the smallest index of the basic variable. Then after finitely many pivots the method stops, either with all reduced costs non-negative or with an entering column that has no positive entry.

*Proof.* This is Bland's theorem (Bland 1977). We give the standard argument. There are finitely many bases, and each pivot keeps the basis feasible because of the ratio test, and does not increase the objective. A non-degenerate pivot decreases it strictly, so a basis seen once can come back only within a run of degenerate pivots, where the objective and the vertex stay fixed. Assume such a cycle exists. Call a variable fickle if it enters or leaves the basis during the cycle, and let $t$ be the largest fickle index. Take a tableau $T_1$ of the cycle where $x_t$ leaves, with entering variable $x_s$, $s < t$, and a tableau $T_2$ of the cycle where $x_t$ enters. In $T_2$ the reduced costs $\bar d_j$ satisfy $\bar d_t < 0$ and $\bar d_j \ge 0$ for $j < t$, since $x_t$ is the smallest index with a negative reduced cost. Consider the direction $w$ of $T_1$ that increases $x_s$ by 1, keeps the other non-basic variables at 0, and changes the basic variables so that $A w = 0$. Then $d^{\mathsf T} w = \bar d^{(1)}_s < 0$. The reduced costs of $T_2$ differ from $d$ by a row combination of $A$, so $\bar d^{(2)\mathsf T} w = d^{\mathsf T} w < 0$. So some index $r$ has $\bar d^{(2)}_r w_r < 0$. Then $r$ is not basic in $T_2$ (basic reduced costs are 0), and $w_r \ne 0$, so $r = s$ or $r$ is basic in $T_1$. If $r = s$, then $w_s = 1$ and $\bar d^{(2)}_s < 0$. If $r$ is basic in $T_1$ and non-basic in $T_2$, then $r$ is fickle. So in both cases $r$ is fickle and $r \le t$. For $r = t$: $\bar d^{(2)}_t < 0$ and $w_t < 0$, since $x_t$ leaves in $T_1$, which needs a positive pivot entry, and $w_t$ is minus that entry; then $\bar d^{(2)}_t w_t > 0$, a contradiction. So $r < t$, and $\bar d^{(2)}_r \ge 0$ forces $\bar d^{(2)}_r > 0$ and $w_r < 0$. As $w_s = 1 > 0$, $r \ne s$, so $r$ is basic in $T_1$. A fickle basic variable of a degenerate cycle has the value 0 in every tableau of the cycle, so $x_r = 0$ in $T_1$, and $w_r < 0$ means that row $r$ of $T_1$ has a positive entry in column $s$ with ratio 0, the same ratio as the row of $x_t$. The tie rule then picks the smaller index $r < t$ to leave, not $t$. This contradicts the choice of $T_1$. So no cycle exists, and the method stops after finitely many pivots. $\square$

**Lemma 3 (the stopping conditions).** If the method of Lemma 2 stops with all reduced costs non-negative, the basic solution is optimal. If it stops at an entering column $j$ with no positive entry, the objective has no lower bound on the feasible set.

*Proof.* Let $y$ be the basic solution and $\bar d = d - A^{\mathsf T} \pi$ the reduced costs, with $\pi$ the simplex multipliers. For every feasible $y'$, $d^{\mathsf T} y' = \pi^{\mathsf T} A y' + \bar d^{\mathsf T} y' = \pi^{\mathsf T} b + \bar d^{\mathsf T} y' \ge \pi^{\mathsf T} b = d^{\mathsf T} y$, since $\bar d \ge 0$, $y' \ge 0$, and $\bar d$ is 0 on the basic columns. This is weak duality with the dual solution $\pi$. In the second case, increasing $y_j$ by $\theta \ge 0$ and moving the basic variables along the column keeps $A y = b$, and every basic variable changes by $-\theta$ times a non-positive entry, so it stays non-negative. The objective changes by $\theta \bar d_j \to -\infty$. $\square$

**Lemma 4 (phase 1).** Line L5 first flips the rows with $b_i < 0$, then minimizes $\mathbf{1}^{\mathsf T} a$ over $A y + a = b$, $y, a \ge 0$, from the feasible basis $a = b$. The phase 1 optimum is 0 if and only if $Q$ is non-empty. After the cleanup, the code has a feasible basis of $Q$ in canonical form, for the matrix $A$ without some redundant rows, and these rows have the same solution set as $A y = b$.

*Proof.* Flipping a row multiplies an equation by $-1$, which keeps the solution set. The phase 1 LP is feasible and bounded below by 0, so by Lemmas 2 and 3 its simplex run ends at an optimum. If $Q$ contains some $y$, then $(y, 0)$ is phase 1 feasible with value 0, so the optimum is 0. If the optimum is 0, the basic solution has $a = 0$ and so $y \in Q$. Then the code returns "infeasible" exactly when $Q$ is empty. In the case of value 0, every artificial variable that is still basic has the value 0. If its row has a non-zero entry in some column $j$ of $y$, a pivot on that entry makes $y_j$ basic. The right side of the row is 0, so the pivot changes no value and the basis stays feasible. If the row has only zeros in the $y$ columns, then this row of the current tableau, which is a combination of the original rows, says $0 = 0$ on the $y$ variables. So the original row is a combination of the other rows, and deleting it keeps the solution set. After this, all basic variables are $y$ variables, and the code drops the artificial columns. $\square$

**Theorem.** For every input, the code returns "infeasible" if and only if $P$ is empty, "unbounded" if and only if $c^{\mathsf T} v$ has no upper bound on $P$, and otherwise $(v^*, z^*)$ with $v^* \in P$ and $z^* = c^{\mathsf T} v^* = \max_P c^{\mathsf T} v$.

*Proof.* If some $lb_j > ub_j$, Lemma 1 gives the answer. Otherwise, by Lemma 4 phase 1 decides whether $Q$ is empty, and by Lemma 1 this decides whether $P$ is empty. If $Q$ is not empty, phase 2 starts from a feasible basis, and with the row of reduced costs set from $d$ in the code, it stops after finitely many pivots by Lemma 2. By Lemma 3 it returns either "unbounded", with no lower bound for $d^{\mathsf T} y$ on $Q$, or an optimal $y^*$. In the empty-row case, $Q = \{y \ge 0\}$ and $y = 0$ is optimal exactly when $d \ge 0$; otherwise one coordinate with $d_k < 0$ can grow without bound, and the code returns these two answers. By the remark after Lemma 1, the answers carry over to (FBA), and line L7 maps $y^*$ to $v^* = v(y^*) \in P$, which is optimal. Line L8 computes $z^* = c^{\mathsf T} v^*$ from $v^*$ itself, so it does not need the constant $\kappa$. $\square$

**Remark (uniqueness).** The theorem says that $z^*$ is the optimum and $v^*$ is one optimal vector. The set of optimal vectors is the face $P \cap \{c^{\mathsf T} v = z^*\}$, which can contain more than one point, as in the example of the page. The code returns the vertex of $Q$ that Bland's rule reaches first, so a different order of the reactions can return a different optimal vector with the same $z^*$.
