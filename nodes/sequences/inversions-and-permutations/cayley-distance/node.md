The Cayley distance between two [permutations](/permutation/) $\sigma$ and $\tau$ of $[n]$ is the least number of transpositions, exchanges of two items in any two positions, that turn $\sigma$ into $\tau$. It equals $n - c(\sigma^{-1}\tau)$, where $c$ counts [cycles](/permutation-cycles/), so it takes $\Theta(n)$ time to compute. It is a metric on the [symmetric group](/symmetric-group/), invariant under relabeling of items and of positions, and it is never more than the [Kendall tau distance](/kendall-tau-distance/), which allows only exchanges of neighbors. The name refers to Arthur Cayley, who observed the cycle formula in the nineteenth century.

## Definition

**Distance to the identity.** For $\pi \in S_n$, let $T(\pi)$ be the least $k$ such that $\pi$ is a product of $k$ transpositions, $\pi = t_1 t_2 \cdots t_k$, with $T(\iota) = 0$ for the identity $\iota$. Equivalently, $T(\pi)$ is the least number of exchanges of two entries that sort the array $\pi(1), \ldots, \pi(n)$.

**Distance between two permutations.** $d_C(\sigma, \tau) = T(\sigma^{-1}\tau)$. If $\tau = \sigma t_1 \cdots t_k$, then each $t_i$ exchanges two positions of the array $\sigma$, so $d_C(\sigma, \tau)$ is the least number of exchanges that turn the arrangement $\sigma$ into $\tau$. For two arrangements of the same $n$ distinct items, label the items by their positions in one arrangement and apply the same definition.

**Theorem.** $T(\pi) = n - c(\pi)$, where $c(\pi)$ is the number of cycles of $\pi$, fixed points included. So
$$d_C(\sigma, \tau) = n - c(\sigma^{-1}\tau).$$

*Proof.* Let $t = (i\ j)$ be a transposition. If $i$ and $j$ lie in the same cycle $(i\ a_1 \cdots a_p\ j\ b_1 \cdots b_q)$ of $\pi$, then $\pi t$ maps $i \mapsto \pi(j) = b_1$ (or $i$ if $q = 0$) and $j \mapsto \pi(i) = a_1$ (or $j$ if $p = 0$), and agrees with $\pi$ elsewhere, so this cycle splits into $(i\ b_1 \cdots b_q)$ and $(j\ a_1 \cdots a_p)$. If $i$ and $j$ lie in different cycles, the same computation read backwards shows that the two cycles merge into one. So multiplying by a transposition changes the number of cycles by exactly 1. The identity has $n$ cycles, so at least $n - c(\pi)$ transpositions are needed to reach it from $\pi$. And $n - c(\pi)$ suffice, because as long as some cycle has two items $i$ and $\pi(i)$, the transposition $(i\ \pi(i))$ splits it. $\square$

**Metric properties.** $d_C$ is a metric: it is 0 only for $\sigma = \tau$, it is symmetric because $c(\pi^{-1}) = c(\pi)$, and it satisfies the triangle inequality because it is a shortest-path distance in the Cayley graph of $S_n$ generated by the transpositions. It is invariant on both sides: $d_C(\rho\sigma, \rho\tau) = d_C(\sigma, \tau)$ and $d_C(\sigma\rho, \tau\rho) = d_C(\sigma, \tau)$, because $\rho^{-1}\sigma^{-1}\tau\rho$ is conjugate to $\sigma^{-1}\tau$ and has the same cycle type. So it does not matter whether the exchanges act on positions or on values.

**Range and distribution.** $0 \le d_C \le n - 1$, with $n - 1$ exactly when $\sigma^{-1}\tau$ is an $n$-cycle. The number of permutations at distance $k$ from a fixed one is the [Stirling number of the first kind](/stirling-numbers-first-kind/) ${n \brack n - k}$. For a uniform random $\pi$ the mean of $T(\pi)$ is $n - H_n$, with $H_n = 1 + \frac12 + \cdots + \frac1n$, because the mean number of cycles is $H_n$.

**Computing it.** Find the cycles of $\sigma^{-1}\tau$ with a visited mark, or equivalently follow $i \to \sigma^{-1}(\tau(i))$ from each unvisited $i$, in $\Theta(n)$ time and $n$ extra bits.

## Examples and non-examples

**To the identity.** $\pi = 3\,1\,4\,5\,2$ is a single 5-cycle, so $T(\pi) = 5 - 1 = 4$. Four exchanges, each putting one item in its place by following the cycle from position 1: $3\,1\,4\,5\,2 \to 4\,1\,3\,5\,2 \to 5\,1\,3\,4\,2 \to 2\,1\,3\,4\,5 \to 1\,2\,3\,4\,5$.

**Two cycles.** $\sigma = 2\,4\,1\,3\,6\,5 = (1\ 2\ 4\ 3)(5\ 6)$ has $c = 2$, so $T(\sigma) = 4$: three exchanges for the 4-cycle and one for the 2-cycle.

**Between two permutations.** For $\sigma = 3\,1\,4\,5\,2$ and $\tau = 2\,5\,1\,3\,4$, $\sigma^{-1}\tau = 5\,4\,2\,1\,3$, which is the single cycle $(1\ 5\ 3\ 2\ 4)$. So $d_C(\sigma, \tau) = 4$.

**Distribution for $n = 5$.** Of the 120 permutations, $1, 10, 35, 50, 24$ are at Cayley distance $0, 1, 2, 3, 4$ from the identity, which are ${5 \brack 5}, \ldots, {5 \brack 1}$. For $n = 4$ the counts are $1, 6, 11, 6$.

**Non-example: adjacent exchanges.** The reversal $3\,2\,1$ has Cayley distance 1, by one exchange of the first and last items, but Kendall tau distance 3, since exchanges of neighbors need 3 steps. In general $d_C \le d_K$, because every adjacent exchange is an exchange.

**Non-example: repeated items.** For sequences with repeated items, such as $(1, 2, 1, 2)$ and $(2, 1, 2, 1)$, there is no single permutation between them, and the formula needs a choice of which copy goes where. The least number of exchanges is $n$ minus the largest number of cycles over all such choices: here 2, by exchanging positions 1 and 2 and positions 3 and 4.

## Related definitions

- **[Kendall tau distance](/kendall-tau-distance/).** The least number of adjacent exchanges, equal to $\operatorname{inv}(\sigma^{-1}\tau)$. It is at least $d_C$ and at most $\binom n2$.
- **[Spearman's footrule](/spearman-footrule/).** $\sum_i |\sigma(i) - \tau(i)|$, the total displacement.
- **[Ulam distance](/ulam-distance/).** $n$ minus the length of a longest common subsequence, the least number of moves of one item to another place.
- **[Hamming distance](/hamming-distance/).** The number $h$ of positions where $\sigma$ and $\tau$ differ. Each cycle of $\sigma^{-1}\tau$ that is not a fixed point has at least 2 items, so $h/2 \le d_C \le h - 1$ when $h > 0$.
- **[Parity](/permutation-parity/).** $d_C(\sigma, \tau) \equiv \operatorname{inv}(\sigma^{-1}\tau) \pmod 2$, the parity of $\sigma^{-1}\tau$.
- **[Cycle sort](/cycle-sort/).** It sorts an array with distinct keys using $n - c$ exchanges, the Cayley distance to the sorted order, and so with the fewest writes. [Selection sort](/selection-sort/) that skips the exchange when the minimum is already in place makes exactly $n - c$ exchanges too, because the item it moves into position $i$ is in the same cycle as $i$, so each exchange splits a cycle.
